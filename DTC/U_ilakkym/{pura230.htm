{PUṞAM 230}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 230-1} kaṉṟu amar āyam kāṉattu alka um
  • {PU 230-2} ve kāl vampalar vēṇṭu pulattu uṟaiya um
  • {PU 230-3} kaḷam mali kuppai kāppu ila vaika um
  • {PU 230-4} vilaṅku pakai kaṭinta kalaṅkā ce kōl
  • {PU 230-5} vaiyakam pukaḻnta vayaṅku viṉai oḷ vāḷ
  • {PU 230-6} poyyā eḻiṉi porutu kaḷam cēra
  • {PU 230-7} īṉṟōḷ nītta kuḻavi pōla
  • {PU 230-8} taṉ amar cuṟṟam talaittalai iṉaiya
  • {PU 230-9} kaṭum paci kalakkiya iṭumpai kūr neñcamoṭu
  • {PU 230-10} nōy uḻantu vaikiya ulakiṉum mika naṉi
  • {PU 230-11} nī iḻantaṉai ē aṟaṉ il kūṟṟam
  • {PU 230-12} vāḻtaliṉ varūum vayal vaḷaṉ aṟiyāṉ
  • {PU 230-13} vīḻ kuṭi uḻavaṉ vittu uṇṭāaṅku
  • {PU 230-14} oruvaṉ ār uyir uṇṇāy āyiṉ
  • {PU 230-15} nērār pal uyir paruki
  • {PU 230-16} ārkuvai maṉ ō avaṉ amar aṭu kaḷattu ē
