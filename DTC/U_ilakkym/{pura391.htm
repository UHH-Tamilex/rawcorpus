{PUṞAM 391}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 391-1} taṇ tuḷi pala poḻintu eḻili icaikkum
  • {PU 391-2} viṇṭu aṉaiya viṇ tōy piṟaṅkal
  • {PU 391-3} mukaṭuṟa uyarnta nelliṉ makiḻ vara
  • {PU 391-4} pakaṭu taru peru vaḷam vāḻtti peṟṟa
  • {PU 391-5} tiruntā mūri parantu paṭa keṇṭi
  • {PU 391-6} ariyal ārkaiyar uṇṭu iṉitu uvakkum
  • {PU 391-7} vēṅkaṭa varaippiṉ vaṭa pulam pacitteṉa
  • {PU 391-8} īṅku vantu iṟutta eṉ irum pēr okkal
  • {PU 391-9} tīrkai viṭukkum paṇpu ila mutu kuṭi
  • {PU 391-10} viṉavaliṉ
  • {PU 391-11} muṉ um vantōṉ maruṅku ilaṉ iṉṉum
  • {PU 391-12} aḷiyaṉ ākaliṉ porunaṉ ivaṉ eṉa
  • {PU 391-13} niṉ uṇarntu aṟiyunar eṉ uṇarntu kūṟa
  • {PU 391-14} kāṇku vanticiṉ peruma
  • {PU 391-15} perum kaḻi nuḻai mīṉ aruntum
  • {PU 391-16} tutainta tūvi am putāam cēkkum
  • {PU 391-17} tatainta puṉal niṉ ceḻu nakar varaippiṉ
  • {PU 391-18} neñcu amar kātal niṉ veyyōḷoṭu
  • {PU 391-19} iṉ cāl
  • {PU 391-20} tuḷi pataṉ aṟintu poḻiya
  • {PU 391-21} vēli āyiram viḷaika niṉ vayal ē
