{PUṞAM 33}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 33-1} kāṉ uṟai vāḻkkai kata nāy vēṭṭuvaṉ
  • {PU 33-2} māṉ tacai corinta vaṭṭi um āy makaḷ
  • {PU 33-3} tayir koṭu vanta tacumpu um niṟaiya
  • {PU 33-4} ēriṉ vāḻnar pēr il arivaiyar
  • {PU 33-5} kuḷam kīḻ viḷainta kaḷam koḷ veṇṇel
  • {PU 33-6} mukantaṉar koṭuppa ukantaṉar peyarum
  • {PU 33-7} teṉṉam poruppaṉ nal nāṭṭu uḷ um
  • {PU 33-8} ēḻ eyil katavam eṟintu kaikkoṇṭu niṉ
  • {PU 33-9} pēḻ vāy uḻuvai poṟikkum āṟṟalai
  • {PU 33-10} pāṭunar vañci pāṭa paṭaiyōr
  • {PU 33-11} tātu eru maṟukiṉ pācaṟai poliya
  • {PU 33-12} pularā paccu ilai iṭai iṭupu toṭutta
  • {PU 33-13} malarā mālai pantu kaṇṭaṉṉa
  • {PU 33-14} ūṉ cōṟṟu amalai pāṇ kaṭumpu aruttum
  • {PU 33-15} cemmaṟṟu amma niṉ ve muṉai irukkai
  • {PU 33-16} vallōṉ taiiya vari vaṉappu uṟṟa
  • {PU 33-17} alli pāvai āṭu vaṉappu ēyppa
  • {PU 33-18} kāma iruvar allatu yāmattu
  • {PU 33-19} taṉi makaṉ vaḻaṅkā paṉi malar kāviṉ
  • {PU 33-20} otukkiṉ tiṇi maṇal putu pūm paḷḷi
  • {PU 33-21} vāyil māṭam toṟum mai viṭai vīḻppa
  • {PU 33-22} nī āṅku koṇṭa viḻaviṉum pala ē
