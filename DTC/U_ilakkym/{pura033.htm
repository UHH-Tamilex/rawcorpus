{PUṞAM 33}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 33-1} kāṉ uṟi vāḻkki kata nāy vēṭṭuvaṉ
  • {PU 33-2} māṉ taci corinta vaṭṭi um āy makaḷ
  • {PU 33-3} tayir koṭu vanta tacumpu um niṟiya
  • {PU 33-4} ēriṉ vāḻnar pēr il ariviyar
  • {PU 33-5} kuḷam kīḻ viḷinta kaḷam koḷ veṇṇel
  • {PU 33-6} mukantaṉar koṭuppa ukantaṉar peyarum
  • {PU 33-7} teṉṉam poruppaṉ nal nāṭṭu uḷ um
  • {PU 33-8} ēḻ eyil katavam eṟintu kikkoṇṭu niṉ
  • {PU 33-9} pēḻ vāy uḻuvi poṟikkum āṟṟali
  • {PU 33-10} pāṭunar vañci pāṭa paṭiyōr
  • {PU 33-11} tātu eru maṟukiṉ pācaṟi poliya
  • {PU 33-12} pularā paccu ili iṭi iṭupu toṭutta
  • {PU 33-13} malarā māli pantu kaṇṭaṉṉa
  • {PU 33-14} ūṉ cōṟṟu amali pāṇ kaṭumpu aruttum
  • {PU 33-15} cemmaṟṟu amma niṉ ve muṉi irukki
  • {PU 33-16} vallōṉ tiiya vari vaṉappu uṟṟa
  • {PU 33-17} alli pāvi āṭu vaṉappu ēyppa
  • {PU 33-18} kāma iruvar allatu yāmattu
  • {PU 33-19} taṉi makaṉ vaḻaṅkā paṉi malar kāviṉ
  • {PU 33-20} otukkiṉ tiṇi maṇal putu pūm paḷḷi
  • {PU 33-21} vāyil māṭam toṟum mi viṭi vīḻppa
  • {PU 33-22} nī āṅku koṇṭa viḻaviṉum pala ē
