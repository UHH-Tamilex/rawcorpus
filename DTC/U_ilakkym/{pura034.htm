{PUṞAM 34}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 34-1} āṉ mulai aṟutta aṟaṉ ilōrkku um
  • {PU 34-2} māṇ iḻai makaḷir karu citai tōrkku um
  • {PU 34-3} pārppār tappiya koṭumaiyōrkku um
  • {PU 34-4} vaḻuvāy maruṅkil kaḻuvāy um uḷa eṉa
  • {PU 34-5} nilam puṭai peyarvatu āyiṉum oruvaṉ
  • {PU 34-6} ceyti koṉṟōrkku uyti il eṉa
  • {PU 34-7} aṟam pāṭiṉṟu ē āy iḻai kaṇava
  • {PU 34-8} kālai anti um mālai anti um
  • {PU 34-9} puṟavu karu aṉṉa puṉpulam varakiṉ
  • {PU 34-10} pāl pey puṉkam tēṉoṭu mayakki
  • {PU 34-11} kuṟu muyal koḻum cūṭu kiḻitta okkaloṭu
  • {PU 34-12} iratti nīṭiya akal talai maṉṟattu
  • {PU 34-13} karappu il uḷḷamoṭu vēṇṭu moḻi payiṟṟi
  • {PU 34-14} amalai koḻum cōṟu ārnta pāṇarkku
  • {PU 34-15} akalā celvam muḻuvatu um ceytōṉ
  • {PU 34-16} em kōṉ vaḷavaṉ vāḻka eṉṟu niṉ
  • {PU 34-17} pīṭu keḻu nōṉ tāḷ pāṭēṉ āyiṉ
  • {PU 34-18} paṭupu aṟiyalaṉ ē pal katir celvaṉ
  • {PU 34-19} yāṉ ō tañcam peruma i ulakattu
  • {PU 34-20} cāṉṟōr ceyta naṉṟu uṇṭu āyiṉ
  • {PU 34-21} imayattu īṇṭi iṉ kural payiṟṟi
  • {PU 34-22} koṇṭal mā maḻai poḻinta
  • {PU 34-23} nuṇ pal tuḷiyiṉum vāḻiya pala ē
