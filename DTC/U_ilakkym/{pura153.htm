{PUṞAM 153}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 153-1} maḻai aṇi kuṉṟattu kiḻavaṉ nāḷ um
  • {PU 153-2} iḻai aṇi yāṉai irappōrkku īyum
  • {PU 153-3} cuṭarviṭu pacum pūṇ cūrppu amai muṉkai
  • {PU 153-4} aṭu pōr āṉā ātaṉ ōri
  • {PU 153-5} māri vaṇ koṭai kāṇiya naṉṟu um
  • {PU 153-6} ceṉṟatu maṉ em kaṇṇuḷ am kaṭumpu ē
  • {PU 153-7} paṉi nīr pūvā maṇi miṭai kuvaḷai
  • {PU 153-8} vāl nār toṭutta kaṇṇi um kalaṉ um
  • {PU 153-9} yāṉai iṉattoṭu peṟṟaṉar nīṅki
  • {PU 153-10} paciyār ākal māṟu kol vici piṇi
  • {PU 153-11} kūṭu koḷ iṉ iyam kaṟaṅka
  • {PU 153-12} āṭal um ollār tam pāṭal um maṟantu ē
