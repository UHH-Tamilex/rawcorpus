{PUṞAM 69}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 69-1} kaiyatu kaṭaṉ niṟai yāḻ ē meyyatu
  • {PU 69-2} puravalar iṉmaiyiṉ paci ē araiyatu
  • {PU 69-3} vēṟṟu iḻai nuḻainta vēr naṉai citāar
  • {PU 69-4} ōmpi uṭutta uyaval pāṇa
  • {PU 69-5} pūṭkai illōṉ yākkai pōla
  • {PU 69-6} perum pulleṉṟa irum pēr okkalai
  • {PU 69-7} vaiyakam muḻutu uṭaṉ vaḷaii paiyeṉa
  • {PU 69-8} eṉṉai viṉavuti āyiṉ maṉṉar
  • {PU 69-9} aṭu kaḷiṟu uyavum koṭi koḷ pācaṟai
  • {PU 69-10} kuruti parappiṉ kōṭṭumā tolaicci
  • {PU 69-11} pulā kaḷam ceyta kalāa tāṉaiyaṉ
  • {PU 69-12} piṟaṅku nilai māṭattu uṟantaiyōṉ ē
  • {PU 69-13} porunarkku ōkkiya vēlaṉ oru nilai
  • {PU 69-14} pakai pulam paṭartal um uriyaṉ takai tār
  • {PU 69-15} oḷ eri puraiyum uru keḻu pacum pūṇ
  • {PU 69-16} kiḷḷi vaḷavaṉ paṭarkuvai āyiṉ
  • {PU 69-17} neṭum kaṭai niṟṟal um ilai ē kaṭum pakal
  • {PU 69-18} tēr vīcu irukkai āra nōkki
  • {PU 69-19} nī avaṉ kaṇṭa piṉṟai pūviṉ
  • {PU 69-20} āṭu vaṇṭu imirā tāmarai
  • {PU 69-21} cūṭāy ātal ataṉiṉum ilai ē
