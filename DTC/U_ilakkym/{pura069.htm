{PUṞAM 69}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 69-1} kiyatu kaṭaṉ niṟi yāḻ ē meyyatu
  • {PU 69-2} puravalar iṉmiyiṉ paci ē ariyatu
  • {PU 69-3} vēṟṟu iḻi nuḻinta vēr naṉi citāar
  • {PU 69-4} ōmpi uṭutta uyaval pāṇa
  • {PU 69-5} pūṭki illōṉ yākki pōla
  • {PU 69-6} perum pulleṉṟa irum pēr okkali
  • {PU 69-7} viyakam muḻutu uṭaṉ vaḷii piyeṉa
  • {PU 69-8} eṉṉi viṉavuti āyiṉ maṉṉar
  • {PU 69-9} aṭu kaḷiṟu uyavum koṭi koḷ pācaṟi
  • {PU 69-10} kuruti parappiṉ kōṭṭumā tolicci
  • {PU 69-11} pulā kaḷam ceyta kalāa tāṉiyaṉ
  • {PU 69-12} piṟaṅku nili māṭattu uṟantiyōṉ ē
  • {PU 69-13} porunarkku ōkkiya vēlaṉ oru nili
  • {PU 69-14} paki pulam paṭartal um uriyaṉ taki tār
  • {PU 69-15} oḷ eri puriyum uru keḻu pacum pūṇ
  • {PU 69-16} kiḷḷi vaḷavaṉ paṭarkuvi āyiṉ
  • {PU 69-17} neṭum kaṭi niṟṟal um ili ē kaṭum pakal
  • {PU 69-18} tēr vīcu irukki āra nōkki
  • {PU 69-19} nī avaṉ kaṇṭa piṉṟi pūviṉ
  • {PU 69-20} āṭu vaṇṭu imirā tāmari
  • {PU 69-21} cūṭāy ātal ataṉiṉum ili ē
