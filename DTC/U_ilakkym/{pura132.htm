{PUṞAM 132}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 132-1} muṉ uḷḷuvōṉi piṉ uḷḷiṉēṉ ē
  • {PU 132-2} āḻka eṉ uḷḷam pōḻka eṉ nā ē
  • {PU 132-3} pāḻ ūr kiṇaṟṟiṉ tūrka eṉ cevi ē
  • {PU 132-4} naranti naṟum pul mēynta kavari
  • {PU 132-5} kuvaḷi pim cuṉi paruki ayala
  • {PU 132-6} takara taṇ niḻal piṇiyoṭu vatiyum
  • {PU 132-7} vaṭa ticiyatu ē vāṉ tōy imayam
  • {PU 132-8} teṉ tici āay kuṭi iṉṟu āyiṉ
  • {PU 132-9} piṟaḻvatu maṉ ō i malar tali ulaku ē
