{PUṞAM 23}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 23-1} veḷiṟu il nōṉ kāḻ paṇai nilai muṉaii
  • {PU 23-2} kaḷiṟu paṭintu uṇṭeṉa kalaṅkiya tuṟai um
  • {PU 23-3} kār naṟum kaṭampiṉ pācu ilai teriyal
  • {PU 23-4} cūr navai murukaṉ cuṟṟattu aṉṉa niṉ
  • {PU 23-5} kūr nal ampiṉ koṭu vil kūḷiyar
  • {PU 23-6} koḷvatu koṇṭu koḷḷā miccil
  • {PU 23-7} koḷ patam oḻiya vīciya pulaṉ um
  • {PU 23-8} vaṭi navil naviyam pāytaliṉ ūr toṟum
  • {PU 23-9} kaṭi maram tuḷaṅkiya kā um neṭu nakar
  • {PU 23-10} viṉai puṉai nal il ve eri naippa
  • {PU 23-11} kaṉai eri uraṟiya maruṅku um nōkki
  • {PU 23-12} naṇṇār nāṇa nāḷ toṟum talai ceṉṟu
  • {PU 23-13} iṉṉum iṉṉa pala ceykuvaṉ yāvar um
  • {PU 23-14} tuṉṉal pōkiya tuṇiviṉōṉ eṉa
  • {PU 23-15} ñālam neḷiya īṇṭiya viyaṉ paṭai
  • {PU 23-16} ālaṅkāṉattu amar kaṭantu aṭṭa
  • {PU 23-17} kāla muṉpa niṉ kaṇṭaṉeṉ varuval
  • {PU 23-18} aṟu maruppu eḻil kalai puli pāl paṭṭeṉa
  • {PU 23-19} ciṟu maṟi taḻīiya teṟi naṭai maṭa piṇai
  • {PU 23-20} pūḷai nīṭiya veruvaru paṟantalai
  • {PU 23-21} vēḷai veḷ pū kaṟikkum
  • {PU 23-22} āḷ il attam ākiya kāṭu ē
