  • {PU 122-1} kaṭal koḷappaṭāatu uṭalunar ūkkār
  • {PU 122-2} kaḻal puṉai tiruntu aṭi kāri niṉ nāṭu ē
  • {PU 122-3} aḻal puṟantarūum antaṇaratu ē
  • {PU 122-4} vīyā tiruviṉ viṟal keḻu tāṉai
  • {PU 122-5} mūvar uḷ oruvaṉ tuppu ākiyar eṉa
  • {PU 122-6} ēttiṉar tarūum kūḻ ē num kuṭi
  • {PU 122-7} vāḻttiṉar varūum iravalaratu ē
  • {PU 122-8} vaṭamīṉ puraiyum kaṟpiṉ maṭam moḻi
  • {PU 122-9} arivai tōḷ aḷavu allatai
  • {PU 122-10} niṉatu eṉa ilai nī perumitattai ē
