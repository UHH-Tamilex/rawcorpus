{PUṞAM 324}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 324-1} verukku viṭai aṉṉa vekuḷ nōkku kayam talai
  • {PU 324-2} puḷ ūṉ tiṉṟa pulavu nāṟu kayam vāy
  • {PU 324-3} veḷ vāy vēṭṭuvar vīḻ tuṇai makāar
  • {PU 324-4} ciṟu ilai uṭaiyiṉ curai uṭai vāl muḷ
  • {PU 324-5} ūka nuṇ kōl ceṟitta ampiṉ
  • {PU 324-6} valāar val vil kulā vara kōli
  • {PU 324-7} parutti vēli karuppai pārkkum
  • {PU 324-8} puṉpulam taḻīiya am kuṭi cīṟūr
  • {PU 324-9} kumiḻ uṇ veḷḷai paku vāy peyartta
  • {PU 324-10} veḷ kāḻ tāya vaṇ kāl pantar
  • {PU 324-11} iṭaiyaṉ pottiya ciṟu tī viḷakkattu
  • {PU 324-12} pāṇaroṭu irunta nāṇ uṭai neṭuntakai
  • {PU 324-13} valam paṭu tāṉai vēntarkku
  • {PU 324-14} ulantuḻi ulakkum neñcu aṟi tuṇai ē
