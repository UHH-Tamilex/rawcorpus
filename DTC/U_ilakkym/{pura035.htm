{PUṞAM 35}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 35-1} naḷi iru munnīr ēṇi āka
  • {PU 35-2} vaḷi iṭi vaḻaṅkā vāṉam cūṭiya
  • {PU 35-3} maṇ tiṇi kiṭakki taṇ tamiḻ kiḻavar
  • {PU 35-4} muracu muḻaṅku tāṉi mūvar uḷ um
  • {PU 35-5} aracu eṉappaṭuvatu niṉatu ē peruma
  • {PU 35-6} alaṅku katir kaṉali nāl vayiṉ tōṉṟiṉum
  • {PU 35-7} ilaṅku katir veḷḷi teṉ pulam paṭariṉum
  • {PU 35-8} am taṇ kāviri vantu kavarpu ūṭṭa
  • {PU 35-9} tōṭu koḷ vēliṉ tōṟṟam pōla
  • {PU 35-10} āṭu kaṇ karumpiṉ veḷ pū nuṭaṅkum
  • {PU 35-11} nāṭu eṉappaṭuvatu niṉatu ē atti āṅka
  • {PU 35-12} nāṭu keḻu celvattu pīṭu keḻu vēntu ē
  • {PU 35-13} niṉava kūṟuval eṉava kēṇmati
  • {PU 35-14} aṟam purintaṉṉa ce kōl nāṭṭattu
  • {PU 35-15} muṟi vēṇṭu poḻutil pataṉ eḷiyōr īṇṭu
  • {PU 35-16} uṟi vēṇṭu poḻutil peyal peṟṟōr ē
  • {PU 35-17} ñāyiṟu cumanta kōṭu tiraḷ koṇmū
  • {PU 35-18} māka vicumpiṉ naṭuvu niṉṟāṅku
  • {PU 35-19} kaṇ pora viḷaṅku niṉ viṇ poru viyaṉ kuṭi
  • {PU 35-20} veyil maṟi koṇṭaṉṟu ō aṉṟu ē varuntiya
  • {PU 35-21} kuṭi maṟippatu ē kūr vēl vaḷava
  • {PU 35-22} veḷiṟṟu paṉam tuṇiyiṉ vīṟṟu vīṟṟu kiṭappa
  • {PU 35-23} kaḷiṟṟu kaṇam poruta kaṇ akal paṟantali
  • {PU 35-24} varu paṭi tāṅki peyar puṟattu ārttu
  • {PU 35-25} poru paṭi tarūum koṟṟam um uḻupaṭi
  • {PU 35-26} ūṉṟu cāl maruṅkiṉ īṉṟataṉ payaṉ ē
  • {PU 35-27} māri poyppiṉ um vāri kuṉṟiṉ um
  • {PU 35-28} iyaṟki allaṉa ceyaṟkiyil tōṉṟiṉum
  • {PU 35-29} kāvalar paḻikkum i kaṇ akal ñālam
  • {PU 35-30} atu naṟku aṟintaṉi āyiṉ nī um
  • {PU 35-31} notumalāḷar potumoḻi koḷḷātu
  • {PU 35-32} pakaṭu puṟantarunar pāram ōmpi
  • {PU 35-33} kuṭi puṟantarukuvi āyiṉ niṉ
  • {PU 35-34} aṭi puṟantarukuvar aṭaṅkātōr ē
