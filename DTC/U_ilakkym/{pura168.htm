{PUṞAM 168}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 168-1} aruvi ārkkum kaḻai payil naṉam talai
  • {PU 168-2} kaṟi vaḷar aṭukkattu malarnta kāntaḷ
  • {PU 168-3} koḻum kiḻaṅku miḷira kiṇṭi kiḷaiyoṭu
  • {PU 168-4} kaṭuṅkaṇ kēḻal uḻuta pūḻi
  • {PU 168-5} naṉṉāḷ varu patam nōkki kuṟavar
  • {PU 168-6} uḻāatu vittiya parūu kural ciṟu tiṉai
  • {PU 168-7} muntu viḷai yāṇar nāḷ putitu uṇmār
  • {PU 168-8} maraiyāṉ kaṟanta nurai koḷ tīm pāl
  • {PU 168-9} māṉ taṭi puḻukkiya pulavu nāṟu kuḻici
  • {PU 168-10} vāṉ kēḻ irum puṭai kaḻāatu ēṟṟi
  • {PU 168-11} cānta viṟakiṉ uvitta puṉkam
  • {PU 168-12} kūtaḷam kaviṉiya kuḷavi muṉṟil
  • {PU 168-13} ceḻum kōḷ vāḻai akal ilai pakukkum
  • {PU 168-14} ūrā kutirai kiḻava kūr vēl
  • {PU 168-15} naṟai nār toṭutta vēṅkai am kaṇṇi
  • {PU 168-16} vaṭi navil ampiṉ villōr peruma
  • {PU 168-17} kai vaḷ īkai kaṭu māṉ koṟṟa
  • {PU 168-18} vaiyaka varaippil tamiḻakam kēṭpa
  • {PU 168-19} poyyā ce nā neḷiya ētti
  • {PU 168-20} pāṭupa eṉpa paricilar nāḷ um
  • {PU 168-21} īyā maṉṉar nāṇa
  • {PU 168-22} vīyātu paranta niṉ vacai il vāṉ pukaḻ ē
