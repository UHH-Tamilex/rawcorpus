{PUṞAM 168}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 168-1} aruvi ārkkum kaḻi payil naṉam tali
  • {PU 168-2} kaṟi vaḷar aṭukkattu malarnta kāntaḷ
  • {PU 168-3} koḻum kiḻaṅku miḷira kiṇṭi kiḷiyoṭu
  • {PU 168-4} kaṭuṅkaṇ kēḻal uḻuta pūḻi
  • {PU 168-5} naṉṉāḷ varu patam nōkki kuṟavar
  • {PU 168-6} uḻāatu vittiya parūu kural ciṟu tiṉi
  • {PU 168-7} muntu viḷi yāṇar nāḷ putitu uṇmār
  • {PU 168-8} mariyāṉ kaṟanta nuri koḷ tīm pāl
  • {PU 168-9} māṉ taṭi puḻukkiya pulavu nāṟu kuḻici
  • {PU 168-10} vāṉ kēḻ irum puṭi kaḻāatu ēṟṟi
  • {PU 168-11} cānta viṟakiṉ uvitta puṉkam
  • {PU 168-12} kūtaḷam kaviṉiya kuḷavi muṉṟil
  • {PU 168-13} ceḻum kōḷ vāḻi akal ili pakukkum
  • {PU 168-14} ūrā kutiri kiḻava kūr vēl
  • {PU 168-15} naṟi nār toṭutta vēṅki am kaṇṇi
  • {PU 168-16} vaṭi navil ampiṉ villōr peruma
  • {PU 168-17} ki vaḷ īki kaṭu māṉ koṟṟa
  • {PU 168-18} viyaka varippil tamiḻakam kēṭpa
  • {PU 168-19} poyyā ce nā neḷiya ētti
  • {PU 168-20} pāṭupa eṉpa paricilar nāḷ um
  • {PU 168-21} īyā maṉṉar nāṇa
  • {PU 168-22} vīyātu paranta niṉ vaci il vāṉ pukaḻ ē
