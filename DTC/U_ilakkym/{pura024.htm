{PUṞAM 24}

((Last updated on 2004 April 14th))

  • {PU 24-1} nel ariyum irum toḻuvar
  • {PU 24-2} ce ñāyiṟṟu veyil muṉiyiṉ
  • {PU 24-3} teḷ kaṭal tiri mici pāyuntu
  • {PU 24-4} tiṇ timil vaṉ paratavar
  • {PU 24-5} veppu uṭiya maṭṭu uṇṭu
  • {PU 24-6} taṇ kuravi cīr tūṅkuntu
  • {PU 24-7} tūval kalitta tēm pāy puṉṉi
  • {PU 24-8} mel iṇar kaṇṇi milinta mintar
  • {PU 24-9} el vaḷi makaḷir tali ki tarūuntu
  • {PU 24-10} vaṇṭu paṭa malarnta taṇ naṟum kāṉal
  • {PU 24-11} muṇṭaka kōti oḷ toṭi makaḷir
  • {PU 24-12} irum paṉiyiṉ kurumpi nīr um
  • {PU 24-13} pūm karumpiṉ tīm cāṟu um
  • {PU 24-14} ōṅku maṇal kuvavu tāḻi
  • {PU 24-15} tīm nīroṭu uṭaṉ virāay
  • {PU 24-16} mu nīr uṇṭu mu nīr pāyum
  • {PU 24-17} tāṅkā uṟiyuḷ nal ūr keḻīiya
  • {PU 24-18} ōmpā īki mā vēḷ evvi
  • {PU 24-19} puṉal am putaviṉ miḻaliyoṭu kaḻaṉi
  • {PU 24-20} kayal ār nāri pōrvil cēkkum
  • {PU 24-21} poṉ aṇi yāṉi tol mutir vēḷir
  • {PU 24-22} kuppi nelliṉ muttūṟu tanta
  • {PU 24-23} koṟṟa nīḷ kuṭi koṭi tēr ceḻiya
  • {PU 24-24} niṉṟu niliiyar niṉ nāḷmīṉ nillātu
  • {PU 24-25} paṭāa celīiyar niṉ pakivar mīṉ ē
  • {PU 24-26} niṉṉoṭu toṉṟu mūtta uyiriṉum uyiroṭu
  • {PU 24-27} niṉṟu mūtta yākki aṉṉa niṉ
  • {PU 24-28} āṭu kuṭi mūtta viḻu tiṇi ciṟanta
  • {PU 24-29} vāḷiṉ vāḻnar tāḷ valam vāḻtta
  • {PU 24-30} iraval mākkaḷ īki nuvala
  • {PU 24-31} oḷ toṭi makaḷir polam kalattu ēntiya
  • {PU 24-32} taṇ kamaḻ tēṟal maṭuppa makiḻ ciṟantu
  • {PU 24-33} āṅku iṉitu oḻukumati peruma āṅku atu
  • {PU 24-34} vallunar vāḻntōr eṉpa tol ici
  • {PU 24-35} malar tali ulakattu tōṉṟi
  • {PU 24-36} palar cela cellātu niṉṟu viḷintōr ē
