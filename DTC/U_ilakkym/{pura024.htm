{PUṞAM 24}

  • {PU 24-1} nel ariyum irum toḻuvar
  • {PU 24-2} ce ñāyiṟṟu veyil muṉaiyiṉ
  • {PU 24-3} teḷ kaṭal tirai micai pāyuntu
  • {PU 24-4} tiṇ timil vaṉ paratavar
  • {PU 24-5} veppu uṭaiya maṭṭu uṇṭu
  • {PU 24-6} taṇ kuravai cīr tūṅkuntu
  • {PU 24-7} tūval kalitta tēm pāy puṉṉai
  • {PU 24-8} mel iṇar kaṇṇi milainta maintar
  • {PU 24-9} el vaḷai makaḷir talai kai tarūuntu
  • {PU 24-10} vaṇṭu paṭa malarnta taṇ naṟum kāṉal
  • {PU 24-11} muṇṭaka kōtai oḷ toṭi makaḷir
  • {PU 24-12} irum paṉaiyiṉ kurumpai nīr um
  • {PU 24-13} pūm karumpiṉ tīm cāṟu um
  • {PU 24-14} ōṅku maṇal kuvavu tāḻai
  • {PU 24-15} tīm nīroṭu uṭaṉ virāay
  • {PU 24-16} mu nīr uṇṭu mu nīr pāyum
  • {PU 24-17} tāṅkā uṟaiyuḷ nal ūr keḻīiya
  • {PU 24-18} ōmpā īkai mā vēḷ evvi
  • {PU 24-19} puṉal am putaviṉ miḻalaiyoṭu kaḻaṉi
  • {PU 24-20} kayal ār nārai pōrvil cēkkum
  • {PU 24-21} poṉ aṇi yāṉai tol mutir vēḷir
  • {PU 24-22} kuppai nelliṉ muttūṟu tanta
  • {PU 24-23} koṟṟa nīḷ kuṭai koṭi tēr ceḻiya
  • {PU 24-24} niṉṟu nilaiiyar niṉ nāḷmīṉ nillātu
  • {PU 24-25} paṭāa celīiyar niṉ pakaivar mīṉ ē
  • {PU 24-26} niṉṉoṭu toṉṟu mūtta uyiriṉum uyiroṭu
  • {PU 24-27} niṉṟu mūtta yākkai aṉṉa niṉ
  • {PU 24-28} āṭu kuṭi mūtta viḻu tiṇai ciṟanta
  • {PU 24-29} vāḷiṉ vāḻnar tāḷ valam vāḻtta
  • {PU 24-30} iraval mākkaḷ īkai nuvala
  • {PU 24-31} oḷ toṭi makaḷir polam kalattu ēntiya
  • {PU 24-32} taṇ kamaḻ tēṟal maṭuppa makiḻ ciṟantu
  • {PU 24-33} āṅku iṉitu oḻukumati peruma āṅku atu
  • {PU 24-34} vallunar vāḻntōr eṉpa tol icai
  • {PU 24-35} malar talai ulakattu tōṉṟi
  • {PU 24-36} palar cela cellātu niṉṟu viḷintōr ē
