{PUṞAM 126}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 126-1} oṉṉār yāṉi ōṭi poṉ koṇṭu
  • {PU 126-2} pāṇar ceṉṉi poliya tii
  • {PU 126-3} vāṭā tāmari cūṭṭiya viḻu cīr
  • {PU 126-4} ōṭā pūṭki uravōṉ maruka
  • {PU 126-5} vallēm allēm āyiṉum vallē
  • {PU 126-6} niṉ vayiṉ kiḷakkuvam āyiṉ kaṅkul
  • {PU 126-7} tuyil maṭintaṉṉa tūṅku iruḷ iṟumpiṉ
  • {PU 126-8} paṟi ici aruvi muḷḷūr poruna
  • {PU 126-9} teṟal aru marapiṉ niṉ kiḷiyoṭu um poliya
  • {PU 126-10} nilam mici paranta makkaṭku ellām
  • {PU 126-11} pulaṉ aḻukku aṟṟa antaṇāḷaṉ
  • {PU 126-12} irantu cel mākkaṭku iṉi iṭaṉ iṉṟi
  • {PU 126-13} parantu ici niṟka pāṭiṉaṉ ataṉ koṇṭu
  • {PU 126-14} ciṉam miku tāṉi vāṉavaṉ kuṭa kaṭal
  • {PU 126-15} polam taru nāvāy ōṭṭiya a vaḻi
  • {PU 126-16} piṟa kalam celkalātu aṉiyēm atti
  • {PU 126-17} iṉmi turappa ici tara vantu niṉ
  • {PU 126-18} vaṇmiyiṉ toṭuttaṉam yām ē muḷ eyiṟṟu
  • {PU 126-19} aravu eṟi urumiṉ muracu eḻuntu iyampa
  • {PU 126-20} aṇṇal yāṉiyoṭu vēntu kaḷattu oḻiya
  • {PU 126-21} arum camam tatiya tākki naṉṟu um
  • {PU 126-22} naṇṇā tevvar tāṅkum
  • {PU 126-23} peṇṇi am paṭappi nāṭu kiḻavōy ē
