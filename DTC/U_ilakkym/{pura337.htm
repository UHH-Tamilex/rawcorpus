{PUṞAM 337}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 337-1} ār kaliyiṉaṉ ē cōṇāṭṭu aṇṇal
  • {PU 337-2} kavi kai maṇ āḷ celvar āyiṉum
  • {PU 337-3} vāḷ valattu oḻiya pāṭi ceṉṟāar
  • {PU 337-4} varal tōṟu akam malara
  • {PU 337-5} ītal āṉā vilaṅku toṭi taṭam kai
  • {PU 337-6} pāri paṟampiṉ paṉi cuṉai pōla
  • {PU 337-7} kāṇṭaṟku ariyaḷ āki māṇṭa
  • {PU 337-8} peṇmai niṟainta polivoṭu maṇṇiya
  • {PU 337-9} tukil viri kaṭuppa nuṭaṅki taṇṇeṉa
  • {PU 337-10} akil ār naṟum pukai aitu ceṉṟu aṭaṅkiya
  • {PU 337-11} kapila neṭu nakar kamaḻum nāṟṟamoṭu
  • {PU 337-12} maṉai ceṟintaṉaḷ ē vāḷ nutal iṉi ē
  • {PU 337-13} aṟṟaṉṟu ākaliṉ teṟṟeṉa pōṟṟi
  • {PU 337-14} kāy nel kavaḷam tīṟṟi kāvu toṟum
  • {PU 337-15} kaṭuṅkaṇ yāṉai kāppaṉar aṉṟi
  • {PU 337-16} varutal āṉār vēntar taṉṉaiyar
  • {PU 337-17} poru camam kaṭanta uru keḻu neṭu vēl
  • {PU 337-18} kuruti paṟṟiya veruvaru talaiyar
  • {PU 337-19} maṟṟu ivar maṟaṉ um iṟṟu āl teṟṟeṉa
  • {PU 337-20} yār ākuvar kol tām ē nēr iḻai
  • {PU 337-21} urutta pala cuṇaṅku aṇinta
  • {PU 337-22} maruppu iḷa vaṉa mulai ñemukkuvōr ē
