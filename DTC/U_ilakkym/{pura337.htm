  • {PU 337-1} ār kaliyiṉaṉ ē cōṇāṭṭu aṇṇal
  • {PU 337-2} kavi ki maṇ āḷ celvar āyiṉum
  • {PU 337-3} vāḷ valattu oḻiya pāṭi ceṉṟāar
  • {PU 337-4} varal tōṟu akam malara
  • {PU 337-5} ītal āṉā vilaṅku toṭi taṭam ki
  • {PU 337-6} pāri paṟampiṉ paṉi cuṉi pōla
  • {PU 337-7} kāṇṭaṟku ariyaḷ āki māṇṭa
  • {PU 337-8} peṇmi niṟinta polivoṭu maṇṇiya
  • {PU 337-9} tukil viri kaṭuppa nuṭaṅki taṇṇeṉa
  • {PU 337-10} akil ār naṟum puki aitu ceṉṟu aṭaṅkiya
  • {PU 337-11} kapila neṭu nakar kamaḻum nāṟṟamoṭu
  • {PU 337-12} maṉi ceṟintaṉaḷ ē vāḷ nutal iṉi ē
  • {PU 337-13} aṟṟaṉṟu ākaliṉ teṟṟeṉa pōṟṟi
  • {PU 337-14} kāy nel kavaḷam tīṟṟi kāvu toṟum
  • {PU 337-15} kaṭuṅkaṇ yāṉi kāppaṉar aṉṟi
  • {PU 337-16} varutal āṉār vēntar taṉṉiyar
  • {PU 337-17} poru camam kaṭanta uru keḻu neṭu vēl
  • {PU 337-18} kuruti paṟṟiya veruvaru taliyar
  • {PU 337-19} maṟṟu ivar maṟaṉ um iṟṟu āl teṟṟeṉa
  • {PU 337-20} yār ākuvar kol tām ē nēr iḻi
  • {PU 337-21} urutta pala cuṇaṅku aṇinta
  • {PU 337-22} maruppu iḷa vaṉa muli ñemukkuvōr ē
