{PUṞAM 68}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 68-1} uṭumpu urittaṉṉa eṉpu eḻu maruṅkiṉ
  • {PU 68-2} kaṭumpiṉ kaṭum paci kaḷiyunar kāṇātu
  • {PU 68-3} cil cevittu ākiya kēḷvi nontu nontu
  • {PU 68-4} īṅku evaṉ ceyti ō pāṇa pūṇ cumantu
  • {PU 68-5} am pakaṭṭu eḻiliya ce poṟi ākattu
  • {PU 68-6} meṉmiyiṉ makaḷirkku vaṇaṅki vaṉmiyiṉ
  • {PU 68-7} āṭavar piṇikkum pīṭu keḻu neṭuntaki
  • {PU 68-8} puṉiṟu tīr kuḻavikku iliṟṟu muli pōla
  • {PU 68-9} curanta kāviri maram kol mali nīr
  • {PU 68-10} maṉpati purakkum nal nāṭṭu porunaṉ
  • {PU 68-11} uḷ paki oru tiṟam paṭṭeṉa puḷ pakikku
  • {PU 68-12} ēvāṉ ākaliṉ cāvēm yām eṉa
  • {PU 68-13} nīṅkā maṟavar vīṅku tōḷ puṭippa
  • {PU 68-14} taṇi paṟi aṟiyum aṇi koḷ tēr vaḻi
  • {PU 68-15} kaṭum kaḷ parukunar naṭuṅku ki ukutta
  • {PU 68-16} naṟum cēṟu āṭiya vaṟum tali yāṉi
  • {PU 68-17} neṭu nakar varippil paṭu muḻā ōrkkum
  • {PU 68-18} uṟantiyōṉ ē kurucil
  • {PU 68-19} piṟaṉ kaṭi maṟappa nalkuvaṉ celiṉ ē
