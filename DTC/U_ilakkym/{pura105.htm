{PUṞAM 105}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 105-1} cē iḻai peṟukuvai vāḷ nutal viṟali
  • {PU 105-2} taṭavu vāy kalitta mā itaḻ kuvaḷai
  • {PU 105-3} vaṇṭu paṭu putu malar taṇ citar kalāva
  • {PU 105-4} peyyiṉum peyyātu āyiṉum aruvi
  • {PU 105-5} koḷ uḻu viyaṉ pulattu uḻai kāl āka
  • {PU 105-6} mālpu uṭai neṭu varai kōṭu tōṟu iḻitarum
  • {PU 105-7} nīriṉum iṉiya cāyal
  • {PU 105-8} pāri vēḷ pāl pāṭiṉai celiṉ ē
