{PUṞAM 25}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 25-1} mīṉ tikaḻ vicumpil pāy iruḷ akala
  • {PU 25-2} īṇṭu celal marapiṉ taṉ iyal vaḻāatu
  • {PU 25-3} uravu ciṉam tirukiya uru keḻu ñāyiṟu
  • {PU 25-4} nilavu tikaḻ matiyamoṭu nilam cērntāaṅku
  • {PU 25-5} uṭal arum tuppiṉ oṉṟumoḻi vēntarai
  • {PU 25-6} aṇaṅku arum paṟantalai uṇaṅka paṇṇi
  • {PU 25-7} piṇiyuṟu muracam koṇṭa kālai
  • {PU 25-8} nilai tiripu eṟiya tiṇ maṭai kalaṅki
  • {PU 25-9} citaital uyntaṉṟu ō niṉ vēl ceḻiya
  • {PU 25-10} mulai poli ākam uruppa nūṟi
  • {PU 25-11} meym maṟantu paṭṭa varaiyā pūcal
  • {PU 25-12} oḷ nutal makaḷir kaimmai kūra
  • {PU 25-13} avir aṟal kaṭukkum am mel
  • {PU 25-14} kuvai irum kūntal koytal kaṇṭu ē
