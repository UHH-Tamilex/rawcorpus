{PUṞAM 25}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 25-1} mīṉ tikaḻ vicumpil pāy iruḷ akala
  • {PU 25-2} īṇṭu celal marapiṉ taṉ iyal vaḻāatu
  • {PU 25-3} uravu ciṉam tirukiya uru keḻu ñāyiṟu
  • {PU 25-4} nilavu tikaḻ matiyamoṭu nilam cērntāaṅku
  • {PU 25-5} uṭal arum tuppiṉ oṉṟumoḻi vēntari
  • {PU 25-6} aṇaṅku arum paṟantali uṇaṅka paṇṇi
  • {PU 25-7} piṇiyuṟu muracam koṇṭa kāli
  • {PU 25-8} nili tiripu eṟiya tiṇ maṭi kalaṅki
  • {PU 25-9} citital uyntaṉṟu ō niṉ vēl ceḻiya
  • {PU 25-10} muli poli ākam uruppa nūṟi
  • {PU 25-11} meym maṟantu paṭṭa variyā pūcal
  • {PU 25-12} oḷ nutal makaḷir kimmi kūra
  • {PU 25-13} avir aṟal kaṭukkum am mel
  • {PU 25-14} kuvi irum kūntal koytal kaṇṭu ē
