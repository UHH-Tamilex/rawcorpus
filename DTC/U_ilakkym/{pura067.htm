{PUṞAM 67}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 67-1} aṉṉam cēval aṉṉam cēval
  • {PU 67-2} āṭu koḷ veṉṟi aṭu pōr aṇṇal
  • {PU 67-3} nāṭu talaiyaḷikkum oḷ mukam pōla
  • {PU 67-4} kōṭu kūṭu matiyam mukiḻ nilā viḷaṅkum
  • {PU 67-5} maiyal mālai yām kaiyaṟupu iṉaiya
  • {PU 67-6} kumari am perum tuṟai ayirai mānti
  • {PU 67-7} vaṭa malai peyarkuvai āyiṉ iṭaiyatu
  • {PU 67-8} cōḻa nal nāṭṭu paṭiṉ ē kōḻi
  • {PU 67-9} uyarnilai māṭattu kuṟum paṟai acaii
  • {PU 67-10} vāyil viṭātu kōyil pukku em
  • {PU 67-11} perum kō kiḷḷi kēṭka irum picir
  • {PU 67-12} āntai aṭiyuṟai eṉiṉ ē māṇṭa niṉ
  • {PU 67-13} iṉpuṟu pēṭai aṇiya taṉ
  • {PU 67-14} aṉpuṟu nal kalam nalkuvaṉ niṉakku ē
