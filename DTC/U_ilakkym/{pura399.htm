{PUṞAM 399}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 399-1} aṭu makaḷ mukanta aḷavā veṇṇel
  • {PU 399-2} toṭi māṇ ulakkai parūu kuṟṟu arici
  • {PU 399-3} kāṭi veḷ ulai koḷīi nīḻal
  • {PU 399-4} ōṅku ciṉai māviṉ tīm kaṉi naṟum puḷi
  • {PU 399-5} mōṭṭu iru varāal kōṭṭumīṉ koḻum kuṟai
  • {PU 399-6} ceṟuviṉ vaḷḷai ciṟu koṭi pākal
  • {PU 399-7} pātiri ūḻ mukai aviḻ viṭuttaṉṉa
  • {PU 399-8} mey kaḷaintu iṉaṉoṭu viraii
  • {PU 399-9} mūḻppa peyta muḻu aviḻ puḻukkal
  • {PU 399-10} aḻikaḷiṉ paṭunar kaḷi aṭa vaikiṉ
  • {PU 399-11} paḻam cōṟu ayilum muḻaṅku nīr paṭappai
  • {PU 399-12} kāviri kiḻavaṉ māyā nal icai
  • {PU 399-13} kiḷḷivaḷavaṉ uḷḷi avaṉ paṭartum
  • {PU 399-14} cellēṉ cellēṉ piṟar mukam nōkkēṉ
  • {PU 399-15} neṭum kaḻai tūṇṭil viṭu mīṉ noṭuttu
  • {PU 399-16} kiṇaimakaḷ aṭṭa pāval puḷiṅkūḻ
  • {PU 399-17} poḻutu maṟuttu uṇṇum uṇṭiyēṉ aḻivu koṇṭu
  • {PU 399-18} oru ciṟai iruntēṉ eṉ ē iṉi ē
  • {PU 399-19} aṟavar aṟavaṉ maṟavar maṟavaṉ
  • {PU 399-20} maḷḷar maḷḷaṉ tollōr marukaṉ
  • {PU 399-21} icaiyiṉ koṇṭāṉ nacai amutu uṇka eṉa
  • {PU 399-22} mī paṭarntu iṟantu vaṉ kōl maṇṇi
  • {PU 399-23} vaḷ parintu kiṭanta
  • {PU 399-24} vicippuṟuttu amainta putu kāḻ pōrvai
  • {PU 399-25} alakiṉ mālai ārppa vaṭṭittu
  • {PU 399-26} kaṭiyum uṇavu eṉṉa kaṭavuṭku um toṭēṉ
  • {PU 399-27} kaṭum tēr aḷḷaṟku acāvā nōṉ cuval
  • {PU 399-28} pakaṭu ē attai yāṉ vēṇṭi vantatu eṉa
  • {PU 399-29} oṉṟu yāṉ peṭṭā aḷavai aṉṟu ē
  • {PU 399-30} āṉṟu viṭṭaṉṉa attai vicumpiṉ
  • {PU 399-31} mīṉ pūttaṉṉa uruva pal nirai
  • {PU 399-32} ūrtiyoṭu nalkiyōṉ ē cīr koḷa
  • {PU 399-33} iḻumeṉa iḻitarum aruvi
  • {PU 399-34} vāṉ tōy uyar cimai tōṉṟi kō ē
