{PUṞAM 399}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 399-1} aṭu makaḷ mukanta aḷavā veṇṇel
  • {PU 399-2} toṭi māṇ ulakki parūu kuṟṟu arici
  • {PU 399-3} kāṭi veḷ uli koḷīi nīḻal
  • {PU 399-4} ōṅku ciṉi māviṉ tīm kaṉi naṟum puḷi
  • {PU 399-5} mōṭṭu iru varāal kōṭṭumīṉ koḻum kuṟi
  • {PU 399-6} ceṟuviṉ vaḷḷi ciṟu koṭi pākal
  • {PU 399-7} pātiri ūḻ muki aviḻ viṭuttaṉṉa
  • {PU 399-8} mey kaḷintu iṉaṉoṭu virii
  • {PU 399-9} mūḻppa peyta muḻu aviḻ puḻukkal
  • {PU 399-10} aḻikaḷiṉ paṭunar kaḷi aṭa vikiṉ
  • {PU 399-11} paḻam cōṟu ayilum muḻaṅku nīr paṭappi
  • {PU 399-12} kāviri kiḻavaṉ māyā nal ici
  • {PU 399-13} kiḷḷivaḷavaṉ uḷḷi avaṉ paṭartum
  • {PU 399-14} cellēṉ cellēṉ piṟar mukam nōkkēṉ
  • {PU 399-15} neṭum kaḻi tūṇṭil viṭu mīṉ noṭuttu
  • {PU 399-16} kiṇimakaḷ aṭṭa pāval puḷiṅkūḻ
  • {PU 399-17} poḻutu maṟuttu uṇṇum uṇṭiyēṉ aḻivu koṇṭu
  • {PU 399-18} oru ciṟi iruntēṉ eṉ ē iṉi ē
  • {PU 399-19} aṟavar aṟavaṉ maṟavar maṟavaṉ
  • {PU 399-20} maḷḷar maḷḷaṉ tollōr marukaṉ
  • {PU 399-21} iciyiṉ koṇṭāṉ naci amutu uṇka eṉa
  • {PU 399-22} mī paṭarntu iṟantu vaṉ kōl maṇṇi
  • {PU 399-23} vaḷ parintu kiṭanta
  • {PU 399-24} vicippuṟuttu aminta putu kāḻ pōrvi
  • {PU 399-25} alakiṉ māli ārppa vaṭṭittu
  • {PU 399-26} kaṭiyum uṇavu eṉṉa kaṭavuṭku um toṭēṉ
  • {PU 399-27} kaṭum tēr aḷḷaṟku acāvā nōṉ cuval
  • {PU 399-28} pakaṭu ē atti yāṉ vēṇṭi vantatu eṉa
  • {PU 399-29} oṉṟu yāṉ peṭṭā aḷavi aṉṟu ē
  • {PU 399-30} āṉṟu viṭṭaṉṉa atti vicumpiṉ
  • {PU 399-31} mīṉ pūttaṉṉa uruva pal niri
  • {PU 399-32} ūrtiyoṭu nalkiyōṉ ē cīr koḷa
  • {PU 399-33} iḻumeṉa iḻitarum aruvi
  • {PU 399-34} vāṉ tōy uyar cimi tōṉṟi kō ē
