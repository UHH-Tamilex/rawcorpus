{PUṞAM 144}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 144-1} aruḷāy ākal ō koṭitu ē iruḷ vara
  • {PU 144-2} cīṟiyāḻ cevvaḻi paṇṇi yāḻa niṉ
  • {PU 144-3} kār etir kāṉam pāṭiṉēm āka
  • {PU 144-4} nīl naṟu neytaliṉ polinta uṇ kaṇ
  • {PU 144-5} kaluḻntu vār ari paṉi pūṇ akam naṉippa
  • {PU 144-6} iṉital āṉāḷ āka iḷiyōy
  • {PU 144-7} kiḷiyi maṉ em kēḷ veyyōṟku eṉa
  • {PU 144-8} yām taṉ toḻutaṉam viṉava kāntaḷ
  • {PU 144-9} muki puri viraliṉ kaṇṇīr tuṭiyā
  • {PU 144-10} yām avaṉ kiḷiñarēm allēm kēḷ iṉi
  • {PU 144-11} em pōl orutti nalaṉ nayantu eṉṟum
  • {PU 144-12} varūum eṉpa vayaṅku pukaḻ pēkaṉ
  • {PU 144-13} olleṉa olikkum tēroṭu
  • {PU 144-14} mulli vēli nal ūrāṉ ē
