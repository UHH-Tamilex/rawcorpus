{PUṞAM 201}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 201-1} ivar yār eṉkuvi āyiṉ ivar ē
  • {PU 201-2} ūr uṭaṉ iravalarkku aruḷi tēr uṭaṉ
  • {PU 201-3} mullikku ītta cellā nal ici
  • {PU 201-4} paṭu maṇi yāṉi paṟampiṉ kōmāṉ
  • {PU 201-5} neṭu mā pāri makaḷir yāṉ ē
  • {PU 201-6} tanti tōḻaṉ ivar eṉ makaḷir
  • {PU 201-7} antaṇaṉ pulavaṉ koṇṭu vantaṉaṉ ē
  • {PU 201-8} nī ē vaṭa pāl muṉivaṉ taṭaviṉ uḷ tōṉṟi
  • {PU 201-9} cempu puṉintu iyaṟṟiya cēṇ neṭum purici
  • {PU 201-10} uvarā īki tuvari āṇṭu
  • {PU 201-11} nāṟpattoṉpatu vaḻimuṟi vanta
  • {PU 201-12} vēḷir uḷ vēḷ ē viṟal pōr aṇṇal
  • {PU 201-13} tār aṇi yāṉi cēṭṭu iruṅkō ē
  • {PU 201-14} āṇ kaṭaṉ uṭimiyiṉ pāṇ kaṭaṉ āṟṟiya
  • {PU 201-15} oliyal kaṇṇi pulikaṭimāal
  • {PU 201-16} yāṉ tara ivari koṇmati vāṉ kavittu
  • {PU 201-17} irum kaṭal uṭutta i viyakattu arum tiṟal
  • {PU 201-18} poṉ paṭu māl vari kiḻava veṉ vēl
  • {PU 201-19} uṭalunar uṭkum tāṉi
  • {PU 201-20} keṭal arum kuriya nāṭu kiḻavōy ē
