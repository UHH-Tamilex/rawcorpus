{PUṞAM 201}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 201-1} ivar yār eṉkuvai āyiṉ ivar ē
  • {PU 201-2} ūr uṭaṉ iravalarkku aruḷi tēr uṭaṉ
  • {PU 201-3} mullaikku ītta cellā nal icai
  • {PU 201-4} paṭu maṇi yāṉai paṟampiṉ kōmāṉ
  • {PU 201-5} neṭu mā pāri makaḷir yāṉ ē
  • {PU 201-6} tantai tōḻaṉ ivar eṉ makaḷir
  • {PU 201-7} antaṇaṉ pulavaṉ koṇṭu vantaṉaṉ ē
  • {PU 201-8} nī ē vaṭa pāl muṉivaṉ taṭaviṉ uḷ tōṉṟi
  • {PU 201-9} cempu puṉaintu iyaṟṟiya cēṇ neṭum puricai
  • {PU 201-10} uvarā īkai tuvarai āṇṭu
  • {PU 201-11} nāṟpattoṉpatu vaḻimuṟai vanta
  • {PU 201-12} vēḷir uḷ vēḷ ē viṟal pōr aṇṇal
  • {PU 201-13} tār aṇi yāṉai cēṭṭu iruṅkō ē
  • {PU 201-14} āṇ kaṭaṉ uṭaimaiyiṉ pāṇ kaṭaṉ āṟṟiya
  • {PU 201-15} oliyal kaṇṇi pulikaṭimāal
  • {PU 201-16} yāṉ tara ivarai koṇmati vāṉ kavittu
  • {PU 201-17} irum kaṭal uṭutta i vaiyakattu arum tiṟal
  • {PU 201-18} poṉ paṭu māl varai kiḻava veṉ vēl
  • {PU 201-19} uṭalunar uṭkum tāṉai
  • {PU 201-20} keṭal arum kuraiya nāṭu kiḻavōy ē
