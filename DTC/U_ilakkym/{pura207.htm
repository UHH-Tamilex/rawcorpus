{PUṞAM 207}

  • {PU 207-1} eḻu iṉi neñcam celkam yār ō
  • {PU 207-2} paruku aṉṉa vēṭki il vaḻi
  • {PU 207-3} arukil kaṇṭu um aṟiyār pōla
  • {PU 207-4} akam naka vārā mukaṉ aḻi paricil
  • {PU 207-5} tāḷ ilāḷar vēḷār allar
  • {PU 207-6} varuka eṉa vēṇṭum variciyōrkku ē
  • {PU 207-7} peritu ē ulakam pēṇunar palar ē
  • {PU 207-8} mīḷi muṉpiṉ āḷi pōla
  • {PU 207-9} uḷḷam uḷ avintu aṭaṅkātu veḷḷeṉa
  • {PU 207-10} nōvātōṉ vayiṉ tiraṅki
  • {PU 207-11} vāyā vaṉ kaṉikku ulamaruvōr ē
