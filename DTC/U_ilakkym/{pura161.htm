{PUṞAM 161}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 161-1} nīṇṭu oli aḻuvam kuṟai paṭa mukantukoṇṭu
  • {PU 161-2} īṇṭu celal koṇmū vēṇṭu vayiṉ kuḻīi
  • {PU 161-3} peru malai aṉṉa tōṉṟala cūl mutirpu
  • {PU 161-4} urum uraṟu karuviyoṭu peyal kaṭaṉ iṟuttu
  • {PU 161-5} vaḷam maḻai māṟiya eṉṟūḻ kālai
  • {PU 161-6} maṉpatai ellām ceṉṟu uṇa kaṅkai
  • {PU 161-7} karai poru mali nīr niṟaintu tōṉṟiyāṅku
  • {PU 161-8} emakku um piṟarkku um cemmalai ākaliṉ
  • {PU 161-9} aṉpu il āṭavar koṉṟu āṟu kavara
  • {PU 161-10} ceṉṟu talaivaruna alla aṉpu iṉṟu
  • {PU 161-11} vaṉ kalai teviṭṭum arum curam iṟantōrkku
  • {PU 161-12} iṟṟai nāḷoṭu um yāṇṭu talaippeyara eṉa
  • {PU 161-13} kaṇ poṟi pōkiya kacivoṭu uraṉ aḻintu
  • {PU 161-14} arum tuyar uḻakkum eṉ perum tuṉpuṟuvi niṉ
  • {PU 161-15} tāḷ paṭu celvam kāṇtoṟum maruḷa
  • {PU 161-16} paṉai maruḷ taṭam kaiyoṭu muttu paṭa muṟṟiya
  • {PU 161-17} uyar maruppu ēntiya varai maruḷ nōṉ pakaṭu
  • {PU 161-18} oḷi tikaḻ ōṭai poliya maruṅkil
  • {PU 161-19} paṭu maṇi iraṭṭa ēṟi cemmāntu
  • {PU 161-20} celal nacaii uṟṟaṉeṉ viṟal miku kurucil
  • {PU 161-21} iṉmai turappa icaitara vantu niṉ
  • {PU 161-22} vaṇmaiyiṉ toṭutta eṉ nayantaṉai kēṇmati
  • {PU 161-23} valliṉum vallēṉ āyiṉum vallē
  • {PU 161-24} eṉ aḷantu aṟintaṉai nōkkātu ciṟanta
  • {PU 161-25} niṉ aḷantu aṟimati peruma eṉṟum
  • {PU 161-26} vēntar nāṇa peyarvēṉ cāntu arunti
  • {PU 161-27} pal poṟi koṇṭa ēntu eḻil akalam
  • {PU 161-28} māṇ iḻai makaḷir pullutoṟum pukala
  • {PU 161-29} nāḷ muracu iraṅkum iṭaṉ uṭai varaippil niṉ
  • {PU 161-30} tāḷ niḻal vāḻnar nal kalam mikuppa
  • {PU 161-31} vāḷ amar uḻanta niṉ tāṉai um
  • {PU 161-32} cīr miku celvam um ēttukam pala ē
