{PUṞAM 161}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 161-1} nīṇṭu oli aḻuvam kuṟi paṭa mukantukoṇṭu
  • {PU 161-2} īṇṭu celal koṇmū vēṇṭu vayiṉ kuḻīi
  • {PU 161-3} peru mali aṉṉa tōṉṟala cūl mutirpu
  • {PU 161-4} urum uraṟu karuviyoṭu peyal kaṭaṉ iṟuttu
  • {PU 161-5} vaḷam maḻi māṟiya eṉṟūḻ kāli
  • {PU 161-6} maṉpati ellām ceṉṟu uṇa kaṅki
  • {PU 161-7} kari poru mali nīr niṟintu tōṉṟiyāṅku
  • {PU 161-8} emakku um piṟarkku um cemmali ākaliṉ
  • {PU 161-9} aṉpu il āṭavar koṉṟu āṟu kavara
  • {PU 161-10} ceṉṟu talivaruna alla aṉpu iṉṟu
  • {PU 161-11} vaṉ kali teviṭṭum arum curam iṟantōrkku
  • {PU 161-12} iṟṟi nāḷoṭu um yāṇṭu talippeyara eṉa
  • {PU 161-13} kaṇ poṟi pōkiya kacivoṭu uraṉ aḻintu
  • {PU 161-14} arum tuyar uḻakkum eṉ perum tuṉpuṟuvi niṉ
  • {PU 161-15} tāḷ paṭu celvam kāṇtoṟum maruḷa
  • {PU 161-16} paṉi maruḷ taṭam kiyoṭu muttu paṭa muṟṟiya
  • {PU 161-17} uyar maruppu ēntiya vari maruḷ nōṉ pakaṭu
  • {PU 161-18} oḷi tikaḻ ōṭi poliya maruṅkil
  • {PU 161-19} paṭu maṇi iraṭṭa ēṟi cemmāntu
  • {PU 161-20} celal nacii uṟṟaṉeṉ viṟal miku kurucil
  • {PU 161-21} iṉmi turappa icitara vantu niṉ
  • {PU 161-22} vaṇmiyiṉ toṭutta eṉ nayantaṉi kēṇmati
  • {PU 161-23} valliṉum vallēṉ āyiṉum vallē
  • {PU 161-24} eṉ aḷantu aṟintaṉi nōkkātu ciṟanta
  • {PU 161-25} niṉ aḷantu aṟimati peruma eṉṟum
  • {PU 161-26} vēntar nāṇa peyarvēṉ cāntu arunti
  • {PU 161-27} pal poṟi koṇṭa ēntu eḻil akalam
  • {PU 161-28} māṇ iḻi makaḷir pullutoṟum pukala
  • {PU 161-29} nāḷ muracu iraṅkum iṭaṉ uṭi varippil niṉ
  • {PU 161-30} tāḷ niḻal vāḻnar nal kalam mikuppa
  • {PU 161-31} vāḷ amar uḻanta niṉ tāṉi um
  • {PU 161-32} cīr miku celvam um ēttukam pala ē
