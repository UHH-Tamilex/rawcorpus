{PUṞAM 376}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 376-1} vicumpu nīttam iṟanta ñāyiṟṟu
  • {PU 376-2} pacum katir maḻukiya civantu vāṅku anti
  • {PU 376-3} ciṟu naṉi piṟanta piṉṟai ceṟi piṇi
  • {PU 376-4} citāar vaḷpiṉ eṉ teṭāri taḻīi
  • {PU 376-5} pāṇar ārum aḷavai yāṉ taṉ
  • {PU 376-6} yāṇar nal maṉai kūṭṭu mutal niṉṟaṉeṉ
  • {PU 376-7} imaittōr viḻitta māttirai ñerēreṉa
  • {PU 376-8} kuṇakku eḻu tiṅkaḷ kaṉai iruḷ akaṟṟa
  • {PU 376-9} paṇṭu aṟivārā uruvōṭu eṉ arai
  • {PU 376-10} toṉṟu paṭu tuḷaiyoṭu paru iḻai pōki
  • {PU 376-11} naintu karai paṟainta eṉ uṭai um nōkki
  • {PU 376-12} viruntiṉaṉ aḷiyaṉ ivaṉ eṉa peruntakai
  • {PU 376-13} niṉṟa muraṟkai nīkki naṉṟu um
  • {PU 376-14} aravu vekuṇṭaṉṉa tēṟaloṭu cūṭu tarupu
  • {PU 376-15} nirayattu aṉṉa eṉ vaṟaṉ kaḷaintu aṉṟu ē
  • {PU 376-16} iraviṉāṉ ē īttōṉ entai
  • {PU 376-17} aṉṟai ñāṉṟiṉoṭu iṉṟiṉ ūṅku um
  • {PU 376-18} irappu cintiyēṉ nirappu aṭu puṇaiyiṉ
  • {PU 376-19} uḷattiṉ aḷakkum miḷirnta takaiyēṉ
  • {PU 376-20} niṟai kuḷam putaviṉ makiḻntaṉeṉ āki
  • {PU 376-21} oru nāḷ iravalar varaiyā vaḷḷiyōr kaṭai talai
  • {PU 376-22} ñāṅkar neṭumoḻi payiṟṟi
  • {PU 376-23} tōṉṟal cellātu eṉ ciṟu kiṇai kural ē
