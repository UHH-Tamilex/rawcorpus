{PUṞAM 376}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 376-1} vicumpu nīttam iṟanta ñāyiṟṟu
  • {PU 376-2} pacum katir maḻukiya civantu vāṅku anti
  • {PU 376-3} ciṟu naṉi piṟanta piṉṟi ceṟi piṇi
  • {PU 376-4} citāar vaḷpiṉ eṉ teṭāri taḻīi
  • {PU 376-5} pāṇar ārum aḷavi yāṉ taṉ
  • {PU 376-6} yāṇar nal maṉi kūṭṭu mutal niṉṟaṉeṉ
  • {PU 376-7} imittōr viḻitta māttiri ñerēreṉa
  • {PU 376-8} kuṇakku eḻu tiṅkaḷ kaṉi iruḷ akaṟṟa
  • {PU 376-9} paṇṭu aṟivārā uruvōṭu eṉ ari
  • {PU 376-10} toṉṟu paṭu tuḷiyoṭu paru iḻi pōki
  • {PU 376-11} nintu kari paṟinta eṉ uṭi um nōkki
  • {PU 376-12} viruntiṉaṉ aḷiyaṉ ivaṉ eṉa peruntaki
  • {PU 376-13} niṉṟa muraṟki nīkki naṉṟu um
  • {PU 376-14} aravu vekuṇṭaṉṉa tēṟaloṭu cūṭu tarupu
  • {PU 376-15} nirayattu aṉṉa eṉ vaṟaṉ kaḷintu aṉṟu ē
  • {PU 376-16} iraviṉāṉ ē īttōṉ enti
  • {PU 376-17} aṉṟi ñāṉṟiṉoṭu iṉṟiṉ ūṅku um
  • {PU 376-18} irappu cintiyēṉ nirappu aṭu puṇiyiṉ
  • {PU 376-19} uḷattiṉ aḷakkum miḷirnta takiyēṉ
  • {PU 376-20} niṟi kuḷam putaviṉ makiḻntaṉeṉ āki
  • {PU 376-21} oru nāḷ iravalar variyā vaḷḷiyōr kaṭi tali
  • {PU 376-22} ñāṅkar neṭumoḻi payiṟṟi
  • {PU 376-23} tōṉṟal cellātu eṉ ciṟu kiṇi kural ē
