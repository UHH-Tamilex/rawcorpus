{PUṞAM 14}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 14-1} kaṭum kaṇṇa kol kaḷiṟṟāl
  • {PU 14-2} kāppu uṭaiya eḻu murukki
  • {PU 14-3} poṉ iyal puṉai tōṭṭiyāl
  • {PU 14-4} muṉpu turantu camam tāṅka um
  • {PU 14-5} pār uṭaitta kuṇṭu akaḻi
  • {PU 14-6} nīr aḻuva nivappu kuṟittu
  • {PU 14-7} nimir pariya mā tāṅka um
  • {PU 14-8} āvam cērnta puṟattai tēr micai
  • {PU 14-9} cāpa nōṉ ñāṇ vaṭu koḷa vaḻaṅka um
  • {PU 14-10} paricilarkku arum kalam nalka um kuricil
  • {PU 14-11} valiya ākum niṉ tāḷ tōy taṭam kai
  • {PU 14-12} pulavu nāṟṟatta paim taṭi
  • {PU 14-13} pū nāṟṟatta pukai koḷīi ūṉ tuvai
  • {PU 14-14} kaṟi cōṟu uṇṭu varuntu toḻil allatu
  • {PU 14-15} piṟitu toḻil aṟiyā ākaliṉ naṉṟu um
  • {PU 14-16} melliya peruma tām ē nallavarkku
  • {PU 14-17} ār aṇaṅku ākiya mārpiṉ porunarkku
  • {PU 14-18} iru nilattu aṉṉa nōṉmai
  • {PU 14-19} ceru miku cēey niṉ pāṭunar kai ē
