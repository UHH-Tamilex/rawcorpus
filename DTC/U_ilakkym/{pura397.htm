{PUṞAM 397}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 397-1} veḷḷi um iru vicumpu ērtarum puḷ um
  • {PU 397-2} uyar ciṉi kuṭampi kural tōṟṟiṉa ē
  • {PU 397-3} poyki um pōtu kaṇ viḻittaṉa pipaya
  • {PU 397-4} cuṭar um curuṅkiṉṟu oḷi ē pāṭu eḻuntu
  • {PU 397-5} iraṅku kural muracamoṭu valampuri ārppa
  • {PU 397-6} iravu puṟaṅkaṇṭa kāli tōṉṟi
  • {PU 397-7} eḵku iruḷ akaṟṟum ēma pācaṟi
  • {PU 397-8} vikaṟi aravam kēḷiyar pala kōḷ
  • {PU 397-9} cey tār mārpa eḻumati tuyil eṉa
  • {PU 397-10} teḷ kaṇ mā kiṇi teḷirppa oṟṟi
  • {PU 397-11} neṭum kaṭi tōṉṟiyēṉ ē atu nayantu
  • {PU 397-12} uḷḷi vanta paricilaṉ ivaṉ eṉa
  • {PU 397-13} neyyuṟa poritta kuy uṭi neṭum cūṭu
  • {PU 397-14} maṇi kalaṉ niṟinta maṇam nāṟu tēṟal
  • {PU 397-15} pāmpu urittaṉṉa vāṉ pūm kaliṅkamoṭu
  • {PU 397-16} māri aṉṉa vaṇmiyiṉ corintu
  • {PU 397-17} vēṉil aṉṉa eṉ veppu nīṅka
  • {PU 397-18} arum kalam nalkiyōṉ ē eṉṟum
  • {PU 397-19} ceṟuvil pūtta cē itaḻ tāmari
  • {PU 397-20} aṟu toḻil antaṇar aṟam purintu eṭutta
  • {PU 397-21} tīyoṭu viḷaṅkum nāṭaṉ vāy vāḷ
  • {PU 397-22} valam paṭu tīviṉ polam pūṇ vaḷavaṉ
  • {PU 397-23} eṟi tiri perum kaṭal iṟuti kaṇ celiṉum
  • {PU 397-24} teṟu katir kaṉali teṉ tici tōṉṟiṉum
  • {PU 397-25} eṉ eṉṟu añcalam yām ē veṉ vēl
  • {PU 397-26} arum camam kaṭakkum āṟṟal avaṉ
  • {PU 397-27} tiruntu kaḻal nōṉ tāḷ taṇ niḻalēm ē
