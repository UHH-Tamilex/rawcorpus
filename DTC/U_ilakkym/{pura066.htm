{PUṞAM 66}

((Originally extracted from master file ^PURAM.OCP))

  • {PU 66-1} naḷi iru munnīr nāvāy ōṭṭi
  • {PU 66-2} vaḷi toḻil āṇṭa uravōṉ maruka
  • {PU 66-3} kaḷi iyal yāṉi karikālvaḷava
  • {PU 66-4} ceṉṟu amar kaṭanta niṉ āṟṟal tōṉṟa
  • {PU 66-5} veṉṟōy niṉṉiṉum nallaṉ aṉṟu ē
  • {PU 66-6} kali koḷ yāṇar veṇṇi paṟantali
  • {PU 66-7} mika pukaḻ ulakam eyti
  • {PU 66-8} puṟam puṇ nāṇi vaṭakkiruntōṉ ē
