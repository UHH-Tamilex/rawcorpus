{PUṞAM 52}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 52-1} aṇaṅku uṭai neṭum kōṭṭu aḷai akam muṉaii
  • {PU 52-2} muṇaṅku nimir vaya māṉ muḻu vali oruttal
  • {PU 52-3} ūṉ nacai uḷḷam turappa irai kuṟittu
  • {PU 52-4} tāṉ vēṇṭu maruṅkiṉ vēṭṭu eḻuntāṅku
  • {PU 52-5} vaṭa pulam maṉṉar vāṭa aṭal kuṟittu
  • {PU 52-6} iṉṉā ve pōr iyal tēr vaḻuti
  • {PU 52-7} itu nī kaṇṇiyatu āyiṉ iru nilattu
  • {PU 52-8} yār kol aḷiyar tām ē ūr toṟum
  • {PU 52-9} mīṉ cuṭu pukaiyiṉ pulavu nāṟu neṭum koṭi
  • {PU 52-10} vayal uḻai marutiṉ vāṅku ciṉai valakkum
  • {PU 52-11} peru nal yāṇariṉ orīi iṉi ē
  • {PU 52-12} kali keḻu kaṭavuḷ kantam kaiviṭa
  • {PU 52-13} pali kaṇ māṟiya pāḻ paṭu potiyil
  • {PU 52-14} narai mūtāḷar nāy iṭa kuḻinta
  • {PU 52-15} valliṉ nal akam niṟaiya pal poṟi
  • {PU 52-16} kāṉavāraṇam īṉum
  • {PU 52-17} kāṭu āki viḷiyum nāṭu uṭaiyōr ē
