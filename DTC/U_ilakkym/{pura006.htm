{PUṞAM 6}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 6-1} vaṭāatu paṉi paṭu neṭu varai vaṭakku um
  • {PU 6-2} teṉāatu uru keḻu kumariyiṉ teṟku um
  • {PU 6-3} kuṇāatu karai poru toṭu kaṭal kuṇakku um
  • {PU 6-4} kuṭāatu toṉṟu mutir pauvattiṉ kuṭakku um
  • {PU 6-5} kīḻatu mu puṇar aṭukkiya muṟai mutal kaṭṭiṉ
  • {PU 6-6} nīr nilai nivappiṉ kīḻ um mēlatu
  • {PU 6-7} āṉilai ulakattāṉ um āṉātu
  • {PU 6-8} uru um pukaḻ um āki viri cīr
  • {PU 6-9} teri kōl ñamaṉ pōla oru tiṟam
  • {PU 6-10} paṟṟal iliyar ō niṉ tiṟam ciṟakka
  • {PU 6-11} cey viṉaikku etirnta tevvar tēettu
  • {PU 6-12} kaṭal paṭai kuḷippa maṇṭi aṭar pukar
  • {PU 6-13} ciṟu kaṇ yāṉai cevvitiṉ ēvi
  • {PU 6-14} pācu aval paṭappai ār eyil pala tantu
  • {PU 6-15} a eyil koṇṭa ceyvuṟu nal kalam
  • {PU 6-16} paricil mākkaṭku varicaiyiṉ nalki
  • {PU 6-17} paṇiyiyar attai niṉ kuṭai ē muṉivar
  • {PU 6-18} mukkaṭcelvar nakar valam ceyaṟku ē
  • {PU 6-19} iṟaiñcuka peruma niṉ ceṉṉi ciṟanta
  • {PU 6-20} nāṉmaṟai muṉivar ēntu kai etir ē
  • {PU 6-21} vāṭuka iṟaiva niṉ kaṇṇi oṉṉār
  • {PU 6-22} nāṭu cuṭu kamaḻ pukai eṟittalāṉ ē
  • {PU 6-23} celiyar attai niṉ vekuḷi vāl iḻai
  • {PU 6-24} maṅkaiyar tuṉitta vāḷ mukattu etir ē
  • {PU 6-25} āṅka veṉṟi ellām veṉṟu akattu aṭakkiya
  • {PU 6-26} taṇṭā īkai takai māṇ kuṭumi
  • {PU 6-27} taṇ katir matiyam pōla um teṟu cuṭar
  • {PU 6-28} oḷ katir ñāyiṟu pōla um
  • {PU 6-29} maṉṉiya peruma nī nilam micaiyāṉ ē
