{PUṞAM 56}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 56-1} ēṟṟu valaṉ uyariya eri maruḷ avir caṭai
  • {PU 56-2} māṟṟu arum kaṇicci maṇi miṭaṟṟōṉ um
  • {PU 56-3} kaṭal vaḷar puri vaḷai puraiyum mēṉi
  • {PU 56-4} aṭal ve nāñcil paṉai koṭiyōṉ um
  • {PU 56-5} maṇṇuṟu tiru maṇi puraiyum mēṉi
  • {PU 56-6} viṇ uyar puḷ koṭi viṟal veyyōṉ um
  • {PU 56-7} maṇi mayil uyariya māṟā veṉṟi
  • {PU 56-8} piṇimuka ūrti oḷ ceyyōṉ um eṉa
  • {PU 56-9} ñālam kākum kāla muṉpiṉ
  • {PU 56-10} tōlā nal icai nālvar uḷ um
  • {PU 56-11} kūṟṟu ottī ē māṟṟu arum cīṟṟam
  • {PU 56-12} vali ottī ē vāliyōṉai
  • {PU 56-13} pukaḻ ottī ē ikaḻunar aṭunaṉai
  • {PU 56-14} muruku otīi ē muṉṉiyatu muṭittaliṉ
  • {PU 56-15} āṅku āṅku avar avar ottaliṉ yāṅku um
  • {PU 56-16} ariya um uḷa ō niṉakku ē ataṉāl
  • {PU 56-17} iravalarkku arum kalam arukātu īyā
  • {PU 56-18} yavaṉar nal kalam tanta taṇ kamaḻ tēṟal
  • {PU 56-19} poṉ cey puṉai kalattu ēnti nāḷ um
  • {PU 56-20} oḷ toṭi makaḷir maṭuppa makiḻ ciṟantu
  • {PU 56-21} āṅku iṉitu oḻukumati ōṅku vāḷ māṟa
  • {PU 56-22} am kaṇ vicumpiṉ ār iruḷ akaṟṟum
  • {PU 56-23} ve katir celvaṉ pōla um kuṭa ticai
  • {PU 56-24} taṇ katir matiyam pōla um
  • {PU 56-25} niṉṟu nilaiiyar ulakamōṭu uṭaṉ ē
