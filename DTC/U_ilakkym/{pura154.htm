  • {PU 154-1} tirai poru munnīr karai naṇi celiṉum
  • {PU 154-2} aṟiyunar kāṇiṉ vēṭkai nīkkum
  • {PU 154-3} cil nīr viṉavuvar māntar atu pōl
  • {PU 154-4} aracar uḻaiyar āka um purai tapu
  • {PU 154-5} vaḷḷiyōr paṭarkuvar pulavar ataṉāl
  • {PU 154-6} yāṉ um peṟṟatu ūtiyam pēṟu yātu eṉṉēṉ
  • {PU 154-7} uṟṟaṉeṉ ātaliṉ uḷḷi vantaṉaṉ ē
  • {PU 154-8} ī eṉa irattal ō aritu ē nī atu
  • {PU 154-9} nalkiṉum nalkāy āyiṉum vel pōr
  • {PU 154-10} eṟi paṭaikku ōṭā āṇmai aṟuvai
  • {PU 154-11} tū viri kaṭuppa tuvaṉṟi mīmicai
  • {PU 154-12} taṇ pala iḻitarum aruvi niṉ
  • {PU 154-13} koṇ perum kāṉam pāṭal eṉakku eḷitu ē
