{PUṞAM 141}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 141-1} pāṇaṉ cūṭiya pacum poṉ tāmarai
  • {PU 141-2} māṇ iḻai viṟali mālaiyoṭu viḷaṅka
  • {PU 141-3} kaṭum pari neṭum tēr pūṭṭu viṭṭu acaii
  • {PU 141-4} ūrīr pōla curattu iṭai iruntaṉir
  • {PU 141-5} yārīr ō eṉa viṉaval āṉā
  • {PU 141-6} kār eṉ okkal kaṭum paci iravala
  • {PU 141-7} veṉ vēl aṇṇal kāṇā ūṅku ē
  • {PU 141-8} niṉṉiṉum pulliyēm maṉ ē iṉi ē
  • {PU 141-9} iṉṉēm āyiṉēm maṉ ē eṉṟum
  • {PU 141-10} uṭāa pōrā ākutal aṟintu um
  • {PU 141-11} paṭāam maññaikku ītta em kō
  • {PU 141-12} kaṭāa yāṉai kali māṉ pēkaṉ
  • {PU 141-13} ettuṇai āyiṉum īttal naṉṟu eṉa
  • {PU 141-14} maṟumai nōkkiṉṟu ō aṉṟu ē
  • {PU 141-15} piṟar vaṟumai nōkkiṉṟu avaṉ kai vaṇmai ē
