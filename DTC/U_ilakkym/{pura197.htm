{PUṞAM 197}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 197-1} vaḷi naṭantaṉṉa vā celal ivuḷiyoṭu
  • {PU 197-2} koṭi nuṭaṅku micaiya tēriṉar eṉāa
  • {PU 197-3} kaṭal kaṇṭaṉṉa oḷ paṭai tāṉaiyoṭu
  • {PU 197-4} malai māṟu malaikkum kaḷiṟṟiṉar eṉāa
  • {PU 197-5} urum uraṟṟu aṉṉa uṭkuvaru muracamoṭu
  • {PU 197-6} ceru mēmpaṭūum veṉṟiyar eṉāa
  • {PU 197-7} maṇ keḻu tāṉai oḷ pūṇ vēntar
  • {PU 197-8} veḷ kuṭai celvam viyattal ō ilam ē
  • {PU 197-9} emmāl viyakkappaṭūumōr ē
  • {PU 197-10} iṭu muḷ paṭappai maṟi mēyntu oḻinta
  • {PU 197-11} kuṟu naṟu muññai koḻum kaṇ kuṟṟu aṭaku
  • {PU 197-12} puṉpulam varakiṉ coṉṟiyoṭu peṟūum
  • {PU 197-13} cīṟūr maṉṉar āyiṉum em vayiṉ
  • {PU 197-14} pāṭu aṟintu oḻukum paṇpiṉar ē
  • {PU 197-15} mika pēr evvamuṟiṉum eṉaittu um
  • {PU 197-16} uṇarcci illōr uṭaimai uḷḷēm
  • {PU 197-17} nal aṟivu uṭaiyōr nalkuravu
  • {PU 197-18} uḷḷutum peruma yām uvantu naṉi peritu ē
