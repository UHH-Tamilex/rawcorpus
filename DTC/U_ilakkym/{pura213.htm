{PUṞAM 213}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 213-1} maṇṭu amar aṭṭa mataṉ uṭai nōṉ tāḷ
  • {PU 213-2} veḷ kuṭai viḷakkum viṟal keḻu vēntu ē
  • {PU 213-3} poṅku nīr uṭutta i malar talai ulakattu
  • {PU 213-4} niṉ talai vanta iruvarai niṉaippiṉ
  • {PU 213-5} toṉṟu uṟai tuppiṉ niṉ pakaiñar um allar
  • {PU 213-6} amar ve kāṭciyoṭu māṟu etirpu eḻuntavar
  • {PU 213-7} niṉaiyum kālai nī um maṟṟavarkku
  • {PU 213-8} aṉaiyai allai aṭu māṉ tōṉṟal
  • {PU 213-9} parantu paṭu nal icai eyti maṟṟu nī
  • {PU 213-10} uyarntōr ulakam eyti piṉ um
  • {PU 213-11} oḻitta tāyam avarkku urittaṉṟu ē
  • {PU 213-12} ataṉāl aṉṉatu ātal um aṟivōy naṉṟu um
  • {PU 213-13} iṉṉum kēṇmati icai veyyōy ē
  • {PU 213-14} niṉṟa tuppoṭu niṉ kuṟittu eḻunta
  • {PU 213-15} eṇ il kāṭci iḷaiyōr tōṟpiṉ
  • {PU 213-16} niṉ perum celvam yārkku eñcuvai ē
  • {PU 213-17} amar ve celva nī avarkku ulaiyiṉ
  • {PU 213-18} ikaḻunar uvappa paḻi eñcuvai ē
  • {PU 213-19} ataṉāl oḻika til attai niṉ maṟaṉ ē val viraintu
  • {PU 213-20} eḻumati vāḻka niṉ uḷḷam aḻintōrkku
  • {PU 213-21} ēmam ākum niṉ tāḷ niḻal mayaṅkātu
  • {PU 213-22} ceytal vēṇṭum āl naṉṟu ē vāṉōr
  • {PU 213-23} arum peṟal ulakattu āṉṟavar
  • {PU 213-24} vitumpuṟu viruppoṭu viruntu etirkoḷaṟku ē
