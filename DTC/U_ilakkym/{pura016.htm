  • {PU 16-1} viṉai māṭciya virai puraviyoṭu
  • {PU 16-2} maḻai uruviṉa tōl parappi
  • {PU 16-3} muṉai muruṅka talai ceṉṟu avar
  • {PU 16-4} viḷai vayal kavarpu ūṭṭi
  • {PU 16-5} maṉai maram viṟaku āka
  • {PU 16-6} kaṭi tuṟai nīr kaḷiṟu paṭīi
  • {PU 16-7} ellu paṭa iṭṭa cuṭu tī viḷakkam
  • {PU 16-8} cel cuṭar ñāyiṟṟu cekkariṉ tōṉṟa
  • {PU 16-9} pulam keṭa iṟukkum varampu il tāṉai
  • {PU 16-10} tuṇai vēṇṭā ceru veṉṟi
  • {PU 16-11} pulavu vāḷ pular cāntiṉ
  • {PU 16-12} murukaṉ cīṟṟattu uru keḻu kurucil
  • {PU 16-13} mayaṅku vaḷḷai malar āmpal
  • {PU 16-14} paṉi pakaṉṟai kaṉi pākal
  • {PU 16-15} karumpu allatu kāṭu aṟiyā
  • {PU 16-16} perum taṇ paṇai pāḻ āka
  • {PU 16-17} ēma nal nāṭu oḷ eri ūṭṭiṉai
  • {PU 16-18} nāma nal amar ceyya
  • {PU 16-19} ōrāṅku malaintaṉa peruma niṉ kaḷiṟu ē
