{PUṞAM 38}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 38-1} vari puriyum maḻa kaḷiṟṟiṉ mici
  • {PU 38-2} vāṉ tuṭikkum vakiya pōla
  • {PU 38-3} viravu uruviṉa koṭi nuṭaṅkum
  • {PU 38-4} viyaṉ tāṉi viṟal vēntu ē
  • {PU 38-5} nī uṭaṉṟu nōkkum vāy eri tavaḻa
  • {PU 38-6} nī nayantu nōkkum vāy poṉ pūppa
  • {PU 38-7} ce ñāyiṟṟu nilavu vēṇṭiṉum
  • {PU 38-8} veḷ tiṅkaḷ uḷ veyil vēṇṭiṉum
  • {PU 38-9} vēṇṭiyatu viḷikkum āṟṟali ākaliṉ
  • {PU 38-10} niṉ niḻal piṟantu niṉ niḻal vaḷarnta
  • {PU 38-11} em aḷavu evaṉ ō maṟṟu ē iṉ nili
  • {PU 38-12} polam pūm kāviṉ nal nāṭṭōr um
  • {PU 38-13} cey viṉi maruṅkiṉ eytal allati
  • {PU 38-14} uṭiyōr ītal um illōr irattal um
  • {PU 38-15} kaṭavatu aṉmiyiṉ kiyaṟavu uṭittu eṉa
  • {PU 38-16} āṇṭu cey nukarcci īṇṭu um kūṭaliṉ
  • {PU 38-17} niṉ nāṭu uḷḷuvar paricilar
  • {PU 38-18} oṉṉār tēettu um niṉ uṭittu eṉa ē
