  • {PU 360-2} cila collāṉ pala kēḷviyar
  • {PU 360-3} nuṇ uṇarviṉāṉ perum koṭaiyar
  • {PU 360-4} kaluḻ naṉaiyāṉ taṇ tēṟalar
  • {PU 360-5} kaṉi kuyyāṉ koḻum tuvaiyar
  • {PU 360-6} tāḻ uvantu taḻūu moḻiyar
  • {PU 360-7} payaṉ uṟuppa palarkku āṟṟi
  • {PU 360-8} ēmam āka i nilam āṇṭōr
  • {PU 360-9} cilar ē peruma kēḷ iṉi nāḷ um
  • {PU 360-10} palar ē takaiyaḵtu aṟiyātōr ē
  • {PU 360-11} aṉṉōr celvam um maṉṉi nillātu
  • {PU 360-12} iṉṉum aṟṟu ataṉ paṇpu ē ataṉāl
  • {PU 360-13} niccam um oḻukkam muṭṭilai paricil
  • {PU 360-14} naccuvar kaiyiṉ nirappal ōmpumati accu vara
  • {PU 360-15} pāṟu iṟaikoṇṭa paṟantalai mā kata
  • {PU 360-16} kaḷḷi pōkiya kaḷari maruṅkiṉ
  • {PU 360-17} veḷḷil niṟutta piṉṟai kaḷḷoṭu
  • {PU 360-18} pul akattu iṭṭa cil aviḻ valci
  • {PU 360-19} pulaiyaṉ ēva pul mēl amarntu uṇṭu
  • {PU 360-20} aḻal vāy pukka piṉ um
  • {PU 360-21} palar vāyttu irāar paruttu uṇṭōr ē
