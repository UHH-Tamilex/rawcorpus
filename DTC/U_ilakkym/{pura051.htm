{PUṞAM 51}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 51-1} nīr mikiṉ ciṟai um illai tī mikiṉ
  • {PU 51-2} maṉ uyir niḻaṟṟum niḻal um illai
  • {PU 51-3} vaḷi mikiṉ vali um illai oḷi mikku
  • {PU 51-4} avaṟṟu ōraṉṉa ciṉam pōr vaḻuti
  • {PU 51-5} taṇ tamiḻ potu eṉa poṟāaṉ pōr etirntu
  • {PU 51-6} koṇṭi vēṇṭuvaṉ āyiṉ koḷka eṉa
  • {PU 51-7} koṭutta maṉṉar naṭukku aṟṟaṉar ē
  • {PU 51-8} aḷiyar ō aḷiyar avaṉ aḷi iḻantōr ē
  • {PU 51-9} nuṇ pala citalai aritu muyaṉṟu eṭutta
  • {PU 51-10} ce puṟṟu īyal pōla
  • {PU 51-11} oru pakal vāḻkkaikku ulamaruvōr ē
