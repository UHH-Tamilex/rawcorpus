{PUṞAM 50}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 50-1} mācu aṟa vicitta vārpuṟu vaḷpiṉ
  • {PU 50-2} mai paṭu maruṅkul poliya maññai
  • {PU 50-3} oli neṭum pīli oḷ poṟi maṇi tār
  • {PU 50-4} polam kuḻai uḻiñaiyoṭu poliya cūṭṭi
  • {PU 50-5} kuruti vēṭkai uru keḻu muracam
  • {PU 50-6} maṇṇi vārā aḷavai eṇṇey
  • {PU 50-7} nurai mukantaṉṉa mel pūm cēkkai
  • {PU 50-8} aṟiyātu ēṟiya eṉṉai teṟuvara
  • {PU 50-9} iru pāl paṭukkum niṉ vāḷ vāy oḻittatu ai
  • {PU 50-10} atū um cālum nal tamiḻ muḻutu aṟital
  • {PU 50-11} ataṉoṭu um amaiyātu aṇuka vantu niṉ
  • {PU 50-12} mataṉ uṭai muḻavu tōḷ ōcci taṇṇeṉa
  • {PU 50-13} vīciyōy ē viyal iṭam kamaḻa
  • {PU 50-14} ivaṉ icai uṭaiyōrkku allatu avaṇatu
  • {PU 50-15} uyarnilai ulakattu uṟaiyuḷ iṉmai
  • {PU 50-16} viḷaṅka kēṭṭa māṟu kol
  • {PU 50-17} valam paṭu kurucil nī īṅku itu ceyal ē
