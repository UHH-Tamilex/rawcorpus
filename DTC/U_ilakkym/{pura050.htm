  • {PU 50-1} mācu aṟa vicitta vārpuṟu vaḷpiṉ
  • {PU 50-2} mi paṭu maruṅkul poliya maññi
  • {PU 50-3} oli neṭum pīli oḷ poṟi maṇi tār
  • {PU 50-4} polam kuḻi uḻiñiyoṭu poliya cūṭṭi
  • {PU 50-5} kuruti vēṭki uru keḻu muracam
  • {PU 50-6} maṇṇi vārā aḷavi eṇṇey
  • {PU 50-7} nuri mukantaṉṉa mel pūm cēkki
  • {PU 50-8} aṟiyātu ēṟiya eṉṉi teṟuvara
  • {PU 50-9} iru pāl paṭukkum niṉ vāḷ vāy oḻittatu ai
  • {PU 50-10} atū um cālum nal tamiḻ muḻutu aṟital
  • {PU 50-11} ataṉoṭu um amiyātu aṇuka vantu niṉ
  • {PU 50-12} mataṉ uṭi muḻavu tōḷ ōcci taṇṇeṉa
  • {PU 50-13} vīciyōy ē viyal iṭam kamaḻa
  • {PU 50-14} ivaṉ ici uṭiyōrkku allatu avaṇatu
  • {PU 50-15} uyarnili ulakattu uṟiyuḷ iṉmi
  • {PU 50-16} viḷaṅka kēṭṭa māṟu kol
  • {PU 50-17} valam paṭu kurucil nī īṅku itu ceyal ē
