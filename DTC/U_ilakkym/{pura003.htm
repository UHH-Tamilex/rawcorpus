{PUṞAM 3}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 3-1} uvavu mati uruviṉ ōṅkal veḷ kuṭai
  • {PU 3-2} nilavu kaṭal varaippiṉ maṇṇakam niḻaṟṟa
  • {PU 3-3} ēma muracam iḻumeṉa muḻaṅka
  • {PU 3-4} nēmi uytta nēe neñciṉ
  • {PU 3-5} tavirā īkai kavuriyar maruka
  • {PU 3-6} ceyir tīr kaṟpiṉ cē iḻai kaṇava
  • {PU 3-7} poṉ ōṭai pukar aṇi nutal
  • {PU 3-8} tuṉ arum tiṟal kamaḻ kaṭāattu
  • {PU 3-9} eyiṟu paṭai āka eyil katavu iṭāa
  • {PU 3-10} kayiṟu piṇi koṇṭa kaviḻ maṇi maruṅkiṉ
  • {PU 3-11} perum kai yāṉai irum piṭar talai iruntu
  • {PU 3-12} maruntu il kūṟṟattu arum toḻil cāyā
  • {PU 3-13} karum kai oḷ vāḷ perum peyar vaḻuti
  • {PU 3-14} nilam peyariṉum niṉ col peyaral
  • {PU 3-15} polam kaḻal kāl pular cāntiṉ
  • {PU 3-16} vilaṅku akaṉṟa viyal mārpa
  • {PU 3-17} ūr illa uyavu ariya
  • {PU 3-18} nīr illa nīḷ iṭaiya
  • {PU 3-19} pārval irukkai kavi kaṇ nōkkiṉ
  • {PU 3-20} ce toṭai piḻaiyā vaṉkaṇ āṭavar
  • {PU 3-21} ampu viṭa vīḻntōr vampa patukkai
  • {PU 3-22} tiruntu ciṟai vaḷai vāy paruntu iruntu uyavum
  • {PU 3-23} uṉṉa maratta tuṉ arum kavalai
  • {PU 3-24} niṉ nacai vēṭkaiyiṉ iravalar varuvar atu
  • {PU 3-25} muṉṉam mukattiṉ uṇarntu avar
  • {PU 3-26} iṉmai tīrttal vaṉmaiyāṉ ē
