{PUṞAM 158}

((Last updated on 2004 April 14th))

  • {PU 158-1} muracu kaṭippu ikuppa um vāl vaḷai tuvaippa um
  • {PU 158-2} aracu uṭaṉ poruta aṇṇal neṭu varai
  • {PU 158-3} kaṟaṅku veḷ aruvi kal alaittu oḻukum
  • {PU 158-4} paṟampiṉ kōmāṉ pāri um piṟaṅku micai
  • {PU 158-5} kolli āṇṭa val vil ōri um
  • {PU 158-6} kāri ūrntu pēr amar kaṭanta
  • {PU 158-7} māri īkai maṟa pōr malaiyaṉ um
  • {PU 158-8} ūrātu ēntiya kutirai kūr vēl
  • {PU 158-9} kūviḷam kaṇṇi koṭum pūṇ eḻiṉi um
  • {PU 158-10} īrm taṇ cilampiṉ iruḷ tūṅku naḷi muḻai
  • {PU 158-11} arum tiṟal kaṭavuḷ kākkum uyar cimai
  • {PU 158-12} perum kal nāṭaṉ pēkaṉ um tiruntu moḻi
  • {PU 158-13} mōci pāṭiya āy um ārvamuṟṟu
  • {PU 158-14} uḷḷi varunar ulaivu naṉi tīra
  • {PU 158-15} taḷḷātu īyum takai cāl vaṇmai
  • {PU 158-16} koḷḷār ōṭṭiya naḷḷi um eṉa āṅku
  • {PU 158-17} eḻuvar māynta piṉṟai aḻi vara
  • {PU 158-18} pāṭi varunar um piṟar um kūṭi
  • {PU 158-19} irantōr aṟṟam tīrkku eṉa viraintu ivaṇ
  • {PU 158-20} uḷḷi vantaṉeṉ yāṉ ē vicumpuṟa
  • {PU 158-21} kaḻai vaḷar cilampiṉ vāḻaiyoṭu nīṭi
  • {PU 158-22} āciṉi kaviṉiya palaviṉ ārvuṟṟu
  • {PU 158-23} muḷ puṟa mutu kaṉi peṟṟa kaṭuvaṉ
  • {PU 158-24} tuy talai mantiyai kaiyiṭūu payirum
  • {PU 158-25} atirā yāṇar mutirattu kiḻava
  • {PU 158-26} ivaṇ viḷaṅku ciṟappiṉ iyal tēr kumaṇa
  • {PU 158-27} icai mēm tōṉṟiya vaṇmaiyoṭu
  • {PU 158-28} pakai mēmpaṭuka nī ēntiya vēl ē
