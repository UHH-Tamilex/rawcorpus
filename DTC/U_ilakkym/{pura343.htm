{PUṞAM 343}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 343-1} mīṉ noṭuttu nel kuvii
  • {PU 343-2} mici ampiyiṉ maṉi maṟukkuntu
  • {PU 343-3} maṉi kuviiya kaṟi mūṭi āl
  • {PU 343-4} kali cummiya kari kalakkuṟuntu
  • {PU 343-5} kalam tanta poṉ paricam
  • {PU 343-6} kaḻi tōṇiyāṉ kari cērkkuntu
  • {PU 343-7} mali tāram um kaṭal tāram um
  • {PU 343-8} tali peytu varunarkku īyum
  • {PU 343-9} puṉal am kaḷḷiṉ polam tār kuṭṭuvaṉ
  • {PU 343-10} muḻaṅku kaṭal muḻaviṉ muciṟi aṉṉa
  • {PU 343-11} nalam cāl viḻu poruḷ paṇintu vantu koṭuppiṉum
  • {PU 343-12} puriyar allōr variyalaḷ ivaḷ eṉa
  • {PU 343-13} tanti um koṭāaṉ āyiṉ vantōr
  • {PU 343-14} vāyppaṭa iṟutta ēṇi āyiṭi
  • {PU 343-15} varuntiṉṟu kol ō tāṉ ē paruntu uyirttu
  • {PU 343-16} iṭi matil cēkkum purici
  • {PU 343-17} paṭi mayaṅku ār iṭi neṭu nal ūr ē
