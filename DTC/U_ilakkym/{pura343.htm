{PUṞAM 343}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 343-1} mīṉ noṭuttu nel kuvaii
  • {PU 343-2} micai ampiyiṉ maṉai maṟukkuntu
  • {PU 343-3} maṉai kuvaiiya kaṟi mūṭai āl
  • {PU 343-4} kali cummaiya karai kalakkuṟuntu
  • {PU 343-5} kalam tanta poṉ paricam
  • {PU 343-6} kaḻi tōṇiyāṉ karai cērkkuntu
  • {PU 343-7} malai tāram um kaṭal tāram um
  • {PU 343-8} talai peytu varunarkku īyum
  • {PU 343-9} puṉal am kaḷḷiṉ polam tār kuṭṭuvaṉ
  • {PU 343-10} muḻaṅku kaṭal muḻaviṉ muciṟi aṉṉa
  • {PU 343-11} nalam cāl viḻu poruḷ paṇintu vantu koṭuppiṉum
  • {PU 343-12} puraiyar allōr varaiyalaḷ ivaḷ eṉa
  • {PU 343-13} tantai um koṭāaṉ āyiṉ vantōr
  • {PU 343-14} vāyppaṭa iṟutta ēṇi āyiṭai
  • {PU 343-15} varuntiṉṟu kol ō tāṉ ē paruntu uyirttu
  • {PU 343-16} iṭai matil cēkkum puricai
  • {PU 343-17} paṭai mayaṅku ār iṭai neṭu nal ūr ē
