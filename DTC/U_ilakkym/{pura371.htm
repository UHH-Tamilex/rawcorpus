{PUṞAM 371}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 371-1} akal talai vaiyattu puravalar kāṇātu
  • {PU 371-2} maram talai cērntu paṭṭiṉi vaiki
  • {PU 371-3} pōtu aviḻ alari nāriṉ toṭuttu
  • {PU 371-4} tayaṅku irum pittai poliya cūṭi
  • {PU 371-5} paṟaiyoṭu takaitta kalam paiyeṉ muravu vāy
  • {PU 371-6} āṭuṟu kuḻici pāṭu iṉṟu tūkki
  • {PU 371-7} maṉṟa vēmpiṉ oḷ pū uṟaippa
  • {PU 371-8} kuṟai ceyal vēṇṭā nacaiya irukkaiyēṉ
  • {PU 371-9} arici iṉmaiyiṉ ār iṭai nīnti
  • {PU 371-10} kūr vāy irum paṭai nīriṉ miḷirppa
  • {PU 371-11} varu kaṇai vāḷi aṉpu iṉṟu talaii
  • {PU 371-12} irai muracu ārkkum urai cāl pācaṟai
  • {PU 371-13} vil ēr uḻaviṉ niṉ nal icai uḷḷi
  • {PU 371-14} kuṟai talai paṭu piṇaṉ etira pōrpu aḻittu
  • {PU 371-15} yāṉai eruttiṉ vāḷ maṭal ōcci
  • {PU 371-16} atari tiritta āḷ uku kaṭāviṉ
  • {PU 371-17} matiyattu aṉṉa eṉ viciyuṟu taṭāri
  • {PU 371-18} akal kaṇ atira ākuḷi toṭāliṉ
  • {PU 371-19} paṇai maruḷ neṭum tāḷ pal piṇar taṭam kai
  • {PU 371-20} pukar mukam mukavaikku vanticiṉ peruma
  • {PU 371-21} kaḷiṟṟu kōṭṭu aṉṉa vāl eyiṟu aḻutti
  • {PU 371-22} viḻukkoṭu viraiiya veḷ niṇam cuvaiyiṉaḷ
  • {PU 371-23} kuṭar talai mālai cūṭi uṇa tiṉa
  • {PU 371-24} āṉā peru vaḷam ceytōṉ vāṉattu
  • {PU 371-25} vayaṅku pal mīṉiṉum vāḻiyar pala eṉa
  • {PU 371-26} uru keḻu pēymakaḷ ayara
  • {PU 371-27} kuruti tukaḷ āṭiya kaḷam kiḻavōy ē
