{PUṞAM 73}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 73-1} mella vantu eṉ nal aṭi porunti
  • {PU 73-2} ī eṉa irakkuvar āyiṉ cīr uṭai
  • {PU 73-3} muracu keḻu tāyattu aracu ō tañcam
  • {PU 73-4} iṉ uyir āyiṉum koṭukkuveṉ i nilattu
  • {PU 73-5} āṟṟal uṭaiyōr āṟṟal pōṟṟātu eṉ
  • {PU 73-6} uḷḷam eḷḷiya maṭavōṉ teḷḷitiṉ
  • {PU 73-7} tuñcu puli iṭaṟiya citaṭaṉ pōla
  • {PU 73-8} uyntaṉaṉ peyartal ō aritu ē maintu uṭai
  • {PU 73-9} kaḻai tiṉ yāṉai kāl akappaṭṭa
  • {PU 73-10} vaṉ tiṇi nīḷ muḷai pōla ceṉṟu avaṇ
  • {PU 73-11} varunta porēeṉ āyiṉ poruntiya
  • {PU 73-12} tītu il neñcattu kātal koḷḷā
  • {PU 73-13} pal irum kūntal makaḷir
  • {PU 73-14} ollā muyakku iṭai kuḻaika eṉ tār ē
