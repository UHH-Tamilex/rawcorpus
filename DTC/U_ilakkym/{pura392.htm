{PUṞAM 392}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 392-1} mati ēr veḷ kuṭai atiyar kōmāṉ
  • {PU 392-2} koṭum pūṇ eḻiṉi neṭum kaṭai niṉṟu yāṉ
  • {PU 392-3} pacalai nilaviṉ paṉi paṭu viṭiyal
  • {PU 392-4} poru kaḷiṟṟu aṭi vaḻi aṉṉa eṉ kai
  • {PU 392-5} oru kaṇ mā kiṇai oṟṟupu koṭāa
  • {PU 392-6} uru keḻu maṉṉar ār eyil kaṭantu
  • {PU 392-7} niṇam paṭu kuruti perum pāṭṭu īrattu
  • {PU 392-8} aṇaṅku uṭai marapiṉ irum kaḷam tōṟum
  • {PU 392-9} veḷ vāy kaḻutai pul iṉam pūṭṭi
  • {PU 392-10} veḷḷai varaku um koḷ um vittum
  • {PU 392-11} vaikal uḻava vāḻiya peritu eṉa
  • {PU 392-12} ceṉṟu yāṉ niṉṟaṉeṉ āka aṉṟu ē
  • {PU 392-13} ūr uṇ kēṇi pakaṭṭu ilai pāci
  • {PU 392-14} vēr purai citāar nīkki nēr karai
  • {PU 392-15} nuṇ nūl kaliṅkam uṭīi uṇ eṉa
  • {PU 392-16} tēḷ kaṭuppu aṉṉa nāṭpaṭu tēṟal
  • {PU 392-17} kōḷmīṉ aṉṉa polam kalattu aḷaii
  • {PU 392-18} ūṇ muṟai īttal aṉṟi um kōḷ muṟai
  • {PU 392-19} viruntu iṟai nalkiyōṉ ē antarattu
  • {PU 392-20} arum peṟal amiḻtam aṉṉa
  • {PU 392-21} karumpu ivaṇ tantōṉ perum piṟaṅkaṭai ē
