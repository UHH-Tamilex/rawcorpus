{PUṞAM 72}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 72-1} nakutakkaṉar ē nāṭu mīkūṟunar
  • {PU 72-2} iḷiyaṉ ivaṉ eṉa uḷiya kūṟi
  • {PU 72-3} paṭu maṇi iraṭṭum pā aṭi paṇi tāḷ
  • {PU 72-4} neṭu nal yāṉi um tēr um mā um
  • {PU 72-5} paṭi ami maṟavar um uṭiyam yām eṉṟu
  • {PU 72-6} uṟu tuppu añcātu uṭal ciṉam cerukki
  • {PU 72-7} ciṟucol colliya ciṉam keḻu vēntari
  • {PU 72-8} arum camam citiya tākki muracamoṭu
  • {PU 72-9} oruṅku akappaṭēeṉ āyiṉ poruntiya
  • {PU 72-10} eṉ niḻal vāḻnar cel niḻal kāṇātu
  • {PU 72-11} koṭiyaṉ em iṟi eṉa kaṇṇīr parappi
  • {PU 72-12} kuṭi paḻi tūṟṟum kōlēṉ ākuka
  • {PU 72-13} ōṅkiya ciṟappiṉ uyarnta kēḷvi
  • {PU 72-14} māṅkuṭi marutaṉ talivaṉ āka
  • {PU 72-15} ulakamoṭu niliiya palar pukaḻ ciṟappiṉ
  • {PU 72-16} pulavar pāṭātu varika eṉ nila vari
  • {PU 72-17} purappōr puṉkaṇ kūra
  • {PU 72-18} irappōrkku īyā iṉmi yāṉ uṟa ē
