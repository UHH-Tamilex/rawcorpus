{PUṞAM 72}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 72-1} nakutakkaṉar ē nāṭu mīkūṟunar
  • {PU 72-2} iḷaiyaṉ ivaṉ eṉa uḷaiya kūṟi
  • {PU 72-3} paṭu maṇi iraṭṭum pā aṭi paṇai tāḷ
  • {PU 72-4} neṭu nal yāṉai um tēr um mā um
  • {PU 72-5} paṭai amai maṟavar um uṭaiyam yām eṉṟu
  • {PU 72-6} uṟu tuppu añcātu uṭal ciṉam cerukki
  • {PU 72-7} ciṟucol colliya ciṉam keḻu vēntarai
  • {PU 72-8} arum camam citaiya tākki muracamoṭu
  • {PU 72-9} oruṅku akappaṭēeṉ āyiṉ poruntiya
  • {PU 72-10} eṉ niḻal vāḻnar cel niḻal kāṇātu
  • {PU 72-11} koṭiyaṉ em iṟai eṉa kaṇṇīr parappi
  • {PU 72-12} kuṭi paḻi tūṟṟum kōlēṉ ākuka
  • {PU 72-13} ōṅkiya ciṟappiṉ uyarnta kēḷvi
  • {PU 72-14} māṅkuṭi marutaṉ talaivaṉ āka
  • {PU 72-15} ulakamoṭu nilaiiya palar pukaḻ ciṟappiṉ
  • {PU 72-16} pulavar pāṭātu varaika eṉ nila varai
  • {PU 72-17} purappōr puṉkaṇ kūra
  • {PU 72-18} irappōrkku īyā iṉmai yāṉ uṟa ē
