{PUṞAM 372}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 372-1} vici piṇi taṭāri immeṉa oṟṟi
  • {PU 372-2} ētti vantatu ellām muḻutta
  • {PU 372-3} ilaṅku vāḷ avir oḷi valam paṭa miṉṉi
  • {PU 372-4} kaṇai tuḷi poḻinta kaṇ kūṭu pācaṟai
  • {PU 372-5} poruntā tevvar arinta talai aṭuppiṉ
  • {PU 372-6} kūviḷa viṟakiṉ ākku vari nuṭaṅkal
  • {PU 372-7} āṉā maṇṭai vaṉṉi am tuṭuppiṉ
  • {PU 372-8} īṉā vēṇmāḷ iṭam tuḻantu aṭṭa
  • {PU 372-9} mā maṟi piṇṭam vāluvaṉ ēnta
  • {PU 372-10} vatuvai viḻaviṉ putuvōrkku ellām
  • {PU 372-11} ve vāy peyta pūta nīr cālka eṉa
  • {PU 372-12} pulavu kaḷam poliya vēṭṭōy niṉ
  • {PU 372-13} nilavu tikaḻ āram mukakkuvam eṉa ē
