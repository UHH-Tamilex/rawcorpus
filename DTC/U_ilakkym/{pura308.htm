{PUṞAM 308}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 308-1} poṉ vārntaṉṉa puri aṭaṅku narampiṉ
  • {PU 308-2} miṉ nēr paccai miñiṟṟu kural cīṟiyāḻ
  • {PU 308-3} naṉmai niṟainta nayavaru pāṇa
  • {PU 308-4} cīṟūr maṉṉaṉ ciṟu ilai eḵkam
  • {PU 308-5} vēntu ūr yāṉai ēntu mukattatu ē
  • {PU 308-6} vēntu uṭaṉṟu eṟinta vēl ē eṉṉai
  • {PU 308-7} cāntu ār akalam uḷam kaḻintaṉṟu ē
  • {PU 308-8} uḷam kaḻi cuṭar paṭai ēnti nam peruviṟal
  • {PU 308-9} ōcciṉaṉ turanta kālai maṟṟavaṉ
  • {PU 308-10} puṉ talai maṭam piṭi nāṇa
  • {PU 308-11} kuñcaram ellām puṟakkoṭuttaṉa ē
