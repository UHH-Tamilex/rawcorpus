{PUṞAM 308}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 308-1} poṉ vārntaṉṉa puri aṭaṅku narampiṉ
  • {PU 308-2} miṉ nēr pacci miñiṟṟu kural cīṟiyāḻ
  • {PU 308-3} naṉmi niṟinta nayavaru pāṇa
  • {PU 308-4} cīṟūr maṉṉaṉ ciṟu ili eḵkam
  • {PU 308-5} vēntu ūr yāṉi ēntu mukattatu ē
  • {PU 308-6} vēntu uṭaṉṟu eṟinta vēl ē eṉṉi
  • {PU 308-7} cāntu ār akalam uḷam kaḻintaṉṟu ē
  • {PU 308-8} uḷam kaḻi cuṭar paṭi ēnti nam peruviṟal
  • {PU 308-9} ōcciṉaṉ turanta kāli maṟṟavaṉ
  • {PU 308-10} puṉ tali maṭam piṭi nāṇa
  • {PU 308-11} kuñcaram ellām puṟakkoṭuttaṉa ē
