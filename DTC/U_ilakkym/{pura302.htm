((Originally extracted from master file ^PURAM.OCP))

  • {PU 302-1} veṭi vēy koḷvatu pōla ōṭi
  • {PU 302-2} tāvupu ukaḷum mā ē pū ē
  • {PU 302-3} viḷaṅku iḻai makaḷir kūntal koṇṭa
  • {PU 302-4} naranta pal kāḻ kōtai cuṟṟiya
  • {PU 302-5} aitu amai pāṇi vaṇar kōṭṭu cīṟiyāḻ
  • {PU 302-6} kai vār narampiṉ pāṇarkku ōkkiya
  • {PU 302-7} nirampā iyalpiṉ karampai cīṟūr
  • {PU 302-8} nōkkiṉar cekukkum kāḷai ūkki
  • {PU 302-9} vēliṉ aṭṭa kaḷiṟu peyarttu eṇṇiṉ
  • {PU 302-10} viṇ ivar vicumpiṉ mīṉ um
  • {PU 302-11} taṇ peyal uṟai um uṟai āṟṟā ē
