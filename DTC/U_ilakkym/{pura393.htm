{PUṞAM 393}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 393-1} pati mutal paḻakā paḻaṅkaṇ vāḻkki
  • {PU 393-2} kuṟu neṭum tuṇiyoṭu kūmi vītaliṉ
  • {PU 393-3} kuṭi muṟi pāṭi oyyeṉa varunti
  • {PU 393-4} aṭal naci maṟanta em kuḻici malarkkum
  • {PU 393-5} kaṭaṉ aṟiyāḷar piṟa nāṭṭu iṉmiyiṉ
  • {PU 393-6} vaḷḷaṉmiyiṉ em varivōr yār eṉa
  • {PU 393-7} uḷḷiya uḷḷamoṭu uli naci tuṇiyā
  • {PU 393-8} ellām oru pāl paṭṭeṉa
  • {PU 393-9} malar tār aṇṇal niṉ nal ici uḷḷi
  • {PU 393-10} īrm ki maṟanta eṉ irum pēr okkal
  • {PU 393-11} kūrnta evvam viṭa koḻu niṇam kiḻippa
  • {PU 393-12} kōṭi parutti vīṭu niṟi peyta
  • {PU 393-13} mūṭi paṇṭam miṭi niṟintaṉṉa
  • {PU 393-14} veḷ niṇa mūri aruḷa nāḷ uṟa
  • {PU 393-15} īṉṟa araviṉ nā uru kaṭukkum eṉ
  • {PU 393-16} toṉṟu paṭu citāar tuvara nīkki
  • {PU 393-17} pōtu viri pakaṉṟi putu malar aṉṉa
  • {PU 393-18} akaṉṟu maṭi kaliṅkam uṭīi celvam um
  • {PU 393-19} kēṭu iṉṟu nalkumati peruma mācu il
  • {PU 393-20} mati puri mā kiṇi teḷirppa oṟṟi
  • {PU 393-21} āṭu makaḷ alkul oppa vāṭi
  • {PU 393-22} kōṭi āyiṉum
  • {PU 393-23} kāviri purakkum nal nāṭṭu poruna
  • {PU 393-24} vāy vāḷ vaḷavaṉ vāḻka eṉa
  • {PU 393-25} pīṭu keḻu nōṉ tāḷ pāṭukam pala ē
