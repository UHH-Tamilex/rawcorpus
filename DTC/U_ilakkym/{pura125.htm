{PUṞAM 125}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 125-1} parutti peṇṭiṉ paṉuval aṉṉa
  • {PU 125-2} neruppu ciṉam taṇinta niṇam tayaṅku koḻum kuṟi
  • {PU 125-3} parūu kaḷ maṇṭiyoṭu ūḻ māṟu peyara
  • {PU 125-4} uṇkum enti niṉ kāṇku vanticiṉ ē
  • {PU 125-5} naḷḷātār miṭal cāytta
  • {PU 125-6} vallāḷa niṉ makiḻ irukki ē
  • {PU 125-7} uḻuta nōṉ pakaṭu aḻi tiṉṟāṅku
  • {PU 125-8} nal amiḻtu āka nī nayantu uṇṇum naṟavu ē
  • {PU 125-9} kuṉṟattu aṉṉa kaḷiṟu peyara
  • {PU 125-10} kaṭantu aṭṭu veṉṟōṉ um niṉ kūṟum ē
  • {PU 125-11} velīiyōṉ ivaṉ eṉa
  • {PU 125-12} kaḻal aṇi polinta cē aṭi nilam kavarpu
  • {PU 125-13} virintu vantu camam tāṅkiya
  • {PU 125-14} val vēl maliyaṉ allaṉ āyiṉ
  • {PU 125-15} nal amar kaṭattal eḷitu maṉ namakku eṉa
  • {PU 125-16} tōṟṟōṉ tāṉ um niṉ kūṟum ē
  • {PU 125-17} toliiyōṉ ivaṉ eṉa
  • {PU 125-18} oru nī āyiṉi peruma peru maḻikku
  • {PU 125-19} irukki cāṉṟa uyar mali
  • {PU 125-20} tiru taku cēey niṉ peṟṟiciṉōrkku ē
