{PUṞAM 209}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 209-1} poykai nārai pōrvil cēkkum
  • {PU 209-2} neytal am kaḻaṉi nel ari toḻuvar
  • {PU 209-3} kūmpu viṭu mel piṇi aviḻnta āmpal
  • {PU 209-4} akal aṭai ariyal mānti teḷ kaṭal
  • {PU 209-5} paṭu tirai iṉ cīr pāṇi tūṅkum
  • {PU 209-6} meṉpulam vaippiṉ nal nāṭṭu poruna
  • {PU 209-7} pal kaṉi nacaii alku vicumpu ukantu
  • {PU 209-8} peru malai viṭar akam cilampa muṉṉi
  • {PU 209-9} paḻaṉ uṭai peru maram tīrnteṉa kaiyaṟṟu
  • {PU 209-10} peṟātu peyarum puḷ iṉam pōla niṉ
  • {PU 209-11} nacai tara vantu niṉ icai nuval paricileṉ
  • {PU 209-12} vaṟuviyēṉ peyarku ō vāḷ mēmpaṭuna
  • {PU 209-13} īyāy āyiṉum iraṅkuveṉ allēṉ
  • {PU 209-14} nōy ilai ākumati peruma nam uḷ
  • {PU 209-15} kuṟu naṇi kāṇkuvatu āka nāḷ um
  • {PU 209-16} naṟum pal olivarum katuppiṉ tēm moḻi
  • {PU 209-17} teri iḻai makaḷir pāṇi pārkkum
  • {PU 209-18} peru varai aṉṉa mārpiṉ
  • {PU 209-19} ceru ve cēey niṉ makiḻ irukkai ē
