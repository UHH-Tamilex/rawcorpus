{PUṞAM 209}

  • {PU 209-1} poyki nāri pōrvil cēkkum
  • {PU 209-2} neytal am kaḻaṉi nel ari toḻuvar
  • {PU 209-3} kūmpu viṭu mel piṇi aviḻnta āmpal
  • {PU 209-4} akal aṭi ariyal mānti teḷ kaṭal
  • {PU 209-5} paṭu tiri iṉ cīr pāṇi tūṅkum
  • {PU 209-6} meṉpulam vippiṉ nal nāṭṭu poruna
  • {PU 209-7} pal kaṉi nacii alku vicumpu ukantu
  • {PU 209-8} peru mali viṭar akam cilampa muṉṉi
  • {PU 209-9} paḻaṉ uṭi peru maram tīrnteṉa kiyaṟṟu
  • {PU 209-10} peṟātu peyarum puḷ iṉam pōla niṉ
  • {PU 209-11} naci tara vantu niṉ ici nuval paricileṉ
  • {PU 209-12} vaṟuviyēṉ peyarku ō vāḷ mēmpaṭuna
  • {PU 209-13} īyāy āyiṉum iraṅkuveṉ allēṉ
  • {PU 209-14} nōy ili ākumati peruma nam uḷ
  • {PU 209-15} kuṟu naṇi kāṇkuvatu āka nāḷ um
  • {PU 209-16} naṟum pal olivarum katuppiṉ tēm moḻi
  • {PU 209-17} teri iḻi makaḷir pāṇi pārkkum
  • {PU 209-18} peru vari aṉṉa mārpiṉ
  • {PU 209-19} ceru ve cēey niṉ makiḻ irukki ē
