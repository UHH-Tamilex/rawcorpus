{PUṞAM 351}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 351-1} paṭu maṇi maruṅkiṉa paṇai tāḷ yāṉai um
  • {PU 351-2} koṭi nuṭaṅku micaiya tēr um mā um
  • {PU 351-3} paṭai amai maṟavaroṭu tuvaṉṟi kalleṉa
  • {PU 351-4} kaṭal kaṇṭaṉṉa kaṇ akal tāṉai
  • {PU 351-5} veṉṟu eṟi muraciṉ vēntar eṉṟum
  • {PU 351-6} vaṇ kai eyiṉaṉ vākai aṉṉa
  • {PU 351-7} ivaḷ nalam tārātu amaikuvar allar
  • {PU 351-8} eṉ āvatu kol tāṉ ē teḷ nīr
  • {PU 351-9} poykai mēynta ce vari nārai
  • {PU 351-10} tēm koḷ marutiṉ pūm ciṉai muṉaiyiṉ
  • {PU 351-11} kāmaru kāñci tuñcum
  • {PU 351-12} ēmam cāl ciṟappiṉ i paṇai nal ūr ē
