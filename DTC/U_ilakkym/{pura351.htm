{PUṞAM 351}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 351-1} paṭu maṇi maruṅkiṉa paṇi tāḷ yāṉi um
  • {PU 351-2} koṭi nuṭaṅku miciya tēr um mā um
  • {PU 351-3} paṭi ami maṟavaroṭu tuvaṉṟi kalleṉa
  • {PU 351-4} kaṭal kaṇṭaṉṉa kaṇ akal tāṉi
  • {PU 351-5} veṉṟu eṟi muraciṉ vēntar eṉṟum
  • {PU 351-6} vaṇ ki eyiṉaṉ vāki aṉṉa
  • {PU 351-7} ivaḷ nalam tārātu amikuvar allar
  • {PU 351-8} eṉ āvatu kol tāṉ ē teḷ nīr
  • {PU 351-9} poyki mēynta ce vari nāri
  • {PU 351-10} tēm koḷ marutiṉ pūm ciṉi muṉiyiṉ
  • {PU 351-11} kāmaru kāñci tuñcum
  • {PU 351-12} ēmam cāl ciṟappiṉ i paṇi nal ūr ē
