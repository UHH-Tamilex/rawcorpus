{PUṞAM 43}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 43-1} nilam micai vāḻnar alamaral tīra
  • {PU 43-2} teṟu katir kaṉali vemmai tāṅki
  • {PU 43-3} kāl uṇavu āka cuṭaroṭu koṭkum
  • {PU 43-4} avir caṭai muṉivar um maruḷa koṭum ciṟai
  • {PU 43-5} kūr ukir paruntiṉ ēṟu kuṟittu orīi
  • {PU 43-6} taṉ akam pukka kuṟu naṭai puṟaviṉ
  • {PU 43-7} taputi añci cīrai pukka
  • {PU 43-8} varaiyā īkai uravōṉ maruka
  • {PU 43-9} nērār kaṭanta muraṇ miku tiruviṉ
  • {PU 43-10} tēr vaṇ kiḷḷi tampi vār kōl
  • {PU 43-11} koṭumara maṟavar peruma kaṭu māṉ
  • {PU 43-12} kai vaṇ tōṉṟal aiyam uṭaiyēṉ
  • {PU 43-13} ār puṉai teriyal niṉ muṉṉōr ellām
  • {PU 43-14} pārppār nōvaṉa ceyyalar maṟṟu itu
  • {PU 43-15} nīrttu ō niṉakku eṉa veṟuppa kūṟi
  • {PU 43-16} niṉ yāṉ piḻaittatu nōvāy eṉṉiṉum
  • {PU 43-17} nī piḻaittāy pōl naṉi nāṇiṉai ē
  • {PU 43-18} tammai piḻaittōr poṟukkum cemmal
  • {PU 43-19} i kuṭi piṟantōrkku eṇmai kāṇum eṉa
  • {PU 43-20} kāṇtaku moympa kāṭṭiṉai ākaliṉ
  • {PU 43-21} yāṉ ē piḻaittaṉeṉ ciṟakka niṉ āyuḷ
  • {PU 43-22} mikku varum iṉ nīr kāviri
  • {PU 43-23} ekkar iṭṭa maṇaliṉum pala ē
