{PUṞAM 43}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 43-1} nilam mici vāḻnar alamaral tīra
  • {PU 43-2} teṟu katir kaṉali vemmi tāṅki
  • {PU 43-3} kāl uṇavu āka cuṭaroṭu koṭkum
  • {PU 43-4} avir caṭi muṉivar um maruḷa koṭum ciṟi
  • {PU 43-5} kūr ukir paruntiṉ ēṟu kuṟittu orīi
  • {PU 43-6} taṉ akam pukka kuṟu naṭi puṟaviṉ
  • {PU 43-7} taputi añci cīri pukka
  • {PU 43-8} variyā īki uravōṉ maruka
  • {PU 43-9} nērār kaṭanta muraṇ miku tiruviṉ
  • {PU 43-10} tēr vaṇ kiḷḷi tampi vār kōl
  • {PU 43-11} koṭumara maṟavar peruma kaṭu māṉ
  • {PU 43-12} ki vaṇ tōṉṟal aiyam uṭiyēṉ
  • {PU 43-13} ār puṉi teriyal niṉ muṉṉōr ellām
  • {PU 43-14} pārppār nōvaṉa ceyyalar maṟṟu itu
  • {PU 43-15} nīrttu ō niṉakku eṉa veṟuppa kūṟi
  • {PU 43-16} niṉ yāṉ piḻittatu nōvāy eṉṉiṉum
  • {PU 43-17} nī piḻittāy pōl naṉi nāṇiṉi ē
  • {PU 43-18} tammi piḻittōr poṟukkum cemmal
  • {PU 43-19} i kuṭi piṟantōrkku eṇmi kāṇum eṉa
  • {PU 43-20} kāṇtaku moympa kāṭṭiṉi ākaliṉ
  • {PU 43-21} yāṉ ē piḻittaṉeṉ ciṟakka niṉ āyuḷ
  • {PU 43-22} mikku varum iṉ nīr kāviri
  • {PU 43-23} ekkar iṭṭa maṇaliṉum pala ē
