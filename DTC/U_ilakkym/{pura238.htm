{PUṞAM 238}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 238-1} kavi ce tāḻi kuvi puṟattu irunta
  • {PU 238-2} cevi ce cēval um pokuval um veruvā
  • {PU 238-3} vāy vaṉ kākki um kūki um kūṭi
  • {PU 238-4} pēey āyamoṭu peṭṭāṅku vaḻaṅkum
  • {PU 238-5} kāṭu muṉṉiṉaṉ ē kaḷ kāmuṟunaṉ
  • {PU 238-6} toṭi kaḻi makaḷiriṉ tol kaviṉ vāṭi
  • {PU 238-7} pāṭunar kaṭumpu um piyeṉṟaṉa ē
  • {PU 238-8} tōṭu koḷ muracu um kiḻintaṉa kaṇ ē
  • {PU 238-9} āḷ il vari pōl yāṉi um maruppu iḻantaṉa ē
  • {PU 238-10} ve tiṟal kūṟṟam perum pētuṟuppa
  • {PU 238-11} enti ākutal ataṉ paṭal aṟiyēṉ
  • {PU 238-12} antō aḷiyēṉ vantaṉeṉ maṉṟa
  • {PU 238-13} eṉ ākuvar kol eṉ tuṉṉiyōr ē
  • {PU 238-14} māri iraviṉ maram kaviḻ poḻutiṉ
  • {PU 238-15} ār añar uṟṟa neñcamoṭu orāṅku
  • {PU 238-16} kaṇ il ūmaṉ kaṭal paṭṭāṅku
  • {PU 238-17} vari aḷantu aṟiyā tiri aru nīttattu
  • {PU 238-18} avala maṟu cuḻi maṟukaliṉ
  • {PU 238-19} taval ē naṉṟu maṉ takuti um atu ē
