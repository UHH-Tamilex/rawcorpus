{PUṞAM 19}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 19-1} imiḻ kaṭal vaḷiiya īṇṭu akal kiṭakki
  • {PU 19-2} tamiḻ tali mayaṅkiya taliyālaṅkāṉattu
  • {PU 19-3} maṉ uyir paṉmi um kūṟṟattu orumi um
  • {PU 19-4} niṉṉoṭu tūkkiya veṉ vēl ceḻiya
  • {PU 19-5} irum puli vēṭṭuvaṉ poṟi aṟintu māṭṭiya
  • {PU 19-6} perum kal aṭār um pōṉm eṉa virumpi
  • {PU 19-7} muyaṅkiṉēṉ allaṉ ō yāṉ ē mayaṅki
  • {PU 19-8} kuṉṟattu iṟutta kurīi iṉam pōla
  • {PU 19-9} ampu ceṉṟu iṟutta arum puṇ yāṉi
  • {PU 19-10} tūmpu uṭi taṭam ki vāyoṭu tumintu
  • {PU 19-11} nāñcil oppa nilam mici puraḷa
  • {PU 19-12} eṟintu kaḷam paṭutta ēntu vāḷ valattar
  • {PU 19-13} entiyoṭu kiṭantōr em puṉ tali putalvar
  • {PU 19-14} iṉṉa viṟal um uḷa kol namakku eṉa
  • {PU 19-15} mūtil peṇṭir kacintu aḻa nāṇi
  • {PU 19-16} kūṟṟu kaṇṇōṭiya veruvaru paṟantali
  • {PU 19-17} eḻuvar nal valam kaṭantōy niṉ
  • {PU 19-18} kaḻūu viḷaṅku āram kaviiya mārpu ē
