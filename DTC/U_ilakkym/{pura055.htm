  • {PU 55-1} ōṅku malai peru vil pāmpu ñāṇ koḷīi
  • {PU 55-2} oru kaṇai koṇṭu mū eyil uṭaṟṟi
  • {PU 55-3} peru viṟal amararkku veṉṟi tanta
  • {PU 55-4} kaṟai miṭaṟṟu aṇṇal kāmar ceṉṉi
  • {PU 55-5} piṟai nutal viḷaṅkum oru kaṇ pōla
  • {PU 55-6} vēntu mēmpaṭṭa pūm tār māṟa
  • {PU 55-7} kaṭum ciṉatta kol kaḷiṟu um kataḻ pariya kali mā um
  • {PU 55-8} neṭum koṭiya nimir tēr um neñcu uṭaiya pukal maṟavar um eṉa
  • {PU 55-9} nāṉku uṭaṉ māṇṭatu āyiṉum māṇṭa
  • {PU 55-10} aṟam neṟi mutaṟṟu ē araciṉ koṟṟam
  • {PU 55-11} ataṉāl namar eṉa kōl kōṭātu
  • {PU 55-12} piṟar eṉa kuṇam kollātu
  • {PU 55-13} ñāyiṟṟu aṉṉa ve tiṟal āṇmai um
  • {PU 55-14} tiṅkaḷ aṉṉa taṇ perum cāyal um
  • {PU 55-15} vāṉattu aṉṉa vaṇmai um mūṉṟu um
  • {PU 55-16} uṭaiyai āki illōr kaiyaṟa
  • {PU 55-17} nī nīṭu vāḻiya neṭuntakai tāḻ nīr
  • {PU 55-18} veḷ talai puṇari alaikkum centil
  • {PU 55-19} neṭu vēḷ nilaiiya kāmar viyaṉ tuṟai
  • {PU 55-20} kaṭu vaḷi tokuppa īṇṭiya
  • {PU 55-21} vaṭu āḻ ekkar maṇaliṉum pala ē
