{PUṞAM 224}

  • {PU 224-1} aruppam pēṇātu amar kaṭantatū um
  • {PU 224-2} tuṇi puṇar āyamoṭu tacumpu uṭaṉ tolicci
  • {PU 224-3} irum pāṇ okkal kaṭumpu purantatū um
  • {PU 224-4} aṟam aṟa kaṇṭa neṟi māṇ aviyattu
  • {PU 224-5} muṟi naṟku aṟiyunar muṉṉuṟa pukaḻnta
  • {PU 224-6} tū iyal koḷki tukaḷ aṟu makaḷiroṭu
  • {PU 224-7} paruti uruviṉ pal paṭi purici
  • {PU 224-8} eruvi nukarcci yūpa neṭum tūṇ
  • {PU 224-9} vētam vēḷvi toḻil muṭittatū um
  • {PU 224-10} aṟintōṉ maṉṟa aṟivu uṭiyāḷaṉ
  • {PU 224-11} iṟantōṉ tāṉ ē aḷittu i ulakam
  • {PU 224-12} aruvi māṟi añcuvara karuki
  • {PU 224-13} peru vaṟam kūrnta vēṉil kāli
  • {PU 224-14} pacitta āyattu payaṉ niri tarumār
  • {PU 224-15} pū vāḷ kōvalar pū uṭaṉ utira
  • {PU 224-16} koytu kaṭṭu aḻitta vēṅkiyiṉ
  • {PU 224-17} mel iyal makaḷir um iḻi kaḷintaṉar ē
