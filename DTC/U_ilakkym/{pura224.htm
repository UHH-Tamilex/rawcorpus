  • {PU 224-1} aruppam pēṇātu amar kaṭantatū um
  • {PU 224-2} tuṇai puṇar āyamoṭu tacumpu uṭaṉ tolaicci
  • {PU 224-3} irum pāṇ okkal kaṭumpu purantatū um
  • {PU 224-4} aṟam aṟa kaṇṭa neṟi māṇ avaiyattu
  • {PU 224-5} muṟai naṟku aṟiyunar muṉṉuṟa pukaḻnta
  • {PU 224-6} tū iyal koḷkai tukaḷ aṟu makaḷiroṭu
  • {PU 224-7} paruti uruviṉ pal paṭai puricai
  • {PU 224-8} eruvai nukarcci yūpa neṭum tūṇ
  • {PU 224-9} vētam vēḷvi toḻil muṭittatū um
  • {PU 224-10} aṟintōṉ maṉṟa aṟivu uṭaiyāḷaṉ
  • {PU 224-11} iṟantōṉ tāṉ ē aḷittu i ulakam
  • {PU 224-12} aruvi māṟi añcuvara karuki
  • {PU 224-13} peru vaṟam kūrnta vēṉil kālai
  • {PU 224-14} pacitta āyattu payaṉ nirai tarumār
  • {PU 224-15} pū vāḷ kōvalar pū uṭaṉ utira
  • {PU 224-16} koytu kaṭṭu aḻitta vēṅkaiyiṉ
  • {PU 224-17} mel iyal makaḷir um iḻai kaḷaintaṉar ē
