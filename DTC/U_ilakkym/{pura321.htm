{PUṞAM 321}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 321-1} poṟi puṟam pūḻiṉ pōr val cēval
  • {PU 321-2} mēm tōl kaḷinta tīm kōḷ veḷ eḷ
  • {PU 321-3} cuḷaku iṭi uṇaṅkal cevvi koṇṭu uṭaṉ
  • {PU 321-4} vēṉil kōṅkiṉ pūm pokuṭṭu aṉṉa
  • {PU 321-5} kuṭanti am ceviya kōṭṭu eli āṭṭa
  • {PU 321-6} kali ār varakiṉ piṟaṅku pīḷ oḷikkum
  • {PU 321-7} vaṉpulam vippiṉatu ē ceṉṟu
  • {PU 321-8} tiṉ paḻam pacīi pāṇa
  • {PU 321-9} vāḷ vaṭu viḷaṅkiya ceṉṉi
  • {PU 321-10} ceru ve kurucil ōmpum ūr ē
