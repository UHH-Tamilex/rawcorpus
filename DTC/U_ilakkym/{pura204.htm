{PUṞAM 204}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 204-1} ī eṉa irattal iḻintaṉṟu ataṉ etir
  • {PU 204-2} īyēṉ eṉṟal ataṉiṉum iḻintaṉṟu
  • {PU 204-3} koḷ eṉa koṭuttal uyarntaṉṟu ataṉ etir
  • {PU 204-4} koḷḷēṉ eṉṟal ataṉiṉum uyarntaṉṟu
  • {PU 204-5} teḷ nīr parappiṉ imiḻ tiri perum kaṭal
  • {PU 204-6} uṇṇār ākupa nīr vēṭṭōr ē
  • {PU 204-7} ā um mā um ceṉṟu uṇa kalaṅki
  • {PU 204-8} cēṟṟoṭu paṭṭa ciṟumittu āyiṉum
  • {PU 204-9} uṇ nīr maruṅkiṉ atar pala ākum
  • {PU 204-10} puḷ um poḻutu um paḻittal allati
  • {PU 204-11} uḷḷi ceṉṟōr paḻiyalar ataṉāl
  • {PU 204-12} pulavēṉ vāḻiyar ōri vicumpil
  • {PU 204-13} karuvi vāṉam pōla
  • {PU 204-14} variyātu curakkum vaḷḷiyōy niṉ ē
