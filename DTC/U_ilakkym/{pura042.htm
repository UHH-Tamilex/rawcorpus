{PUṞAM 42}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 42-1} āṉā īkai aṭu pōr aṇṇal niṉ
  • {PU 42-2} yāṉai um malaiyiṉ tōṉṟum peruma niṉ
  • {PU 42-3} tāṉai um kaṭal eṉa muḻaṅkum kūr nuṉai
  • {PU 42-4} vēl um miṉṉiṉ viḷaṅkum ulakattu
  • {PU 42-5} araicu talai paṉikkum āṟṟalai ātaliṉ
  • {PU 42-6} purai tīrntaṉṟu atu putuvatu ō aṉṟu ē
  • {PU 42-7} taṇ puṉal pūcal allatu nontu
  • {PU 42-8} kaḷaika vāḻi vaḷava eṉṟu niṉ
  • {PU 42-9} muṉai taru pūcal kaṉaviṉum aṟiyātu
  • {PU 42-10} puli puṟaṅkākkum kuruḷai pōla
  • {PU 42-11} melivu il ce kōl nī puṟaṅkāppa
  • {PU 42-12} peru viṟal yāṇarttu āki arinar
  • {PU 42-13} kīḻ maṭai koṇṭa vāḷai um uḻavar
  • {PU 42-14} paṭai miḷirntiṭṭa yāmai um aṟainar
  • {PU 42-15} karumpil koṇṭa tēṉ um perum tuṟai
  • {PU 42-16} nīr taru makaḷir kuṟṟa kuvaḷai um
  • {PU 42-17} vaṉpulam kēḷirkku varu viruntu ayarum
  • {PU 42-18} meṉpulam vaippiṉ nal nāṭṭu poruna
  • {PU 42-19} malaiyiṉ iḻintu mā kaṭal nōkki
  • {PU 42-20} nila varai iḻitarum pal yāṟu pōla
  • {PU 42-21} pulavar ellām niṉ nōkkiṉar ē
  • {PU 42-22} nī ē maruntu il kaṇicci varunta vaṭṭittu
  • {PU 42-23} kūṟṟu vekuṇṭaṉṉa muṉpoṭu
  • {PU 42-24} māṟṟu iru vēntar maṇ nōkkiṉai ē
