{PUṞAM 42}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 42-1} āṉā īki aṭu pōr aṇṇal niṉ
  • {PU 42-2} yāṉi um maliyiṉ tōṉṟum peruma niṉ
  • {PU 42-3} tāṉi um kaṭal eṉa muḻaṅkum kūr nuṉi
  • {PU 42-4} vēl um miṉṉiṉ viḷaṅkum ulakattu
  • {PU 42-5} aricu tali paṉikkum āṟṟali ātaliṉ
  • {PU 42-6} puri tīrntaṉṟu atu putuvatu ō aṉṟu ē
  • {PU 42-7} taṇ puṉal pūcal allatu nontu
  • {PU 42-8} kaḷika vāḻi vaḷava eṉṟu niṉ
  • {PU 42-9} muṉi taru pūcal kaṉaviṉum aṟiyātu
  • {PU 42-10} puli puṟaṅkākkum kuruḷi pōla
  • {PU 42-11} melivu il ce kōl nī puṟaṅkāppa
  • {PU 42-12} peru viṟal yāṇarttu āki arinar
  • {PU 42-13} kīḻ maṭi koṇṭa vāḷi um uḻavar
  • {PU 42-14} paṭi miḷirntiṭṭa yāmi um aṟinar
  • {PU 42-15} karumpil koṇṭa tēṉ um perum tuṟi
  • {PU 42-16} nīr taru makaḷir kuṟṟa kuvaḷi um
  • {PU 42-17} vaṉpulam kēḷirkku varu viruntu ayarum
  • {PU 42-18} meṉpulam vippiṉ nal nāṭṭu poruna
  • {PU 42-19} maliyiṉ iḻintu mā kaṭal nōkki
  • {PU 42-20} nila vari iḻitarum pal yāṟu pōla
  • {PU 42-21} pulavar ellām niṉ nōkkiṉar ē
  • {PU 42-22} nī ē maruntu il kaṇicci varunta vaṭṭittu
  • {PU 42-23} kūṟṟu vekuṇṭaṉṉa muṉpoṭu
  • {PU 42-24} māṟṟu iru vēntar maṇ nōkkiṉi ē
