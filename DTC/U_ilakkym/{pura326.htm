{PUṞAM 326}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 326-1} ūr mutu vēli pār naṭi verukiṉ
  • {PU 326-2} iruḷ paki verīiya nāku iḷam pēṭi
  • {PU 326-3} uyir naṭukkuṟṟu pulā viṭṭu araṟṟa
  • {PU 326-4} ciṟi um ceṟṟi um puṭiyunaḷ eḻunta
  • {PU 326-5} parutti peṇṭiṉ ciṟu tī viḷakkattu
  • {PU 326-6} kavir pū neṟṟi cēvaliṉ taṇiyum
  • {PU 326-7} aru miḷi irukkiyatu ē maṉivi um
  • {PU 326-8} vēṭṭa ciṟāar cēṇ pulam paṭarātu
  • {PU 326-9} paṭappi koṇṭa kuṟum tāḷ uṭumpiṉ
  • {PU 326-10} viḻukku niṇam peyta tayir kaṇ vitavi
  • {PU 326-11} yāṇar nallavi pāṇaroṭu orāṅku
  • {PU 326-12} varu viruntu ayarum viruppiṉaḷ kiḻavaṉ um
  • {PU 326-13} arum camam tatiya tākki perum camattu
  • {PU 326-14} aṇṇal yāṉi aṇinta
  • {PU 326-15} poṉ cey ōṭi perum paricilaṉ ē
