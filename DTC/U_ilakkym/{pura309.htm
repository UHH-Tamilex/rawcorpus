{PUṞAM 309}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 309-1} irumpu mukam citiya nūṟi oṉṉār
  • {PU 309-2} irum camam kaṭattal ēṉōrkku um eḷitu ē
  • {PU 309-3} nal arā uṟiyum puṟṟam pōla um
  • {PU 309-4} kol ēṟu tiritaru maṉṟam pōla um
  • {PU 309-5} māṟṟu arum tuppiṉ māṟṟōr pācaṟi
  • {PU 309-6} uḷaṉ eṉa verūum ōr oḷi
  • {PU 309-7} valaṉ uyar neṭu vēl eṉṉi kaṇṇatu ē
