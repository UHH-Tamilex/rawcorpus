{PUṞAM 29}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 29-1} aḻal purinta aṭar tāmari
  • {PU 29-2} aitu aṭarnta nūl peytu
  • {PU 29-3} puṉi vili polinta polaṉ naṟum teriyal
  • {PU 29-4} pāṟu mayir irum tali poliya cūṭi
  • {PU 29-5} pāṇ muṟṟuka niṉ nāḷ makiḻ irukki
  • {PU 29-6} pāṇ muṟṟu oḻinta piṉṟi makaḷir
  • {PU 29-7} tōḷ muṟṟuka niṉ cāntu pular akalam āṅka
  • {PU 29-8} muṉivu il muṟṟattu iṉitu muracu iyampa
  • {PU 29-9} koṭiyōr teṟutal um cevviyōrkku aḷittal um
  • {PU 29-10} oṭiyā muṟiyiṉ maṭivu ili āki
  • {PU 29-11} nallataṉ nalaṉ um tīyataṉ tīmi um
  • {PU 29-12} illi eṉpōrkku iṉaṉ ākiliyar
  • {PU 29-13} nel viḷi kaḻaṉi paṭu puḷ ōppunar
  • {PU 29-14} oḻi maṭal viṟakiṉ kaḻi mīṉ cuṭṭu
  • {PU 29-15} ve kaḷ tolicci um amiyār teṅkiṉ
  • {PU 29-16} iḷanīr utirkkum vaḷam miku nal nāṭu
  • {PU 29-17} peṟṟaṉar uvakkum niṉ paṭikoḷ mākkaḷ
  • {PU 29-18} paṟṟā mākkaḷiṉ parivu muntuṟuttu
  • {PU 29-19} kūvi tuṟṟa nāl kāl pantar
  • {PU 29-20} ciṟu maṉi vāḻkkiyiṉ orīi varunarkku
  • {PU 29-21} utavi āṟṟum naṇpiṉ paṇpu uṭi
  • {PU 29-22} ūḻiṟṟu āka niṉ ceyki viḻavil
  • {PU 29-23} kōṭiyar nīrmi pōla muṟi muṟi
  • {PU 29-24} āṭunar kaḻiyum i ulakattu kūṭiya
  • {PU 29-25} naki puṟaṉ āka niṉ cuṟṟam
  • {PU 29-26} ici puṟaṉ āka nī ōmpiya poruḷ ē
