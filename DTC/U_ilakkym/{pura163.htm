{PUṞAM 163}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 163-1} niṉ nayantu uṟainarkku um nī nayantu uṟainarkku um
  • {PU 163-2} pal māṇ kaṟpiṉ niṉ kiḷai mutalōrkku um
  • {PU 163-3} kaṭumpiṉ kaṭum paci tīra yāḻa niṉ
  • {PU 163-4} neṭum kuṟiyetirppai nalkiyōrkku um
  • {PU 163-5} iṉṉōrkku eṉṉātu eṉṉoṭu um cūḻātu
  • {PU 163-6} vallāṅku vāḻtum eṉṉātu nī um
  • {PU 163-7} ellōrkkum koṭumati maṉai kiḻavōy ē
  • {PU 163-8} paḻam tūṅku mutirattu kiḻavaṉ
  • {PU 163-9} tiruntu vēl kumaṇaṉ nalkiya vaḷaṉ ē
