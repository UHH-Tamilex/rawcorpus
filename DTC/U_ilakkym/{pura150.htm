{PUṞAM 150}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 150-1} kūtir paruntiṉ irum ciṟaku aṉṉa
  • {PU 150-2} pāṟiya citārēṉ palavu mutal porunti
  • {PU 150-3} taṉ um uḷḷēṉ piṟitu pulam paṭarnta eṉ
  • {PU 150-4} uyaṅku paṭar varuttam um ulaivu um nōkki
  • {PU 150-5} māṉ kaṇam tolaicciya kuruti am kaḻal kāl
  • {PU 150-6} vāṉ katir tiru maṇi viḷaṅkum ceṉṉi
  • {PU 150-7} celvam tōṉṟal ōr val vil vēṭṭuvaṉ
  • {PU 150-8} toḻutaṉeṉ eḻu vēl kai kavittu irīi
  • {PU 150-9} iḻutiṉ aṉṉa vāl niṇam koḻum kuṟai
  • {PU 150-10} kāṉ atar mayaṅkiya iḷaiyar vallē
  • {PU 150-11} tām vantu eytā aḷavai oyyeṉa
  • {PU 150-12} tāṉ ñeli tīyiṉ viraivaṉaṉ cuṭṭu niṉ
  • {PU 150-13} irum pēr okkaloṭu tiṉm eṉa tarutaliṉ
  • {PU 150-14} amiḻtiṉ micaintu kāy paci nīṅki
  • {PU 150-15} nal maraṉ naḷiya naṟum taṇ cāral
  • {PU 150-16} kal micai aruvi taṇṇeṉa paruki
  • {PU 150-17} viṭuttal toṭaṅkiṉēṉ āka vallē
  • {PU 150-18} peṟutaṟku ariya vīṟu cāl nal kalam
  • {PU 150-19} piṟitu oṉṟu illai kāṭṭu nāṭṭēm eṉa
  • {PU 150-20} mārpil pūṇṭa vayaṅku kāḻ āram
  • {PU 150-21} maṭai ceṟi muṉkai kaṭakamoṭu īttaṉaṉ
  • {PU 150-22} e nāṭu ō eṉa nāṭu um collāṉ
  • {PU 150-23} yārīr ō eṉa pēr um collāṉ
  • {PU 150-24} piṟar piṟar kūṟa vaḻi kēṭṭiciṉ ē
  • {PU 150-25} irumpu puṉaintu iyaṟṟā perum peyar tōṭṭi
  • {PU 150-26} a malai kākkum aṇi neṭum kuṉṟiṉ
  • {PU 150-27} paḷiṅku vakuttaṉṉa tīm nīr
  • {PU 150-28} naḷi malai nāṭaṉ naḷḷi avaṉ eṉa ē
