{PUṞAM 211}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 211-1} añcu varu marapiṉ ve ciṉam puyal ēṟu
  • {PU 211-2} aṇaṅku uṭai araviṉ arum talai tumiya
  • {PU 211-3} niṉṟu kāṇpaṉṉa nīḷ malai miḷira
  • {PU 211-4} kuṉṟu tūva eṟiyum aravam pōla
  • {PU 211-5} muracu eḻuntu iraṅkum tāṉaiyoṭu talai ceṉṟu
  • {PU 211-6} araicu paṭa kaṭakkum urai cāl tōṉṟal niṉ
  • {PU 211-7} uḷḷi vanta ōṅku nilai paricileṉ
  • {PU 211-8} vaḷḷiyai ātaliṉ vaṇaṅkuvaṉ ivaṉ eṉa
  • {PU 211-9} koḷḷā māntar koṭumai kūṟa niṉ
  • {PU 211-10} uḷḷiyatu muṭittōy maṉṟa muṉ nāḷ
  • {PU 211-11} kai uḷḷatu pōl kāṭṭi vaḻi nāḷ
  • {PU 211-12} poyyoṭu niṉṟa puṟanilai varuttam
  • {PU 211-13} nāṇāy āyiṉum nāṇa kūṟi eṉ
  • {PU 211-14} nuṇaṅku ce nā aṇaṅka ētti
  • {PU 211-15} pāṭa pāṭa pāṭu pukaḻ koṇṭa niṉ
  • {PU 211-16} āṭu koḷ viyaṉ mārpu toḻutaṉeṉ paḻicci
  • {PU 211-17} celval attai yāṉ ē vaikal um
  • {PU 211-18} valci iṉmaiyiṉ vayiṉ vayiṉ māṟi
  • {PU 211-19} il eli maṭinta tol cuvar varaippiṉ
  • {PU 211-20} pāal iṉmaiyiṉ pal pāṭu cuvaittu
  • {PU 211-21} mulaikkōḷ maṟanta putalvaṉoṭu
  • {PU 211-22} maṉai tolaintirunta eṉ vāḷ nutal paṭarntu ē
