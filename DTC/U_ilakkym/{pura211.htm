{PUṞAM 211}

  • {PU 211-1} añcu varu marapiṉ ve ciṉam puyal ēṟu
  • {PU 211-2} aṇaṅku uṭi araviṉ arum tali tumiya
  • {PU 211-3} niṉṟu kāṇpaṉṉa nīḷ mali miḷira
  • {PU 211-4} kuṉṟu tūva eṟiyum aravam pōla
  • {PU 211-5} muracu eḻuntu iraṅkum tāṉiyoṭu tali ceṉṟu
  • {PU 211-6} aricu paṭa kaṭakkum uri cāl tōṉṟal niṉ
  • {PU 211-7} uḷḷi vanta ōṅku nili paricileṉ
  • {PU 211-8} vaḷḷiyi ātaliṉ vaṇaṅkuvaṉ ivaṉ eṉa
  • {PU 211-9} koḷḷā māntar koṭumi kūṟa niṉ
  • {PU 211-10} uḷḷiyatu muṭittōy maṉṟa muṉ nāḷ
  • {PU 211-11} ki uḷḷatu pōl kāṭṭi vaḻi nāḷ
  • {PU 211-12} poyyoṭu niṉṟa puṟanili varuttam
  • {PU 211-13} nāṇāy āyiṉum nāṇa kūṟi eṉ
  • {PU 211-14} nuṇaṅku ce nā aṇaṅka ētti
  • {PU 211-15} pāṭa pāṭa pāṭu pukaḻ koṇṭa niṉ
  • {PU 211-16} āṭu koḷ viyaṉ mārpu toḻutaṉeṉ paḻicci
  • {PU 211-17} celval atti yāṉ ē vikal um
  • {PU 211-18} valci iṉmiyiṉ vayiṉ vayiṉ māṟi
  • {PU 211-19} il eli maṭinta tol cuvar varippiṉ
  • {PU 211-20} pāal iṉmiyiṉ pal pāṭu cuvittu
  • {PU 211-21} mulikkōḷ maṟanta putalvaṉoṭu
  • {PU 211-22} maṉi tolintirunta eṉ vāḷ nutal paṭarntu ē
