{PUṞAM 174}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 174-1} aṇaṅku uṭai avuṇar kaṇam koṇṭu oḷitteṉa
  • {PU 174-2} cēṇ viḷaṅku ciṟappiṉ ñāyiṟu kāṇātu
  • {PU 174-3} iruḷ kaṇ keṭutta paruti ñālattu
  • {PU 174-4} iṭumpai koḷ paruvaral tīra kaṭum tiṟal
  • {PU 174-5} añcaṉam uruvaṉ tantu niṟuttāṅku
  • {PU 174-6} aracu iḻantirunta allal kālai
  • {PU 174-7} muracu eḻuntu iraṅkum muṟṟamoṭu karai porutu
  • {PU 174-8} iraṅku puṉal neri taru miku perum kāviri
  • {PU 174-9} mallal nal nāṭṭu allal tīra
  • {PU 174-10} poyyā nāviṉ kapilaṉ pāṭiya
  • {PU 174-11} mai aṇi neṭu varai āṅkaṇ oyyeṉa
  • {PU 174-12} ceru pukal maṟavar cel puṟaṅkaṇṭa
  • {PU 174-13} eḷ aṟu ciṟappiṉ muḷḷūr mīmicai
  • {PU 174-14} aru vaḻi irunta peru viṟal vaḷavaṉ
  • {PU 174-15} mati maruḷ veḷ kuṭai kāṭṭi a kuṭai
  • {PU 174-16} putumaiyiṉ niṟutta pukaḻ mēmpaṭuna
  • {PU 174-17} viṭar puli poṟitta kōṭṭai cuṭar pūṇ
  • {PU 174-18} curumpu ār kaṇṇi perum peyar num muṉ
  • {PU 174-19} īṇṭu cey nal viṉai āṇṭu ceṉṟu uṇīiyar
  • {PU 174-20} uyarntōr ulakattu peyarntaṉaṉ ākaliṉ
  • {PU 174-21} āṟu kol maruṅkiṉ mātiram tuḻavum
  • {PU 174-22} kavalai neñcattu avalam tīra
  • {PU 174-23} nī tōṉṟiṉai ē nirai tār aṇṇal
  • {PU 174-24} kal kaṇ poṭiya kāṉam vempa
  • {PU 174-25} malku nīr varaippiṉ kayam pala uṇaṅka
  • {PU 174-26} kōṭai nīṭiya paitu aṟu kālai
  • {PU 174-27} iru nilam neḷiya īṇṭi
  • {PU 174-28} urum uraṟu karuviya maḻai poḻintāṅku ē
