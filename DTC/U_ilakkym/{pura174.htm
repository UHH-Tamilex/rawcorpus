{PUṞAM 174}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 174-1} aṇaṅku uṭi avuṇar kaṇam koṇṭu oḷitteṉa
  • {PU 174-2} cēṇ viḷaṅku ciṟappiṉ ñāyiṟu kāṇātu
  • {PU 174-3} iruḷ kaṇ keṭutta paruti ñālattu
  • {PU 174-4} iṭumpi koḷ paruvaral tīra kaṭum tiṟal
  • {PU 174-5} añcaṉam uruvaṉ tantu niṟuttāṅku
  • {PU 174-6} aracu iḻantirunta allal kāli
  • {PU 174-7} muracu eḻuntu iraṅkum muṟṟamoṭu kari porutu
  • {PU 174-8} iraṅku puṉal neri taru miku perum kāviri
  • {PU 174-9} mallal nal nāṭṭu allal tīra
  • {PU 174-10} poyyā nāviṉ kapilaṉ pāṭiya
  • {PU 174-11} mi aṇi neṭu vari āṅkaṇ oyyeṉa
  • {PU 174-12} ceru pukal maṟavar cel puṟaṅkaṇṭa
  • {PU 174-13} eḷ aṟu ciṟappiṉ muḷḷūr mīmici
  • {PU 174-14} aru vaḻi irunta peru viṟal vaḷavaṉ
  • {PU 174-15} mati maruḷ veḷ kuṭi kāṭṭi a kuṭi
  • {PU 174-16} putumiyiṉ niṟutta pukaḻ mēmpaṭuna
  • {PU 174-17} viṭar puli poṟitta kōṭṭi cuṭar pūṇ
  • {PU 174-18} curumpu ār kaṇṇi perum peyar num muṉ
  • {PU 174-19} īṇṭu cey nal viṉi āṇṭu ceṉṟu uṇīiyar
  • {PU 174-20} uyarntōr ulakattu peyarntaṉaṉ ākaliṉ
  • {PU 174-21} āṟu kol maruṅkiṉ mātiram tuḻavum
  • {PU 174-22} kavali neñcattu avalam tīra
  • {PU 174-23} nī tōṉṟiṉi ē niri tār aṇṇal
  • {PU 174-24} kal kaṇ poṭiya kāṉam vempa
  • {PU 174-25} malku nīr varippiṉ kayam pala uṇaṅka
  • {PU 174-26} kōṭi nīṭiya pitu aṟu kāli
  • {PU 174-27} iru nilam neḷiya īṇṭi
  • {PU 174-28} urum uraṟu karuviya maḻi poḻintāṅku ē
