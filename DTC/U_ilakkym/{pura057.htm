{PUṞAM 57}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 57-1} vallār āyiṉum vallunar āyiṉum
  • {PU 57-2} pukaḻtal uṟṟōrkku māyōṉ aṉṉa
  • {PU 57-3} urai cāl ciṟappiṉ pukaḻ cāl māṟa
  • {PU 57-4} niṉ oṉṟu kūṟuvatu uṭaiyēṉ eṉ eṉiṉ
  • {PU 57-5} nī ē piṟar nāṭu koḷḷum kālai avar nāṭṭu
  • {PU 57-6} iṟaṅku katir kaḻaṉi niṉ iḷaiyar um kavarka
  • {PU 57-7} naṉam talai pēr ūr eri um naikka
  • {PU 57-8} miṉṉu nimirntaṉṉa niṉ oḷiṟu ilaṅku neṭu vēl
  • {PU 57-9} oṉṉār cekuppiṉum cekukka eṉṉatūum
  • {PU 57-10} kaṭimaram taṭital ōmpu niṉ
  • {PU 57-11} neṭu nal yāṉaikku kantu āṟṟā ē
