{PUṞAM 41}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 41-1} kālaṉ um kālam pārkkum pārātu
  • {PU 41-2} vēl īṇṭu tāṉai viḻumiyōr tolaiya
  • {PU 41-3} vēṇṭu iṭattu aṭūum vel pōr vēntu ē
  • {PU 41-4} ticai iru nāṉku um uṟkam uṟka um
  • {PU 41-5} peru marattu ilai il neṭum kōṭu vaṟṟal paṟṟa um
  • {PU 41-6} ve katir kaṉali tuṟṟa um piṟa um
  • {PU 41-7} añcuvara takuna puḷḷu kural iyampa um
  • {PU 41-8} eyiṟu nilattu vīḻa um eṇṇey āṭa um
  • {PU 41-9} kaḷiṟu mēl koḷḷa um kāḻakam nīppa um
  • {PU 41-10} veḷḷi nōṉ paṭai kaṭṭiloṭu kaviḻa um
  • {PU 41-11} kaṉaviṉ ariyaṉa kāṇā naṉavil
  • {PU 41-12} ceru cey muṉpa niṉ varu tiṟaṉ nōkki
  • {PU 41-13} maiyal koṇṭa ēmam il irukkaiyar
  • {PU 41-14} putalvar pūm kaṇ mutti maṉaiyōṭku
  • {PU 41-15} evvam karakkum paital mākkaḷoṭu
  • {PU 41-16} perum kalakkuṟṟaṉṟu āl tāṉ ē kāṟṟōṭu
  • {PU 41-17} eri nikaḻntaṉṉa celaviṉ
  • {PU 41-18} ceru miku vaḷava niṉ ciṉaiiyōr nāṭu ē
