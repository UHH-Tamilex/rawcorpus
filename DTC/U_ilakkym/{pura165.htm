{PUṞAM 165}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 165-1} maṉṉā ulakattu maṉṉutal kuṟittōr
  • {PU 165-2} tam pukaḻ niṟīi tām māyntaṉar ē
  • {PU 165-3} tuṉ arum ciṟappiṉ uyarnta celvar
  • {PU 165-4} iṉmiyiṉ irappōrkku īiyāmiyiṉ
  • {PU 165-5} toṉmi mākkaḷiṉ toṭarpu aṟiyalar ē
  • {PU 165-6} tāḷ tāḻ paṭu maṇi iraṭṭum pū nutal
  • {PU 165-7} āṭu iyal yāṉi pāṭunarkku arukā
  • {PU 165-8} kēṭu il nal ici vaya māṉ tōṉṟali
  • {PU 165-9} pāṭi niṉṟaṉeṉ āka koṉ ē
  • {PU 165-10} pāṭu peṟu paricilaṉ vāṭiṉaṉ peyartal eṉ
  • {PU 165-11} nāṭu iḻantataṉiṉum naṉi iṉṉātu eṉa
  • {PU 165-12} vāḷ tantaṉaṉ ē tali eṉakku īya
  • {PU 165-13} taṉṉiṉ ciṟantatu piṟitu oṉṟu iṉmiyiṉ
  • {PU 165-14} āṭu mali uvakiyoṭu varuval
  • {PU 165-15} ōṭā pūṭki niṉ kiḻamiyōṉ kaṇṭu ē
