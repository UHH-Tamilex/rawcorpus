{PUṞAM 266}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 266-1} payam keḻu mā maḻai peyyātu māṟi
  • {PU 266-2} kayam kaḷi muḷiyum kōṭai āyiṉum
  • {PU 266-3} puḻal kāl āmpal akal aṭai nīḻal
  • {PU 266-4} katir kōṭṭu nantiṉ curi mukam ēṟṟai
  • {PU 266-5} nāku iḷa vaḷaiyoṭu pakal maṇam pukūum
  • {PU 266-6} nīr tikaḻ kaḻaṉi nāṭu keḻu peru viṟal
  • {PU 266-7} vāṉ tōy nīḷ kuṭai vaya māṉ ceṉṉi
  • {PU 266-8} cāṉṟōr irunta avaiyattu uṟṟōṉ
  • {PU 266-9} ācu āku eṉṉum pūcal pōla
  • {PU 266-10} vallē kaḷaimati attai uḷḷiya
  • {PU 266-11} viruntu kaṇṭu oḷikkum tiruntā vāḻkkai
  • {PU 266-12} poṟi puṇar uṭampil tōṉṟi eṉ
  • {PU 266-13} aṟivu keṭa niṉṟa nalkūrmai ē
