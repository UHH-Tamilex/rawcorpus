{PUṞAM 266}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 266-1} payam keḻu mā maḻi peyyātu māṟi
  • {PU 266-2} kayam kaḷi muḷiyum kōṭi āyiṉum
  • {PU 266-3} puḻal kāl āmpal akal aṭi nīḻal
  • {PU 266-4} katir kōṭṭu nantiṉ curi mukam ēṟṟi
  • {PU 266-5} nāku iḷa vaḷiyoṭu pakal maṇam pukūum
  • {PU 266-6} nīr tikaḻ kaḻaṉi nāṭu keḻu peru viṟal
  • {PU 266-7} vāṉ tōy nīḷ kuṭi vaya māṉ ceṉṉi
  • {PU 266-8} cāṉṟōr irunta aviyattu uṟṟōṉ
  • {PU 266-9} ācu āku eṉṉum pūcal pōla
  • {PU 266-10} vallē kaḷimati atti uḷḷiya
  • {PU 266-11} viruntu kaṇṭu oḷikkum tiruntā vāḻkki
  • {PU 266-12} poṟi puṇar uṭampil tōṉṟi eṉ
  • {PU 266-13} aṟivu keṭa niṉṟa nalkūrmi ē
