{PUṞAM 236}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 236-1} kalai uṇa kiḻinta muḻavu maruḷ perum paḻam
  • {PU 236-2} cilai keḻu kuṟavarkku alku micaivu ākum
  • {PU 236-3} malai keḻu nāṭa mā vaṇ pāri
  • {PU 236-4} kalanta kēṇmaikku ovvāy nī eṉ
  • {PU 236-5} pulantaṉai ākuvai puranta āṇṭu ē
  • {PU 236-6} perum taku ciṟappiṉ naṭpiṟku ollātu
  • {PU 236-7} oruṅku varal viṭātu oḻika eṉa kūṟi
  • {PU 236-8} iṉaiyai ātaliṉ niṉakku maṟṟu yāṉ
  • {PU 236-9} mēyiṉēṉ aṉmaiyāṉ ē āyiṉum
  • {PU 236-10} immai pōla kāṭṭi ummai
  • {PU 236-11} iṭai il kāṭci niṉṉōṭu
  • {PU 236-12} uṭaṉ uṟaivu ākkuka uyarnta pāl ē
