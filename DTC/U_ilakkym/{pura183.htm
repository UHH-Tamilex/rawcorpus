{PUṞAM 183}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 183-1} uṟṟuḻi utavi um uṟu poruḷ koṭuttu um
  • {PU 183-2} piṟṟi nili muṉiyātu kaṟṟal naṉṟu ē
  • {PU 183-3} piṟappu ōraṉṉa uṭaṉ vayiṟṟu uḷ um
  • {PU 183-4} ciṟappiṉ pālāl tāy um maṉam tiriyum
  • {PU 183-5} oru kuṭi piṟanta pallōr uḷ um
  • {PU 183-6} mūttōṉ varuka eṉṉātu avar uḷ
  • {PU 183-7} aṟivu uṭiyōṉ āṟu aracu um cellum
  • {PU 183-8} vēṟṟumi terinta nāṟpāl uḷ um
  • {PU 183-9} kīḻ pāl oruvaṉ kaṟpiṉ
  • {PU 183-10} mēl pāl oruvaṉ um avaṉ kaṇ paṭum ē
