  • {PU 198-1} aruvi tāḻnta peru varai pōla
  • {PU 198-2} āramoṭu polinta mārpil taṇṭā
  • {PU 198-3} kaṭavuḷ cāṉṟa kaṟpiṉ cē iḻai
  • {PU 198-4} maṭavōḷ payanta maṇi maruḷ a vāy
  • {PU 198-5} kiṇkiṇi putalvar polika eṉṟu ētti
  • {PU 198-6} tiṇ tēr aṇṇal niṉ pārāṭṭi
  • {PU 198-7} kātal perumaiyiṉ kaṉaviṉum araṟṟum eṉ
  • {PU 198-8} kāmar neñcam ēmāntu uvappa
  • {PU 198-9} āl amar kaṭavuḷ aṉṉa niṉ celvam
  • {PU 198-10} vēl keḻu kurucil kaṇṭēṉ ātaliṉ
  • {PU 198-11} viṭuttaṉeṉ vāḻka niṉ kaṇṇi toṭutta
  • {PU 198-12} taṇ tamiḻ varaippu akam koṇṭi āka
  • {PU 198-13} paṉittu kūṭṭu uṇṇum taṇippu arum kaṭum tiṟal
  • {PU 198-14} niṉ ōraṉṉa niṉ putalvar eṉṟum
  • {PU 198-15} oṉṉār vāṭa arum kalam tantu num
  • {PU 198-16} poṉ uṭai neṭu nakar niṟaiya vaitta niṉ
  • {PU 198-17} muṉṉōr pōlka ivar perum kaṇṇōṭṭam
  • {PU 198-18} yāṇṭu um nāḷ um peruki īṇṭu tirai
  • {PU 198-19} perum kaṭal nīriṉum a kaṭal maṇaliṉum
  • {PU 198-20} nīṇṭu uyar vāṉattu uṟaiyiṉum naṉṟu um
  • {PU 198-21} ivar peṟum putalvar kāṇtoṟum nī um
  • {PU 198-22} pukaṉṟa celvamoṭu pukaḻ iṉitu viḷaṅki
  • {PU 198-23} nīṭu vāḻiya neṭuntakai yāṉ um
  • {PU 198-24} kēḷ il cēey nāṭṭiṉ e nāḷ um
  • {PU 198-25} tuḷi nacai puḷḷiṉ niṉ aḷi nacaikku iraṅki niṉ
  • {PU 198-26} aṭi niḻal paḻakiya aṭiyuṟai
  • {PU 198-27} kaṭu māṉ māṟa maṟavātīm ē
