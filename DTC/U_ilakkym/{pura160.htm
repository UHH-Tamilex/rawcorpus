{PUṞAM 160}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 160-1} uru keḻu ñāyiṟṟu oḷ katir micainta
  • {PU 160-2} muḷi pul kāṉam kuḻaippa kalleṉa
  • {PU 160-3} atir kural ēṟoṭu tuḷi corintāṅku
  • {PU 160-4} paci tiṉa tiraṅkiya kacivu uṭai yākkai
  • {PU 160-5} aviḻ pukuvu aṟiyātu ākaliṉ vāṭiya
  • {PU 160-6} neṟi koḷ vari kuṭar kuḷippa taṇṇeṉa
  • {PU 160-7} kuy koḷ koḻum tuvai ney uṭai aṭicil
  • {PU 160-8} mati cēr nāḷmīṉ pōla naviṉṟa
  • {PU 160-9} ciṟu poṉ nal kalam cuṟṟa irīi
  • {PU 160-10} kēṭu iṉṟu āka paṭunar kaṭumpu eṉa
  • {PU 160-11} aritu peṟu polam kalam eḷitiṉiṉ vīci
  • {PU 160-12} naṭṭōr naṭṭa nal icai kumaṇaṉ
  • {PU 160-13} maṭṭu ār maṟukiṉ mutirattōṉ ē
  • {PU 160-14} celkuvai āyiṉ nalkuvaṉ peritu eṉa
  • {PU 160-15} pal pukaḻ nuvalunar kūṟa val viraintu
  • {PU 160-16} uḷḷam turappa vantaṉeṉ eḷḷuṟṟu
  • {PU 160-17} il uṇā tuṟattaliṉ il maṟantu uṟaiyum
  • {PU 160-18} pul uḷai kuṭumi putalvaṉ pal māṇ
  • {PU 160-19} pāl il vaṟu mulai cuvaittaṉaṉ peṟāaṉ
  • {PU 160-20} kūḻ um cōṟu um kaṭaii ūḻiṉ
  • {PU 160-21} uḷ il vaṟum kalam tiṟantu aḻa kaṇṭu
  • {PU 160-22} maṟam puli uraittu um matiyam kāṭṭi um
  • {PU 160-23} nontaṉaḷ āki nuntaiyai uḷḷi
  • {PU 160-24} poṭinta niṉ cevvi kāṭṭu eṉa pala um
  • {PU 160-25} viṉaval āṉāḷ āki naṉaviṉ
  • {PU 160-26} allal uḻappōḷ mallal ciṟappa
  • {PU 160-27} cellā celvam mikuttaṉai vallē
  • {PU 160-28} viṭutal vēṇṭuval attai paṭu tirai
  • {PU 160-29} nīr cūḻ nila varai uyara niṉ
  • {PU 160-30} cīr keḻu viḻu pukaḻ ēttukam pala ē
