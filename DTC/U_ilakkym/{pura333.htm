{PUṞAM 333}

  • {PU 333-1} nīr uḷ paṭṭa māri pēr uṟi
  • {PU 333-2} mokkuḷ aṉṉa pokuṭṭu viḻi kaṇṇa
  • {PU 333-3} karum piṭar taliya perum cevi kuṟu muyal
  • {PU 333-4} uḷ ūr kuṟum putal tuḷḷuvaṉa ukaḷum
  • {PU 333-5} toḷḷi maṉṟattu āṅkaṇ paṭariṉ
  • {PU 333-6} uṇka eṉa uṇarā uyaviṟṟu āyiṉum
  • {PU 333-7} taṅkiṉir ceṉmō pulavir naṉṟu um
  • {PU 333-8} ceṉṟataṉ koṇṭu maṉiyōḷ virumpi
  • {PU 333-9} varaku um tiṉi um uḷḷavi ellām
  • {PU 333-10} iraval mākkaḷ uṇa koḷa tīrnteṉa
  • {PU 333-11} kuṟittu māṟu etirppi peṟāamiyiṉ
  • {PU 333-12} kural uṇaṅku viti tiṉi ural vāy peytu
  • {PU 333-13} ciṟitu puṟappaṭṭaṉṟu ō ilaḷ ē taṉ ūr
  • {PU 333-14} vēṭṭam kuṭi toṟum kūṭṭu
  • {PU 333-15} uṭumpu cey
  • {PU 333-16} pāṇi neṭum tēr vallarōṭu ūrā
  • {PU 333-17} vampu aṇi yāṉi vēntu tali variṉum
  • {PU 333-18} uṇpatu maṉṉum atu ē
  • {PU 333-19} paricil maṉṉum kurucil koṇṭatu ē
