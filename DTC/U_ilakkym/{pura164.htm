{PUṞAM 164}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 164-1} āṭu naṉi maṟanta kōṭu uyar aṭuppiṉ
  • {PU 164-2} āmpi pūppa tēmpu paci uḻavā
  • {PU 164-3} pāal iṉmaiyiṉ tōloṭu tiraṅki
  • {PU 164-4} illi tūrnta pollā vaṟu mulai
  • {PU 164-5} cuvaittoṟu aḻūum taṉ makattu mukam nōkki
  • {PU 164-6} nīroṭu niṟainta īr itaḻ maḻai kaṇ eṉ
  • {PU 164-7} maṉaiyōḷ evvam nōkki niṉaii
  • {PU 164-8} niṉ paṭarnticiṉ ē nal pōr kumaṇa
  • {PU 164-9} eṉ nilai aṟintaṉai āyiṉ i nilai
  • {PU 164-10} toṭuttu um koḷḷātu amaiyaleṉ aṭukkiya
  • {PU 164-11} paṇ amai narampiṉ paccai nal yāḻ
  • {PU 164-12} maṇ amai muḻaviṉ vayiriyar
  • {PU 164-13} iṉmai tīrkkum kuṭi piṟantōy ē
