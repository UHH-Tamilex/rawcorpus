  • {PU 342-1} kāṉa kākkai kali ciṟaku ēykkum
  • {PU 342-2} mayilai kaṇṇi perum tōḷ kuṟumakaḷ
  • {PU 342-3} ēṉōr makaḷ kol ivaḷ eṉa vituppuṟṟu
  • {PU 342-4} eṉṉoṭu viṉavum veṉ vēl neṭuntakai
  • {PU 342-5} tiru nayattakka paṇpiṉ ivaḷ nalaṉ ē
  • {PU 342-6} porunarkku allatu piṟarkku ākātu ē
  • {PU 342-7} paim kāl kokkiṉ paku vāy piḷḷai
  • {PU 342-8} mel cēṟṟu aṭai karai mēyntu uṇṭataṉ piṉ
  • {PU 342-9} āral īṉṟa aiyavi muṭṭai
  • {PU 342-10} kūr nal iṟaviṉ piḷḷaiyoṭu peṟūum
  • {PU 342-11} taṇ paṇai kiḻavaṉ ivaḷ tantai um vēntar um
  • {PU 342-12} peṟāamaiyiṉ pēr amar ceytaliṉ
  • {PU 342-13} kaḻi piṇam piṟaṅku pōrpu aḻi kaḷiṟu erutu ā
  • {PU 342-14} vāḷ taka vaikal um uḻakkum
  • {PU 342-15} māṭciyavar ivaḷ taṉṉaimār ē
