{PUṞAM 4}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 4-1} vāḷ valam tara maṟu paṭṭaṉa
  • {PU 4-2} ce vāṉattu vaṉappu pōṉṟaṉa
  • {PU 4-3} tāḷ kaḷam koḷa kaḻal paṟintaṉa
  • {PU 4-4} kol ēṟṟiṉ maruppu pōṉṟaṉa
  • {PU 4-5} tōl tuvittu ampiṉ tuḷi tōṉṟuva
  • {PU 4-6} nilikku orāa ilakkam pōṉṟaṉa
  • {PU 4-7} mā ē eṟi patattāṉ iṭam kāṭṭa
  • {PU 4-8} kaṟuḻ poruta ce vāyāṉ
  • {PU 4-9} eruttu vavviya puli pōṉṟaṉa
  • {PU 4-10} kaḷiṟu katavu eṟiyā civantu urāay
  • {PU 4-11} nuti maḻuṅkiya veḷ kōṭṭāṉ
  • {PU 4-12} uyir uṇṇum kūṟṟu pōṉṟaṉa
  • {PU 4-13} nī ē alaṅku uḷi parīi ivuḷi
  • {PU 4-14} polam tēr mici polivu tōṉṟi
  • {PU 4-15} mā kaṭal nivantu eḻutarum
  • {PU 4-16} ce ñāyiṟṟu kaviṉi mātō
  • {PU 4-17} aṉiyi ākal māṟu ē
  • {PU 4-18} tāy il tūvā kuḻavi pōla
  • {PU 4-19} ōvātu kūum niṉ uṭaṟṟiyōr nāṭu ē
