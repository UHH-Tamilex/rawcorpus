{PUṞAM 113}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 113-1} maṭṭu vāy tiṟappa um mai viṭai vīḻppa um
  • {PU 113-2} aṭṭu āṉṟu āṉā koḻum tuvai ūṉ cōṟu um
  • {PU 113-3} peṭṭāṅku īyum peru vaḷam paḻuṉi
  • {PU 113-4} naṭṭaṉai maṉ ō muṉ ē iṉi ē
  • {PU 113-5} pāri māynteṉa kalaṅki kaiyaṟṟu
  • {PU 113-6} nīr vār kaṇṇēm toḻutu niṉ paḻicci
  • {PU 113-7} cēṟum vāḻi ō perum peyar paṟampu ē
  • {PU 113-8} kōl tiraḷ muṉkai kuṟum toṭi makaḷir
  • {PU 113-9} nāṟu irum kūntal kiḻavarai paṭarntu ē
