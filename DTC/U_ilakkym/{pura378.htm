{PUṞAM 378}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 378-1} teṉ paratavar miṭal cāya
  • {PU 378-2} vaṭa vaṭukar vāḷ ōṭṭiya
  • {PU 378-3} toṭai amai kaṇṇi tiruntu vēl taṭam kai
  • {PU 378-4} kaṭu mā kaṭaiiya viṭu pari vaṭimpiṉ
  • {PU 378-5} nal tār kaḷḷiṉ cōḻaṉ kōyil
  • {PU 378-6} putu piṟai aṉṉa cutai cēy māṭattu
  • {PU 378-7} paṉi kayattu aṉṉa nīḷ nakar niṉṟu eṉ
  • {PU 378-8} ari kūṭu mā kiṇai iriya oṟṟi
  • {PU 378-9} eñcā marapiṉ vañci pāṭa
  • {PU 378-10} emakku eṉa vakutta alla mika pala
  • {PU 378-11} mēmpaṭu ciṟappiṉ arum kala veṟukkai
  • {PU 378-12} tāṅkātu poḻitantōṉ ē atu kaṇṭu
  • {PU 378-13} ilampāṭu uḻanta eṉ irum pēr okkal
  • {PU 378-14} viral ceṟi marapiṉa cevi toṭakkunar um
  • {PU 378-15} cevi toṭar marapiṉa viral ceṟikkunar um
  • {PU 378-16} araikku amai marapiṉa miṭaṟṟu yākkunar um
  • {PU 378-17} miṭaṟṟu amai marapiṉa araikku yākkunar um
  • {PU 378-18} kaṭum teṟal irāmaṉ uṭaṉ puṇar cītaiyai
  • {PU 378-19} vali takai arakkaṉ vauviya ñāṉṟai
  • {PU 378-20} nilam cēr matar aṇi kaṇṭa kuraṅkiṉ
  • {PU 378-21} ce mukam perum kiḷai iḻai polintāaṅku
  • {PU 378-22} aṟāa aru nakai iṉitu peṟṟikum ē
  • {PU 378-23} irum kiḷai talaimai eyti
  • {PU 378-24} arum paṭar evvam uḻantataṉ talai ē
