  • {PU 54-1} em kōṉ irunta kampalai mūtūr
  • {PU 54-2} uṭaiyōr pōla iṭai iṉṟu kuṟuki
  • {PU 54-3} cemmal nāḷavai aṇṇāntu pukutal
  • {PU 54-4} em aṉa vāḻkkai iravalarkku eḷitu ē
  • {PU 54-5} iravalarkku eṇmai allatu puravu etirntu
  • {PU 54-6} vāṉam nāṇa varaiyātu ceṉṟōrkku
  • {PU 54-7} āṉātu īyum kavi kai vaṇmai
  • {PU 54-8} kaṭu māṉ kōtai tuppu etirntu eḻunta
  • {PU 54-9} neṭumoḻi maṉṉar niṉaikkum kālai
  • {PU 54-10} pācu ilai toṭutta uvalai kaṇṇi
  • {PU 54-11} mācu uṇ uṭukkai maṭi vāy iṭaiyaṉ
  • {PU 54-12} ciṟu talai āyamoṭu kuṟukal cellā
  • {PU 54-13} puli tuñcu viyaṉ pulattu aṟṟu ē
  • {PU 54-14} vali tuñcu taṭam kai avaṉ uṭai nāṭu ē
