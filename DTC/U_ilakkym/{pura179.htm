{PUṞAM 179}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 179-1} ñāla mīmici vaḷḷiyōr māynteṉa
  • {PU 179-2} ēlātu kaviḻnta eṉ iraval maṇṭi
  • {PU 179-3} malarppōr yār eṉa viṉavaliṉ malintōr
  • {PU 179-4} vici piṇi muracamoṭu maṇ pala tanta
  • {PU 179-5} tiru vīḻ nuṇ pūṇ pāṇṭiyaṉ maṟavaṉ
  • {PU 179-6} paṭi vēṇṭuvaḻi vāḷ utavi um
  • {PU 179-7} viṉi vēṇṭuvaḻi aṟivu utavi um
  • {PU 179-8} vēṇṭupa vēṇṭupa vēntaṉ tēettu
  • {PU 179-9} aci nukam paṭāa āṇtaki uḷḷattu
  • {PU 179-10} tōlā nal ici nāli kiḻavaṉ
  • {PU 179-11} paruntu paci tīrkkum nal pōr
  • {PU 179-12} tiruntu vēl nākaṉ kūṟiṉar palar ē
