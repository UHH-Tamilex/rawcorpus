{PUṞAM 179}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 179-1} ñāla mīmicai vaḷḷiyōr māynteṉa
  • {PU 179-2} ēlātu kaviḻnta eṉ iraval maṇṭai
  • {PU 179-3} malarppōr yār eṉa viṉavaliṉ malaintōr
  • {PU 179-4} vici piṇi muracamoṭu maṇ pala tanta
  • {PU 179-5} tiru vīḻ nuṇ pūṇ pāṇṭiyaṉ maṟavaṉ
  • {PU 179-6} paṭai vēṇṭuvaḻi vāḷ utavi um
  • {PU 179-7} viṉai vēṇṭuvaḻi aṟivu utavi um
  • {PU 179-8} vēṇṭupa vēṇṭupa vēntaṉ tēettu
  • {PU 179-9} acai nukam paṭāa āṇtakai uḷḷattu
  • {PU 179-10} tōlā nal icai nālai kiḻavaṉ
  • {PU 179-11} paruntu paci tīrkkum nal pōr
  • {PU 179-12} tiruntu vēl nākaṉ kūṟiṉar palar ē
