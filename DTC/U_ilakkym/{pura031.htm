{PUṞAM 31}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 31-1} ciṟappu uṭai marapiṉ poruḷ um iṉpam um
  • {PU 31-2} aṟattu vaḻippaṭūum tōṟṟam pōla
  • {PU 31-3} iru kuṭai piṉ paṭa ōṅkiya oru kuṭai
  • {PU 31-4} uru keḻu matiyiṉ nivantu cēṇ viḷaṅka
  • {PU 31-5} nal icai vēṭṭam vēṇṭi vel pōr
  • {PU 31-6} pācaṟai allatu nī ollāy ē
  • {PU 31-7} nuti mukam maḻuṅka maṇṭi oṉṉār
  • {PU 31-8} kaṭi matil pāyum niṉ kaḷiṟu aṭaṅkala ē
  • {PU 31-9} pōr eṉiṉ pukalum puṉai kaḻal maṟavar
  • {PU 31-10} kāṭu iṭai kiṭanta nāṭu naṉi cēeya
  • {PU 31-11} celvēm allēm eṉṉār kalleṉ
  • {PU 31-12} viḻavu uṭai āṅkaṇ vēṟṟu pulattu iṟuttu
  • {PU 31-13} kuṇa kaṭal piṉṉatu āka kuṭa kaṭal
  • {PU 31-14} veḷ talai puṇari niṉ māṉ kuḷampu alaippa
  • {PU 31-15} vala muṟai varutal um uṇṭu eṉṟu alamantu
  • {PU 31-16} neñcu naṭuṅku avalam pāya
  • {PU 31-17} tuñcā kaṇṇa vaṭa pulattu aracu ē
