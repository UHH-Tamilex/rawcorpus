{PUṞAM 116}

((Last updated on 2004 April 14th))

  • {PU 116-1} tīm nīr perum kuṇṭu cuṉi pūtta kuvaḷi
  • {PU 116-2} kūmpu aviḻ muḻu neṟi puraḷ varum alkul
  • {PU 116-3} ēntu eḻil maḻi kaṇ iṉ naki makaḷir
  • {PU 116-4} pul mūcu kavaliya muḷ miṭi vēli
  • {PU 116-5} pañci muṉṟil ciṟṟil āṅkaṇ
  • {PU 116-6} pīri nāṟiya curi ivar maruṅkiṉ
  • {PU 116-7} īttu ili kuppi ēri umaṇar
  • {PU 116-8} uppu oy oḻuki eṇṇupa mātō
  • {PU 116-9} nōku ō yāṉ ē tēykamā kāli
  • {PU 116-10} payil pūm cōli mayil eḻuntu āla um
  • {PU 116-11} payil irum cilampil kali pāyntu ukaḷa um
  • {PU 116-12} kali um koḷḷā āka pala um
  • {PU 116-13} kālam aṉṟi um maram payam pakarum
  • {PU 116-14} yāṇar aṟāa viyal mali aṟṟu ē
  • {PU 116-15} aṇṇal neṭu vari ēṟi tanti
  • {PU 116-16} periya naṟaviṉ kūr vēl pāriyatu
  • {PU 116-17} arumi aṟiyār pōr etirntu vanta
  • {PU 116-18} valam paṭu tāṉi vēntar
  • {PU 116-19} polam paṭi kali mā eṇṇuvōr ē
