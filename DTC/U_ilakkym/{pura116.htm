{PUṞAM 116}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 116-1} tīm nīr perum kuṇṭu cuṉai pūtta kuvaḷai
  • {PU 116-2} kūmpu aviḻ muḻu neṟi puraḷ varum alkul
  • {PU 116-3} ēntu eḻil maḻai kaṇ iṉ nakai makaḷir
  • {PU 116-4} pul mūcu kavalaiya muḷ miṭai vēli
  • {PU 116-5} pañci muṉṟil ciṟṟil āṅkaṇ
  • {PU 116-6} pīrai nāṟiya curai ivar maruṅkiṉ
  • {PU 116-7} īttu ilai kuppai ēri umaṇar
  • {PU 116-8} uppu oy oḻukai eṇṇupa mātō
  • {PU 116-9} nōku ō yāṉ ē tēykamā kālai
  • {PU 116-10} payil pūm cōlai mayil eḻuntu āla um
  • {PU 116-11} payil irum cilampil kalai pāyntu ukaḷa um
  • {PU 116-12} kalai um koḷḷā āka pala um
  • {PU 116-13} kālam aṉṟi um maram payam pakarum
  • {PU 116-14} yāṇar aṟāa viyal malai aṟṟu ē
  • {PU 116-15} aṇṇal neṭu varai ēṟi tantai
  • {PU 116-16} periya naṟaviṉ kūr vēl pāriyatu
  • {PU 116-17} arumai aṟiyār pōr etirntu vanta
  • {PU 116-18} valam paṭu tāṉai vēntar
  • {PU 116-19} polam paṭai kali mā eṇṇuvōr ē
