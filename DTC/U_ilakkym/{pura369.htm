{PUṞAM 369}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 369-1} iruppu mukam ceṟitta ēntu eḻil maruppiṉ
  • {PU 369-2} karum kai yāṉai koṇmū āka
  • {PU 369-3} nīḷ moḻi maṟavar eṟivaṉar uyartta
  • {PU 369-4} vāḷ miṉ āka vayaṅku kaṭippu amainta
  • {PU 369-5} kuruti paliya muracu muḻakku āka
  • {PU 369-6} aracu arā paṉikkum aṇaṅku uṟu poḻutiṉ
  • {PU 369-7} ve vicai puravi vīcu vaḷi āka
  • {PU 369-8} vicaippuṟu val vil vīṅku nāṇ ukaitta
  • {PU 369-9} kaṇai tuḷi poḻinta kaṇ akal kiṭakkai
  • {PU 369-10} īram ceṟu vayiṉ tēr ēr āka
  • {PU 369-11} viṭiyal pukku neṭiya nīṭṭi niṉ
  • {PU 369-12} ceru paṭai miḷirnta tiruttuṟu paim cāl
  • {PU 369-13} piṭittu eṟi veḷ vēl kaṇaiyamoṭu vitti
  • {PU 369-14} viḻu talai cāytta veruvaru paim kūḻ
  • {PU 369-15} pēymakaḷ paṟṟiya piṇam piṟaṅku pal pōrpu
  • {PU 369-16} kaṇa nariyōṭu kaḻutu kaḷam paṭuppa
  • {PU 369-17} pūtam kāppa polikaḷam taḻīi
  • {PU 369-18} pāṭunarkku irunta pīṭu uṭaiyāḷa
  • {PU 369-19} tēyvai veḷ kāḻ puraiyum vici piṇi
  • {PU 369-20} vēyvai kāṇā viruntiṉ pōrvai
  • {PU 369-21} ari kural taṭāri uruppa oṟṟi
  • {PU 369-22} pāṭi vanticiṉ peruma pāṭu āṉṟu
  • {PU 369-23} eḻili tōyum imiḻ icai aruvi
  • {PU 369-24} poṉ uṭai neṭum kōṭṭu imaiyattu aṉṉa
  • {PU 369-25} ōṭai nutala olkutal aṟiyā
  • {PU 369-26} tuṭi aṭi kuḻaviya piṭi iṭai miṭainta
  • {PU 369-27} vēḻa mukavai nalkumati
  • {PU 369-28} tāḻā īkai takai veyyōy ē
