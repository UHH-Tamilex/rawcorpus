{PUṞAM 369}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 369-1} iruppu mukam ceṟitta ēntu eḻil maruppiṉ
  • {PU 369-2} karum ki yāṉi koṇmū āka
  • {PU 369-3} nīḷ moḻi maṟavar eṟivaṉar uyartta
  • {PU 369-4} vāḷ miṉ āka vayaṅku kaṭippu aminta
  • {PU 369-5} kuruti paliya muracu muḻakku āka
  • {PU 369-6} aracu arā paṉikkum aṇaṅku uṟu poḻutiṉ
  • {PU 369-7} ve vici puravi vīcu vaḷi āka
  • {PU 369-8} vicippuṟu val vil vīṅku nāṇ ukitta
  • {PU 369-9} kaṇi tuḷi poḻinta kaṇ akal kiṭakki
  • {PU 369-10} īram ceṟu vayiṉ tēr ēr āka
  • {PU 369-11} viṭiyal pukku neṭiya nīṭṭi niṉ
  • {PU 369-12} ceru paṭi miḷirnta tiruttuṟu pim cāl
  • {PU 369-13} piṭittu eṟi veḷ vēl kaṇiyamoṭu vitti
  • {PU 369-14} viḻu tali cāytta veruvaru pim kūḻ
  • {PU 369-15} pēymakaḷ paṟṟiya piṇam piṟaṅku pal pōrpu
  • {PU 369-16} kaṇa nariyōṭu kaḻutu kaḷam paṭuppa
  • {PU 369-17} pūtam kāppa polikaḷam taḻīi
  • {PU 369-18} pāṭunarkku irunta pīṭu uṭiyāḷa
  • {PU 369-19} tēyvi veḷ kāḻ puriyum vici piṇi
  • {PU 369-20} vēyvi kāṇā viruntiṉ pōrvi
  • {PU 369-21} ari kural taṭāri uruppa oṟṟi
  • {PU 369-22} pāṭi vanticiṉ peruma pāṭu āṉṟu
  • {PU 369-23} eḻili tōyum imiḻ ici aruvi
  • {PU 369-24} poṉ uṭi neṭum kōṭṭu imiyattu aṉṉa
  • {PU 369-25} ōṭi nutala olkutal aṟiyā
  • {PU 369-26} tuṭi aṭi kuḻaviya piṭi iṭi miṭinta
  • {PU 369-27} vēḻa mukavi nalkumati
  • {PU 369-28} tāḻā īki taki veyyōy ē
