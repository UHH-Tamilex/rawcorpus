{PUṞAM 394}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 394-1} cilai ulāy nimirnta cāntu paṭu mārpiṉ
  • {PU 394-2} oli katir kaḻaṉi veḷ kuṭai kiḻavōṉ
  • {PU 394-3} vali tuñcu taṭam kai vāy vāḷ kuṭṭuvaṉ
  • {PU 394-4} vaḷḷiyaṉ ātal vaiyakam pukaḻiṉum
  • {PU 394-5} uḷḷal ōmpumiṉ uyar moḻi pulavīr
  • {PU 394-6} yāṉ um iruḷ nilā kaḻinta pakal cey vaikaṟai
  • {PU 394-7} oru kaṇ mā kiṇai teḷirppa oṟṟi
  • {PU 394-8} pāṭu imiḻ muraciṉ iyal tēr tantai
  • {PU 394-9} vāṭā vañci pāṭiṉēṉ āka
  • {PU 394-10} akam mali uvakaiyoṭu aṇukal vēṇṭi
  • {PU 394-11} koṉṟu ciṉam taṇiyā pulavu nāṟu maruppiṉ
  • {PU 394-12} ve ciṉam vēḻam nalkiṉaṉ añci
  • {PU 394-13} yāṉ atu peyarttaṉeṉ āka tāṉ atu
  • {PU 394-14} ciṟitu eṉa uṇarntamai nāṇi piṟitu um ōr
  • {PU 394-15} perum kaḷiṟu nalkiyōṉ ē ataṉ koṇṭu
  • {PU 394-16} irum pēr okkal perum pulampuṟiṉum
  • {PU 394-17} tuṉ arum paricil tarum eṉa
  • {PU 394-18} eṉṟum cellēṉ avaṉ kuṉṟu keḻu nāṭṭu ē
