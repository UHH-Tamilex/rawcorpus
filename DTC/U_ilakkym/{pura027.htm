{PUṞAM 27}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 27-1} cēṟṟu vaḷar tāmarai payanta oḷ kēḻ
  • {PU 27-2} nūṟṟu itaḻ alariṉ kaṇṭaṉṉa
  • {PU 27-3} vēṟṟumai illā viḻu tiṇai piṟantu
  • {PU 27-4} vīṟṟiruntōrai eṇṇum kālai
  • {PU 27-5} urai um pāṭṭu um uṭaiyōr cilar ē
  • {PU 27-6} marai ilai pōla māynticiṉōr palar ē
  • {PU 27-7} pulavar pāṭum pukaḻ uṭaiyōr vicumpiṉ
  • {PU 27-8} valavaṉ ēvā vāṉa ūrti
  • {PU 27-9} eytupa eṉpa tam cey viṉai muṭittu eṉa
  • {PU 27-10} kēṭpal entai cēṭceṉṉi nalaṅkiḷḷi
  • {PU 27-11} tēytal uṇmai um perukal uṇmai um
  • {PU 27-12} māytal uṇmai um piṟattal uṇmai um
  • {PU 27-13} aṟiyātōrai um aṟiya kāṭṭi
  • {PU 27-14} tiṅkaḷ puttēḷ tiritarum ulakattu
  • {PU 27-15} vallār āyiṉum vallunar āyiṉum
  • {PU 27-16} varunti vantōr maruṅku nōkki
  • {PU 27-17} aruḷa vallai ākumati aruḷ ilar
  • {PU 27-18} koṭāamai vallar ākuka
  • {PU 27-19} keṭāata tuppiṉ niṉ pakai etirntōr ē
