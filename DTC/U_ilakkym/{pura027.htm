{PUṞAM 27}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 27-1} cēṟṟu vaḷar tāmari payanta oḷ kēḻ
  • {PU 27-2} nūṟṟu itaḻ alariṉ kaṇṭaṉṉa
  • {PU 27-3} vēṟṟumi illā viḻu tiṇi piṟantu
  • {PU 27-4} vīṟṟiruntōri eṇṇum kāli
  • {PU 27-5} uri um pāṭṭu um uṭiyōr cilar ē
  • {PU 27-6} mari ili pōla māynticiṉōr palar ē
  • {PU 27-7} pulavar pāṭum pukaḻ uṭiyōr vicumpiṉ
  • {PU 27-8} valavaṉ ēvā vāṉa ūrti
  • {PU 27-9} eytupa eṉpa tam cey viṉi muṭittu eṉa
  • {PU 27-10} kēṭpal enti cēṭceṉṉi nalaṅkiḷḷi
  • {PU 27-11} tēytal uṇmi um perukal uṇmi um
  • {PU 27-12} māytal uṇmi um piṟattal uṇmi um
  • {PU 27-13} aṟiyātōri um aṟiya kāṭṭi
  • {PU 27-14} tiṅkaḷ puttēḷ tiritarum ulakattu
  • {PU 27-15} vallār āyiṉum vallunar āyiṉum
  • {PU 27-16} varunti vantōr maruṅku nōkki
  • {PU 27-17} aruḷa valli ākumati aruḷ ilar
  • {PU 27-18} koṭāami vallar ākuka
  • {PU 27-19} keṭāata tuppiṉ niṉ paki etirntōr ē
