{PUṞAM 58}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 58-1} nī ē taṇ puṉal kāviri kiḻavaṉai ivaṉ ē
  • {PU 58-2} muḻu mutal tolainta kōḷi ālattu
  • {PU 58-3} koḻu niḻal neṭum ciṉai vīḻ poṟuttāṅku
  • {PU 58-4} tollōr māynteṉa tuḷaṅkal cellātu
  • {PU 58-5} nal icai mutu kuṭi naṭukku aṟa taḻīi
  • {PU 58-6} iḷaiyatu āyiṉum kiḷai arā eṟiyum
  • {PU 58-7} aru narai urumiṉ porunarai poṟāa
  • {PU 58-8} ceru māṇ pañcavar ēṟu ē nī ē
  • {PU 58-9} aṟam tuñcu uṟantai porunaṉ ai ivaṉ ē
  • {PU 58-10} nel um nīr um ellārkkum eḷiya eṉa
  • {PU 58-11} varaiya cāntam um tiraiya muttam um
  • {PU 58-12} imiḻ kural muracam mūṉṟu uṭaṉ āḷum
  • {PU 58-13} tamiḻ keḻu kūṭal taṇ kōl vēntu ē
  • {PU 58-14} pāl niṟam uruviṉ paṉai koṭiyōṉ um
  • {PU 58-15} nīl niṟam uruviṉ nēmiyōṉ um eṉṟu
  • {PU 58-16} iru perum teyvam um uṭaṉ niṉṟāaṅku
  • {PU 58-17} uru keḻu tōṟṟamoṭu uṭkuvara viḷaṅki
  • {PU 58-18} iṉṉīr ākaliṉ iṉiya um uḷa ō
  • {PU 58-19} iṉṉum kēṇmiṉ num icai vāḻiya ē
  • {PU 58-20} oruvīr oruvīrkku āṟṟutir iruvīr um
  • {PU 58-21} uṭaṉ nilai tiriyīr āyiṉ imiḻ tirai
  • {PU 58-22} pauvam uṭutta i payam keḻu mā nilam
  • {PU 58-23} kaiyakappaṭuvatu poy ākātu ē
  • {PU 58-24} ataṉāl nalla pōla um nayava pōla um
  • {PU 58-25} tollōr ceṉṟa neṟiya pōla um
  • {PU 58-26} kātal neñciṉ num iṭai pukaṟku alamarum
  • {PU 58-27} ētil mākkaḷ potumoḻi koḷḷātu
  • {PU 58-28} iṉṟu ē pōlka num puṇarcci veṉṟu veṉṟu
  • {PU 58-29} aṭu kaḷattu uyarka num vēl ē koṭu vari
  • {PU 58-30} kōṇmā kuyiṉṟa cēṇ viḷaṅku toṭu poṟi
  • {PU 58-31} neṭu nīr keṇṭaiyoṭu poṟitta
  • {PU 58-32} kuṭumiya āka piṟar kuṉṟu keḻu nāṭu ē
