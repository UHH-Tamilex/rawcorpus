  • {PU 20-1} iru munnīr kuṭṭam um
  • {PU 20-2} viyal ñālattu akalam um
  • {PU 20-3} vaḷi vaḻaṅku tici um
  • {PU 20-4} vaṟitu niliiya kāyam um eṉṟāṅku
  • {PU 20-5} avi aḷantu aṟiyiṉum aḷattaṟku ariyi
  • {PU 20-6} aṟivu um īram um perum kaṇṇōṭṭam um
  • {PU 20-7} cōṟu paṭukkum tīyōṭu
  • {PU 20-8} ce ñāyiṟṟu teṟal allatu
  • {PU 20-9} piṟitu teṟal aṟiyār niṉ niḻal vāḻvōr ē
  • {PU 20-10} tiruvil allatu koli vil aṟiyār
  • {PU 20-11} nāñcil allatu paṭi um aṟiyār
  • {PU 20-12} tiṟaṉ aṟi vayavaroṭu tevvar tēya a
  • {PU 20-13} piṟar maṇ uṇṇum cemmal niṉ nāṭṭu
  • {PU 20-14} vayavuṟu makaḷir vēṭṭu uṇiṉ allatu
  • {PU 20-15} pakivar uṇṇā aru maṇṇiṉi ē
  • {PU 20-16} ampu tuñcum kaṭi araṇāl
  • {PU 20-17} aṟam tuñcum ce kōli ē
  • {PU 20-18} putu puḷ variṉum paḻam puḷ pōkiṉum
  • {PU 20-19} vituppuṟavu aṟiyā ēma kāppiṉi
  • {PU 20-20} aṉiyi ākal māṟu ē
  • {PU 20-21} maṉ uyir ellām niṉ añcum ē
