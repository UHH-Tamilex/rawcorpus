{PUṞAM 243}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 243-1} iṉi niṉintu irakkam ākiṉṟu tiṇi maṇal
  • {PU 243-2} ceyvuṟu pāvikku koy pū tii
  • {PU 243-3} taṇ kayam āṭum makaḷiroṭu ki piṇintu
  • {PU 243-4} taḻuvu vaḻi taḻīi tūṅkuvaḻi tūṅki
  • {PU 243-5} maṟi eṉal aṟiyā māyam il āyamoṭu
  • {PU 243-6} uyar ciṉi maruta tuṟi uṟa tāḻntu
  • {PU 243-7} nīr naṇi paṭi kōṭu ēṟi cīr mika
  • {PU 243-8} kariyavar maruḷa tiri akam pitira
  • {PU 243-9} neṭu nīr kuṭṭattu tuṭumeṉa pāyntu
  • {PU 243-10} kuḷittu maṇal koṇṭa kallā iḷami
  • {PU 243-11} aḷitu ō tāṉ ē yāṇṭu uṇṭu kol ō
  • {PU 243-12} toṭi tali viḻu taṇṭu ūṉṟi naṭukkuṟṟu
  • {PU 243-13} irum iṭi miṭinta cila col
  • {PU 243-14} peru mūtāḷarēm ākiya emakku ē
