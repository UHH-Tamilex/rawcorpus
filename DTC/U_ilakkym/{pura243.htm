{PUṞAM 243}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 243-1} iṉi niṉaintu irakkam ākiṉṟu tiṇi maṇal
  • {PU 243-2} ceyvuṟu pāvaikku koy pū taii
  • {PU 243-3} taṇ kayam āṭum makaḷiroṭu kai piṇaintu
  • {PU 243-4} taḻuvu vaḻi taḻīi tūṅkuvaḻi tūṅki
  • {PU 243-5} maṟai eṉal aṟiyā māyam il āyamoṭu
  • {PU 243-6} uyar ciṉai maruta tuṟai uṟa tāḻntu
  • {PU 243-7} nīr naṇi paṭi kōṭu ēṟi cīr mika
  • {PU 243-8} karaiyavar maruḷa tirai akam pitira
  • {PU 243-9} neṭu nīr kuṭṭattu tuṭumeṉa pāyntu
  • {PU 243-10} kuḷittu maṇal koṇṭa kallā iḷamai
  • {PU 243-11} aḷitu ō tāṉ ē yāṇṭu uṇṭu kol ō
  • {PU 243-12} toṭi talai viḻu taṇṭu ūṉṟi naṭukkuṟṟu
  • {PU 243-13} irum iṭai miṭainta cila col
  • {PU 243-14} peru mūtāḷarēm ākiya emakku ē
