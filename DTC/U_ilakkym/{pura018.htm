{PUṞAM 18}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 18-1} muḻaṅku munnīr muḻutu um vaḷiip
  • {PU 18-2} parantupaṭṭa viyal ñālam
  • {PU 18-3} tāḷiṉ tantu tam pukaḻ niṟīi
  • {PU 18-4} oru tām ākiya uravōr umpal
  • {PU 18-5} oṉṟu pattu aṭukkiya kōṭi kaṭi irīiya
  • {PU 18-6} perumittu āka niṉ āyuḷ tāṉ ē
  • {PU 18-7} nīr tāḻnta kuṟum kāñci
  • {PU 18-8} pū katūum iṉa vāḷi
  • {PU 18-9} nuṇ āral paru varāl
  • {PU 18-10} kurūu keṭiṟṟa kuṇṭu akaḻi
  • {PU 18-11} vāṉ uṭkum vaṭi nīḷ matil
  • {PU 18-12} mallal mūtūr vaya vēntu ē
  • {PU 18-13} cellum ulakattu celvam vēṇṭiṉum
  • {PU 18-14} ñālam kāvalar tōḷ vali murukki
  • {PU 18-15} oru nī ākal vēṇṭiṉum ciṟanta
  • {PU 18-16} nal ici niṟuttal vēṇṭiṉum maṟṟu ataṉ
  • {PU 18-17} takuti kēḷ iṉi mikutiyāḷa
  • {PU 18-18} nīr iṉṟu amiyā yākkikku ellām
  • {PU 18-19} uṇṭi koṭuttōr uyir koṭuttōr ē
  • {PU 18-20} uṇṭi mutaṟṟu ē uṇaviṉ piṇṭam
  • {PU 18-21} uṇavu eṉappaṭuvatu nilattoṭu nīr ē
  • {PU 18-22} nīr um nilaṉ um puṇariyōr īṇṭu
  • {PU 18-23} uṭampu um uyir um paṭitticiṉōr ē
  • {PU 18-24} vitti vāṉ nōkkum puṉpulam kaṇ akal
  • {PU 18-25} vippiṟṟu āyiṉum naṇṇi āḷum
  • {PU 18-26} iṟivaṉ tāṭku utavātu ē ataṉāl
  • {PU 18-27} aṭu pōr ceḻiya ikaḻātu vallē
  • {PU 18-28} nilaṉ neḷi maruṅkil nīrnili peruka
  • {PU 18-29} taṭṭōr amma ivaṇ taṭṭōr ē
  • {PU 18-30} taḷḷātōr ivaṇ taḷḷātōr ē
