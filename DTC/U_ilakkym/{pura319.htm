{PUṞAM 319}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 319-1} pūval paṭuvil kūval tōṇṭiya
  • {PU 319-2} ce kaṇ cil nīr peyta cīṟil
  • {PU 319-3} muṉṟil irunta mutu vāy cāṭi
  • {PU 319-4} yām kaḵṭu uṇṭeṉa vaṟitu mācu iṉṟu
  • {PU 319-5} paṭalai muṉṟil ciṟu tiṉai uṇaṅkal
  • {PU 319-6} puṟavu um ital um aṟa um uṇka eṉa
  • {PU 319-7} peytaṟku elliṉṟu poḻutu ē ataṉāṉ
  • {PU 319-8} muyal cuṭṭa āyiṉum tarukuvēm pukutantu
  • {PU 319-9} īṅku iruntīm ō mutu vāy pāṇa
  • {PU 319-10} koṭum kōṭṭu āmāṉ naṭuṅku talai kuḻavi
  • {PU 319-11} puṉ talai ciṟāar kaṉṟu eṉa pūṭṭum
  • {PU 319-12} cīṟūr maṉṉaṉ nerunai ñāṅkar
  • {PU 319-13} vēntu viṭu toḻiloṭu ceṉṟaṉaṉ vantu niṉ
  • {PU 319-14} pāṭiṉi mālai aṇiya
  • {PU 319-15} vāṭā tāmarai cūṭṭuvaṉ niṉakku ē
