{PUṞAM 325}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 325-1} kaḷiṟu nīṟu āṭiya viṭu nilam maruṅkiṉ
  • {PU 325-2} vampa perum peyal varaintu corintu iṟanteṉa
  • {PU 325-3} kuḻi koḷ cil nīr kurāal uṇṭaliṉ
  • {PU 325-4} cēṟu kiḷaittiṭṭa kaluḻ kaṇ ūṟal
  • {PU 325-5} muṟaiyiṉ uṇṇum niṟaiyā vāḻkkai
  • {PU 325-6} muḷavu mā tolaicciya muḻu col āṭavar
  • {PU 325-7} uṭumpu iḻutu aṟutta oṭu kāḻ paṭalai
  • {PU 325-8} cīṟil muṉṟil kūṟu ceytiṭumār
  • {PU 325-9} koḷḷi vaitta koḻu niṇam nāṟṟam
  • {PU 325-10} maṟuku uṭaṉ kamaḻum matukai maṉṟattu
  • {PU 325-11} alam talai iratti alaṅku paṭu nīḻal
  • {PU 325-12} kayam talai ciṟāar kaṇai viḷaiyāṭum
  • {PU 325-13} aru miḷai irukkaiyatu ē veṉ vēl
  • {PU 325-14} vēntu talai variṉum tāṅkum
  • {PU 325-15} tāṅkā īkai neṭuntakai ūr ē
