{PUṞAM 78}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 78-1} vaṇaṅku toṭi polinta vali keḻu nōṉ tāḷ
  • {PU 78-2} aṇaṅku arum kaṭum tiṟal eṉṉi muṇaṅku nimirntu
  • {PU 78-3} aḷi ceṟi uḻuvi irikku vantaṉṉa
  • {PU 78-4} malippu arum akalam matiyār cilittu eḻuntu
  • {PU 78-5} viḻumiyam periyam yām ē nammiṉ
  • {PU 78-6} porunaṉ um iḷiyaṉ koṇṭi um peritu eṉa
  • {PU 78-7} eḷḷi vanta vampa maḷḷar
  • {PU 78-8} pulleṉ kaṇṇar puṟattil peyara
  • {PU 78-9} īṇṭu avar aṭutal um ollāṉ āṇṭu avar
  • {PU 78-10} māṇ iḻi makaḷir nāṇiṉar kaḻiya
  • {PU 78-11} tanti tam ūr āṅkaṇ
  • {PU 78-12} teḷ kiṇi kaṟaṅka ceṉṟu āṇṭu aṭṭaṉaṉ ē
