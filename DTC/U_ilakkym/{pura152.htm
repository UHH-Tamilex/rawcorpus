{PUṞAM 152}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 152-1} vēḻam vīḻatta viḻu toṭai pakaḻi
  • {PU 152-2} pēḻ vāy uḻuvaiyai perumpiṟitu uṟīi
  • {PU 152-3} puḻal talai pukar kalai uruṭṭi ural talai
  • {PU 152-4} kēḻal paṉṟi vīḻa ayalatu
  • {PU 152-5} āḻal puṟṟattu uṭumpil ceṟṟum
  • {PU 152-6} val vil vēṭṭam valam paṭuttu iruntōṉ
  • {PU 152-7} pukaḻ cāl ciṟappiṉ ampu mika tiḷaikkum
  • {PU 152-8} kolaivaṉ yār kol ō kolaivaṉ maṟṟu ivaṉ
  • {PU 152-9} vilaivaṉ pōlāṉ veṟukkai naṉku uṭaiyaṉ
  • {PU 152-10} āram tāḻnta am pakaṭṭu mārpiṉ
  • {PU 152-11} cāral aruvi paya malai kiḻavaṉ
  • {PU 152-12} ōri kol ō allaṉ kol ō
  • {PU 152-13} pāṭuval viṟali ōr vaṇṇam nīr um
  • {PU 152-14} maṇ muḻā amaimiṉ paṇ yāḻ niṟumiṉ
  • {PU 152-15} kaṇ viṭu tūmpiṉ kaḷiṟṟu uyir toṭumiṉ
  • {PU 152-16} ellari toṭumiṉ ākuḷi toṭumiṉ
  • {PU 152-17} patalai oru kaṇ paiyeṉa iyakkumiṉ
  • {PU 152-18} matalai mā kōl kaivalam tamiṉ eṉṟu
  • {PU 152-19} iṟaivaṉ ākaliṉ collupu kuṟuki
  • {PU 152-20} mū ēḻ tuṟai um muṟai uḷi kaḻippi
  • {PU 152-21} kō eṉa peyariya kālai āṅku atu
  • {PU 152-22} taṉ peyar ākaliṉ nāṇi maṟṟu yām
  • {PU 152-23} nāṭṭu iṭaṉ nāṭṭu iṭaṉ varutum īṅku ōr
  • {PU 152-24} vēṭṭuvar illai niṉ oppōr eṉa
  • {PU 152-25} vēṭṭatu moḻiya um viṭāaṉ vēṭṭattil
  • {PU 152-26} tāṉ uyir cekutta māṉ niṇam puḻukkōṭu
  • {PU 152-27} āṉ urukku aṉṉa vēriyai nalki
  • {PU 152-28} taṉ malai piṟanta tā il nal poṉ
  • {PU 152-29} pal maṇi kuvaiyoṭu um viraii koṇm eṉa
  • {PU 152-30} curattu iṭai nalkiyōṉ ē viṭar cimai
  • {PU 152-31} ōṅku irum kolli porunaṉ
  • {PU 152-32} ōmpā īkai viṟal veyyōṉ ē
