{PUṞAM 152}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 152-1} vēḻam vīḻatta viḻu toṭi pakaḻi
  • {PU 152-2} pēḻ vāy uḻuviyi perumpiṟitu uṟīi
  • {PU 152-3} puḻal tali pukar kali uruṭṭi ural tali
  • {PU 152-4} kēḻal paṉṟi vīḻa ayalatu
  • {PU 152-5} āḻal puṟṟattu uṭumpil ceṟṟum
  • {PU 152-6} val vil vēṭṭam valam paṭuttu iruntōṉ
  • {PU 152-7} pukaḻ cāl ciṟappiṉ ampu mika tiḷikkum
  • {PU 152-8} kolivaṉ yār kol ō kolivaṉ maṟṟu ivaṉ
  • {PU 152-9} vilivaṉ pōlāṉ veṟukki naṉku uṭiyaṉ
  • {PU 152-10} āram tāḻnta am pakaṭṭu mārpiṉ
  • {PU 152-11} cāral aruvi paya mali kiḻavaṉ
  • {PU 152-12} ōri kol ō allaṉ kol ō
  • {PU 152-13} pāṭuval viṟali ōr vaṇṇam nīr um
  • {PU 152-14} maṇ muḻā amimiṉ paṇ yāḻ niṟumiṉ
  • {PU 152-15} kaṇ viṭu tūmpiṉ kaḷiṟṟu uyir toṭumiṉ
  • {PU 152-16} ellari toṭumiṉ ākuḷi toṭumiṉ
  • {PU 152-17} patali oru kaṇ piyeṉa iyakkumiṉ
  • {PU 152-18} matali mā kōl kivalam tamiṉ eṉṟu
  • {PU 152-19} iṟivaṉ ākaliṉ collupu kuṟuki
  • {PU 152-20} mū ēḻ tuṟi um muṟi uḷi kaḻippi
  • {PU 152-21} kō eṉa peyariya kāli āṅku atu
  • {PU 152-22} taṉ peyar ākaliṉ nāṇi maṟṟu yām
  • {PU 152-23} nāṭṭu iṭaṉ nāṭṭu iṭaṉ varutum īṅku ōr
  • {PU 152-24} vēṭṭuvar illi niṉ oppōr eṉa
  • {PU 152-25} vēṭṭatu moḻiya um viṭāaṉ vēṭṭattil
  • {PU 152-26} tāṉ uyir cekutta māṉ niṇam puḻukkōṭu
  • {PU 152-27} āṉ urukku aṉṉa vēriyi nalki
  • {PU 152-28} taṉ mali piṟanta tā il nal poṉ
  • {PU 152-29} pal maṇi kuviyoṭu um virii koṇm eṉa
  • {PU 152-30} curattu iṭi nalkiyōṉ ē viṭar cimi
  • {PU 152-31} ōṅku irum kolli porunaṉ
  • {PU 152-32} ōmpā īki viṟal veyyōṉ ē
