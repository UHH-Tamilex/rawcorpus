{PUṞAM 109}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 109-1} aḷitu ō tāṉ ē pāriyatu paṟampu ē
  • {PU 109-2} naḷi koḷ muraciṉ mūvir um muṟṟiṉum
  • {PU 109-3} uḻavar uḻātaṉa nāṉku payaṉ uṭittu ē
  • {PU 109-4} oṉṟu ē ciṟu ili vetiriṉ nel viḷiyum ē
  • {PU 109-5} iraṇṭu ē tīm cuḷi palaviṉ paḻam ūḻkkum ē
  • {PU 109-6} mūṉṟu ē koḻum koṭi vaḷḷi kiḻaṅku vīḻkkum ē
  • {PU 109-7} nāṉku ē aṇi niṟam ōri pāytaliṉ mītu aḻintu
  • {PU 109-8} tiṇi neṭum kuṉṟam tēṉ coriyum ē
  • {PU 109-9} vāṉ kaṇ aṟṟu avaṉ mali ē vāṉattu
  • {PU 109-10} mīṉ kaṇ aṟṟu ataṉ cuṉi ē āṅku
  • {PU 109-11} maram toṟum piṇitta kaḷiṟṟiṉir āyiṉum
  • {PU 109-12} pulam toṟum parappiya tēriṉir āyiṉum
  • {PU 109-13} tāḷiṉ koḷḷalir vāḷiṉ tāralaṉ
  • {PU 109-14} yāṉ aṟikuveṉ atu koḷḷum āṟu ē
  • {PU 109-15} cukir puri naṟampiṉ cīṟu yāḻ paṇṇi
  • {PU 109-16} viri oli kūntal num viṟaliyar piṉ vara
  • {PU 109-17} āṭiṉir pāṭiṉir celiṉ ē
  • {PU 109-18} nāṭu um kuṉṟu um oruṅku īyum ē
