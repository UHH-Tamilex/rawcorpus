  • {PU 390-1} aṟavai neñcattu āyar vaḷarum
  • {PU 390-2} maṟavai neñcattu āyivāḷar
  • {PU 390-3} arumpu alar cerunti neṭum kāl malar kamaḻ
  • {PU 390-4} aṉṉa muṟṟattu
  • {PU 390-5} ārvalar kuṟukiṉ allatu kāvalar
  • {PU 390-6} kaṉaviṉum kuṟukā kaṭi uṭai viyal nakar
  • {PU 390-7} malai kaṇattu aṉṉa māṭam cilampa eṉ
  • {PU 390-8} ari kural taṭāri iriya oṟṟi
  • {PU 390-9} pāṭi niṉṟa pal nāḷ aṉṟi um
  • {PU 390-10} ceṉṟa ñāṉṟai ceṉṟu paṭar iraviṉ
  • {PU 390-11} vantataṉ koṇṭu neṭum kaṭai niṉṟa
  • {PU 390-12} puṉ talai porunaṉ aḷiyaṉ tāṉ eṉa
  • {PU 390-13} taṉ uḻai kuṟukal vēṇṭi eṉ arai
  • {PU 390-14} mutu nīr pāci aṉṉa uṭai kaḷaintu
  • {PU 390-15} tiru malar aṉṉa putu maṭi koḷīi
  • {PU 390-16} makiḻ taral marapiṉ maṭṭu ē aṉṟi um
  • {PU 390-17} amiḻtu aṉa marapiṉ ūṉ tuvai aṭicil
  • {PU 390-18} veḷḷi veḷ kalattu ūṭṭal aṉṟi
  • {PU 390-19} muṉ ūr potiyil cērnta mel naṭai
  • {PU 390-20} irum pēr okkal perum pulampu akaṟṟa
  • {PU 390-21} akaṭu naṉai vēṅkai vī kaṇṭaṉṉa
  • {PU 390-22} pakaṭu taru cennel pōroṭu nalki
  • {PU 390-23} koṇṭi peṟuka eṉṟōṉ ē uṇ tuṟai
  • {PU 390-24} malai alar aṇiyum talai nīr nāṭaṉ
  • {PU 390-25} kaṇṭāl koṇṭu um avaṉ tiruntu aṭi vāḻtti
  • {PU 390-27} vāṉ aṟiyala eṉ pāṭu paci pōkkal
  • {PU 390-28} aṇṇal yāṉai vēntar
  • {PU 390-29} uṇmai ō aṟiyal kāṇpu aṟiyalar ē
