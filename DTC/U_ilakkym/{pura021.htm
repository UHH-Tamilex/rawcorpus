{PUṞAM 21}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 21-1} pula vari iṟanta pukaḻ cāl tōṉṟal
  • {PU 21-2} nila vari iṟanta kuṇṭu kaṇ akaḻi
  • {PU 21-3} vāṉ tōyvu aṉṉa purici vicumpiṉ
  • {PU 21-4} mīṉ pūttaṉṉa uruva ñāyil
  • {PU 21-5} katir nuḻiku allā maram payil kaṭi miḷi
  • {PU 21-6} arum kuṟumpu uṭutta kāṉappēr eyil
  • {PU 21-7} karum ki kollaṉ ce tī māṭṭiya
  • {PU 21-8} irumpu uṇ nīriṉum mīṭṭaṟku aritu eṉa
  • {PU 21-9} vēṅki mārpaṉ iraṅka vikal um
  • {PU 21-10} āṭu koḷa kuḻinta tumpi pulavar
  • {PU 21-11} pāṭu tuṟi muṟṟiya koṟṟa vēntu ē
  • {PU 21-12} ikaḻunar iciyoṭu māya
  • {PU 21-13} pukaḻoṭu viḷaṅki pūkka niṉ vēl ē
