{PUṞAM 15}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 15-1} kaṭum tēr kuḻitta ñeḷḷal āṅkaṇ
  • {PU 15-2} veḷ vāy kaḻuti pul iṉam pūṭṭi
  • {PU 15-3} pāḻ ceytaṉi avar naṉam tali nal eyil
  • {PU 15-4} puḷ iṉam imiḻum pukaḻ cāl viḷi vayal
  • {PU 15-5} veḷ uḷi kali māṉ kavi kuḷampu ukaḷa
  • {PU 15-6} tēr vaḻaṅkiṉi niṉ tevvar tēettu
  • {PU 15-7} tuḷaṅku iyalāṉ paṇi eruttiṉ
  • {PU 15-8} pāvu aṭiyāṉ ceṟal nōkkiṉ
  • {PU 15-9} oḷiṟu maruppiṉ kaḷiṟu avara
  • {PU 15-10} kāppu uṭiya kayam paṭiyiṉi
  • {PU 15-11} aṉṉa cīṟṟattu aṉiyi ākaliṉ
  • {PU 15-12} viḷaṅku poṉ eṟinta nalam kiḷar palakiyoṭu
  • {PU 15-13} niḻal paṭu neṭu vēl ēnti oṉṉār
  • {PU 15-14} oḷ paṭi kaṭum tār muṉpu talikkoṇmār
  • {PU 15-15} naci tara vantōr naci piṟakku oḻiya
  • {PU 15-16} vaci paṭa vāḻntōr palar kol puri il
  • {PU 15-17} nal paṉuval nāl vētattu
  • {PU 15-18} arum cīrtti perum kaṇṇuṟi
  • {PU 15-19} neym mali āvuti poṅka pal māṇ
  • {PU 15-20} vīyā ciṟappiṉ vēḷvi muṟṟi
  • {PU 15-21} yūpam naṭṭa viyaṉ kaḷam pala kol
  • {PU 15-22} yā pala kol ō peruma vār uṟṟu
  • {PU 15-23} vici piṇikkoṇṭa maṇ kaṉi muḻaviṉ
  • {PU 15-24} pāṭiṉi pāṭum vañcikku
  • {PU 15-25} nāṭal cāṉṟa mintiṉōy niṉakku ē
