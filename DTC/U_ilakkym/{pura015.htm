{PUṞAM 15}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 15-1} kaṭum tēr kuḻitta ñeḷḷal āṅkaṇ
  • {PU 15-2} veḷ vāy kaḻutai pul iṉam pūṭṭi
  • {PU 15-3} pāḻ ceytaṉai avar naṉam talai nal eyil
  • {PU 15-4} puḷ iṉam imiḻum pukaḻ cāl viḷai vayal
  • {PU 15-5} veḷ uḷai kali māṉ kavi kuḷampu ukaḷa
  • {PU 15-6} tēr vaḻaṅkiṉai niṉ tevvar tēettu
  • {PU 15-7} tuḷaṅku iyalāṉ paṇai eruttiṉ
  • {PU 15-8} pāvu aṭiyāṉ ceṟal nōkkiṉ
  • {PU 15-9} oḷiṟu maruppiṉ kaḷiṟu avara
  • {PU 15-10} kāppu uṭaiya kayam paṭiyiṉai
  • {PU 15-11} aṉṉa cīṟṟattu aṉaiyai ākaliṉ
  • {PU 15-12} viḷaṅku poṉ eṟinta nalam kiḷar palakaiyoṭu
  • {PU 15-13} niḻal paṭu neṭu vēl ēnti oṉṉār
  • {PU 15-14} oḷ paṭai kaṭum tār muṉpu talaikkoṇmār
  • {PU 15-15} nacai tara vantōr nacai piṟakku oḻiya
  • {PU 15-16} vacai paṭa vāḻntōr palar kol purai il
  • {PU 15-17} nal paṉuval nāl vētattu
  • {PU 15-18} arum cīrtti perum kaṇṇuṟai
  • {PU 15-19} neym mali āvuti poṅka pal māṇ
  • {PU 15-20} vīyā ciṟappiṉ vēḷvi muṟṟi
  • {PU 15-21} yūpam naṭṭa viyaṉ kaḷam pala kol
  • {PU 15-22} yā pala kol ō peruma vār uṟṟu
  • {PU 15-23} vici piṇikkoṇṭa maṇ kaṉai muḻaviṉ
  • {PU 15-24} pāṭiṉi pāṭum vañcikku
  • {PU 15-25} nāṭal cāṉṟa maintiṉōy niṉakku ē
