{PUṞAM 341}

  • {PU 341-1} vēntu kuṟaiyuṟa um koṭāaṉ ēntu kōṭṭu
  • {PU 341-2} am pūm toṭalai aṇi taḻai alkul
  • {PU 341-3} ce poṟi cilampiṉ iḷaiyōḷ tantai
  • {PU 341-4} eḻu viṭṭu amaitta tiṇ nilai kataviṉ
  • {PU 341-5} arai maṇ iñci nāḷ koṭi nuṭaṅkum
  • {PU 341-7} puli kaṇattu aṉṉa kaṭuṅkaṇ cuṟṟamoṭu
  • {PU 341-8} māṟṟam māṟāṉ maṟaliya ciṉattaṉ
  • {PU 341-9} pūkkōḷ eṉa ēey kayam pukkaṉaṉ ē
  • {PU 341-10} viḷaṅku iḻai polinta vēḷā mel iyal
  • {PU 341-11} cuṇaṅku aṇi vaṉa mulai avaḷoṭu nāḷai
  • {PU 341-12} maṇam puku vaikal ākutal oṉṟu ō
  • {PU 341-13} ār amar uḻakkiya maṟam kiḷar muṉpiṉ
  • {PU 341-14} nīḷ ilai eḵkam maṟutta uṭampoṭu
  • {PU 341-15} vārā ulakam pukutal oṉṟu eṉa
  • {PU 341-16} paṭai toṭṭaṉaṉ ē kurucil āyiṭai
  • {PU 341-17} kaḷiṟu pora kalaṅkiya taṇ kayam pōla
  • {PU 341-18} perum kaviṉ iḻappatu kol ō
  • {PU 341-19} mel puṉal vaippiṉ i taṇ paṇai ūr ē
