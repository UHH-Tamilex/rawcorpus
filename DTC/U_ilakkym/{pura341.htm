  • {PU 341-1} vēntu kuṟiyuṟa um koṭāaṉ ēntu kōṭṭu
  • {PU 341-2} am pūm toṭali aṇi taḻi alkul
  • {PU 341-3} ce poṟi cilampiṉ iḷiyōḷ tanti
  • {PU 341-4} eḻu viṭṭu amitta tiṇ nili kataviṉ
  • {PU 341-5} ari maṇ iñci nāḷ koṭi nuṭaṅkum
  • {PU 341-7} puli kaṇattu aṉṉa kaṭuṅkaṇ cuṟṟamoṭu
  • {PU 341-8} māṟṟam māṟāṉ maṟaliya ciṉattaṉ
  • {PU 341-9} pūkkōḷ eṉa ēey kayam pukkaṉaṉ ē
  • {PU 341-10} viḷaṅku iḻi polinta vēḷā mel iyal
  • {PU 341-11} cuṇaṅku aṇi vaṉa muli avaḷoṭu nāḷi
  • {PU 341-12} maṇam puku vikal ākutal oṉṟu ō
  • {PU 341-13} ār amar uḻakkiya maṟam kiḷar muṉpiṉ
  • {PU 341-14} nīḷ ili eḵkam maṟutta uṭampoṭu
  • {PU 341-15} vārā ulakam pukutal oṉṟu eṉa
  • {PU 341-16} paṭi toṭṭaṉaṉ ē kurucil āyiṭi
  • {PU 341-17} kaḷiṟu pora kalaṅkiya taṇ kayam pōla
  • {PU 341-18} perum kaviṉ iḻappatu kol ō
  • {PU 341-19} mel puṉal vippiṉ i taṇ paṇi ūr ē
