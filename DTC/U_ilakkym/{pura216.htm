{PUṞAM 216}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 216-1} kēṭṭal māttiri allatu yāvatu um
  • {PU 216-2} kāṇṭal illātu yāṇṭu pala kaḻiya
  • {PU 216-3} vaḻu iṉṟu paḻakiya kiḻamiyar āyiṉum
  • {PU 216-4} aritu ē tōṉṟal ataṉ paṭa oḻukal eṉṟu
  • {PU 216-5} aiyam koḷḷaṉmiṉ ār aṟivāḷīr
  • {PU 216-6} ikaḻvu ilaṉ iṉiyaṉ yātta naṇpiṉaṉ
  • {PU 216-7} pukaḻ keṭa varūum poy vēṇṭalaṉ ē
  • {PU 216-8} taṉ peyar kiḷakkum kāli eṉ peyar
  • {PU 216-9} pēti cōḻaṉ eṉṉum ciṟanta
  • {PU 216-10} kātal kiḻami um uṭiyaṉ ataṉ tali
  • {PU 216-11} iṉṉatu ōr kāli nillalaṉ
  • {PU 216-12} iṉṉē varukuvaṉ oḻikka avaṟku iṭam ē
