{PUṞAM 363}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 363-1} irum kaṭal uṭutta i perum kaṇ mā nilam
  • {PU 363-2} uṭi ili naṭuvaṇatu iṭi piṟarkku iṉṟi
  • {PU 363-3} tām ē āṇṭa ēmam kāvalar
  • {PU 363-4} iṭu tiri maṇaliṉum palar ē cuṭu piṇam
  • {PU 363-5} kāṭu pati āka pōki tamtam
  • {PU 363-6} nāṭu piṟar koḷa ceṉṟu māyntaṉar ē
  • {PU 363-7} ataṉāl nī um kēṇmati atti vīyātu
  • {PU 363-8} uṭampoṭu niṉṟa uyir um illi
  • {PU 363-9} maṭaṅkal uṇmi māyam ō aṉṟu ē
  • {PU 363-10} kaḷḷi vēynta muḷḷi am puṟaṅkāṭṭu
  • {PU 363-11} veḷḷil pōkiya viyaluḷ āṅkaṇ
  • {PU 363-12} uppu ilāa avi puḻukkal
  • {PU 363-13} kikkoṇṭu piṟakku nōkkātu
  • {PU 363-14} iḻi piṟappiṉōṉ īya peṟṟu
  • {PU 363-15} nilam kalaṉ āka ilaṅku pali miciyum
  • {PU 363-16} iṉṉā vikal vārā muṉ ē
  • {PU 363-17} cey nī muṉṉiya viṉi ē
  • {PU 363-18} munnīr varippu akam muḻutu uṭaṉ tuṟantu ē
