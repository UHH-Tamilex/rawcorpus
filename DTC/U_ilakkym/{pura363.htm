{PUṞAM 363}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 363-1} irum kaṭal uṭutta i perum kaṇ mā nilam
  • {PU 363-2} uṭai ilai naṭuvaṇatu iṭai piṟarkku iṉṟi
  • {PU 363-3} tām ē āṇṭa ēmam kāvalar
  • {PU 363-4} iṭu tirai maṇaliṉum palar ē cuṭu piṇam
  • {PU 363-5} kāṭu pati āka pōki tamtam
  • {PU 363-6} nāṭu piṟar koḷa ceṉṟu māyntaṉar ē
  • {PU 363-7} ataṉāl nī um kēṇmati attai vīyātu
  • {PU 363-8} uṭampoṭu niṉṟa uyir um illai
  • {PU 363-9} maṭaṅkal uṇmai māyam ō aṉṟu ē
  • {PU 363-10} kaḷḷi vēynta muḷḷi am puṟaṅkāṭṭu
  • {PU 363-11} veḷḷil pōkiya viyaluḷ āṅkaṇ
  • {PU 363-12} uppu ilāa avi puḻukkal
  • {PU 363-13} kaikkoṇṭu piṟakku nōkkātu
  • {PU 363-14} iḻi piṟappiṉōṉ īya peṟṟu
  • {PU 363-15} nilam kalaṉ āka ilaṅku pali micaiyum
  • {PU 363-16} iṉṉā vaikal vārā muṉ ē
  • {PU 363-17} cey nī muṉṉiya viṉai ē
  • {PU 363-18} munnīr varaippu akam muḻutu uṭaṉ tuṟantu ē
