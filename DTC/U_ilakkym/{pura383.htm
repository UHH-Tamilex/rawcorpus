{PUṞAM 383}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 383-1} oḷ poṟi cēval eṭuppa ēṟṟu eḻuntu
  • {PU 383-2} taṇ paṉi uṟikkum pularā ñāṅkar
  • {PU 383-3} nuṇ kōl ciṟu kiṇi cilampa oṟṟi
  • {PU 383-4} neṭum kaṭi niṉṟu pakaṭu pala vāḻtti
  • {PU 383-5} taṉ pukaḻ ēttiṉeṉ āka ūṉ pulantu
  • {PU 383-6} arum kaṭi viyal nakar kuṟukal vēṇṭi
  • {PU 383-7} kūmpu viṭu mel piṇi aviḻtta āmpal
  • {PU 383-8} tēm pāy uḷḷa tam kamaḻ maṭar uḷa
  • {PU 383-9} pāmpu uri aṉṉa vaṭiviṉa kāmpiṉ
  • {PU 383-10} kaḻi paṭu coliyiṉ iḻi aṇi vārā
  • {PU 383-11} oḷ pūm kaliṅkam uṭīi nuṇ pūṇ
  • {PU 383-12} vacintu vāṅku nucuppiṉ a vāṅku unti
  • {PU 383-13} kaṟpu uṭi maṭanti taṉ puṟam pulla
  • {PU 383-14} eṉ peyarnta nōkki
  • {PU 383-15} kal koṇṭu
  • {PU 383-16} aḻittu piṟantaṉeṉ āki a vaḻi
  • {PU 383-17} piṟar pāṭu pukaḻ pāṭi paṭarpu aṟiyēṉ ē
  • {PU 383-18} kuṟu mulikku alamarum pāl ār veḷ maṟi
  • {PU 383-19} nari mukam ūkamoṭu ukaḷum
  • {PU 383-20} kaṉṟu pala keḻīiya
  • {PU 383-21} kāṉ keḻu nāṭaṉ kaṭum tēr aviyaṉ eṉa
  • {PU 383-22} oruvaṉi uṭiyēṉ maṉ ē yāṉ ē
  • {PU 383-23} aṟāṉ evaṉ pariku ō veḷḷiyatu nili ē
