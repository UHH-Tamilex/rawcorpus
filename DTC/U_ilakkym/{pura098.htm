{PUṞAM 98}

  • {PU 98-1} muṉi tevvar muraṇ aviya
  • {PU 98-2} pora kuṟukiya nuti maruppiṉ niṉ
  • {PU 98-3} iṉam kaḷiṟu cela kaṇṭavar
  • {PU 98-4} matil katavam eḻu cella um
  • {PU 98-5} piṇaṉ aḻuṅka kaḷaṉ uḻakki
  • {PU 98-6} celavu aciiya maṟu kuḷampiṉ niṉ
  • {PU 98-7} iṉam nal mā cela kaṇṭavar
  • {PU 98-8} kavi muḷḷiṉ puḻi aṭippa um
  • {PU 98-9} mārpuṟa cērntu olkā
  • {PU 98-10} tōl ceṟippu il niṉ vēl kaṇṭavar
  • {PU 98-11} tōl kaḻiyoṭu piṭi ceṟippa um
  • {PU 98-12} vāḷ vāytta vaṭu paranta niṉ
  • {PU 98-13} maṟa mintar mintu kaṇṭavar
  • {PU 98-14} puṇ paṭu kuruti ampu oṭukka um
  • {PU 98-15} nī ē aiyavi pukippa um tāṅkātu oyyeṉa
  • {PU 98-16} uṟu muṟi marapiṉ puṟam niṉṟu uykkum
  • {PU 98-17} kūṟṟattu aṉiyi ākaliṉ pōṟṟār
  • {PU 98-18} iraṅka viḷivatu kol ō varampu aṇintu
  • {PU 98-19} iṟaṅku katir alamvaru kaḻaṉi
  • {PU 98-20} perum puṉal paṭappi avar akal tali nāṭu ē
