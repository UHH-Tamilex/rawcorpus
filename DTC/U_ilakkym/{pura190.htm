{PUṞAM 190}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 190-1} viḷi patam cīṟu iṭam nōkki vaḷi katir
  • {PU 190-2} valci koṇṭu aḷi malka vikkum
  • {PU 190-3} eli muyaṉṟaṉiyar āki uḷḷa tam
  • {PU 190-4} vaḷaṉ valiyuṟukkum uḷam ilāḷaroṭu
  • {PU 190-5} iyinta kēṇmi illākiyar ō
  • {PU 190-6} kaṭuṅkaṇ kēḻal iṭampaṭa vīḻnteṉa
  • {PU 190-7} aṉṟu avaṇ uṇṇātu āki vaḻi nāḷ
  • {PU 190-8} peru mali viṭar akam pulampa vēṭṭu eḻuntu
  • {PU 190-9} irum kaḷiṟṟu oruttal nal valam paṭukkum
  • {PU 190-10} puli pacittaṉṉa melivu il uḷḷattu
  • {PU 190-11} uraṉ uṭiyāḷar kēṇmiyoṭu
  • {PU 190-12} iyinta vikal uḷa ākiyar ō
