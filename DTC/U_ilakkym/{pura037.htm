{PUṞAM 37}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 37-1} nañcu uṭai vāl eyiṟṟu aim talai cumanta
  • {PU 37-2} vēkam ve tiṟal nākam pukkeṉa
  • {PU 37-3} vicumpu tī piṟappa tiruki pacum koṭi
  • {PU 37-4} peru malai viṭar akattu urum eṟintāṅku
  • {PU 37-5} puḷ uṟu puṉkaṇ tīrtta veḷ vēl
  • {PU 37-6} ciṉam keḻu tāṉai cempiyaṉ maruka
  • {PU 37-7} karāam kalitta kuṇṭu kaṇ akaḻi
  • {PU 37-8} iṭam karum kuṭṭattu uṭaṉ tokku ōṭi
  • {PU 37-9} yāmam koḷpavar cuṭar niḻal katūum
  • {PU 37-10} kaṭu muraṇ mutalaiya neṭu nīr ilañci
  • {PU 37-11} cempu uṟaḻ puricai cemmal mūtūr
  • {PU 37-12} vampu aṇi yāṉai vēntu akattu uṇmaiyiṉ
  • {PU 37-13} nalla eṉṉātu citaittal
  • {PU 37-14} vallaiyāl neṭuntakai ceruvattāṉ ē
