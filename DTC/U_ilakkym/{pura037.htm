{PUṞAM 37}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 37-1} nañcu uṭi vāl eyiṟṟu aim tali cumanta
  • {PU 37-2} vēkam ve tiṟal nākam pukkeṉa
  • {PU 37-3} vicumpu tī piṟappa tiruki pacum koṭi
  • {PU 37-4} peru mali viṭar akattu urum eṟintāṅku
  • {PU 37-5} puḷ uṟu puṉkaṇ tīrtta veḷ vēl
  • {PU 37-6} ciṉam keḻu tāṉi cempiyaṉ maruka
  • {PU 37-7} karāam kalitta kuṇṭu kaṇ akaḻi
  • {PU 37-8} iṭam karum kuṭṭattu uṭaṉ tokku ōṭi
  • {PU 37-9} yāmam koḷpavar cuṭar niḻal katūum
  • {PU 37-10} kaṭu muraṇ mutaliya neṭu nīr ilañci
  • {PU 37-11} cempu uṟaḻ purici cemmal mūtūr
  • {PU 37-12} vampu aṇi yāṉi vēntu akattu uṇmiyiṉ
  • {PU 37-13} nalla eṉṉātu citittal
  • {PU 37-14} valliyāl neṭuntaki ceruvattāṉ ē
