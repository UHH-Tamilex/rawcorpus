{PUṞAM 261}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 261-1} antō entai aṭaiyā pēr il
  • {PU 261-2} vaṇṭu paṭu naṟaviṉ taṇṭā maṇṭaiyoṭu
  • {PU 261-3} varaiyā perum cōṟṟu muri vāy muṟṟam
  • {PU 261-4} veṟṟu yāṟṟu ampiyiṉ eṟṟu aṟṟu āka
  • {PU 261-5} kaṇṭaṉeṉ maṉṟa cōrka eṉ kaṇ ē
  • {PU 261-6} vaiyam kāvalar vaḷam keḻu tiru nakar
  • {PU 261-7} maiyal yāṉai ayā uyirttaṉṉa
  • {PU 261-8} ney ulai corinta mai ūṉ ōcai
  • {PU 261-9} putu kaṇ mākkaḷ cetu kaṇ āra
  • {PU 261-10} payantaṉai maṉ āl muṉ ē iṉi ē
  • {PU 261-11} pal ā taḻīiya kallā val vil
  • {PU 261-12} uḻai kural kūkai aḻaippa āṭṭi
  • {PU 261-13} nāku mulai aṉṉa naṟum pū karantai
  • {PU 261-14} viraku aṟiyāḷar marapiṉ cūṭṭa
  • {PU 261-15} nirai ivaṇ tantu naṭukal ākiya
  • {PU 261-16} veṉ vēl viṭalai iṉmaiyiṉ pulampi
  • {PU 261-17} koym maḻi talaiyoṭu kaimmaiyuṟa kalaṅkiya
  • {PU 261-18} kaḻi kala makaṭūu pōla
  • {PU 261-19} pulleṉṟaṉai āl pal aṇi iḻantu ē
