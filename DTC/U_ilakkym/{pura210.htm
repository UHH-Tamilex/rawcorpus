{PUṞAM 210}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 210-1} maṉpati kākkum niṉ purimi nōkkātu
  • {PU 210-2} aṉpu kaṇ māṟiya aṟaṉ il kāṭciyoṭu
  • {PU 210-3} nummaṉōr um maṟṟu iṉiyar āyiṉ
  • {PU 210-4} emmaṉōr ivaṇ piṟavalar mātō
  • {PU 210-5} ceyir tīr koḷki em ve kātali
  • {PU 210-6} uyir ciṟitu uṭiyaḷ āyiṉ em vayiṉ
  • {PU 210-7} uḷḷātu iruttal ō aritu ē ataṉāl
  • {PU 210-8} aṟaṉ il kūṟṟam tiṟaṉ iṉṟu tuṇiya
  • {PU 210-9} piṟaṉ āyiṉaṉ kol iṟīiyar eṉ uyir eṉa
  • {PU 210-10} nuvalvuṟu ciṟumiyaḷ pala pulantu uṟiyum
  • {PU 210-11} iṭukkaṇ maṉiyōḷ tīriya i nili
  • {PU 210-12} viṭuttēṉ vāḻiyar kurucil utu kāṇ
  • {PU 210-13} avala neñcamoṭu celval niṉ kaṟuttōr
  • {PU 210-14} arum kaṭi muṉi araṇ pōla
  • {PU 210-15} perum kiyaṟṟa eṉ pulampu muntuṟuttu ē
