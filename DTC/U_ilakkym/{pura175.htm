{PUṞAM 175}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 175-1} enti vāḻi ātaṉuṅka eṉ
  • {PU 175-2} neñcam tiṟappōr niṉ kāṇkuvar ē
  • {PU 175-3} niṉ yāṉ maṟappiṉ maṟakkum kāli
  • {PU 175-4} eṉ uyir yākkiyiṉ piriyum poḻutu um
  • {PU 175-5} eṉ yāṉ maṟappiṉ maṟakkuveṉ veṉ vēl
  • {PU 175-6} viṇ poru neṭum kuṭi koṭi tēr mōriyar
  • {PU 175-7} tiṇ katir tikiri tiritara kuṟitta
  • {PU 175-8} ulaka iṭi kaḻi aṟi vāy niliiya
  • {PU 175-9} malar vāy maṇṭilattu aṉṉa nāḷ um
  • {PU 175-10} palar puravu etirnta aṟattuṟi niṉ ē
