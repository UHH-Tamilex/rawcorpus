{PUṞAM 175}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 175-1} entai vāḻi ātaṉuṅka eṉ
  • {PU 175-2} neñcam tiṟappōr niṉ kāṇkuvar ē
  • {PU 175-3} niṉ yāṉ maṟappiṉ maṟakkum kālai
  • {PU 175-4} eṉ uyir yākkaiyiṉ piriyum poḻutu um
  • {PU 175-5} eṉ yāṉ maṟappiṉ maṟakkuveṉ veṉ vēl
  • {PU 175-6} viṇ poru neṭum kuṭai koṭi tēr mōriyar
  • {PU 175-7} tiṇ katir tikiri tiritara kuṟaitta
  • {PU 175-8} ulaka iṭai kaḻi aṟai vāy nilaiiya
  • {PU 175-9} malar vāy maṇṭilattu aṉṉa nāḷ um
  • {PU 175-10} palar puravu etirnta aṟattuṟai niṉ ē
