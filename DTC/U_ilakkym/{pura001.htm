{PUṞAM 1: kaṭavuḷ vāḻttu}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 1-1} kaṇṇi kār naṟum koṉṟai kāmar
  • {PU 1-2} vaṇṇa mārpiṉ tār um koṉṟai
  • {PU 1-3} ūrti vāl veḷ ēṟu ē ciṟanta
  • {PU 1-4} cīr keḻu koṭi um a ēṟu eṉpa
  • {PU 1-5} kaṟai miṭaṟu aṇiyal um aṇintaṉṟu a kaṟai
  • {PU 1-6} maṟai navil antaṇar nuvala um paṭum ē
  • {PU 1-7} peṇ uru oru tiṟaṉ ākiṉṟu a uru
  • {PU 1-8} taṉ uḷ aṭakki karakkiṉum karakkum
  • {PU 1-9} piṟai nutal vaṇṇam ākiṉṟu a piṟai
  • {PU 1-10} patiṉeṇ kaṇaṉ um ētta um paṭum ē
  • {PU 1-11} ellā uyirkku um ēmam ākiya
  • {PU 1-12} nīr aṟavu aṟiyā karakattu
  • {PU 1-13} tāḻ caṭai polinta arum tavattōṟku ē
