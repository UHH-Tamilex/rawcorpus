  • {PU 202-3} kaṭaṟu maṇi kiḷara citaṟu poṉ miḷira
  • {PU 202-4} kaṭiya kataḻum neṭu varai paṭappai
  • {PU 202-5} veṉṟi nilaiiya viḻu pukaḻ oṉṟi
  • {PU 202-6} iru pāl peyariya uru keḻu mūtūr
  • {PU 202-7} kōṭi pala aṭukkiya poruḷ numakku utaviya
  • {PU 202-8} nīṭu nilai araiyattu kēṭu um kēḷ iṉi
  • {PU 202-9} nuntai tāyam niṟaiyuṟa eytiya
  • {PU 202-10} oliyal kaṇṇi pulikaṭimāal
  • {PU 202-11} num pōl aṟiviṉ numar uḷ oruvaṉ
  • {PU 202-12} pukaḻnta ceyyuḷ kaḻāattalaiyai
  • {PU 202-13} ikaḻntataṉ payaṉ ē iyal tēr aṇṇal
  • {PU 202-14} evvi tol kuṭi paṭīiyar maṟṟu ivar
  • {PU 202-15} kaivaṇ pāri makaḷir eṉṟa eṉ
  • {PU 202-16} tēṟṟā puṉcol nōṟṟiciṉ peruma
  • {PU 202-17} viṭuttaṉeṉ velīiyar niṉ vēl ē aṭukkattu
  • {PU 202-18} arumpu aṟa malarnta karum kāl vēṅkai
  • {PU 202-19} mā takaṭṭu oḷ vī tāya tuṟukal
  • {PU 202-20} irum puli vari puṟam kaṭukkum
  • {PU 202-21} perum kal vaippiṉ nāṭu kiḻavōy ē
