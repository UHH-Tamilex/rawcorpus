{PUṞAM 385}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 385-1} veḷḷi tōṉṟa puḷḷu kural iyampa
  • {PU 385-2} pulari viṭiyal pakaṭu pala vāḻtti
  • {PU 385-3} taṉ kaṭi tōṉṟiṉum ilaṉ ē piṟaṉ kaṭi
  • {PU 385-4} akal kaṇ taṭāri pāṭu kēṭṭaruḷi
  • {PU 385-5} vaṟaṉ yāṉ nīṅkal vēṇṭi eṉ ari
  • {PU 385-6} nīl niṟam citāar kaḷintu
  • {PU 385-7} veḷiyatu uṭīi eṉ paci kaḷintōṉ ē
  • {PU 385-8} kāviri aṇiyum tāḻ nīr paṭappi
  • {PU 385-9} nel viḷi kaḻaṉi ampar kiḻavōṉ
  • {PU 385-10} nal aruvanti vāḻiyar pulliya
  • {PU 385-11} vēṅkaṭa viṟal vari paṭṭa
  • {PU 385-12} ōṅkal vāṉattu uṟiyiṉum pala ē
