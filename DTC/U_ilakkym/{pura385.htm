{PUṞAM 385}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 385-1} veḷḷi tōṉṟa puḷḷu kural iyampa
  • {PU 385-2} pulari viṭiyal pakaṭu pala vāḻtti
  • {PU 385-3} taṉ kaṭai tōṉṟiṉum ilaṉ ē piṟaṉ kaṭai
  • {PU 385-4} akal kaṇ taṭāri pāṭu kēṭṭaruḷi
  • {PU 385-5} vaṟaṉ yāṉ nīṅkal vēṇṭi eṉ arai
  • {PU 385-6} nīl niṟam citāar kaḷaintu
  • {PU 385-7} veḷiyatu uṭīi eṉ paci kaḷaintōṉ ē
  • {PU 385-8} kāviri aṇaiyum tāḻ nīr paṭappai
  • {PU 385-9} nel viḷai kaḻaṉi ampar kiḻavōṉ
  • {PU 385-10} nal aruvantai vāḻiyar pulliya
  • {PU 385-11} vēṅkaṭa viṟal varai paṭṭa
  • {PU 385-12} ōṅkal vāṉattu uṟaiyiṉum pala ē
