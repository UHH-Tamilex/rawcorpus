{PUṞAM 379}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 379-1} yāṉ ē peṟuka avaṉ tāḷ niḻal vāḻkki
  • {PU 379-2} avaṉ ē peṟuka eṉ nā ici nuvaṟal
  • {PU 379-3} nel ari toḻuvar kūr vāḷ maḻuṅkiṉ
  • {PU 379-4} piṉṉi maṟattōṭu ariya kal cettu
  • {PU 379-5} aḷḷal yāmi kūṉ puṟattu uriñcum
  • {PU 379-6} nel amal puraviṉ ilaṅki kiḻavōṉ
  • {PU 379-7} villiyātaṉ kiṇiyēm peruma
  • {PU 379-8} kuṟum tāḷ ēṟṟi koḻum kaṇ a viḷar
  • {PU 379-9} naṟu ney urukki nāḷ cōṟu īyā
  • {PU 379-10} vallaṉ enti paci tīrttal eṉa
  • {PU 379-11} koṉ varal vāḻkki niṉ kiṇivaṉ kūṟa
  • {PU 379-12} kēṭṭataṉ koṇṭu um vēṭki taṇṭātu
  • {PU 379-13} viṇ tōy taliya kuṉṟam piṉpaṭa
  • {PU 379-14} vantaṉeṉ yāṉ ē
  • {PU 379-15} tāy il tūvā kuḻavi pōla āṅku a
  • {PU 379-16} tiru uṭi tiru maṉi aitu tōṉṟu kamaḻ puki
  • {PU 379-17} varu maḻi maṅkuliṉ maṟuku uṭaṉ maṟikkum
  • {PU 379-18} kuṟumpu aṭu kuṇṭu akaḻ nīḷ matil ūr ē
