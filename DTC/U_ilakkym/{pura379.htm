{PUṞAM 379}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 379-1} yāṉ ē peṟuka avaṉ tāḷ niḻal vāḻkkai
  • {PU 379-2} avaṉ ē peṟuka eṉ nā icai nuvaṟal
  • {PU 379-3} nel ari toḻuvar kūr vāḷ maḻuṅkiṉ
  • {PU 379-4} piṉṉai maṟattōṭu ariya kal cettu
  • {PU 379-5} aḷḷal yāmai kūṉ puṟattu uriñcum
  • {PU 379-6} nel amal puraviṉ ilaṅkai kiḻavōṉ
  • {PU 379-7} villiyātaṉ kiṇaiyēm peruma
  • {PU 379-8} kuṟum tāḷ ēṟṟai koḻum kaṇ a viḷar
  • {PU 379-9} naṟu ney urukki nāḷ cōṟu īyā
  • {PU 379-10} vallaṉ entai paci tīrttal eṉa
  • {PU 379-11} koṉ varal vāḻkkai niṉ kiṇaivaṉ kūṟa
  • {PU 379-12} kēṭṭataṉ koṇṭu um vēṭkai taṇṭātu
  • {PU 379-13} viṇ tōy talaiya kuṉṟam piṉpaṭa
  • {PU 379-14} vantaṉeṉ yāṉ ē
  • {PU 379-15} tāy il tūvā kuḻavi pōla āṅku a
  • {PU 379-16} tiru uṭai tiru maṉai aitu tōṉṟu kamaḻ pukai
  • {PU 379-17} varu maḻai maṅkuliṉ maṟuku uṭaṉ maṟaikkum
  • {PU 379-18} kuṟumpu aṭu kuṇṭu akaḻ nīḷ matil ūr ē
