{PUṞAM 97}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 97-1} pōrkku urii pukaṉṟu kaḻitta vāḷ
  • {PU 97-2} uṭaṉṟavar kāppu uṭi matil aḻittaliṉ
  • {PU 97-3} ūṉ uṟa mūḻki uru iḻantaṉa ē
  • {PU 97-4} vēl ē kuṟumpu aṭinta araṇ kaṭantu avar
  • {PU 97-5} naṟum kaḷḷiṉ nāṭu nittaliṉ
  • {PU 97-6} curi taḻīiya irum kāḻoṭu
  • {PU 97-7} maṭi kalaṅki nili tirintaṉa ē
  • {PU 97-8} kaḷiṟu ē eḻūu tāṅkiya katavam malittu avar
  • {PU 97-9} kuḻūu kaḷiṟṟu kuṟumpu uṭittaliṉ
  • {PU 97-10} parūu piṇiya toṭi kaḻintaṉa ē
  • {PU 97-11} mā ē parantu oruṅku malinta maṟavar
  • {PU 97-12} polam pim tār keṭa paritaliṉ
  • {PU 97-13} kaḷaṉ uḻantu aciiya maṟu kuḷampiṉa ē
  • {PU 97-14} avaṉ tāṉ um nilam tirikkum kaṭal tāṉi
  • {PU 97-15} polam tumpi kaḻal pāṇṭil
  • {PU 97-16} kaṇi poruta tuḷi tōlaṉ ē
  • {PU 97-17} āyiṭi uṭaṉṟōr uytal yāvatu taṭam tāḷ
  • {PU 97-18} piṇi katir nelliṉ cemmal mūtūr
  • {PU 97-19} numakku urittākal vēṇṭiṉ ceṉṟu avaṟku
  • {PU 97-20} iṟukkal vēṇṭum tiṟi ē maṟuppiṉ
  • {PU 97-21} olvāṉ allaṉ vel pōrāṉ eṉa
  • {PU 97-22} colla um tēṟīr āyiṉ mel iyal
  • {PU 97-23} kaḻal kaṉi vakutta tuṇi cil ōti
  • {PU 97-24} kuṟum toṭi makaḷir tōḷ viṭal
  • {PU 97-25} iṟumpūtu aṉṟu aḵtu aṟintu āṭumiṉ ē
