{PUṞAM 97}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 97-1} pōrkku uraii pukaṉṟu kaḻitta vāḷ
  • {PU 97-2} uṭaṉṟavar kāppu uṭai matil aḻittaliṉ
  • {PU 97-3} ūṉ uṟa mūḻki uru iḻantaṉa ē
  • {PU 97-4} vēl ē kuṟumpu aṭainta araṇ kaṭantu avar
  • {PU 97-5} naṟum kaḷḷiṉ nāṭu naittaliṉ
  • {PU 97-6} curai taḻīiya irum kāḻoṭu
  • {PU 97-7} maṭai kalaṅki nilai tirintaṉa ē
  • {PU 97-8} kaḷiṟu ē eḻūu tāṅkiya katavam malaittu avar
  • {PU 97-9} kuḻūu kaḷiṟṟu kuṟumpu uṭaittaliṉ
  • {PU 97-10} parūu piṇiya toṭi kaḻintaṉa ē
  • {PU 97-11} mā ē parantu oruṅku malainta maṟavar
  • {PU 97-12} polam paim tār keṭa paritaliṉ
  • {PU 97-13} kaḷaṉ uḻantu acaiiya maṟu kuḷampiṉa ē
  • {PU 97-14} avaṉ tāṉ um nilam tiraikkum kaṭal tāṉai
  • {PU 97-15} polam tumpai kaḻal pāṇṭil
  • {PU 97-16} kaṇai poruta tuḷai tōlaṉ ē
  • {PU 97-17} āyiṭai uṭaṉṟōr uytal yāvatu taṭam tāḷ
  • {PU 97-18} piṇi katir nelliṉ cemmal mūtūr
  • {PU 97-19} numakku urittākal vēṇṭiṉ ceṉṟu avaṟku
  • {PU 97-20} iṟukkal vēṇṭum tiṟai ē maṟuppiṉ
  • {PU 97-21} olvāṉ allaṉ vel pōrāṉ eṉa
  • {PU 97-22} colla um tēṟīr āyiṉ mel iyal
  • {PU 97-23} kaḻal kaṉi vakutta tuṇai cil ōti
  • {PU 97-24} kuṟum toṭi makaḷir tōḷ viṭal
  • {PU 97-25} iṟumpūtu aṉṟu aḵtu aṟintu āṭumiṉ ē
