{PUṞAM 171}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 171-1} iṉṟu celiṉum tarum ē ciṟu varai
  • {PU 171-2} niṉṟu celiṉum tarum ē piṉ um
  • {PU 171-3} muṉ ē tantaṉeṉ eṉṉātu tuṉṉi
  • {PU 171-4} vaikal um celiṉum poyyalaṉ āki
  • {PU 171-5} yām vēṇṭiyāṅku em vaṟum kalam niṟaippōṉ
  • {PU 171-6} tāṉ vēṇṭiyāṅku taṉ iṟai uvappa
  • {PU 171-7} arum toḻil muṭiyar ō tiruntu vēl koṟṟaṉ
  • {PU 171-8} iṉam mali kata cē kaḷaṉoṭu vēṇṭiṉum
  • {PU 171-9} kaḷam mali nelliṉ kuppai vēṇṭiṉum
  • {PU 171-10} arum kalam kaḷiṟṟoṭu vēṇṭiṉum peruntakai
  • {PU 171-11} piṟarkku um aṉṉa aṟam takaiyaṉ ē
  • {PU 171-12} aṉṉaṉ ākaliṉ entai uḷ aṭi
  • {PU 171-13} muḷ um nōva uṟāṟka tilla
  • {PU 171-14} īvōr ariya i ulakattu
  • {PU 171-15} vāḻvōr vāḻa avaṉ tāḷ vāḻiya ē
