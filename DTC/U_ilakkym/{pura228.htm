{PUṞAM 228}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 228-1} kalam cey kō ē kalam cey kō ē
  • {PU 228-2} iruḷ tiṇintaṉṉa kurūu tiraḷ parūu puki
  • {PU 228-3} akal iru vicumpiṉ ūṉṟum cūḷi
  • {PU 228-4} naṉam tali mūtūr kalam cey kō ē
  • {PU 228-5} aḷiyi nī ē yāṅku ākuvi kol
  • {PU 228-6} nilam vari cūṭṭiya nīḷ neṭum tāṉi
  • {PU 228-7} pulavar pukaḻnta poyyā nal ici
  • {PU 228-8} viri katir ñāyiṟu vicumpu ivarntaṉṉa
  • {PU 228-9} cēṇ viḷaṅku ciṟappiṉ cempiyar marukaṉ
  • {PU 228-10} koṭi nuṭaṅku yāṉi neṭumāvaḷavaṉ
  • {PU 228-11} tēvar ulakam eytiṉaṉ ātaliṉ
  • {PU 228-12} aṉṉōṉ kavikkum kaṇ akal tāḻi
  • {PU 228-13} vaṉital vēṭṭaṉi āyiṉ eṉiyatūum
  • {PU 228-14} iru nilam tikiri ā peru mali
  • {PU 228-15} maṇ ā vaṉital ollum ō niṉakku ē
