{PUṞAM 8}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 8-1} vaiyam kāvalar vaḻimoḻintu oḻuka
  • {PU 8-2} pōkam vēṇṭi potuccol poṟāatu
  • {PU 8-3} iṭam ciṟitu eṉṉum ūkkam turappa
  • {PU 8-4} oṭuṅkā uḷḷattu ōmpā īkai
  • {PU 8-5} kaṭantu aṭu tāṉai cēralātaṉai
  • {PU 8-6} yāṅkaṉam otti ō vīṅku celal maṇṭilam
  • {PU 8-7} poḻutu eṉa varaiti puṟakkoṭuttu iṟatti
  • {PU 8-8} māṟi varuti malai maṟaintu oḷitti
  • {PU 8-9} akal iru vicumpiṉāṉ um
  • {PU 8-10} pakal viḷaṅkuti āl pal katir virittu ē
