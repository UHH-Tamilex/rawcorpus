{PUṞAM 347}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 347-1} uṇpōṉ tāṉ naṟum kaḷḷiṉ iṭa cila
  • {PU 347-2} nā iṭai pal tēr kōla civanta
  • {PU 347-3} oḷiṟu oḷ vāṭa kuḻainta paim tumpai
  • {PU 347-4} eṟintu ilai muṟinta katuvāy vēliṉ
  • {PU 347-5} maṇam nāṟu mārpiṉ maṟam pōr akutai
  • {PU 347-6} kuṇṭu nīr varaippiṉ kūṭal aṉṉa
  • {PU 347-7} kuvai irum kūntal varu mulai cēppa
  • {PU 347-9} eṉ āvatu kol tāṉ ē
  • {PU 347-10} viḷaṅkuṟu parāraiya āyiṉum vēntar
  • {PU 347-11} viṉai navil yāṉai piṇippa
  • {PU 347-12} vēr tuḷaṅkiṉa nam ūr uḷ maraṉ ē
