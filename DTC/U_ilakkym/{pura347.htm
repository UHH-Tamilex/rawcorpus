{PUṞAM 347}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 347-1} uṇpōṉ tāṉ naṟum kaḷḷiṉ iṭa cila
  • {PU 347-2} nā iṭi pal tēr kōla civanta
  • {PU 347-3} oḷiṟu oḷ vāṭa kuḻinta pim tumpi
  • {PU 347-4} eṟintu ili muṟinta katuvāy vēliṉ
  • {PU 347-5} maṇam nāṟu mārpiṉ maṟam pōr akuti
  • {PU 347-6} kuṇṭu nīr varippiṉ kūṭal aṉṉa
  • {PU 347-7} kuvi irum kūntal varu muli cēppa
  • {PU 347-9} eṉ āvatu kol tāṉ ē
  • {PU 347-10} viḷaṅkuṟu parāriya āyiṉum vēntar
  • {PU 347-11} viṉi navil yāṉi piṇippa
  • {PU 347-12} vēr tuḷaṅkiṉa nam ūr uḷ maraṉ ē
