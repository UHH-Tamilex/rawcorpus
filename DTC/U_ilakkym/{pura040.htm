{PUṞAM 40}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 40-1} nī ē piṟar ōmpuṟu maṟa maṉ eyil
  • {PU 40-2} ōmpātu kaṭantu aṭṭu avar
  • {PU 40-3} muṭi puṉainta pacum poṉ niṉ
  • {PU 40-4} aṭi poliya kaḻal taiiya
  • {PU 40-5} vallāḷaṉai vaya vēntu ē
  • {PU 40-6} yām ē niṉ ikaḻ pāṭuvōr eruttu aṭaṅka
  • {PU 40-7} pukaḻ pāṭuvōr polivu tōṉṟa
  • {PU 40-8} iṉṟu kaṇṭāṅku kāṇkuvam eṉṟum
  • {PU 40-9} iṉ col eṇ patattai ākumati peruma
  • {PU 40-10} oru piṭi paṭiyum cīṟu iṭam
  • {PU 40-11} eḻu kaḷiṟu purakkum nāṭu kiḻavōy ē
