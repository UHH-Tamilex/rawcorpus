{PUṞAM 359}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 359-1} pāṟupaṭa paṟinta pal māṟu maruṅkiṉ
  • {PU 359-2} vēṟu paṭu kurala ve vāy kūkiyoṭu
  • {PU 359-3} piṇam tiṉ kuṟu nari niṇam tikaḻ palla
  • {PU 359-4} pēey makaḷir piṇam taḻūu paṟṟi
  • {PU 359-5} viḷar ūṉ tiṉṟa ve pulāl meyyar
  • {PU 359-6} kaḷari maruṅkiṉ kāl peyarttu āṭi
  • {PU 359-7} īma viḷakkiṉ veruvara pērum
  • {PU 359-8} kāṭu muṉṉiṉar ē nāṭu koṇṭōr um
  • {PU 359-9} niṉakku um varutal vikal aṟṟu ē
  • {PU 359-10} vaci um niṟkum ici um niṟkum
  • {PU 359-11} ataṉāl vaci nīkki ici vēṇṭi um
  • {PU 359-12} naci vēṇṭātu naṉṟu moḻintu um
  • {PU 359-13} nilavu kōṭṭu pala kaḷiṟṟoṭu
  • {PU 359-14} polam paṭiya mā mayaṅkiṭa
  • {PU 359-15} iḻi kiḷar neṭum tēr iravalarkku arukātu
  • {PU 359-16} koḷ eṉa viṭuvi āyiṉ veḷḷeṉa
  • {PU 359-17} āṇṭu nī peyarnta piṉ um
  • {PU 359-18} īṇṭu nīṭu viḷaṅkum nī eytiya pukaḻ ē
