{PUṞAM 247}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 247-1} yāṉai tanta muḷi mara viṟakiṉ
  • {PU 247-2} kāṉavar pottiya ñeli tī viḷakkattu
  • {PU 247-3} maṭa māṉ peru nirai vaiku tuyil eṭuppi
  • {PU 247-4} manti cīkkum aṇaṅku uṭai muṉṟilil
  • {PU 247-5} nīr vār kūntal irum puṟam tāḻa
  • {PU 247-6} pēr añar kaṇṇaḷ perum kāṭu nōkki
  • {PU 247-7} terumarum amma tāṉ ē taṉ koḻunaṉ
  • {PU 247-8} muḻavu kaṇ tuyilā kaṭi uṭai viyal nakar
  • {PU 247-9} ciṟu naṉi tamiyaḷ āyiṉum
  • {PU 247-10} iṉ uyir naṭuṅkum taṉ iḷamai puṟaṅkoṭuttu ē
