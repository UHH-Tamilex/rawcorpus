{PUṞAM 61}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 61-1} koṇṭai kūḻai taṇ taḻai kaṭaiciyar
  • {PU 61-2} ciṟu māṇ neytal āmpaloṭu kaṭkum
  • {PU 61-3} malaṅku miḷir ceṟuviṉ taḷampu taṭintu iṭṭa
  • {PU 61-4} paḻaṉa vāḷai parūu kaṇ tuṇiyal
  • {PU 61-5} putu nel veḷ cōṟṟu kaṇṇuṟai āka
  • {PU 61-6} vilā puṭai maruṅku vicippa mānti
  • {PU 61-7} nīṭu katir kaḻaṉi cūṭu taṭumāṟum
  • {PU 61-8} vaṉ kai viṉaiñar puṉ talai ciṟāar
  • {PU 61-9} teṅku paṭu viyaṉ paḻam muṉaiyiṉ tantaiyar
  • {PU 61-10} kuṟai kaṇ neṭum pōr ēṟi vicaittu eḻuntu
  • {PU 61-11} ceḻum kōḷ peṇṇai paḻam toṭa muyalum
  • {PU 61-12} vaikal yāṇar nal nāṭṭu porunaṉ
  • {PU 61-13} eḵku viḷaṅku taṭam kai iyal tēr ceṉṉi
  • {PU 61-14} cilai tār akalam malaikkunar uḷar eṉiṉ
  • {PU 61-15} tām aṟikuvar tamakku uṟuti yām avaṉ
  • {PU 61-16} eḻu uṟaḻ tiṇi tōḷ vaḻu iṉṟu malaintōr
  • {PU 61-17} vāḻa kaṇṭaṉṟu um ilam ē tāḻātu
  • {PU 61-18} tiruntu aṭi porunta vallōr
  • {PU 61-19} varunta kāṇṭal ataṉiṉum ilam ē
