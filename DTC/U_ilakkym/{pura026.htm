{PUṞAM 26}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 26-1} naḷi kaṭal irum kuṭṭattu
  • {PU 26-2} vaḷi puṭitta kalam pōla
  • {PU 26-3} kaḷiṟu ceṉṟu kaḷaṉ akaṟṟa um
  • {PU 26-4} kaḷaṉ akaṟṟiya viyal āṅkaṇ
  • {PU 26-5} oḷiṟu iliya eḵku ēnti
  • {PU 26-6} aricu paṭa amar uḻakki
  • {PU 26-7} uri cela muracu vuvi
  • {PU 26-8} muṭi tali aṭuppu āka
  • {PU 26-9} puṉal kuruti uli koḷīi
  • {PU 26-10} toṭi tōḷ tuṭuppiṉ tuḻanta valciyiṉ
  • {PU 26-11} aṭu kaḷam vēṭṭa aṭu pōr ceḻiya
  • {PU 26-12} āṉṟa kēḷvi aṭaṅkiya koḷki
  • {PU 26-13} nāṉ maṟi mutalvar cuṟṟam āka
  • {PU 26-14} maṉṉar ēval ceyya maṉṉiya
  • {PU 26-15} vēḷvi muṟṟiya vāy vāḷ vēntu ē
  • {PU 26-16} nōṟṟōr maṉṟa niṉ pakivar niṉṉoṭu
  • {PU 26-17} māṟṟār eṉṉum peyar peṟṟu
  • {PU 26-18} āṟṟār āyiṉum āṇṭu vāḻvōr ē
