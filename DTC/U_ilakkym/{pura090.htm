{PUṞAM 90}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 90-1} uṭai vaḷai kaṭuppa malarnta kāntaḷ
  • {PU 90-2} aṭai malku kuḷaviyoṭu kamaḻum cāral
  • {PU 90-3} maṟam puli uṭaliṉ māṉ kaṇam uḷa ō
  • {PU 90-4} maṟuḷiṉa vicumpiṉ mātirattu īṇṭiya
  • {PU 90-5} iruḷ um uṇṭu ō ñāyiṟu ciṉaviṉ
  • {PU 90-6} accoṭu tākki pār uṟṟu iyaṅkiya
  • {PU 90-7} paṇṭa cākāṭṭu āḻcci colliya
  • {PU 90-8} vari maṇal ñemara kal paka naṭakkum
  • {PU 90-9} perumita pakaṭṭukku tuṟai um uṇṭu ō
  • {PU 90-10} eḻumaram kaṭukkum tāḷ tōy taṭam kai
  • {PU 90-11} vaḻu il vaṉ kai maḻavar peruma
  • {PU 90-12} iru nilam maṇ koṇṭu cilaikkum
  • {PU 90-13} porunar um uḷar ō nī kaḷam pukiṉ ē
