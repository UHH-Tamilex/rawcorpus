  • {PU 99-1} amarar pēṇi um āvuti arutti um
  • {PU 99-2} arum peṟal marapiṉ karumpu ivaṇ tantu um
  • {PU 99-3} nīr aka irukki āḻi cūṭṭiya
  • {PU 99-4} tol nili marapiṉ niṉ muṉṉōr pōla
  • {PU 99-5} īki am kaḻal kāl irum paṉam puṭiyal
  • {PU 99-6} pū ār kāviṉ puṉiṟṟu pulāl neṭu vēl
  • {PU 99-7} eḻu poṟi nāṭṭattu eḻāa tāyam
  • {PU 99-8} vaḻu iṉṟu eyti um amiyāy ceru vēṭṭu
  • {PU 99-9} imiḻ kural muraciṉ eḻuvaroṭu muraṇi
  • {PU 99-10} ceṉṟu amar kaṭantu niṉ āṟṟal tōṟṟiya
  • {PU 99-11} aṉṟu um pāṭunarkku ariyi iṉṟu um
  • {PU 99-12} paraṇaṉ pāṭiṉaṉ maṉ kol maṟṟu nī
  • {PU 99-13} muraṇ miku kōvalūr nūṟi niṉ
  • {PU 99-14} araṇ aṭu tikiri ēntiya tōḷ ē
