{PUṞAM 177}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 177-1} oḷiṟu vāḷ maṉṉar oḷ cuṭar neṭu nakar
  • {PU 177-2} veḷiṟu kaṇ pōka pal nāḷ tiraṅki
  • {PU 177-3} pāṭi peṟṟa poṉ aṇi yāṉi
  • {PU 177-4} tamar eṉiṉ yāvar um pukupa amar eṉiṉ
  • {PU 177-5} tiṅkaḷ um nuḻiyā entira paṭu puḻi
  • {PU 177-6} kaḷ māṟu nīṭṭa naṇi naṇi irunta
  • {PU 177-7} kuṟum pal kuṟumpiṉ tatumpa viki
  • {PU 177-8} puḷi cuvi vēṭṭa ce kaṇ āṭavar
  • {PU 177-9} tīm puḷi kaḷāvoṭu tuṭari muṉiyiṉ
  • {PU 177-10} maṭṭu aṟal nal yāṟṟu ekkar ēṟi
  • {PU 177-11} karum kaṉi nāval iruntu koytu uṇṇum
  • {PU 177-12} perum peyar āti piṇaṅku aril kuṭa nāṭṭu
  • {PU 177-13} eyiṉar tanta eymmāṉ eṟi taci
  • {PU 177-14} pim ñiṇam perutta pacu veḷ amali
  • {PU 177-15} varunarkku variyātu taruvaṉar coriya
  • {PU 177-16} irum paṉam kuṭiyiṉ mici um
  • {PU 177-17} perum pular vikaṟi cīr cālātu ē
