{PUṞAM 44}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 44-1} irum piṭi toḻutiyoṭu perum kayam paṭiyā
  • {PU 44-2} nel uṭai kavaḷamoṭu neym miti peṟāa
  • {PU 44-3} tiruntu arai nōṉ veḷil varunta oṟṟi
  • {PU 44-4} nilam micai puraḷum kaiya veytu uyirttu
  • {PU 44-5} alamaral yāṉai urum eṉa muḻaṅka um
  • {PU 44-6} pāl il kuḻavi alaṟa um makaḷir
  • {PU 44-7} pū il vaṟum talai muṭippa um nīr il
  • {PU 44-8} viṉai puṉai nal il iṉaikūu kēṭpa um
  • {PU 44-9} iṉṉātu amma īṅku iṉitu iruttal
  • {PU 44-10} tuṉ arum tuppiṉ vaya māṉ tōṉṟal
  • {PU 44-11} aṟavai āyiṉ niṉatu eṉa tiṟattal
  • {PU 44-12} maṟavai āyiṉ pōroṭu tiṟattal
  • {PU 44-13} aṟavai um maṟavai um allai āka
  • {PU 44-14} tiṟavātu aṭaitta tiṉ nilai kataviṉ
  • {PU 44-15} nīḷ matil oru ciṟai oṭuṅkutal
  • {PU 44-16} nāṇu takavu uṭaittu itu kāṇum kāl ē
