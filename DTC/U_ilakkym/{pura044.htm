{PUṞAM 44}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 44-1} irum piṭi toḻutiyoṭu perum kayam paṭiyā
  • {PU 44-2} nel uṭi kavaḷamoṭu neym miti peṟāa
  • {PU 44-3} tiruntu ari nōṉ veḷil varunta oṟṟi
  • {PU 44-4} nilam mici puraḷum kiya veytu uyirttu
  • {PU 44-5} alamaral yāṉi urum eṉa muḻaṅka um
  • {PU 44-6} pāl il kuḻavi alaṟa um makaḷir
  • {PU 44-7} pū il vaṟum tali muṭippa um nīr il
  • {PU 44-8} viṉi puṉi nal il iṉikūu kēṭpa um
  • {PU 44-9} iṉṉātu amma īṅku iṉitu iruttal
  • {PU 44-10} tuṉ arum tuppiṉ vaya māṉ tōṉṟal
  • {PU 44-11} aṟavi āyiṉ niṉatu eṉa tiṟattal
  • {PU 44-12} maṟavi āyiṉ pōroṭu tiṟattal
  • {PU 44-13} aṟavi um maṟavi um alli āka
  • {PU 44-14} tiṟavātu aṭitta tiṉ nili kataviṉ
  • {PU 44-15} nīḷ matil oru ciṟi oṭuṅkutal
  • {PU 44-16} nāṇu takavu uṭittu itu kāṇum kāl ē
