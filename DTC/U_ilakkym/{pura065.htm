{PUṞAM 65}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 65-1} maṇ muḻā maṟappa paṇ yāḻ maṟappa
  • {PU 65-2} irum kaṇ kuḻici kaviḻntu iḻutu maṟappa
  • {PU 65-3} curumpu ār tēṟal cuṟṟam maṟappa
  • {PU 65-4} uḻavar ōtai maṟappa viḻavu um
  • {PU 65-5} akaluḷ āṅkaṇ cīṟūr maṟappa
  • {PU 65-6} uvavu talaivanta peru nāḷ amaiyattu
  • {PU 65-7} iru cuṭar tam uḷ nōkki oru cuṭar
  • {PU 65-8} puṉkaṇ mālai malai maṟaintāṅku
  • {PU 65-9} taṉ pōl vēntaṉ muṉpu kuṟittu eṟinta
  • {PU 65-10} puṟam puṇ nāṇi maṟa takai maṉṉaṉ
  • {PU 65-11} vāḷ vaṭakkiruntaṉaṉ īṅku
  • {PU 65-12} nāḷ pōl kaḻiyala ñāyiṟṟu pakal ē
