Naṟṟiṇai

((Originally extracted from master file ^NARRI.OCP))
((Last updated on 2004 April 14th))

  • {NT 204-1} taḷir cēr taṇ taḻai taii nuntai
  • {NT 204-2} kuḷir vāy viyaṉ puṉattu el paṭa varuku ō
  • {NT 204-3} kuṟum cuṉai kuvaḷai aṭaicci nām puṇariya
  • {NT 204-4} naṟum taṇ cāral āṭukam varuku ō
  • {NT 204-5} iṉ col mēvu alaippaṭṭa eṉ neñcu uṇa
  • {NT 204-6} kūṟu iṉi maṭantai niṉ kūr eyiṟu uṇku eṉa
  • {NT 204-7} yāṉ taṉ moḻitaliṉ moḻi etir vantu
  • {NT 204-8} tāṉ cey kuṟi nilai iṉiya kūṟi
  • {NT 204-9} ēṟu piri maṭa piṇai kaṭuppa vēṟupaṭṭu
  • {NT 204-10} uṟu kaḻai nivappiṉ ciṟukuṭi peyarum
  • {NT 204-11} koṭicci cel puṟam nōkki
  • {NT 204-12} viṭutta neñcam viṭal ollātu ē
