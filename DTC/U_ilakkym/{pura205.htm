{PUṞAM 205}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 205-1} muṟṟiya tiruviṉ mūvar āyiṉum
  • {PU 205-2} peṭpu iṉṟu ītal yām vēṇṭalam ē
  • {PU 205-3} viṟal ciṉam taṇinta virai pari puravi
  • {PU 205-4} uṟuvar cel cārvu āki ceṟuvar
  • {PU 205-5} tāḷ uḷam taputta vāḷ miku tāṉai
  • {PU 205-6} veḷ vī vēli kōṭai poruna
  • {PU 205-7} ciṟiya um periya um puḻai keṭa vilaṅkiya
  • {PU 205-8} māṉ kaṇam tolaicciya kaṭu vicai kata nāy
  • {PU 205-9} nōṉ cilai vēṭṭuva nōy ilaiyākuka
  • {PU 205-10} ār kali yāṇar tarīiya kāl vīḻttu
  • {PU 205-11} kaṭal vayiṉ kuḻīiya aṇṇal am koṇmū
  • {PU 205-12} nīr iṉṟu peyarāvāṅku tēroṭu
  • {PU 205-13} oḷiṟu maruppu ēntiya cemmal
  • {PU 205-14} kaḷiṟu iṉṟu peyarala paricilar kaṭumpu ē
