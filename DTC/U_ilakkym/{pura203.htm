{PUṞAM 203}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 203-1} kaḻintatu poḻintu eṉa vāṉ kaṇ māṟiṉum
  • {PU 203-2} tollatu viḷintu eṉa nilam vaḷam karappiṉum
  • {PU 203-3} ellā uyirkku um illāl vāḻkki
  • {PU 203-4} iṉṉum tam eṉa emmaṉōr irappiṉ
  • {PU 203-5} muṉṉum koṇṭir eṉa nummaṉōr maṟuttal
  • {PU 203-6} iṉṉātu amma iyal tēr aṇṇal
  • {PU 203-7} illatu nirappal āṟṟātōriṉum
  • {PU 203-8} uḷḷi varunar naci iḻappōr ē
  • {PU 203-9} aṉiyi um alli nī ē oṉṉār
  • {PU 203-10} ār eyil avar kaṭṭu āka um numatu eṉa
  • {PU 203-11} pāṇ kaṭaṉ iṟukkum vaḷḷiyōy
  • {PU 203-12} pūṇ kaṭaṉ enti nī iravalar puravu ē
