{PUṞAM 28}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 28-1} ciṟappu il citaṭu um uṟuppu il piṇṭam um
  • {PU 28-2} kūṉ um kuṟaḷ um ūm um ceviṭu um
  • {PU 28-3} mā um maruḷ um uḷappaṭa vāḻnarkku
  • {PU 28-4} eṇ pēr eccam eṉṟu ivi ellām
  • {PU 28-5} pētimi allatu ūtiyam il eṉa
  • {PU 28-6} muṉ um aṟintōr kūṟiṉar iṉṉum
  • {PU 28-7} ataṉ tiṟam atti yāṉ urikka vantatu
  • {PU 28-8} vaṭṭa variya ce poṟi cēval
  • {PU 28-9} ēṉal kāppōr uṇarttiya kūum
  • {PU 28-10} kāṉattōr niṉ tevvar nī ē
  • {PU 28-11} puṟañciṟi mākkaṭku aṟam kuṟittu akattōr
  • {PU 28-12} puyttu eṟi karumpiṉ viṭu kaḻi tāmari
  • {PU 28-13} pūm pōtu citiya vīḻnteṉa kūttar
  • {PU 28-14} āṭu kaḷam kaṭukkum aka nāṭṭi ē
  • {PU 28-15} ataṉāl aṟaṉ um poruḷ um iṉpam um mūṉṟu um
  • {PU 28-16} āṟṟum peruma niṉ celvam
  • {PU 28-17} āṟṟāmi niṉ pōṟṟāmi ē
