{PUṞAM 235}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 235-1} ciṟiya kaḷ peṟiṉ ē emakku īyum maṉ ē
  • {PU 235-2} periya kaḷ peṟiṉ ē
  • {PU 235-3} yām pāṭa tāṉ makiḻntu uṇṇum maṉ ē
  • {PU 235-4} ciṟu cōṟṟāṉ um naṉi pala kalattaṉ maṉ ē
  • {PU 235-5} perum cōṟṟāṉ um naṉi pala kalattaṉ maṉ ē
  • {PU 235-6} eṉpoṭu taṭi paṭu vaḻi ellām emakku īyum maṉ ē
  • {PU 235-7} ampoṭu vēl nuḻai vaḻi ellām tāṉ niṟkum maṉ ē
  • {PU 235-8} narantam nāṟum taṉ kaiyāl
  • {PU 235-9} pulavu nāṟum eṉ talai taivarum maṉ ē
  • {PU 235-10} arum talai irum pāṇar akal maṇṭai tuḷai urīi
  • {PU 235-11} irappōr kai uḷ um pōki
  • {PU 235-12} purappōr puṉ kaṇ pāvai cōra
  • {PU 235-13} am col nuṇ tērcci pulavar nāvil
  • {PU 235-14} ceṉṟu vīḻntaṉṟu avaṉ
  • {PU 235-15} aru niṟattu iṅkiya vēl ē
  • {PU 235-16} ācu āku entai yāṇṭu uḷaṉ kol ō
  • {PU 235-17} iṉi pāṭunar um illai pāṭunarkku oṉṟu īkunar um illai
  • {PU 235-18} paṉi tuṟai pakaṉṟai naṟai koḷ mā malar
  • {PU 235-19} cūṭātu vaikiyāṅku piṟarkku oṉṟu
  • {PU 235-20} īyātu vīyum uyir tava pala ē
