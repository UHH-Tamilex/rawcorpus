{PUṞAM 39}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 39-1} puṟaviṉ allal colliya kaṟai aṭi
  • {PU 39-2} yāṉai vāl maruppu eṟinta veḷ kaṭai
  • {PU 39-3} kōl niṟai tulāam pukkōṉ maruka
  • {PU 39-4} ītal niṉ pukaḻ um aṉṟu ē cārtal
  • {PU 39-5} oṉṉār uṭkum tuṉ arum kaṭum tiṟal
  • {PU 39-6} tūṅku eyil eṟinta niṉ ūṅkaṇōr niṉaippiṉ
  • {PU 39-7} aṭutal niṉ pukaḻ um aṉṟu ē keṭu iṉṟu
  • {PU 39-8} maṟam keḻu cōḻar uṟantai avaiyattu
  • {PU 39-9} aṟam niṉṟu nilaiyiṟṟu ākaliṉ ataṉāl
  • {PU 39-10} muṟaimai niṉ pukaḻ um aṉṟu ē maṟam mikku
  • {PU 39-11} eḻu camam kaṭanta eḻu uṟaḻ tiṇi tōḷ
  • {PU 39-12} kaṇ ār kaṇṇi kali māṉ vaḷava
  • {PU 39-13} yāṅkaṉam moḻiku ō yāṉ ē ōṅkiya
  • {PU 39-14} varai aḷantu aṟiyā poṉ paṭu neṭum kōṭṭu
  • {PU 39-15} imayam cūṭṭiya ēma vil poṟi
  • {PU 39-16} māṇ viṉai neṭum tēr vāṉavaṉ tolaiya
  • {PU 39-17} vāṭā vañci vāṭṭum niṉ
  • {PU 39-18} pīṭu keḻu nōṉ tāḷ pāṭum kāl ē
