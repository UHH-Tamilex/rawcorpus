{PUṞAM 297}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 297-1} peru nīr mēval taṇṇaṭi erumi
  • {PU 297-2} iru maruppu uṟaḻum neṭu māṇ neṟṟiṉ
  • {PU 297-3} pim payaṟu utirtta kōtiṉ kōl aṇi
  • {PU 297-4} kaṉṟu uṭi mariyā tuñcum cīṟūr
  • {PU 297-5} kōḷ ivaṇ vēṇṭēm puravu ē nār ari
  • {PU 297-6} naṉi mutir cāṭi naṟaviṉ vāḻtti
  • {PU 297-7} tuṟi naṉi keḻīi kampuḷ īṉum
  • {PU 297-8} taṇṇaṭi peṟutal um urittu ē vi nuti
  • {PU 297-9} neṭu vēl pāynta mārpiṉ
  • {PU 297-10} maṭal vaṉ pōntiyiṉ niṟkumōrkku ē
