{PUṞAM 297}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 297-1} peru nīr mēval taṇṇaṭai erumai
  • {PU 297-2} iru maruppu uṟaḻum neṭu māṇ neṟṟiṉ
  • {PU 297-3} paim payaṟu utirtta kōtiṉ kōl aṇai
  • {PU 297-4} kaṉṟu uṭai maraiyā tuñcum cīṟūr
  • {PU 297-5} kōḷ ivaṇ vēṇṭēm puravu ē nār ari
  • {PU 297-6} naṉai mutir cāṭi naṟaviṉ vāḻtti
  • {PU 297-7} tuṟai naṉi keḻīi kampuḷ īṉum
  • {PU 297-8} taṇṇaṭai peṟutal um urittu ē vai nuti
  • {PU 297-9} neṭu vēl pāynta mārpiṉ
  • {PU 297-10} maṭal vaṉ pōntaiyiṉ niṟkumōrkku ē
