{PUṞAM 285}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 285-1} pācaṟiyīr ē pācaṟiyīr ē
  • {PU 285-2} tuṭiyaṉ kiyatu vēl ē aṭi puṇar
  • {PU 285-3} vāṅku iru maruppiṉ tīm toṭi cīṟiyāḻ
  • {PU 285-4} pāṇaṉ kiyatu tōl ē kāṇvara
  • {PU 285-5} kaṭum teṟṟu mūṭiyiṉ
  • {PU 285-6} vāṭiya māli malinta ceṉṉiyaṉ
  • {PU 285-7} vēntutoḻil ayarum arum tali cuṟṟamoṭu
  • {PU 285-8} neṭu nakar vanteṉa viṭu kaṇi mocitta
  • {PU 285-9} mūri veḷ tōl
  • {PU 285-10} cēṟu paṭu kuruti cemmal ukku ōo
  • {PU 285-11} māṟu ceṟu neṭu vēl mārpu uḷam pōka
  • {PU 285-12} niṇam poti kaḻaloṭu nilam cērntaṉaṉ ē
  • {PU 285-13} atu kaṇṭu parantōr ellām pukaḻa tali paṇintu
  • {PU 285-14} iṟiñciyōṉ ē kurucil piṇaṅku katir
  • {PU 285-15} alamarum kaḻaṉi taṇṇaṭi oḻiya
  • {PU 285-16} ilampāṭu okkal talivaṟku ōr
  • {PU 285-17} karampi cīṟūr nalkiṉaṉ eṉa ē
