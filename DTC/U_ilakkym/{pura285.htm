{PUṞAM 285}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 285-1} pācaṟaiyīr ē pācaṟaiyīr ē
  • {PU 285-2} tuṭiyaṉ kaiyatu vēl ē aṭi puṇar
  • {PU 285-3} vāṅku iru maruppiṉ tīm toṭai cīṟiyāḻ
  • {PU 285-4} pāṇaṉ kaiyatu tōl ē kāṇvara
  • {PU 285-5} kaṭum teṟṟu mūṭaiyiṉ
  • {PU 285-6} vāṭiya mālai malainta ceṉṉiyaṉ
  • {PU 285-7} vēntutoḻil ayarum arum talai cuṟṟamoṭu
  • {PU 285-8} neṭu nakar vanteṉa viṭu kaṇai mocitta
  • {PU 285-9} mūri veḷ tōl
  • {PU 285-10} cēṟu paṭu kuruti cemmal ukku ōo
  • {PU 285-11} māṟu ceṟu neṭu vēl mārpu uḷam pōka
  • {PU 285-12} niṇam poti kaḻaloṭu nilam cērntaṉaṉ ē
  • {PU 285-13} atu kaṇṭu parantōr ellām pukaḻa talai paṇintu
  • {PU 285-14} iṟaiñciyōṉ ē kurucil piṇaṅku katir
  • {PU 285-15} alamarum kaḻaṉi taṇṇaṭai oḻiya
  • {PU 285-16} ilampāṭu okkal talaivaṟku ōr
  • {PU 285-17} karampai cīṟūr nalkiṉaṉ eṉa ē
