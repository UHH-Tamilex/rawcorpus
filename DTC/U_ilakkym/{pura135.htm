{PUṞAM 135}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 135-1} koṭuvari vaḻaṅkum kōṭu uyar neṭu varai
  • {PU 135-2} aru viṭar ciṟu neṟi ēṟaliṉ varunti
  • {PU 135-3} taṭavaral koṇṭa takai mel otukkiṉ
  • {PU 135-4} vaḷai kai viṟali eṉ piṉṉaḷ āka
  • {PU 135-5} poṉ vārntaṉṉa puri aṭaṅku narampiṉ
  • {PU 135-6} vari navil paṉuval pulam peyarntu icaippa
  • {PU 135-7} paṭumalai niṉṟa payam keḻu cīṟiyāḻ
  • {PU 135-8} olkal uḷḷamoṭu oru puṭai taḻīi
  • {PU 135-9} pukaḻ cāl ciṟappiṉ niṉ nal icai uḷḷi
  • {PU 135-10} vantaṉeṉ entai yāṉ ē eṉṟum
  • {PU 135-11} maṉṟu paṭu paricilar kāṇiṉ kaṉṟoṭu
  • {PU 135-12} kaṟai aṭi yāṉai iriyal pōkkum
  • {PU 135-13} malai keḻu nāṭaṉ mā vēḷ āay
  • {PU 135-14} kaḷiṟu um aṉṟu ē mā um aṉṟu ē
  • {PU 135-15} oḷiṟu paṭai puraviya tēr um aṉṟu ē
  • {PU 135-16} pāṇar pāṭunar paricilar āṅku avar
  • {PU 135-17} tamatu eṉa toṭukkuvar āyiṉ ematu eṉa
  • {PU 135-18} paṟṟal tēṟṟā payam keḻu tāyamoṭu
  • {PU 135-19} aṉṉa āka niṉ ūḻi niṉṉai
  • {PU 135-20} kāṇṭal vēṇṭiya aḷavai vēṇṭār
  • {PU 135-21} uṟu muraṇ kaṭanta āṟṟal
  • {PU 135-22} potu mīkkūṟṟattu nāṭu kiḻavōy ē
