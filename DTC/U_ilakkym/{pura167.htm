{PUṞAM 167}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 167-1} nī ē amar kāṇiṉ amar kaṭantu avar
  • {PU 167-2} paṭai vilakki etir niṟṟaliṉ
  • {PU 167-3} vāaḷ vāytta vaṭu āḻ yākkaiyoṭu
  • {PU 167-4} kēḷvikku iṉiyai kaṭku iṉṉāy ē
  • {PU 167-5} avar ē niṉ kāṇiṉ puṟam koṭuttaliṉ
  • {PU 167-6} ūṟu aṟiyā mey yākkaiyoṭu
  • {PU 167-7} kaṇṇukku iṉiyar cevikku iṉṉār ē
  • {PU 167-8} ataṉāl nī um oṉṟu iṉiyai avar um oṉṟu iṉiyar
  • {PU 167-9} ovvā yā uḷa maṟṟu ē vel pōr
  • {PU 167-10} kaḻal puṉai tiruntu aṭi kaṭu māṉ kiḷḷi
  • {PU 167-11} niṉṉai viyakkum i ulakam aḵtu
  • {PU 167-12} eṉ ō peruma uraitticiṉ emakku ē
