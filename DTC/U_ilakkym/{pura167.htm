{PUṞAM 167}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 167-1} nī ē amar kāṇiṉ amar kaṭantu avar
  • {PU 167-2} paṭi vilakki etir niṟṟaliṉ
  • {PU 167-3} vāaḷ vāytta vaṭu āḻ yākkiyoṭu
  • {PU 167-4} kēḷvikku iṉiyi kaṭku iṉṉāy ē
  • {PU 167-5} avar ē niṉ kāṇiṉ puṟam koṭuttaliṉ
  • {PU 167-6} ūṟu aṟiyā mey yākkiyoṭu
  • {PU 167-7} kaṇṇukku iṉiyar cevikku iṉṉār ē
  • {PU 167-8} ataṉāl nī um oṉṟu iṉiyi avar um oṉṟu iṉiyar
  • {PU 167-9} ovvā yā uḷa maṟṟu ē vel pōr
  • {PU 167-10} kaḻal puṉi tiruntu aṭi kaṭu māṉ kiḷḷi
  • {PU 167-11} niṉṉi viyakkum i ulakam aḵtu
  • {PU 167-12} eṉ ō peruma uritticiṉ emakku ē
