{PUṞAM 225}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 225-1} taliyōr nuṅkiṉ tīm cēṟu miciya
  • {PU 225-2} iṭiyōr paḻattiṉ pim kaṉi mānta
  • {PU 225-3} kaṭiyōr viṭu vāy piciroṭu cuṭu kiḻaṅku nukara
  • {PU 225-4} nilam malar viyattu valam muṟi vaḷii
  • {PU 225-5} vēntu pīṭu aḻitta ēntu vēl tāṉiyoṭu
  • {PU 225-6} āṟṟal eṉpataṉ tōṟṟam kēḷ iṉi
  • {PU 225-7} kaḷḷi pōkiya kaḷari am paṟantali
  • {PU 225-8} muḷ uṭi viyaṉ kāṭṭatu ē naṉṟu um
  • {PU 225-9} cēṭceṉṉi nalaṅkiḷḷi kēṭkuvaṉ kol eṉa
  • {PU 225-10} iṉ ici paṟiyoṭu veṉṟi nuvala
  • {PU 225-11} tūkkaṇaṅkurīi tūṅku kūṭu ēyppa
  • {PU 225-12} oru ciṟi koḷīiya tiri vāy valampuri
  • {PU 225-13} ñālam kāvalar kaṭi tali
  • {PU 225-14} kāli tōṉṟiṉum nōku ō yāṉ ē
