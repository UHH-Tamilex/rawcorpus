{PUṞAM 200}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 200-1} paṉi varai nivanta pācu ilai palaviṉ
  • {PU 200-2} kaṉi kavarntu uṇṭa karu viral kaṭuvaṉ
  • {PU 200-3} ce mukam mantiyoṭu ciṟantu cēṇ viḷaṅki
  • {PU 200-4} maḻai micai aṟiyā māl varai aṭukkattu
  • {PU 200-5} kaḻai micai tuñcum kal aka veṟpa
  • {PU 200-6} niṇam tiṉṟu cerukkiya neruppu talai neṭu vēl
  • {PU 200-7} kaḷam koṇṭu kaṉalum kaṭuṅkaṇ yāṉai
  • {PU 200-8} viḷaṅku maṇi koṭum pūṇ viccikkō ē
  • {PU 200-9} ivar ē pū talai aṟāa puṉai koṭi mullai
  • {PU 200-10} nā taḻumpu iruppa pāṭātu āyiṉum
  • {PU 200-11} kaṟaṅku maṇi neṭum tēr koḷka eṉa koṭutta
  • {PU 200-12} parantu ōṅku ciṟappiṉ pāri makaḷir
  • {PU 200-13} yāṉ ē paricilaṉ maṉṉum antaṇaṉ nī ē
  • {PU 200-14} varicaiyil vaṇakkum vāḷ mēmpaṭunaṉ
  • {PU 200-15} niṉakku yāṉ koṭuppa koṇmati ciṉam pōr
  • {PU 200-16} aṭaṅkā maṉṉarai aṭakkum
  • {PU 200-17} maṭaṅkā viḷaiyuḷ nāṭu kiḻavōy ē
