{PUṞAM 200}

((Last updated on 2004 April 14th))

  • {PU 200-1} paṉi vari nivanta pācu ili palaviṉ
  • {PU 200-2} kaṉi kavarntu uṇṭa karu viral kaṭuvaṉ
  • {PU 200-3} ce mukam mantiyoṭu ciṟantu cēṇ viḷaṅki
  • {PU 200-4} maḻi mici aṟiyā māl vari aṭukkattu
  • {PU 200-5} kaḻi mici tuñcum kal aka veṟpa
  • {PU 200-6} niṇam tiṉṟu cerukkiya neruppu tali neṭu vēl
  • {PU 200-7} kaḷam koṇṭu kaṉalum kaṭuṅkaṇ yāṉi
  • {PU 200-8} viḷaṅku maṇi koṭum pūṇ viccikkō ē
  • {PU 200-9} ivar ē pū tali aṟāa puṉi koṭi mulli
  • {PU 200-10} nā taḻumpu iruppa pāṭātu āyiṉum
  • {PU 200-11} kaṟaṅku maṇi neṭum tēr koḷka eṉa koṭutta
  • {PU 200-12} parantu ōṅku ciṟappiṉ pāri makaḷir
  • {PU 200-13} yāṉ ē paricilaṉ maṉṉum antaṇaṉ nī ē
  • {PU 200-14} variciyil vaṇakkum vāḷ mēmpaṭunaṉ
  • {PU 200-15} niṉakku yāṉ koṭuppa koṇmati ciṉam pōr
  • {PU 200-16} aṭaṅkā maṉṉari aṭakkum
  • {PU 200-17} maṭaṅkā viḷiyuḷ nāṭu kiḻavōy ē
