{PUṞAM 62}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 62-1} varu tār tāṅki amar mikal yāvatu
  • {PU 62-2} porutu āṇṭu oḻinta mintar puṇ toṭṭu
  • {PU 62-3} kuruti ce ki kūntal tīṭṭi
  • {PU 62-4} niṟam kiḷar uruviṉ pēey peṇṭir
  • {PU 62-5} eṭuttu eṟi aṉantal paṟi cīr tūṅka
  • {PU 62-6} paruntu aruntuṟṟa tāṉiyoṭu ceru muṉintu
  • {PU 62-7} aṟattiṉ maṇṭiya maṟam pōr vēntar
  • {PU 62-8} tām māyntaṉar ē kuṭi tuḷaṅkiṉa ē
  • {PU 62-9} uri cāl ciṟappiṉ muricu oḻintaṉa ē
  • {PU 62-10} pal nūṟu aṭukkiya vēṟu paṭu pim ñilam
  • {PU 62-11} iṭam keṭa īṇṭiya viyaṉ kaṇ pācaṟi
  • {PU 62-12} kaḷam koḷaṟku uriyōr iṉṟi teṟuvara
  • {PU 62-13} uṭaṉ vīḻntaṉṟu āl amar ē peṇṭir um
  • {PU 62-14} pācu aṭaku miciyār paṉi nīr mūḻkār
  • {PU 62-15} mārpakam porunti āṅku amintaṉar ē
  • {PU 62-16} vāṭā pūviṉ imiyā nāṭṭattu
  • {PU 62-17} nāṟṟa uṇaviṉōr um āṟṟa
  • {PU 62-18} arum peṟal ulakam niṟiya
  • {PU 62-19} viruntu peṟṟaṉar āl polika num pukaḻ ē
