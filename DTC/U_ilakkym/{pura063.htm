{PUṞAM 63}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 63-1} eṉai pal yāṉai um ampoṭu tuḷaṅki
  • {PU 63-2} viḷaikkum viṉai iṉṟi paṭai oḻintaṉa ē
  • {PU 63-3} viṟal pukaḻ māṇṭa puravi ellām
  • {PU 63-4} maṟam takai maintaroṭu āṇṭu paṭṭaṉa ē
  • {PU 63-5} tēr tara vanta cāṉṟōr ellām
  • {PU 63-6} tōl kaṇ maṟaippa oruṅku māyntaṉar ē
  • {PU 63-7} vicittu viṉai māṇṭa mayir kaṇ muracam
  • {PU 63-8} poṟukkunar iṉmaiyiṉ iruntu viḷintaṉa ē
  • {PU 63-9} cāntu amai mārpil neṭu vēl pāynteṉa
  • {PU 63-10} vēntar um porutu kaḷattu oḻintaṉar iṉi ē
  • {PU 63-11} eṉ āvatu kol tāṉ ē kaḻaṉi
  • {PU 63-12} āmpal vaḷḷi toṭi kai makaḷir
  • {PU 63-13} pācu aval mukki taṇ puṉal pāyum
  • {PU 63-14} yāṇar aṟāa vaippiṉ
  • {PU 63-15} kāmar kiṭakkai avar akal talai nāṭu ē
