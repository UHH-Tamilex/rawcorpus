{PUṞAM 63}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 63-1} eṉi pal yāṉi um ampoṭu tuḷaṅki
  • {PU 63-2} viḷikkum viṉi iṉṟi paṭi oḻintaṉa ē
  • {PU 63-3} viṟal pukaḻ māṇṭa puravi ellām
  • {PU 63-4} maṟam taki mintaroṭu āṇṭu paṭṭaṉa ē
  • {PU 63-5} tēr tara vanta cāṉṟōr ellām
  • {PU 63-6} tōl kaṇ maṟippa oruṅku māyntaṉar ē
  • {PU 63-7} vicittu viṉi māṇṭa mayir kaṇ muracam
  • {PU 63-8} poṟukkunar iṉmiyiṉ iruntu viḷintaṉa ē
  • {PU 63-9} cāntu ami mārpil neṭu vēl pāynteṉa
  • {PU 63-10} vēntar um porutu kaḷattu oḻintaṉar iṉi ē
  • {PU 63-11} eṉ āvatu kol tāṉ ē kaḻaṉi
  • {PU 63-12} āmpal vaḷḷi toṭi ki makaḷir
  • {PU 63-13} pācu aval mukki taṇ puṉal pāyum
  • {PU 63-14} yāṇar aṟāa vippiṉ
  • {PU 63-15} kāmar kiṭakki avar akal tali nāṭu ē
