{PUṞAM 10}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 10-1} vaḻipaṭuvōrai val aṟitī ē
  • {PU 10-2} piṟar paḻi kūṟuvōr moḻi tēṟalai ē
  • {PU 10-3} nī mey kaṇṭa tīmai kāṇiṉ
  • {PU 10-4} oppa nāṭi a taka oṟutti
  • {PU 10-5} vantu aṭi porunti muntai niṟpiṉ
  • {PU 10-6} taṇṭam um taṇiti nī paṇṭaiyiṉ peritu ē
  • {PU 10-7} amiḻtu aṭṭu āṉā kamaḻ kuy aṭicil
  • {PU 10-8} varunarkku varaiyā vacai il vāḻkkai
  • {PU 10-9} makaḷir malaittal allatu maḷḷar
  • {PU 10-10} malaittal pōkiya cilai tār mārpa
  • {PU 10-11} ceytu iraṅkā viṉai cēṇ viḷaṅkum pukaḻ
  • {PU 10-12} neytal am kāṉal neṭiyōy
  • {PU 10-13} eyta vantaṉam yām ēttukam pala ē
