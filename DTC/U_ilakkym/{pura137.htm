{PUṞAM 137}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 137-1} iraṅku muraciṉ iṉam cāl yāṉi
  • {PU 137-2} munnīr ēṇi viṟal keḻu mūvari
  • {PU 137-3} iṉṉum ōr yāṉ avā aṟiyēṉ ē
  • {PU 137-4} nī ē muṉ yāṉ aṟiyumōṉ ē tuvaṉṟiya
  • {PU 137-5} kayattu iṭṭa vittu vaṟattiṉ cāvātu
  • {PU 137-6} kaḻi karumpiṉ olikkuntu
  • {PU 137-7} koṇṭal koṇṭa nīr kōṭi kāyiṉum
  • {PU 137-8} kaṇ aṉṉa malar pūkkuntu
  • {PU 137-9} karum kāl vēṅki malariṉ nāḷ um
  • {PU 137-10} poṉ aṉṉa vī cumantu
  • {PU 137-11} maṇi aṉṉa nīr kaṭal paṭarum
  • {PU 137-12} ce vari paṭappi nāñcil poruna
  • {PU 137-13} ciṟu veḷ aruvi perum kal nāṭaṉi
  • {PU 137-14} nī vāḻiyar niṉ tanti
  • {PU 137-15} tāy vāḻiyar niṉ payanticiṉōr ē
