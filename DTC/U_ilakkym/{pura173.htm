{PUṞAM 173}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 173-1} yāṉ vāḻum nāḷ um paṇṇaṉ vāḻiya
  • {PU 173-2} pāṇar kāṇka ivaṉ kaṭumpiṉatu iṭumpi
  • {PU 173-3} yāṇar paḻu maram puḷ imiḻntaṉṉa
  • {PU 173-4} ūṇ oli aravam tāṉ um kēṭkum
  • {PU 173-5} poyyā eḻili peyvu iṭam nōkki
  • {PU 173-6} muṭṭi koṇṭu vaṉpulam cērum
  • {PU 173-7} ciṟu nuṇ eṟumpiṉ cil oḻukku ēyppa
  • {PU 173-8} cōṟu uṭi kiyar vīṟu vīṟu iyaṅkum
  • {PU 173-9} irum kiḷi ciṟāar kāṇṭum kaṇṭu um
  • {PU 173-10} maṟṟu um maṟṟu um viṉavutum teṟṟeṉa
  • {PU 173-11} pacippiṇi maruttuvaṉ illam
  • {PU 173-12} aṇittu ō cēyttu ō kūṟumiṉ emakku ē
