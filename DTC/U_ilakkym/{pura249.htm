{PUṞAM 249}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 249-1} katir mūkku āral kīḻ cēṟṟu oḷippa
  • {PU 249-2} kaṇi kōṭṭu vāḷi mīṉ nīr piṟaḻa
  • {PU 249-3} eri pūm paḻaṉam nerittu uṭaṉ valiñar
  • {PU 249-4} ari kural taṭāriyiṉ yāmi miḷira
  • {PU 249-5} paṉi nukumpu aṉṉa ciṉi mutir varāloṭu
  • {PU 249-6} uṟaḻ vēl aṉṉa oḷ kayal mukakkum
  • {PU 249-7} akal nāṭṭu aṇṇal pukā ē neruni
  • {PU 249-8} pakal iṭam kaṇṇi palaroṭu um kūṭi
  • {PU 249-9} oru vaḻippaṭṭaṉṟu maṉ ē iṉṟu ē
  • {PU 249-10} aṭaṅkiya kaṟpiṉ āy nutal maṭanti
  • {PU 249-11} uyarnili ulakam avaṉ puka vari
  • {PU 249-12} nīṟu āṭu cuḷakiṉ cīṟu iṭam nīkki
  • {PU 249-13} aḻutal āṉā kaṇṇaḷ
  • {PU 249-14} meḻukum āppi kaṇ kaluḻ nīrāṉ ē
