{PUṞAM 140}

((Originally extracted from master file ^PURAM.OCP))

  • {PU 140-1} taṭavu nili palaviṉ nāñcil porunaṉ
  • {PU 140-2} maṭavaṉ maṉṟa ce nā pulavīr
  • {PU 140-3} vaḷi ki viṟaliyar paṭappi koyta
  • {PU 140-4} aṭakiṉ kaṇṇuṟi āka yām cila
  • {PU 140-5} arici vēṇṭiṉēm āka tāṉ piṟa
  • {PU 140-6} varici aṟitaliṉ taṉ um tūkki
  • {PU 140-7} irum kaṭaṟu vaḷiiya kuṉṟattu aṉṉatu ōr
  • {PU 140-8} perum kaḷiṟu nalkiyōṉ ē aṉṉatu ōr
  • {PU 140-9} tēṟṟā īki um uḷatu kol
  • {PU 140-10} pōṟṟār amma periyōr tam kaṭaṉ ē
