  • {PU 180-1} nirappātu koṭukkum celvam um ilaṉ ē
  • {PU 180-2} il eṉa maṟukkum ciṟumai um ilaṉ ē
  • {PU 180-3} iṟai uṟu viḻumam tāṅki amarakattu
  • {PU 180-4} irumpu cuvai koṇṭa viḻuppuṇ nōy tīrntu
  • {PU 180-5} maruntu koḷ marattiṉ vāḷ vaṭu mayaṅki
  • {PU 180-6} vaṭu iṉṟu vaṭinta yākkaiyaṉ koṭai etirntu
  • {PU 180-7} īrntaiyōṉ ē pāṇ paci pakaiñaṉ
  • {PU 180-8} iṉmai tīra vēṇṭiṉ emmoṭu
  • {PU 180-9} nī um vammō mutu vāy iravala
  • {PU 180-10} yām taṉ irakkum kālai tāṉ em
  • {PU 180-11} uṇṇā maruṅkul kāṭṭi taṉ ūr
  • {PU 180-12} karum kai kollaṉai irakkum
  • {PU 180-13} tiruntu ilai neṭu vēl vaṭitticiṉ eṉa ē
