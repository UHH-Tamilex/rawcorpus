{PUṞAM 180}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 180-1} nirappātu koṭukkum celvam um ilaṉ ē
  • {PU 180-2} il eṉa maṟukkum ciṟumi um ilaṉ ē
  • {PU 180-3} iṟi uṟu viḻumam tāṅki amarakattu
  • {PU 180-4} irumpu cuvi koṇṭa viḻuppuṇ nōy tīrntu
  • {PU 180-5} maruntu koḷ marattiṉ vāḷ vaṭu mayaṅki
  • {PU 180-6} vaṭu iṉṟu vaṭinta yākkiyaṉ koṭi etirntu
  • {PU 180-7} īrntiyōṉ ē pāṇ paci pakiñaṉ
  • {PU 180-8} iṉmi tīra vēṇṭiṉ emmoṭu
  • {PU 180-9} nī um vammō mutu vāy iravala
  • {PU 180-10} yām taṉ irakkum kāli tāṉ em
  • {PU 180-11} uṇṇā maruṅkul kāṭṭi taṉ ūr
  • {PU 180-12} karum ki kollaṉi irakkum
  • {PU 180-13} tiruntu ili neṭu vēl vaṭitticiṉ eṉa ē
