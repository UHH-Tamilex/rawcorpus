{PUṞAM 53}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 53-1} mutir vār ippi mutta vār maṇal
  • {PU 53-2} katir viṭu maṇiyiṉ kaṇ poru māṭattu
  • {PU 53-3} ilaṅku vaḷi makaḷir teṟṟi āṭum
  • {PU 53-4} viḷaṅku cīr viḷaṅkil viḻumam koṉṟa
  • {PU 53-5} kaḷam koḷ yāṉi kaṭu māṉ poṟiya
  • {PU 53-6} virippiṉ akalum tokuppiṉ eñcum
  • {PU 53-7} mammar neñcattu emmaṉōrkku orutali
  • {PU 53-8} kimmuṟṟala niṉ pukaḻ ē eṉṟum
  • {PU 53-9} oḷiyōr piṟanta i malar tali ulakattu
  • {PU 53-10} vāḻēm eṉṟal um aritu ē tāḻātu
  • {PU 53-11} ceṟutta ceyyuḷ cey ce nāviṉ
  • {PU 53-12} veṟutta kēḷvi viḷaṅku pukaḻ kapilaṉ
  • {PU 53-13} iṉṟu uḷaṉ āyiṉ naṉṟu maṉ eṉṟa niṉ
  • {PU 53-14} āṭu koḷ varicikku oppa
  • {PU 53-15} pāṭuval maṉ āl pakivari kaṭappu ē
