{PUṞAM 36}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 36-1} aṭuni āyiṉum viṭuni āyiṉum
  • {PU 36-2} nī aḷantu aṟiti niṉ purimi vār kōl
  • {PU 36-3} ceṟi ari cilampiṉ kuṟum toṭi makaḷir
  • {PU 36-4} polam cey kaḻaṅkiṉ teṟṟi āṭum
  • {PU 36-5} taṇ āṉporuni veḷ maṇal citiya
  • {PU 36-6} karum ki kollaṉ aram cey a vāy
  • {PU 36-7} neṭum ki naviyam pāytaliṉ nili aḻintu
  • {PU 36-8} vī kamaḻ neṭum ciṉi pulampa kāvu toṟum
  • {PU 36-9} kaṭimaram taṭiyum ōci taṉ ūr
  • {PU 36-10} neṭu matil varippiṉ kaṭi maṉi iyampa
  • {PU 36-11} āṅku iṉitu irunta vēntaṉoṭu īṅku niṉ
  • {PU 36-12} cili tār muracam kaṟaṅka
  • {PU 36-13} malittaṉi eṉpatu nāṇu takavu uṭittu ē
