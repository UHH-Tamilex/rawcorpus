{PUṞAM 36}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 36-1} aṭunai āyiṉum viṭunai āyiṉum
  • {PU 36-2} nī aḷantu aṟiti niṉ puraimai vār kōl
  • {PU 36-3} ceṟi ari cilampiṉ kuṟum toṭi makaḷir
  • {PU 36-4} polam cey kaḻaṅkiṉ teṟṟi āṭum
  • {PU 36-5} taṇ āṉporunai veḷ maṇal citaiya
  • {PU 36-6} karum kai kollaṉ aram cey a vāy
  • {PU 36-7} neṭum kai naviyam pāytaliṉ nilai aḻintu
  • {PU 36-8} vī kamaḻ neṭum ciṉai pulampa kāvu toṟum
  • {PU 36-9} kaṭimaram taṭiyum ōcai taṉ ūr
  • {PU 36-10} neṭu matil varaippiṉ kaṭi maṉai iyampa
  • {PU 36-11} āṅku iṉitu irunta vēntaṉoṭu īṅku niṉ
  • {PU 36-12} cilai tār muracam kaṟaṅka
  • {PU 36-13} malaittaṉai eṉpatu nāṇu takavu uṭaittu ē
