{PUṞAM 181}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 181-1} maṉṟa viḷaviṉ maṉi vīḻ veḷḷil
  • {PU 181-2} karum kaṇ eyiṟṟi kātal makaṉoṭu
  • {PU 181-3} kāṉa irum piṭi kaṉṟu talikkoḷḷum
  • {PU 181-4} perum kuṟumpu uṭutta vaṉpulam irukki
  • {PU 181-5} pulāa ampiṉ pōr arum kaṭi miḷi
  • {PU 181-6} valāarōṉ ē vāy vāḷ paṇṇaṉ
  • {PU 181-7} uṇṇā vaṟum kaṭumpu uytal vēṇṭiṉ
  • {PU 181-8} iṉṉē ceṉmati nī ē ceṉṟu avaṉ
  • {PU 181-9} paki pulam paṭarā aḷavi niṉ
  • {PU 181-10} paci paki paricil kāṭṭiṉi koḷaṟku ē
