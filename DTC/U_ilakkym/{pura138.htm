{PUṞAM 138}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 138-1} āṉ iṉam kalitta atar pala kaṭantu
  • {PU 138-2} māṉ iṉam kalitta malai piṉ oḻiya
  • {PU 138-3} mīṉ iṉam kalitta tuṟai pala nīnti
  • {PU 138-4} uḷḷi vanta vaḷ uyir cīṟiyāḻ
  • {PU 138-5} citāar uṭukkai mutāari pāṇa
  • {PU 138-6} nī ē pēr eṇṇalai ē niṉ iṟai
  • {PU 138-7} māṟi vā eṉa moḻiyalaṉ mātō
  • {PU 138-8} oli irum katuppiṉ āy iḻai kaṇavaṉ
  • {PU 138-9} kiḷi marīiya viyaṉ puṉattu
  • {PU 138-10} maraṉ aṇi perum kural aṉaiyaṉ ātaliṉ
  • {PU 138-11} niṉṉai varutal aṟintaṉar yār ē
