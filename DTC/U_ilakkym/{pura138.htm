  • {PU 138-1} āṉ iṉam kalitta atar pala kaṭantu
  • {PU 138-2} māṉ iṉam kalitta mali piṉ oḻiya
  • {PU 138-3} mīṉ iṉam kalitta tuṟi pala nīnti
  • {PU 138-4} uḷḷi vanta vaḷ uyir cīṟiyāḻ
  • {PU 138-5} citāar uṭukki mutāari pāṇa
  • {PU 138-6} nī ē pēr eṇṇali ē niṉ iṟi
  • {PU 138-7} māṟi vā eṉa moḻiyalaṉ mātō
  • {PU 138-8} oli irum katuppiṉ āy iḻi kaṇavaṉ
  • {PU 138-9} kiḷi marīiya viyaṉ puṉattu
  • {PU 138-10} maraṉ aṇi perum kural aṉiyaṉ ātaliṉ
  • {PU 138-11} niṉṉi varutal aṟintaṉar yār ē
