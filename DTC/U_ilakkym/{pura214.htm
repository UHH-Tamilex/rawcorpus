{PUṞAM 214}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 214-1} ceykuvam kol ō nalviṉai eṉa ē
  • {PU 214-2} aiyam aṟāar kacaṭu īṇṭu kāṭci
  • {PU 214-3} nīṅkā neñcattu tuṇivu illōr ē
  • {PU 214-4} yāṉai vēṭṭuvaṉ yāṉai um peṟum ē
  • {PU 214-5} kuṟumpūḻ vēṭṭuvaṉ vaṟum kai um varum ē
  • {PU 214-6} ataṉāl uyarnta vēṭṭattu uyarnticiṉōrkku
  • {PU 214-7} cey viṉai maruṅkiṉ eytal uṇṭu eṉiṉ
  • {PU 214-8} toyyā ulakattu nukarcci um kūṭum
  • {PU 214-9} toyyā ulakattu nukarcci il eṉiṉ
  • {PU 214-10} māṟi piṟappiṉ iṉmai um kūṭum
  • {PU 214-11} māṟi piṟavār āyiṉum imayattu
  • {PU 214-12} kōṭu uyarntaṉṉa tam icai naṭṭu
  • {PU 214-13} tītu il yākkaiyoṭu māytal tava talai ē
