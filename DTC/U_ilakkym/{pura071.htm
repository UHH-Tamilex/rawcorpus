  • {PU 71-3} eṉṉoṭu porutum eṉpa avarai
  • {PU 71-4} ār amar alaṟa tākki tēroṭu
  • {PU 71-5} avar puṟaṅkāṇēṉ āyiṉ ciṟanta
  • {PU 71-6} pēr amar uṇ kaṇ ivaḷiṉum pirika
  • {PU 71-7} aṟaṉ nilai tiriyā aṉpiṉ avaiyattu
  • {PU 71-8} tiṟaṉ il oruvaṉai nāṭṭi muṟai tirintu
  • {PU 71-9} melikōl ceytēṉ ākuka mali pukaḻ
  • {PU 71-10} vaiyai cūḻnta vaḷam keḻu vaippiṉ
  • {PU 71-11} poyyā yāṇar maiyal kōmāṉ
  • {PU 71-12} māvaṉ um maṉ eyil āntai um urai cāl
  • {PU 71-13} antuvam cāttaṉ um ātaṉ aḻici um
  • {PU 71-14} ve ciṉa iyakkaṉ um uḷappaṭa piṟar um
  • {PU 71-15} kaṇ pōl naṇpiṉ kēḷiroṭu kalanta
  • {PU 71-16} iṉ kaḷi makiḻ nakai iḻukki yāṉ oṉṟu ō
  • {PU 71-17} maṉpatai kākkum nīḷ kuṭi ciṟanta
  • {PU 71-18} teṉ pulam kāvaliṉ orīi piṟar
  • {PU 71-19} vaṉpulam kāvaliṉ māṟi yāṉ piṟakku ē
