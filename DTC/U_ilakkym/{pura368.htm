{PUṞAM 368}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 368-1} kaḷiṟu mukantu peyarkuvam eṉiṉ ē
  • {PU 368-2} oḷiṟu maḻi tavirkkum kuṉṟam pōla
  • {PU 368-3} kimmā ellām kaṇi iṭa tolintaṉa
  • {PU 368-4} koṭuñci neṭum tēr mukakkuvam eṉiṉ ē
  • {PU 368-5} kaṭum pari nal māṉ vāṅku vayiṉ olki
  • {PU 368-6} neṭum pīṭu aḻintu nilam cērntaṉa ē
  • {PU 368-7} koy cuval puravi mukakkuvam eṉiṉ ē
  • {PU 368-8} mey niṟinta vaḻuvoṭu perumpiṟitu āki
  • {PU 368-9} vaḷi vaḻakku aṟutta vaṅkam pōla
  • {PU 368-10} kuruti am perum puṉal kūrntaṉa ē āṅka
  • {PU 368-11} mukavi iṉmiyiṉ ukavi iṉṟi
  • {PU 368-12} irappōr iraṅkum iṉṉā viyaṉ kaḷattu
  • {PU 368-13} āḷ aḻippaṭutta vāḷ ēr uḻava
  • {PU 368-14} kaṭāa yāṉi kāl vaḻi aṉṉa eṉ
  • {PU 368-15} teṭāri teḷ kaṇ teḷirppa oṟṟi
  • {PU 368-16} pāṭi vantatu ellām kōṭiyar
  • {PU 368-17} muḻavu maruḷ tiru maṇi miṭinta niṉ
  • {PU 368-18} aravu uṟaḻ āram mukakkuvam eṉa ē
