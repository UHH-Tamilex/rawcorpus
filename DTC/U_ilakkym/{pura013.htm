{PUṞAM 13}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 13-1} ivaṉ yār eṉkuvi āyiṉ ivaṉ ē
  • {PU 13-2} puli niṟa kavacam pūm poṟi citiya
  • {PU 13-3} ey kaṇi kiḻitta pakaṭṭu eḻil mārpiṉ
  • {PU 13-4} maṟali aṉṉa kaḷiṟṟu miciyōṉ ē
  • {PU 13-5} kaḷiṟu ē munnīr vaḻaṅku nāvāy pōla um
  • {PU 13-6} pal mīṉ nāppaṇ tiṅkaḷ pōla um
  • {PU 13-7} cuṟavu iṉattu aṉṉa vāḷōr moyppa
  • {PU 13-8} marīiyōr aṟiyātu mintu paṭṭaṉṟu ē
  • {PU 13-9} nōy ilaṉ āki peyarka til amma
  • {PU 13-10} paḻaṉa maññi ukutta pīli
  • {PU 13-11} kaḻaṉi uḻavar cūṭṭoṭu tokukkum
  • {PU 13-12} koḻu mīṉ viḷinta kaḷḷiṉ
  • {PU 13-13} viḻu nīr vēli nāṭu kiḻavōṉ ē
