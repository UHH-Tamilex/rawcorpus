{PUṞAM 93}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 93-1} tiṇ piṇi muracam iḻumeṉa muḻaṅka
  • {PU 93-2} ceṉṟu amar kaṭattal yāvatu vantōr
  • {PU 93-3} tār tāṅkutal um āṟṟār veṭipaṭṭu
  • {PU 93-4} ōṭal marīiya pīṭu il maṉṉar
  • {PU 93-5} nōy pāl viḷinta yākkai taḻīi
  • {PU 93-6} kātal maṟantu avar tītu maruṅku aṟumār
  • {PU 93-7} aṟam puri koḷkai nāṉmaṟai mutalvar
  • {PU 93-8} tiṟam puri pacum pul parappiṉar kiṭappi
  • {PU 93-9} maṟam kantu āka nal amar vīḻnta
  • {PU 93-10} nīḷ kaḻal maṟavar celvuḻi celka eṉa
  • {PU 93-11} vāḷ pōḻntu aṭakkal um uyntaṉar mātō
  • {PU 93-12} vari ñimiṟu ārkkum vāy puku kaṭāattu
  • {PU 93-13} aṇṇal yāṉai aṭu kaḷattu oḻiya
  • {PU 93-14} arum camam tataiya nūṟi nī
  • {PU 93-15} peruntakai viḻuppuṇ paṭṭa māṟu ē
