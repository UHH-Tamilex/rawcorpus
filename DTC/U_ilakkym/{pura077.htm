{PUṞAM 77}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 77-1} kiṇkiṇi kaḷainta kāl oḷ kaḻal toṭṭu
  • {PU 77-2} kuṭumi kaḷainta nutal vēmpiṉ oḷ taḷir
  • {PU 77-3} neṭum koṭi uḻiñai pavaroṭu milaintu
  • {PU 77-4} kuṟum toṭi kaḻitta kai cāpam paṟṟi
  • {PU 77-5} neṭum tēr koṭuñci poliya niṉṟōṉ
  • {PU 77-6} yār kol vāḻka avaṉ kaṇṇi tār pūṇṭu
  • {PU 77-7} tāli kaḷaintaṉṟu um ilaṉ ē pāl viṭṭu
  • {PU 77-8} ayiṉi um iṉṟu ayiṉṟaṉaṉ ē vayiṉ vayiṉ
  • {PU 77-9} uṭaṉṟu mēlvanta vampa maḷḷarai
  • {PU 77-10} viyantaṉṟu um iḻintaṉṟu um ilaṉ ē avarai
  • {PU 77-11} aḻunta paṟṟi akal vicumpu ārppu eḻa
  • {PU 77-12} kaviḻntu nilam cēra aṭṭatai
  • {PU 77-13} makiḻntaṉṟu um malintaṉṟu um ataṉiṉum ilaṉ ē
