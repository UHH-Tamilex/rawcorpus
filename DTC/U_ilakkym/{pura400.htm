{PUṞAM 400}

  • {PU 400-1} māka vicumpiṉ veḷ tiṅkaḷ
  • {PU 400-2} mū aintāṉ muṟi muṟṟa
  • {PU 400-3} kaṭal naṭuvaṇ kaṇṭaṉṉa eṉ
  • {PU 400-4} iyam iciyā marapu ētti
  • {PU 400-5} kaṭi tōṉṟiya kaṭi kaṅkulāṉ
  • {PU 400-6} palar tuñca um tāṉ tuñcāṉ
  • {PU 400-7} ulaku kākkum uyar
  • {PU 400-8} kēṭṭōṉ enti eṉ teḷ kiṇi kural ē
  • {PU 400-9} kēṭṭataṉ koṇṭu um vēṭki taṇṭātu
  • {PU 400-10} toṉṟu paṭu citāar maruṅku nīkki
  • {PU 400-11} mika perum ciṟappiṉ vīṟu
  • {PU 400-13} kaliṅkam aḷittiṭṭu eṉ ari nōkki
  • {PU 400-14} nār ari naṟaviṉ nāḷ makiḻ tūṅkuntu
  • {PU 400-15} pōtu aṟiyēṉ pati paḻaka um
  • {PU 400-16} taṉ paki kaṭital aṉṟi um cērntōr
  • {PU 400-17} paci paki kaṭital um vallaṉ mātō
  • {PU 400-18} maṟavar malinta
  • {PU 400-19} kēḷvi malinta vēḷvi tūṇattu
  • {PU 400-20} irum kaḻi iḻitaru kali vaṅkam
  • {PU 400-21} tēṟu nīr parappiṉ yāṟu cīttu uyttu
  • {PU 400-22} tuṟi toṟum piṇikkum nal ūr
  • {PU 400-23} uṟivu iṉ yāṇar kiḻavōṉ ē
