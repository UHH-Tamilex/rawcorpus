{PUṞAM 96}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 96-1} alar pūm tumpai am pakaṭṭu mārpiṉ
  • {PU 96-2} tiraṇṭu nīṭu taṭam kai eṉṉai iḷaiyōṟku
  • {PU 96-3} iraṇṭu eḻuntaṉa āl pakai ē oṉṟu ē
  • {PU 96-4} pū pōl uṇ kaṇ pacantu tōḷ nuṇuki
  • {PU 96-5} nōkkiya makaḷir piṇittaṉṟu oṉṟu ē
  • {PU 96-6} viḻavu iṉṟu āyiṉum paṭu patam piḻaiyātu
  • {PU 96-7} mai ūṉ mocitta okkaloṭu tuṟai nīr
  • {PU 96-8} kaimāṉ koḷḷum ō eṉa
  • {PU 96-9} uṟaiyuḷ muṉiyum avaṉ cellum ūr ē
