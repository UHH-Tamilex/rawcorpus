{PUṞAM 237}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 237-1} nīṭu vāḻka eṉṟu yāṉ neṭum kaṭai kuṟuki
  • {PU 237-2} pāṭi niṉṟa paci nāḷ kaṇ ē
  • {PU 237-3} kōṭai kālattu koḻu niḻal āki
  • {PU 237-4} poyttal aṟiyā uravōṉ cevi mutal
  • {PU 237-5} vittiya paṉuval viḷaintaṉṟu naṉṟu eṉa
  • {PU 237-6} nacci irunta nacai paḻutu āka
  • {PU 237-7} aṭṭa kuḻici aḻal payantāaṅku
  • {PU 237-8} aḷiyar tām ē ārka eṉṉā
  • {PU 237-9} aṟaṉ il kūṟṟam tiṟaṉ iṉṟu tuṇiya
  • {PU 237-10} ūḻiṉ uruppa erukkiya makaḷir
  • {PU 237-11} vāḻai pūviṉ vaḷai muṟi citaṟa
  • {PU 237-12} mutu vāy okkal paricilar iraṅka
  • {PU 237-13} kaḷḷi pōkiya kaḷari am paṟantalai
  • {PU 237-14} veḷ vēl viṭalai ceṉṟu māyntaṉaṉ ē
  • {PU 237-15} āṅku atu nōy iṉṟu āka ōṅku varai
  • {PU 237-16} puli pārttu oṟṟiya kaḷiṟṟu irai piḻaippiṉ
  • {PU 237-17} eli pārttu oṟṟātu ākum mali tirai
  • {PU 237-18} kaṭal maṇṭu puṉaliṉ iḻumeṉa ceṉṟu
  • {PU 237-19} naṉi uṭai paricil tarukam
  • {PU 237-20} eḻumati neñcu ē tuṇipu muntuṟuttu ē
