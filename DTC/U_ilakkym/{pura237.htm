{PUṞAM 237}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 237-1} nīṭu vāḻka eṉṟu yāṉ neṭum kaṭi kuṟuki
  • {PU 237-2} pāṭi niṉṟa paci nāḷ kaṇ ē
  • {PU 237-3} kōṭi kālattu koḻu niḻal āki
  • {PU 237-4} poyttal aṟiyā uravōṉ cevi mutal
  • {PU 237-5} vittiya paṉuval viḷintaṉṟu naṉṟu eṉa
  • {PU 237-6} nacci irunta naci paḻutu āka
  • {PU 237-7} aṭṭa kuḻici aḻal payantāaṅku
  • {PU 237-8} aḷiyar tām ē ārka eṉṉā
  • {PU 237-9} aṟaṉ il kūṟṟam tiṟaṉ iṉṟu tuṇiya
  • {PU 237-10} ūḻiṉ uruppa erukkiya makaḷir
  • {PU 237-11} vāḻi pūviṉ vaḷi muṟi citaṟa
  • {PU 237-12} mutu vāy okkal paricilar iraṅka
  • {PU 237-13} kaḷḷi pōkiya kaḷari am paṟantali
  • {PU 237-14} veḷ vēl viṭali ceṉṟu māyntaṉaṉ ē
  • {PU 237-15} āṅku atu nōy iṉṟu āka ōṅku vari
  • {PU 237-16} puli pārttu oṟṟiya kaḷiṟṟu iri piḻippiṉ
  • {PU 237-17} eli pārttu oṟṟātu ākum mali tiri
  • {PU 237-18} kaṭal maṇṭu puṉaliṉ iḻumeṉa ceṉṟu
  • {PU 237-19} naṉi uṭi paricil tarukam
  • {PU 237-20} eḻumati neñcu ē tuṇipu muntuṟuttu ē
