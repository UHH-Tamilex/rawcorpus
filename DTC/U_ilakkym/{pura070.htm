{PUṞAM 70}

((Last updated on 2004 April 14th))

  • {PU 70-1} tēem tīm toṭai cīṟiyāḻ pāṇa
  • {PU 70-2} kayattu vāḻ yāmai kāḻ kōttaṉṉa
  • {PU 70-3} nuṇ kōl takaitta teḷ kaṇ mā kiṇai
  • {PU 70-4} iṉiya kāṇka ivaṇ taṇika eṉa kūṟi
  • {PU 70-5} viṉaval āṉā mutu vāy iravala
  • {PU 70-6} taii tiṅkaḷ taṇ kayam pōla
  • {PU 70-7} koḷa koḷa kuṟaipaṭā kūḻ uṭai viyal nakar
  • {PU 70-8} aṭu tī allatu cuṭu tī aṟiyātu
  • {PU 70-9} iru maruntu viḷaikkum nal nāṭṭu porunaṉ
  • {PU 70-10} kiḷḷi vaḷavaṉ nal icai uḷḷi
  • {PU 70-11} nāṟṟa nāṭṭattu aṟukāl paṟavai
  • {PU 70-12} ciṟu veḷ āmpal ñāṅkar ūtum
  • {PU 70-13} kai vaḷ īkai paṇṇaṉ ciṟu kuṭi
  • {PU 70-14} pātiri kamaḻum ōti oḷ nutal
  • {PU 70-15} iṉ nakai viṟaliyoṭu meṉmela iyali
  • {PU 70-16} celvai āyiṉ celvai ākuvai
  • {PU 70-17} viṟaku oy mākkaḷ poṉ peṟṟaṉṉatu ōr
  • {PU 70-18} talaippāṭu aṉṟu avaṉ īkai
  • {PU 70-19} niṉaikka vēṇṭā vāḻka avaṉ tāḷ ē
