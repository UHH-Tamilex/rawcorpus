{PUṞAM 70}

((Originally extracted from master file ^PURAM.OCP))
((Last updated on 2004 April 14th))

  • {PU 70-1} tēem tīm toṭi cīṟiyāḻ pāṇa
  • {PU 70-2} kayattu vāḻ yāmi kāḻ kōttaṉṉa
  • {PU 70-3} nuṇ kōl takitta teḷ kaṇ mā kiṇi
  • {PU 70-4} iṉiya kāṇka ivaṇ taṇika eṉa kūṟi
  • {PU 70-5} viṉaval āṉā mutu vāy iravala
  • {PU 70-6} tii tiṅkaḷ taṇ kayam pōla
  • {PU 70-7} koḷa koḷa kuṟipaṭā kūḻ uṭi viyal nakar
  • {PU 70-8} aṭu tī allatu cuṭu tī aṟiyātu
  • {PU 70-9} iru maruntu viḷikkum nal nāṭṭu porunaṉ
  • {PU 70-10} kiḷḷi vaḷavaṉ nal ici uḷḷi
  • {PU 70-11} nāṟṟa nāṭṭattu aṟukāl paṟavi
  • {PU 70-12} ciṟu veḷ āmpal ñāṅkar ūtum
  • {PU 70-13} ki vaḷ īki paṇṇaṉ ciṟu kuṭi
  • {PU 70-14} pātiri kamaḻum ōti oḷ nutal
  • {PU 70-15} iṉ naki viṟaliyoṭu meṉmela iyali
  • {PU 70-16} celvi āyiṉ celvi ākuvi
  • {PU 70-17} viṟaku oy mākkaḷ poṉ peṟṟaṉṉatu ōr
  • {PU 70-18} talippāṭu aṉṟu avaṉ īki
  • {PU 70-19} niṉikka vēṇṭā vāḻka avaṉ tāḷ ē
