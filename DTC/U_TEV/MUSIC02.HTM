PAṆ TAKKARĀKAM

  • Number of Patikam-s: 28 = 24 (Campantar) + 4 (Cuntarar)
  • Raga considered as equivalent: kāmpōti

VMS remarks that according to periya purāṇam, this paṇ should not be used for hymn [1:45] as recommended in the current editions but that we should have paḻanpañcuram.
