nīti veṇpā

+-----------------------------------------------------------------------+
| kaṭavuḷ vāḻttu                                                          |
|                                                                       |
| mūtuṇarntōr ōtucila mūturaiyaip pētaiyēṉ                                   |
| nītiveṇpā vāka nikaḻntuvēṉ - ātiparaṉ                                      |
| vāmāṉ karuṇai maṇiutaram pūttamutal                                          |
| kōmāṉ peruṅkaruṇai koṇṭu.                                               |
|                                                                       |
| nūl                                                                   |
|                                                                       |
| 1. nallōr eṅkum toṉṟalām                                                |
|                                                                       |
| tāmaraipoṉ muttuc cavaramkō rōcaṉaipāl                                       |
| pūmarutēṉ paṭṭup puṉukucavvātu - āmaḻalmaṟṟu                               |
| eṅkē piṟantālum eḷḷārē nallōrkaḷ                                         |
| eṅkē piṟantālum eṉ                                                     |
|                                                                       |
| 2. uyarvaṭaiya uyariṭamē cērka                                               |
|                                                                       |
| ariman tirampukuntāṉ āṉai maruppum                                        |
| perukoḷicēr muttum peṟalām - narinuḻaiyil                                |
| vālum ciṟiya mayireṉpum karttapattiṉ                                       |
| tōlumallāl vēṟumuṇṭō col.                                              |
|                                                                       |
| 3. aṟivaṭaiyōr pakaivaṉākiṉum naṇpaṉē                                        |
|                                                                       |
| aṟivaṉ pakaiyēṉum aṉpucēr naṭpām                                          |
| ciṟuvaṉ pakaiyām ceṟinta - aṟivuṭaiya                                       |
| veṉṟi vaṉacaraṉtāṉ vētiyaṉaik kāttāṉ muṉ                                    |
| koṉṟatoru vēntaik kuraṅku.                                               |
|                                                                       |
| 4. iṉcollē yāvarum kēṭpar                                               |
|                                                                       |
| meṉmatura vākkāl virumpum cakam kaṭiṉa                                      |
| vaṉmoḻiyi ṉālikaḻum maṇṇulakam - naṉmoḻiyai                                  |
| ōtukuyil ētaṅku utaviyatu karttapantāṉ                                      |
| ētaparā tamceytatu iṉṟu                                                   |
|                                                                       |
| 5. aṉpiṉāl māṟṟōriṭamum naṉmai                                           |
|                                                                       |
| pakaicēṟum eṇṇāṉku palkoṇṭē nalnā                                         |
| vakaicēr cuvaiaruntu māpōl - tokaicēr                                     |
| pakaivariṭam meyyaṉpu pāvittu avarāl                                        |
| cukamuṟutal nallōr toḻil.                                                |
|                                                                       |
| 6. payaṉaṟṟavai                                                            |
|                                                                       |
| kāntaṉil lāta kaṉaṅkuḻalāḷ poṟpuavamām                                      |
| cāntakuṇam illār tavamavamām - ēntiḻaiyē                                    |
| aṉṉaiillāp piḷḷai iruppatu avam avamē                                      |
| tuṉṉeyiṟil lārūṇ cuvai.                                                |
|                                                                       |
| 7. kalvikku iḷamaiyē kālam                                                |
|                                                                       |
| varuntavaḷai vēyaracar māmuṭiyiṉ mēlalām                                     |
| varunta vaḷaiyāta mūṅkil - tarittiramāy                                      |
| vēḻampar kaippukuntu mētiṉiyel lāmtirintu                                |
| tāḻumavar tammaṭikkīḻt tāṉ.                                               |
|                                                                       |
| 8. irappatu aṟpamē                                                       |
|                                                                       |
| noytuām tiraṇattiṉ noytākum veṇpañciṉ                                    |
| noytām irappōṉ nuvaluṅkāl - noyyaciṟu                                    |
| pañcutaṉil noyyāṉaip paṟṟutō kāṟṟaṇuka                                      |
| añcumavaṉ kēṭpatu aṟintu.                                                |
|                                                                       |
| 9. nalamākavāḻa ōr poḻutuṇka                                               |
|                                                                       |
| ōrupōtu yōkiyē ōṇṭaḷirkkai mātē                                         |
| itupōtu pōkiyē yeṉpa - tiripōtu                                        |
| rōkiyē nāṉkupōtu uṇpāṉ uṭalviṭṭup                                      |
| pōkiyē yeṉṟu pukal.                                                    |
|                                                                       |
| 10. ellām aṟivar ñāṉiyar                                                |
|                                                                       |
| kaṇṇiraṇṭē yāvarkkum kaṟṟōrkku mūṉṟuviḻi                                  |
| eṇṇuvaḻi ēḻākum īvōrkku - naṇṇum                                        |
| anantam tavattāl aruḷñāṉam peṟṟōrkku                                       |
| anantam viḻiyeṉṟu aṟi.                                                  |
|                                                                       |
| 11. ilvāḻtalē nalvaḻi                                                    |
|                                                                       |
| uṟṟaperuñ cuṟṟam uṟanaṉ maṉaiviyuṭaṉ                                         |
| paṟṟimika vāḻka pacuviṉpāl - paṟṟi                                         |
| natikaṭattal aṉṟiyē nāyiṉvāl paṟṟi                                         |
| natikaṭattaluṇṭō navil.                                                    |
|                                                                       |
| 12. tuṟantōrē ulakam āḷpavar                                               |
|                                                                       |
| ācaikku aṭiyāṉ akilalō kattiṉukkum                                       |
| ācaṟṟa nallaṭiyāṉ āvāṉē - ācai                                             |
| taṉaiyaṭimai koṇṭavaṉē tappātu ulakam                                          |
| taṉaiyaṭimai koṇṭavaṉē tāṉ.                                                 |
|                                                                       |
| 13. pāvam palavakaiyām                                                     |
|                                                                       |
| āṉan taṇarmakaḷir aṉpām kuḻantaivatai                                         |
| māṉam teṟumpici vārttaiivai - mēṉiṟaiyē                                   |
| kūṟavaru pāvam kuṟaiyātuōv voṉṟukkum                                      |
| nūṟuatikam eṉṟē nuval.                                                  |
|                                                                       |
| 14. ivar iḻiviṉai eytuvar                                                |
|                                                                       |
| peṟṟamaikyum eṉṉāp periyōrum peṟṟaporuḷ                                  |
| maṟṟamaiyum eṉṟē makiḻvēntum - muṟṟiyanaṉ                                   |
| māṉamilā illāḷum māṉamuṟu vēciyarum                                      |
| īṉa muṟuvār ivar.                                                       |
|                                                                       |
| 15. kalvitaṉmāṇpu kaṟṟōrē aṟivar                                          |
|                                                                       |
| kaṟṟōr kaṉamaṟivar kaṟṟōrē kaṟṟaṟiyā                                         |
| maṟṟōr aṟiyār varuttamuṟap - peṟṟaṟiyā                                     |
| vanti parivāy makavaip peṟumtuyaram                                          |
| nontuaṟiku vāḷō nuval.                                                 |
|                                                                       |
| 16. ceyaliṉ muṉ eṇṇuka                                                  |
|                                                                       |
| ceyyum ōrukarumam tērntu purivatuaṉṟic                                   |
| ceyyiṉ maṉattāpam cērumē - ceyyavora                                       |
| naṟkuṭiyaik kātta nakulaṉaimuṉ koṉṟamaṟaip                                     |
| poṟkoṭiyaic cērtuyaram pōl.                                              |
|                                                                       |
| 17. nayamāṉa collāl naṉmaiyē                                               |
|                                                                       |
| nāviṉ nuṉiyil nayamirukkiṉ pūmātum                                      |
| nāviṉiya nallōrum nuṇṇuvār - nāviṉnuṉi                                  |
| āṅkaṭiṉa mākil attiruvum cērāḷmuṉ                                       |
| āṅkē varummaraṇa mām.                                                     |
|                                                                       |
| 18. pullōrkkaṇ ellām nañcē                                              |
|                                                                       |
| īkku viṭamtalaiil eytum iruntēḷukku                                      |
| vāytta viṭamkoṭukkil vāḻumē - nōkkariya                                   |
| paiṅkaṇara vukkuviṭam palaḷavē turccaṉarukku                                  |
| aṅkammuḻu tumviṭamē ām.                                                 |
|                                                                       |
| 19. aṭaṅkāmai tīyavar paṇpu                                                 |
|                                                                       |
| turccaṉarum pāmpum tulaiyokki ṉumpāmpu                                   |
| turccaṉarai yokkumō tokaiyē - turccaṉartām                                  |
| entavitattālum iṇaṅkārē pāmpumaṇi                                         |
| mantirattāl āmē vacam.                                                    |
|                                                                       |
| 20. allōriṉ cēymai naṉṟē                                                |
|                                                                       |
| kompuḷataṟku aintu kutiraikku pattumuḻam                                    |
| vempukarikku āyiramtāṉ vēṇṭumē - vampuceṟi                               |
| tīṅkiṉartam kaṇṇil teriyāta tūrattu                                         |
| nīṅkuvatē nalla neṟi.                                                     |
|                                                                       |
| 21. pullōrai tiruttuvatu eḷitalla                                         |
|                                                                       |
| avviya neñcattu aṟivillāt turccaṉaraic                                     |
| cevviyar ākkum ceyaluṇṭō - tivviyanal                                     |
| kantam palavum kalantālum uḷḷiyatu                                           |
| kantam keṭumō karai.                                                      |
|                                                                       |
| 22.i rumalum pullōrum nikarē                                            |
|                                                                       |
| tuṉṉum irumalum turccaṉarum okkumē                                       |
| maṉṉum iṉimaiyāl māṟākip - paṉṉum                                        |
| kaṭuvum kaṭunēr kaṭumoḻiyum kaṇṭāl                                        |
| kaṭuka vacamākai yāl.                                                      |
|                                                                       |
| 23. pullōr paṇpu                                                       |
|                                                                       |
| ceṅkamalap pōtualarnta cevvipō lumvataṉam                                     |
| taṅku moḻican taṉampōlum - paṅkiyeṟi                                       |
| kattariyaip pōlumiḷaṅ kārikaiyē vañcamaṉam                                     |
| kuttirarpāl mūṉṟu kuṇam.                                                |
|                                                                       |
| 24.kaṭaiyaṉ col niṟkātu                                                  |
|                                                                       |
| nīcaṉō nīcaṉ niṉaiyuṅkāl coltavaṟum                                          |
| nīcaṉē nīcaṉ avaṉaiyē - nīcap                                                 |
| pulaiyaṉām eṉṟuraikkum pulliyaṉē mēlām                                    |
| pulaiyaṉām eṉṟē pukal.                                                   |
|                                                                       |
| 25. tīyavartam ōḻukkam pōṟṟātē                                             |
|                                                                       |
| ñāṉamā cāram nayavār iṭaippukaḻum                                           |
| ēṉaināl vētam irukkuneṟi - tāṉmoḻiyil                                   |
| pāvaniṟai caṇṭāḷar pāṇṭattuk kaṅkainīr                                        |
| mēvuneṟi yeṉṟē viṭu.                                                  |
|                                                                       |
| 26. koṭiyavarai nallōr aṇukār                                             |
|                                                                       |
| kuṇanaṉku uṇarāk koṭiyōr iṭattil                                          |
| kuṇanaṉ kuṭaiyār kuṟukār - kuṇamuṭaimai                                     |
| naṇṇāc camaṇa nakarattil tūcolikkum                                          |
| vaṇṇāṉukku uṇṭō vaḻakku.                                                 |
|                                                                       |
| 27. iṭattiṉāl tāṉ cīr ciṟappu                                            |
|                                                                       |
| āṉai maruppum aruṅkavari māṉmayirum                                        |
| kāṉa variukirum kaṟṟōrum - māṉē                                          |
| piṟantaiṭattu aṉṟip piṟitorutē cattē                                      |
| ceṟintaiṭattu aṉṟō ciṟappu.                                              |
|                                                                       |
| 28. nilaitavaṟāmai perumai                                                 |
|                                                                       |
| talaimayirum kūrukirum veṇpallum tantam                                     |
| nilaiyuṭaiya māṉavarum niṟkum - nilaitavaṟāt                                  |
| tāṉattil pūcciyamē cārum nilaitavaṟum                                      |
| tāṉattil pūcciyamō tāṉ.                                                 |
|                                                                       |
| 29. ñāṉiyartam ciṟappu                                                   |
|                                                                       |
| veṉṟi variyukirum veṇkavari māṉmayirum                                    |
| tuṉṟumata yāṉaic cuṭarmaruppum - niṉṟanilai                                  |
| vēṟupaṭi ṉumciṟappām meyññāṉi niṉṟanilai                                  |
| vēṟupaṭi ṉumciṟappā mē.                                                 |
|                                                                       |
| 30. naṉmaṉaiyāḷ paṇpu                                                     |
|                                                                       |
| aṉṉai tayaiyum aṭiyāḷ paṇiyummalarp                                         |
| poṉṉiṉ aḻakum puvippoṟaiyum - vaṉṉamulai                                   |
| vēci tuyilum viṟalman tirimatiyum                                        |
| pēcil ivaiyuṭaiyāḷ peṇ.                                                 |
|                                                                       |
| 31. makaḷiriṉ vākku nilai                                                |
|                                                                       |
| peṇṇorutti pēcil perumpūmi tāṉatirum                                  |
| peṇṇiruvar pēcilviḻum vāṉmīṉkaḷ - peṇmuvar                                |
| pēcil alaicuvaṟum pētaiyē peṇpalartām                                      |
| pēcilulaku eṉṉākumō piṉ.                                               |
|                                                                       |
| 32. īyukattil illantōṟum kūṟṟuvaṉ                                        |
|                                                                       |
| eṉṉē kirētat tirēṇukaiyē kūṟṟuvaṉām                                      |
| taṉṉēr tiērutattiṟ cāṉakiyē - piṉyukattil                                 |
| kūṭum tiraupatiyē kūṟṟām kaliyukattil                                     |
| vīṭutoṟum kūṟṟuvaṉā mē.                                                 |
|                                                                       |
| 33. aṟpar naṉmai ceyyār                                                  |
|                                                                       |
| kaṟpūram pōlak kaṭaluppu iruntālum                                         |
| kaṟpūram āmō kaṭaluppu - poṟpūrum                                         |
| puṇṇiyaraip pōla iruntālum pulliyartām                                    |
| puṇṇiyarā vārō pukal.                                                   |
|                                                                       |
| 34. nallōr paṇpu                                                        |
|                                                                       |
| cīlamillāṉ ētēṉum ceppiṭiṉum tāṉantak                                     |
| kālam iṭamaṟintu kaṭṭuraittē - ēlavē                                        |
| ceppumava ṉumtāṉē cintainō kātakaṉṟu                                       |
| tappumavaṉ uttamaṉē tāṉ.                                                   |
|                                                                       |
| 35. ārpparippavar pulliyar                                                |
|                                                                       |
| ciṟṟuṇarvōr eṉṟum ciluciluppar āṉṟamainta                                  |
| muṟṟuṇarvōr oṉṟum moḻiyārē - veṟṟipeṟum                                |
| veṇkalattiṉ ōcai mikumē viripacumpoṉ                                      |
| oṇkalattil uṇṭō oli.                                                    |
|                                                                       |
| 36. aṟam ceyya kālam ēṉ                                                  |
|                                                                       |
| uḷḷapoḻutu ētum uvantaḷippatu allāmalōr                                    |
| eḷḷaḷavum īya icaiyumō - teḷḷutamiḻc                                       |
| cīraḷittōṉ uṇṭanāḷ cērmēkat tukkarunta                                      |
| nīraḷitta tōmunnīr niṉṟu.                                                 |
|                                                                       |
| 37. tīyavariṉ cēymai naṉṟu                                                 |
|                                                                       |
| pētaiyaraik kaṇṭāl periyōr vaḻivilaki                                       |
| nītiyoṭu pōtal neṟiyaṉṟō - kātumata                                        |
| mākaratta yāṉai vaḻivilakal puṉmalamtiṉ                                        |
| cūkarattukku añciyō col.                                                |
|                                                                       |
| 38. uḷḷatum allātatum                                                   |
|                                                                       |
| mantiramum tēvum maruntum kuruvaruḷum                                     |
| tantiramum ñāṉam tarummuṟaiyum - yantiramum                                  |
| meyyeṉil meyyāy viḷaṅkumē mētiṉiyil                                    |
| poyyeṉil meyyākip pōm.                                                |
|                                                                       |
| 39. aṭivar vella aritāṉavar                                               |
|                                                                       |
| īcaṉetir niṉṟālum īcaṉaruḷ peṟṟuyarnta                                     |
| nēcaretir niṟpatu aritāmē - tēcuvaḷar                                     |
| ceṅkatirmuṉ niṉṟālum ceṅkatira vaṉkiraṇam                                   |
| taṅkumaṇal niṟkaritē tāṉ.                                                 |
|                                                                       |
| 40. aṭiyavar kaṇṇē kaṭavuḷ tiṟammikum                                       |
|                                                                       |
| muṟṟum iṟaiceyalē muṟṟiṭiṉum taṉaruḷaip                                   |
| peṟṟavartam pālē peritākum - paṟṟuperun                                   |
| tāpat tiṭattē taḻaṉṟiṭiṉum naṟcōti                                         |
| tīpat tiṭattē ciṟappu.                                                    |
|                                                                       |
| 41. nallār niṉaiyātavar                                                   |
|                                                                       |
| kaṉṉiyarai poṉṉāṇ kaḻintōrai maṟṟayalār                                       |
| paṉṉiyarai māyap parattaiyarai - muṉṉariya                                       |
| tātiyarai nallōr taḻuvaniṉai yārnarakat                                        |
| tītuvaru meṉṟu terintu.                                                 |
|                                                                       |
| 42. tāyar aivar                                                          |
|                                                                       |
| taṉṉai yaḷittāḷ tamaiyaṉmaṉai kuruviṉ                                         |
| paṉṉi aracaṉ payiltēvi - taṉmaṉaiyaip                                         |
| peṟṟāḷ ivaraivar pēcil evarukkum                                          |
| naṟṟāyar eṉṟē navil.                                                     |
|                                                                       |
| 43. kuḷaril vemmaiyum kōṭaiyil taṇmaiyum                                   |
|                                                                       |
| vāviyuṟai nīrum vaṭaniḻalum pāvakamum                                        |
| ēvaṉaiya kaṇṇār iḷamulaiyum - ōviyamē                                        |
| meṉcīta kālattu vemmaitarum emmaitaṉil                                       |
| iṉpārum cītaḷamā mē.                                                     |
|                                                                       |
| 44. iṉṉāriṉṉārkku ivaiyivai illaiyeṉal                                    |
|                                                                       |
| uṟṟatoḻil ceyvōrkku uṟupañcam illaiyām                                    |
| paṟṟucepat tōrkkillai pāvaṅkaḷ - muṟṟum                                    |
| mavuṉattōrkku illai varukālam tuñcāp                                       |
| pavaṉattōrkkillai payam.                                                    |
|                                                                       |
| 45. celvattiṉ ciṟappu                                                   |
|                                                                       |
| āpattu vantāl arumporuḷ tāṉvēṇṭumē                                      |
| āpattēṉpūmātu arukiruntāl - āpattu                                      |
| vantāl avaḷum maruvāmal epporuḷum                                         |
| antō vuṭaṉpōm aṟi.                                                     |
|                                                                       |
| 46. poruḷāl tuṉpam                                                     |
|                                                                       |
| iṉṉal tarumporuḷai īṭṭutalum tuṉpamē                                       |
| piṉṉataṉaip pēṇutalum tuṉpamē - aṉṉatu                                      |
| aḻittalum tuṉpamē antō piṟarpāl                                          |
| iḻattalē tuṉpamēyām.                                                     |
|                                                                       |
| 47. viṉaippayaṉ viṭātu                                                   |
|                                                                       |
| tāṉē puriviṉaiyāl cārum irupayaṉum                                       |
| tāṉē aṉupavittal tappātu - tāṉṉūṟu                                       |
| kōṭikaṟpam ceṉṟālum kōtaiyē ceytaviṉai                                     |
| nāṭiniṟkum eṉṟār nayantu.                                               |
|                                                                       |
| 48. ñāṉikku tuṉpamillai tuṭṭaṉukku iṉpamillai                              |
|                                                                       |
| tuya aṟiviṉarmuṉ cūḻtuṉpa millaiyām                                       |
| kāyum viṭamkaruṭarkku illaiyām - āyuṉkāl                                  |
| paṉmukaṉcēr tīmuṉ payilcīta millaiyām                                        |
| tuṉmukaṉukku uṇṭō cukam.                                                |
|                                                                       |
| 49. taṉittuṇṭal takātu                                                   |
|                                                                       |
| teṉpulattār teyvam viruntuokkal eṉṟivarōṭu                                |
| iṉpuṟat tāṉuṇṭal iṉitāmē - aṉpuṟavē                                      |
| takkavarai iṉṟit taṉittuṇṭal tāṉkavarmīṉ                                       |
| kokakaruntal eṉṟē kuṟi.                                                  |
|                                                                       |
| 50. aṭiyāriṭaiyē āṇṭavaṉ nilaippāṉ                                        |
|                                                                       |
| intiravi nīḷkiraṇam eṅkum niṟaintālum                                      |
| intaravi kāntat tilaṅkumē - intiravi                                       |
| ēntirattōṉ eṅkum niṟaintālum nīttaṉaruḷ                                    |
| ēntirattōr pālē niṟaivu.                                                |
|                                                                       |
| 51. āṇṭavaṉai vaṇaṅku                                                      |
|                                                                       |
| tāmō taraṉmutalēr cātalnūl cāṟṟuvatum                                      |
| pūmēlōr oṉṟuvatum kaṇṭōmē - nāmuṭalai                                     |
| nēcippatu eṉṉō nilaiyākum caṅkaraṉaip                                       |
| pūcippa toṉṟē pukal.                                                    |
|                                                                       |
| 52. iṟappataṟku muṉ iṟaivaṉaṭi toḻu                                         |
|                                                                       |
| araciṉ ilaiyataṉiṉ akkiramat tiṉiṉṟu                                        |
| viraiya viḻutuḷiyē pōlum - puraiyuṭaiya                                    |
| ākkaiviṭā muṉṉam araṉpātam pūcittal                                        |
| nōkkalnaṉṟu eṉṟē navil.                                                  |
|                                                                       |
| 53. uyarnta poruḷkaḷ                                                     |
|                                                                       |
| cattiyattai vellātu acattiyantāṉ nīḷpoṟaiyai                                  |
| mettiya kōpamatu vellātu - pattimiku                                      |
| puṇṇayattai pāvamatu vellātu pōrarakkar                                      |
| kaṇṇaṉaittāṉ velluvarō kāṇ.                                               |
|                                                                       |
| 54. naṟputalvaraip peṟuka                                                  |
|                                                                       |
| poṟpaṟivil lātapala puttiraraip pēṟaliṉōr                                    |
| naṟputalvaṉaip peṟutal naṉṟāmē - poṟkoṭiyē                                  |
| paṉṟipala kuṭṭi payantatiṉāl ētupayaṉ                                         |
| oṉṟamaiyātō karikkoṉṟu ōtu.                                              |
|                                                                       |
| 55. peṇmaṉattaiyāraṟivār                                                  |
|                                                                       |
| atti malarum aruṅkākkai veṇṇiṟamum                                        |
| kattupuṉal mīṉpatam kaṇṭālum - pittarē                                       |
| kāṉār teriyal kaṭavuḷarum kāṇparō                                          |
| māṉār viḻiyār maṉam.                                                    |
|                                                                       |
| 56. yōkikaku piṇiyillai                                                 |
|                                                                       |
| kāḷaviṭap pāntaḷ karuṭaṉaik kaṭṭumō                                          |
| vāḷeriyaik kaṭṭumō vaṉkayiṟu - nīḷum                                       |
| pavamaruḷum pācamvem pañcēn tiriyam                                         |
| civayōkiyaip piṇiyāvē.                                                  |
|                                                                       |
| 57. puṇṇiyamē vāḻvu                                                    |
|                                                                       |
| puttiyoṭu muttitarum puṇṇiyattā laṉṟiyē                                  |
| mattamiku pāvattāl vāḻvāmō - vittupayir                                   |
| tāyākiyē vaḷarkkum taṇpuṉalāl allātu                                      |
| tīyāl vaḷarumō ceppu.                                                    |
|                                                                       |
| 58. aṭiyavar piṉ āṇṭavaṉ                                                  |
|                                                                       |
| civaṉē civaṉē civaṉēyeṉ pārpiṉ                                           |
| civaṉumai yāḷoṭum tirivaṉ - civaṉaruḷāl                                    |
| peṟṟaiḷaṅ kaṉṟaip piriyāmal piṉṉōṭic                                       |
| cuṟṟupacup pōl toṭarntu.                                                |
|                                                                       |
| 59. īvatai niṟuttātē                                                    |
|                                                                       |
| tāmumko ṭārkoṭup pōrtamaiyum īyātavakai                                    |
| cēmamceyvārum cilaruṇṭē - ēmaniḻal                                        |
| iṭṭumalar kāykaṉikaḷ īntutavum naṉmarattaik                                    |
| kaṭṭumuṭai muḷeṉavē kāṇ.                                                 |
|                                                                       |
| 60. īvōr varuntāmal ēṟṟal naṉṟu                                           |
|                                                                       |
| āyumalart tēṉvaṇṭu aruntuvatu pōlirappōr                                   |
| īyumavar varuntātu ēṟṟalaṟam - tūyayiḷam                                      |
| paccilaiyaik kīṭamaṟiyāp paṟṟi arippatupōl                                    |
| accamuṟa vāṅkal akam.                                                     |
|                                                                       |
| 61. ivar pirivāl ivai nīṅkum                                             |
|                                                                       |
| mātā marikkiṉ makaṉnāviṉ naṟcuvaipōm                                       |
| tātā veṉilkalvi tāmakalum - ōtiluṭaṉ                                      |
| vantōṉ marittuviṭil vākuvalipōm maṉaiyēl                                   |
| antō ivaiyāvum pōm.                                                    |
|                                                                       |
| 62. kāṇat takkaṉa takātaṉa                                                   |
|                                                                       |
| ōtuporuḷ kaṇṭōrkku uṟumācai nītiyilāp                                    |
| pātakaraik kaṇṭōrkkup pāvamām - cītamalar                                      |
| kaṇṭōrk kuṟumvācam maṟṟamainta naṟṟavarait                                      |
| kaṇṭōrkku uṭaṉām kati.                                                   |
|                                                                       |
| 63. tīyōr celvam nallavarkku yatavātu.                                       |
|                                                                       |
| pāvitaṉam taṇṭippōr pālākum allataruḷ                                      |
| mēvucivaṉ aṉparpāl mēvātē - ōviyamē                                      |
| nāyiṉpāl attaṉaiyum nāytaṉakkām aṉṟiyē                                    |
| tuyavarukku ākumō col.                                                  |
|                                                                       |
| 64. tuṉpattilum nallavar nallavarāvār                                        |
|                                                                       |
| poṉṉum karumpum pukaḻpālum cantaṉamum                                      |
| ciṉṉampaṭa varuttam ceytālum - muṉṉirunta                                   |
| naṟkuṇamē tōṉṟum nalintālum uttamarpāl                                     |
| naṟkuṇamē tōṉṟum nayantu.                                                 |
|                                                                       |
| 65. ekkālattum pakaivarāvōr                                               |
|                                                                       |
| vēciyarum nāyum vitinūl vayittiyarum                                     |
| pūcurarum kōḻikaḷum poṉṉaṉaiyāy - pēcilōru                                |
| kāraṇantāṉ iṉṟiyē kaṇṭavuṭaṉē pakaiyām                                       |
| kāraṇantāṉ appiṟappē kāṇ.                                                |
|                                                                       |
| 66. aḻakaikkoṭuppaṉa                                                      |
|                                                                       |
| aṉṉamaṉaiyāy kuyilukku āṉavaḻaku yiṉṉicaiyē                                  |
| kaṉṉal moḻiyārkku kaṟpāmē - maṉṉukalai                                      |
| kaṟṟōrkku aḻaku karuṇaiyē ācaicamayakku                                       |
| aṟṟōrkku aḻaku poṟaiyām.                                                |
|                                                                       |
| 67. nallatāyiṉum eṇṇiccolluka                                            |
|                                                                       |
| itamakita vārttai evarkēṉum mēlām                                          |
| itameṉavē kūṟilitamaṉṟē - itamuraitta                                        |
| vākkiṉāl ēraṇṭa māmuṉiyumcōḻaṉoṭu                                        |
| tēkkunīr vīḻntoḻintāṉ cērntu.                                           |
|                                                                       |
| 68. mēṉmaiyāṉavar iruvakaiyiṉar                                             |
|                                                                       |
| ittaraiyōr taṉṉil iruvarē mēlāṉōr                                         |
| citti racavāti civayōki - muttaṉaiyāy                                      |
| nalkuravu muṟpavamum nācam purivārē                                        |
| allavarē vīriyak kīṭam.                                                     |
|                                                                       |
| 69. racavāti yōkikaḷiṉ mukkuṇaṅkaḷ                                         |
|                                                                       |
| aṟṟaciva yōkikku aruñciṉṉam mūṉṟuṇṭu                                     |
| paṟṟalakai uṉmattar pālariyal - muṟṟiraca                                       |
| vātikkuc ciṉṉam mūṉṟuṇṭē makiḻ pōkam ītal iravākai eṉṟu.                    |
|                                                                       |
| 70. nallavar tīyavar ceyal                                                   |
|                                                                       |
| vallavarpāl kalvi matamā ṇavampōkkum                                          |
| allavarpāl kalvi avaiyākkum - nalliṭattil                                   |
| yōkam payilvār uyarntōr iḻintōrkaḷ                                        |
| pōkam payilvōr purintu.                                                 |
|                                                                       |
| 71. kaṟṟavarāyiṉum tīyōr tīyavarē.                                           |
|                                                                       |
| tīyavarpāl kalvi ciṟantālum maṟṟavarait                                        |
| tuyavarēṉṟu eṇṇiyē tuṉṉaṟka - cēyiḻaiyē                                    |
| taṇṇoḷiya māṇikkam carppam tarittālum                                       |
| naṇṇuvarō maṟṟataṉai nāṭi.                                                  |
|                                                                       |
| 72. nīttōrukku ulakatuṉpamillai                                            |
|                                                                       |
| ūrur yeṉumvaṉattē oḷvāṭkaṇ mātareṉum                                      |
| kūrur viṭamuṭkuḻām uṇṭē - cīrūr                                         |
| virattivai rākkiyavi vēkattoṭu tōl                                        |
| urattaṇiyat taiyeṉ ṟōtu.                                                  |
|                                                                       |
| 73. ivarkaḷukku ivaiyillai                                                |
|                                                                       |
| pōṟṟu kurukiḷaiñar poṉṉacai yōrkkilalai                                     |
| tōṟṟu pacikkillai cuvaipākam - tēṟṟukalvi                                  |
| nēcarkku illaicukamum nittiraiyum kaimukartam                                |
| ācaikkillaiyām māṉam.                                                    |
|                                                                       |
| 74. tīyavarukku iṭamkoṭukkak kūṭātu                                        |
|                                                                       |
| naṉṟuṟiyāt tīyōrk kiṭamaḷitta nallōrkkum                                    |
| tuṉṟu kiḷaikkum tuyarcērum - kuṉṟiṭattil                                 |
| piṉṉiravil vantakarum piḷḷaik kiṭamakoṭutta                                   |
| aṉṉamutal paṭṭatu pōlām.                                                  |
|                                                                       |
| 75. nallōr tīyavarilpu                                                    |
|                                                                       |
| maṉamvēṟu colvēṟu maṉṉu toḻilvēṟu                                        |
| viṉaivēṟu paṭṭavarpāl mēvum - aṉamē                                        |
| maṉamoṉṟu colloṉṟu vāṉporuḷum oṉṟē                                      |
| kaṉamoṉṟu mēlavartam kaṇ.                                                   |
|                                                                       |
| 76. itaṟku ituvaḻaku                                                     |
|                                                                       |
| kaṇṇukku iṉiya capaikkumaṇi kaṟṟōṉē                                         |
| viṇṇukku iṉiyamaṇi veyyōṉē - vaṇṇanaṟum                                    |
| canta mulaiyāḷ cayaṉattu iṉiyamaṇi                                            |
| mainataṉ maṉaikku maṇi.                                                     |
|                                                                       |
| 77. nallōr naṇṇampaṟku uyirumaḷippar                                        |
|                                                                       |
| pāliṉnīr tīyaṇukap pālvekuṇṭu tīppukantu                                    |
| mēlumnīr kaṇṭamaiyum mēṉmaipōl - nūliṉneṟi                                 |
| uṟṟōr iṭukkaṇ uyirkoṭuttum māṟṟuvarē                                    |
| maṟṟōr pukala matittu.                                                    |
|                                                                       |
| 78. aṭivarporuḷ kavartalākātu                                             |
|                                                                       |
| antō purameritta aṇṇalaṭi yārporuḷkaḷ                                      |
| centīyiṉum koṭiya tīkkaṇṭāy - centīyai                                      |
| nīṅkiṉ cuṭātē neṭuntūram pōṉālum                                        |
| īṅkac cuṭumē itu.                                                      |
|                                                                       |
| 79. tīyōr kēṇmai tīyavē payakkum                                            |
|                                                                       |
| nintaiyilāt tuyavarum nintaiyaraic cērilavar                                  |
| nintaiyatu tammiṭattē niṟkumē - nintaimiku                                 |
| tālaniḻil kīḻiruntāṉ āṉpā laruntiṭiṉum                                   |
| pālateṉac collumō pār.                                                  |
|                                                                       |
| 80. tīyavar naṟcol ēṟkār                                                  |
|                                                                       |
| kaṉmamē pūritta kāyattōr tamceviyil                                        |
| taṉmanūl pukkālum taṅkātē - caṉmamelum                                     |
| puṇṭucamikkum nāy ūṇāviṉ neyyataṉai                                       |
| uṇṭu camikkumō ōtu.                                                    |
|                                                                       |
| 81. maṇamakaṉ ivaṉāvāṉ                                                     |
|                                                                       |
| peṇṇutavuṅ kālaip pitāvirumpum vittaiyē                                  |
| eṇṇil taṉamvirumpum īṉṟatāy - naṇṇiṭaiyil                                  |
| kūriyanal cuṟṟamum kulamvirumpum kāntaṉatu                                  |
| pēraḻuku tāṉvirumpum kaṇ.                                               |
|                                                                       |
| 82. viruppu palvakaittatu                                                 |
|                                                                       |
| kāntanaṟum puṇṇaik kalantī virumpumē                                        |
| vēntar taṉamē virumpuvar - cāntanūl                                        |
| kallār pakaicēr kalakam virumpuvar                                           |
| nallār virumpuvar naṭpu.                                                 |
|                                                                       |
| 83. nīttār nukarpporuḷ naṇṇalākātu                                        |
|                                                                       |
| maṟṟaik kuḻalār kaviṉellām ōrmakavaip                                        |
| peṟṟak kaṇamē piriyumē - kaṟṟaruḷai                                         |
| vēṭṭa poriyōr perumaiyelām vēṟoṉṟaik                                     |
| kēṭṭa poḻutē keṭum.                                                    |
|                                                                       |
| 84. tīyoḻukkam tīmaiyē nalkum                                              |
|                                                                       |
| cīlam kulamaṭiyāḷ tīṇṭiṉkeṭum kaṇikai                                       |
| āliṅkaṉam taṉanā camākum - nūliḻanta                                         |
| vallitaḻuvakkuṟaiyum vāḻnāḷ piṟartāram                                      |
| pulliṉarkkel lānalamum pōm.                                              |
|                                                                       |
| 85. uṇmaiyai cilarē virumpuvar                                            |
|                                                                       |
| cattayam ekkālum caṉavirutta mākumē                                         |
| ettayapoy yārkkum itamākum - nattiyapāl                                    |
| vīṭuceṉṟu vilaiyām matuyirunta                                            |
| vīṭutaṉi lēviai layāmē.                                                   |
|                                                                       |
| 86. tīyor naṇṇiya nallōrkkum tīmaiyē                                        |
|                                                                       |
| nalloḻukkam illār iṭamcērnta nallōrkkum                                    |
| nalloḻukka millāccol naṇṇumē - kollumviṭap                                |
| pāmpeṉa vuṉṉārē paḻutaiyē āṉālum                                         |
| tūmpamarum puṟṟaṭuttāl col.                                              |
|                                                                       |
| 87. nallōrai aṟiya vākku                                                 |
|                                                                       |
| vākkunayat tālaṉṟi kaṟṟavarai maṟṟavarai                                         |
| ākkainayat tālaṟiyal ākātē - kākkaiyoṭu                                    |
| nīlac ciṟukuyilai nīṭuicaiyāl aṉṟiyē                                       |
| kōlattu aṟivarumō kūṟu.                                                 |
|                                                                       |
| 88. tuyaruṇṭu illattil                                                  |
|                                                                       |
| ācaieṉum pācattāl āṭavartam cintaitaṉai                                       |
| vīcumaṉaiyām taṟiyil vīḻttiyē - mācupuri                                   |
| māyā maṉaiviyarām mākkaḷ makaveṉṉum                                         |
| nāyāl kaṭippittal nāṭu.                                                 |
|                                                                       |
| 89. tāṉam mūvakai                                                        |
|                                                                       |
| tāṉaṟintōruk kutavi taṉṉāl amaiyumeṉil                                    |
| tāṉuvantu ītal talaiyāmē - āṉataṉāl                                         |
| coṉṉāl puritaliṭai colliyum paṉṉāḷmaṟuttup                                |
| piṉṉāḷ purivatuvē piṉ.                                                 |
|                                                                       |
| 90. mūvakaiyār taṉmaikaḷ                                                   |
|                                                                       |
| uṟṟa maṟaiyakattiṉ uykkumavaṉ uttamaṉē                                         |
| maṟṟam maṟaipakarvōṉ mattimaṉē - muṟṟiḻaiyē                                    |
| attam uṟalāl pukalvāṉ atamaṉeṉa                                             |
| vittaka nūlōtum virittu.                                                |
|                                                                       |
| 91. mūvakaiyiṉar īkaittaṉmai                                                |
|                                                                       |
| uttamartām īyumiṭattu ōṅkupaṉai pōlvarē                                     |
| mattimartām teṅkutaṉai māṉuvarē - muttalarum                                 |
| āmkamuku pōlvar atamar avarkaḷē                                             |
| tēmkataliyum pōlvār tērntu.                                             |
|                                                                       |
| 92. uyarntōr kaimmāṟu karutār                                            |
|                                                                       |
| ellōr tamakkum iṉitutaval aṉṟiyē                                          |
| nallōr tamakkutavi nāṭārē - vallataru                                        |
| nāmaniti mēkam nayantutaval aṉṟiyē                                          |
| tāmutavi nāṭumō cāṟṟu.                                                 |
|                                                                       |
| 93. tīyōr col mikavum varuttam                                            |
|                                                                       |
| veyyōṉ kiraṇam mikaccuṭumē veyyavaṉiṉ                                      |
| ceyyōṉ kiraṇammikat tītāmē - veyyakatir                                     |
| ellōṉ kiraṇat teriyiṉilum eṇṇamilār                                      |
| collē mikavum cuṭum.                                                   |
|                                                                       |
| 94. iṉiya collē iṉpam payakkum                                            |
|                                                                       |
| tiṅkaḷ amirta kiraṇammikac cītaḷamē                                           |
| tiṅkaḷiṉum cantaṉamē cītaḷamām - iṅkivaṟṟiṉ                                   |
| aṉpaṟivu cāntam aruḷuṭaiyār nalvacaṉam                                       |
| iṉpamikum cītaḷa māmē.                                                    |
|                                                                       |
| 95. nīṟṟiṉ perumai                                                      |
|                                                                       |
| cīrām veṇṇīṟṟut tiripuṇṭaram viṭuttē                                      |
| pērāṉa mutti peṟavirumpal - āramirta                                       |
| cañcīviyai viṭuttē cākā tiruppataṟku                                       |
| nañcē pucittatupōṉm nāṭu.                                               |
|                                                                       |
| 96. aṭiyārkaḷ tiyāṉattil āṇṭavarkaḷai etirpārppar                            |
|                                                                       |
| centāmarai yiravi cērutayam pārkkumē                                       |
| cantrō tayampārkkum taṇkumutam - kantamikum                                  |
| pūvalarap pārkkum poṟivaṇṭu araṉaṉpar                                        |
| tēvaravaip pārppar tauintu.                                                |
|                                                                       |
| 97. mantiraṅkaḷ ainteḻuttukku ōppākā                                      |
|                                                                       |
| villam aṟukukkuovvā meṉmalarkaḷ nālvareṉum                                 |
| nallaṉpar coṟkovvā nāṉmaṟaikaḷ - mellinallāy                                 |
| āmantiram evaiyum ainteḻuttai ovvāvē                                       |
| cōmacunta raṟkueṉṟē col.                                                 |
|                                                                       |
| 98. kaṟṟavarkku nikarillai                                                 |
|                                                                       |
| kallār palarkūṭik kātalittu vāḻiṉumnūl                                    |
| vallāṉ oruvaṉaiyē māṉuvarō - alārum                                       |
| eṇṇilā vāṉmīṉ ilakiṭiṉum vāṉakattōr                                       |
| veṇṇilā ākumō viḷampu.                                                 |
|                                                                       |
| 99. cērnta iṭattiṉ payaṉ                                                  |
|                                                                       |
| cantaṉattaic cērtaruvum takkamaṇam kamaḻum                                       |
| cantaṉattaic cārvēy taḻalpaṟṟa - antavaṉam                                       |
| tāṉumac cantaṉamum taṉṉiṉamum māḷvataṉṟit                                     |
| tāṉum keṭaccuṭumō tāṉ.                                                 |
|                                                                       |
| 100. periyōraic cēriṉ tuṉpam nīṅkum                                      |
|                                                                       |
| kaṅkainati pāvam cacitāpam kaṟpakantāṉ                                         |
| maṅka luṟumvaṟumai māṟṟumē - tuṅkamikum                                    |
| ikkuṇamōr mūṉṟum periyō riṭamcēril                                      |
| akkaṇamē pōmeṉṟu aṟi.                                                   |
