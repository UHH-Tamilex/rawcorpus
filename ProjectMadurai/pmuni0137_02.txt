nīti veṇpā

+-----------------------------------------------------------------------+
| kaṭavuḷ vāḻttu                                                          |
|                                                                       |
| mūtuṇarntōr ōtucila mūturiyip pētiyēṉ                                   |
| nītiveṇpā vāka nikaḻntuvēṉ - ātiparaṉ                                      |
| vāmāṉ karuṇi maṇiutaram pūttamutal                                          |
| kōmāṉ peruṅkaruṇi koṇṭu.                                               |
|                                                                       |
| nūl                                                                   |
|                                                                       |
| 1. nallōr eṅkum toṉṟalām                                                |
|                                                                       |
| tāmaripoṉ muttuc cavaramkō rōcaṉipāl                                       |
| pūmarutēṉ paṭṭup puṉukucavvātu - āmaḻalmaṟṟu                               |
| eṅkē piṟantālum eḷḷārē nallōrkaḷ                                         |
| eṅkē piṟantālum eṉ                                                     |
|                                                                       |
| 2. uyarvaṭiya uyariṭamē cērka                                               |
|                                                                       |
| ariman tirampukuntāṉ āṉi maruppum                                        |
| perukoḷicēr muttum peṟalām - narinuḻiyil                                |
| vālum ciṟiya mayireṉpum karttapattiṉ                                       |
| tōlumallāl vēṟumuṇṭō col.                                              |
|                                                                       |
| 3. aṟivaṭiyōr pakivaṉākiṉum naṇpaṉē                                        |
|                                                                       |
| aṟivaṉ pakiyēṉum aṉpucēr naṭpām                                          |
| ciṟuvaṉ pakiyām ceṟinta - aṟivuṭiya                                       |
| veṉṟi vaṉacaraṉtāṉ vētiyaṉik kāttāṉ muṉ                                    |
| koṉṟatoru vēntik kuraṅku.                                               |
|                                                                       |
| 4. iṉcollē yāvarum kēṭpar                                               |
|                                                                       |
| meṉmatura vākkāl virumpum cakam kaṭiṉa                                      |
| vaṉmoḻiyi ṉālikaḻum maṇṇulakam - naṉmoḻiyi                                  |
| ōtukuyil ētaṅku utaviyatu karttapantāṉ                                      |
| ētaparā tamceytatu iṉṟu                                                   |
|                                                                       |
| 5. aṉpiṉāl māṟṟōriṭamum naṉmi                                           |
|                                                                       |
| pakicēṟum eṇṇāṉku palkoṇṭē nalnā                                         |
| vakicēr cuviaruntu māpōl - tokicēr                                     |
| pakivariṭam meyyaṉpu pāvittu avarāl                                        |
| cukamuṟutal nallōr toḻil.                                                |
|                                                                       |
| 6. payaṉaṟṟavi                                                            |
|                                                                       |
| kāntaṉil lāta kaṉaṅkuḻalāḷ poṟpuavamām                                      |
| cāntakuṇam illār tavamavamām - ēntiḻiyē                                    |
| aṉṉiillāp piḷḷi iruppatu avam avamē                                      |
| tuṉṉeyiṟil lārūṇ cuvi.                                                |
|                                                                       |
| 7. kalvikku iḷamiyē kālam                                                |
|                                                                       |
| varuntavaḷi vēyaracar māmuṭiyiṉ mēlalām                                     |
| varunta vaḷiyāta mūṅkil - tarittiramāy                                      |
| vēḻampar kippukuntu mētiṉiyel lāmtirintu                                |
| tāḻumavar tammaṭikkīḻt tāṉ.                                               |
|                                                                       |
| 8. irappatu aṟpamē                                                       |
|                                                                       |
| noytuām tiraṇattiṉ noytākum veṇpañciṉ                                    |
| noytām irappōṉ nuvaluṅkāl - noyyaciṟu                                    |
| pañcutaṉil noyyāṉip paṟṟutō kāṟṟaṇuka                                      |
| añcumavaṉ kēṭpatu aṟintu.                                                |
|                                                                       |
| 9. nalamākavāḻa ōr poḻutuṇka                                               |
|                                                                       |
| ōrupōtu yōkiyē ōṇṭaḷirkki mātē                                         |
| itupōtu pōkiyē yeṉpa - tiripōtu                                        |
| rōkiyē nāṉkupōtu uṇpāṉ uṭalviṭṭup                                      |
| pōkiyē yeṉṟu pukal.                                                    |
|                                                                       |
| 10. ellām aṟivar ñāṉiyar                                                |
|                                                                       |
| kaṇṇiraṇṭē yāvarkkum kaṟṟōrkku mūṉṟuviḻi                                  |
| eṇṇuvaḻi ēḻākum īvōrkku - naṇṇum                                        |
| anantam tavattāl aruḷñāṉam peṟṟōrkku                                       |
| anantam viḻiyeṉṟu aṟi.                                                  |
|                                                                       |
| 11. ilvāḻtalē nalvaḻi                                                    |
|                                                                       |
| uṟṟaperuñ cuṟṟam uṟanaṉ maṉiviyuṭaṉ                                         |
| paṟṟimika vāḻka pacuviṉpāl - paṟṟi                                         |
| natikaṭattal aṉṟiyē nāyiṉvāl paṟṟi                                         |
| natikaṭattaluṇṭō navil.                                                    |
|                                                                       |
| 12. tuṟantōrē ulakam āḷpavar                                               |
|                                                                       |
| ācikku aṭiyāṉ akilalō kattiṉukkum                                       |
| ācaṟṟa nallaṭiyāṉ āvāṉē - āci                                             |
| taṉiyaṭimi koṇṭavaṉē tappātu ulakam                                          |
| taṉiyaṭimi koṇṭavaṉē tāṉ.                                                 |
|                                                                       |
| 13. pāvam palavakiyām                                                     |
|                                                                       |
| āṉan taṇarmakaḷir aṉpām kuḻantivati                                         |
| māṉam teṟumpici vārttiivi - mēṉiṟiyē                                   |
| kūṟavaru pāvam kuṟiyātuōv voṉṟukkum                                      |
| nūṟuatikam eṉṟē nuval.                                                  |
|                                                                       |
| 14. ivar iḻiviṉi eytuvar                                                |
|                                                                       |
| peṟṟamikyum eṉṉāp periyōrum peṟṟaporuḷ                                  |
| maṟṟamiyum eṉṟē makiḻvēntum - muṟṟiyanaṉ                                   |
| māṉamilā illāḷum māṉamuṟu vēciyarum                                      |
| īṉa muṟuvār ivar.                                                       |
|                                                                       |
| 15. kalvitaṉmāṇpu kaṟṟōrē aṟivar                                          |
|                                                                       |
| kaṟṟōr kaṉamaṟivar kaṟṟōrē kaṟṟaṟiyā                                         |
| maṟṟōr aṟiyār varuttamuṟap - peṟṟaṟiyā                                     |
| vanti parivāy makavip peṟumtuyaram                                          |
| nontuaṟiku vāḷō nuval.                                                 |
|                                                                       |
| 16. ceyaliṉ muṉ eṇṇuka                                                  |
|                                                                       |
| ceyyum ōrukarumam tērntu purivatuaṉṟic                                   |
| ceyyiṉ maṉattāpam cērumē - ceyyavora                                       |
| naṟkuṭiyik kātta nakulaṉimuṉ koṉṟamaṟip                                     |
| poṟkoṭiyic cērtuyaram pōl.                                              |
|                                                                       |
| 17. nayamāṉa collāl naṉmiyē                                               |
|                                                                       |
| nāviṉ nuṉiyil nayamirukkiṉ pūmātum                                      |
| nāviṉiya nallōrum nuṇṇuvār - nāviṉnuṉi                                  |
| āṅkaṭiṉa mākil attiruvum cērāḷmuṉ                                       |
| āṅkē varummaraṇa mām.                                                     |
|                                                                       |
| 18. pullōrkkaṇ ellām nañcē                                              |
|                                                                       |
| īkku viṭamtaliil eytum iruntēḷukku                                      |
| vāytta viṭamkoṭukkil vāḻumē - nōkkariya                                   |
| piṅkaṇara vukkuviṭam palaḷavē turccaṉarukku                                  |
| aṅkammuḻu tumviṭamē ām.                                                 |
|                                                                       |
| 19. aṭaṅkāmi tīyavar paṇpu                                                 |
|                                                                       |
| turccaṉarum pāmpum tuliyokki ṉumpāmpu                                   |
| turccaṉari yokkumō tokiyē - turccaṉartām                                  |
| entavitattālum iṇaṅkārē pāmpumaṇi                                         |
| mantirattāl āmē vacam.                                                    |
|                                                                       |
| 20. allōriṉ cēymi naṉṟē                                                |
|                                                                       |
| kompuḷataṟku aintu kutirikku pattumuḻam                                    |
| vempukarikku āyiramtāṉ vēṇṭumē - vampuceṟi                               |
| tīṅkiṉartam kaṇṇil teriyāta tūrattu                                         |
| nīṅkuvatē nalla neṟi.                                                     |
|                                                                       |
| 21. pullōri tiruttuvatu eḷitalla                                         |
|                                                                       |
| avviya neñcattu aṟivillāt turccaṉaric                                     |
| cevviyar ākkum ceyaluṇṭō - tivviyanal                                     |
| kantam palavum kalantālum uḷḷiyatu                                           |
| kantam keṭumō kari.                                                      |
|                                                                       |
| 22.i rumalum pullōrum nikarē                                            |
|                                                                       |
| tuṉṉum irumalum turccaṉarum okkumē                                       |
| maṉṉum iṉimiyāl māṟākip - paṉṉum                                        |
| kaṭuvum kaṭunēr kaṭumoḻiyum kaṇṭāl                                        |
| kaṭuka vacamāki yāl.                                                      |
|                                                                       |
| 23. pullōr paṇpu                                                       |
|                                                                       |
| ceṅkamalap pōtualarnta cevvipō lumvataṉam                                     |
| taṅku moḻican taṉampōlum - paṅkiyeṟi                                       |
| kattariyip pōlumiḷaṅ kārikiyē vañcamaṉam                                     |
| kuttirarpāl mūṉṟu kuṇam.                                                |
|                                                                       |
| 24.kaṭiyaṉ col niṟkātu                                                  |
|                                                                       |
| nīcaṉō nīcaṉ niṉiyuṅkāl coltavaṟum                                          |
| nīcaṉē nīcaṉ avaṉiyē - nīcap                                                 |
| puliyaṉām eṉṟurikkum pulliyaṉē mēlām                                    |
| puliyaṉām eṉṟē pukal.                                                   |
|                                                                       |
| 25. tīyavartam ōḻukkam pōṟṟātē                                             |
|                                                                       |
| ñāṉamā cāram nayavār iṭippukaḻum                                           |
| ēṉināl vētam irukkuneṟi - tāṉmoḻiyil                                   |
| pāvaniṟi caṇṭāḷar pāṇṭattuk kaṅkinīr                                        |
| mēvuneṟi yeṉṟē viṭu.                                                  |
|                                                                       |
| 26. koṭiyavari nallōr aṇukār                                             |
|                                                                       |
| kuṇanaṉku uṇarāk koṭiyōr iṭattil                                          |
| kuṇanaṉ kuṭiyār kuṟukār - kuṇamuṭimi                                     |
| naṇṇāc camaṇa nakarattil tūcolikkum                                          |
| vaṇṇāṉukku uṇṭō vaḻakku.                                                 |
|                                                                       |
| 27. iṭattiṉāl tāṉ cīr ciṟappu                                            |
|                                                                       |
| āṉi maruppum aruṅkavari māṉmayirum                                        |
| kāṉa variukirum kaṟṟōrum - māṉē                                          |
| piṟantiṭattu aṉṟip piṟitorutē cattē                                      |
| ceṟintiṭattu aṉṟō ciṟappu.                                              |
|                                                                       |
| 28. nilitavaṟāmi perumi                                                 |
|                                                                       |
| talimayirum kūrukirum veṇpallum tantam                                     |
| niliyuṭiya māṉavarum niṟkum - nilitavaṟāt                                  |
| tāṉattil pūcciyamē cārum nilitavaṟum                                      |
| tāṉattil pūcciyamō tāṉ.                                                 |
|                                                                       |
| 29. ñāṉiyartam ciṟappu                                                   |
|                                                                       |
| veṉṟi variyukirum veṇkavari māṉmayirum                                    |
| tuṉṟumata yāṉic cuṭarmaruppum - niṉṟanili                                  |
| vēṟupaṭi ṉumciṟappām meyññāṉi niṉṟanili                                  |
| vēṟupaṭi ṉumciṟappā mē.                                                 |
|                                                                       |
| 30. naṉmaṉiyāḷ paṇpu                                                     |
|                                                                       |
| aṉṉi tayiyum aṭiyāḷ paṇiyummalarp                                         |
| poṉṉiṉ aḻakum puvippoṟiyum - vaṉṉamuli                                   |
| vēci tuyilum viṟalman tirimatiyum                                        |
| pēcil iviyuṭiyāḷ peṇ.                                                 |
|                                                                       |
| 31. makaḷiriṉ vākku nili                                                |
|                                                                       |
| peṇṇorutti pēcil perumpūmi tāṉatirum                                  |
| peṇṇiruvar pēcilviḻum vāṉmīṉkaḷ - peṇmuvar                                |
| pēcil alicuvaṟum pētiyē peṇpalartām                                      |
| pēcilulaku eṉṉākumō piṉ.                                               |
|                                                                       |
| 32. īyukattil illantōṟum kūṟṟuvaṉ                                        |
|                                                                       |
| eṉṉē kirētat tirēṇukiyē kūṟṟuvaṉām                                      |
| taṉṉēr tiērutattiṟ cāṉakiyē - piṉyukattil                                 |
| kūṭum tirupatiyē kūṟṟām kaliyukattil                                     |
| vīṭutoṟum kūṟṟuvaṉā mē.                                                 |
|                                                                       |
| 33. aṟpar naṉmi ceyyār                                                  |
|                                                                       |
| kaṟpūram pōlak kaṭaluppu iruntālum                                         |
| kaṟpūram āmō kaṭaluppu - poṟpūrum                                         |
| puṇṇiyarip pōla iruntālum pulliyartām                                    |
| puṇṇiyarā vārō pukal.                                                   |
|                                                                       |
| 34. nallōr paṇpu                                                        |
|                                                                       |
| cīlamillāṉ ētēṉum ceppiṭiṉum tāṉantak                                     |
| kālam iṭamaṟintu kaṭṭurittē - ēlavē                                        |
| ceppumava ṉumtāṉē cintinō kātakaṉṟu                                       |
| tappumavaṉ uttamaṉē tāṉ.                                                   |
|                                                                       |
| 35. ārpparippavar pulliyar                                                |
|                                                                       |
| ciṟṟuṇarvōr eṉṟum ciluciluppar āṉṟaminta                                  |
| muṟṟuṇarvōr oṉṟum moḻiyārē - veṟṟipeṟum                                |
| veṇkalattiṉ ōci mikumē viripacumpoṉ                                      |
| oṇkalattil uṇṭō oli.                                                    |
|                                                                       |
| 36. aṟam ceyya kālam ēṉ                                                  |
|                                                                       |
| uḷḷapoḻutu ētum uvantaḷippatu allāmalōr                                    |
| eḷḷaḷavum īya iciyumō - teḷḷutamiḻc                                       |
| cīraḷittōṉ uṇṭanāḷ cērmēkat tukkarunta                                      |
| nīraḷitta tōmunnīr niṉṟu.                                                 |
|                                                                       |
| 37. tīyavariṉ cēymi naṉṟu                                                 |
|                                                                       |
| pētiyarik kaṇṭāl periyōr vaḻivilaki                                       |
| nītiyoṭu pōtal neṟiyaṉṟō - kātumata                                        |
| mākaratta yāṉi vaḻivilakal puṉmalamtiṉ                                        |
| cūkarattukku añciyō col.                                                |
|                                                                       |
| 38. uḷḷatum allātatum                                                   |
|                                                                       |
| mantiramum tēvum maruntum kuruvaruḷum                                     |
| tantiramum ñāṉam tarummuṟiyum - yantiramum                                  |
| meyyeṉil meyyāy viḷaṅkumē mētiṉiyil                                    |
| poyyeṉil meyyākip pōm.                                                |
|                                                                       |
| 39. aṭivar vella aritāṉavar                                               |
|                                                                       |
| īcaṉetir niṉṟālum īcaṉaruḷ peṟṟuyarnta                                     |
| nēcaretir niṟpatu aritāmē - tēcuvaḷar                                     |
| ceṅkatirmuṉ niṉṟālum ceṅkatira vaṉkiraṇam                                   |
| taṅkumaṇal niṟkaritē tāṉ.                                                 |
|                                                                       |
| 40. aṭiyavar kaṇṇē kaṭavuḷ tiṟammikum                                       |
|                                                                       |
| muṟṟum iṟiceyalē muṟṟiṭiṉum taṉaruḷip                                   |
| peṟṟavartam pālē peritākum - paṟṟuperun                                   |
| tāpat tiṭattē taḻaṉṟiṭiṉum naṟcōti                                         |
| tīpat tiṭattē ciṟappu.                                                    |
|                                                                       |
| 41. nallār niṉiyātavar                                                   |
|                                                                       |
| kaṉṉiyari poṉṉāṇ kaḻintōri maṟṟayalār                                       |
| paṉṉiyari māyap parattiyari - muṉṉariya                                       |
| tātiyari nallōr taḻuvaniṉi yārnarakat                                        |
| tītuvaru meṉṟu terintu.                                                 |
|                                                                       |
| 42. tāyar aivar                                                          |
|                                                                       |
| taṉṉi yaḷittāḷ tamiyaṉmaṉi kuruviṉ                                         |
| paṉṉi aracaṉ payiltēvi - taṉmaṉiyip                                         |
| peṟṟāḷ ivarivar pēcil evarukkum                                          |
| naṟṟāyar eṉṟē navil.                                                     |
|                                                                       |
| 43. kuḷaril vemmiyum kōṭiyil taṇmiyum                                   |
|                                                                       |
| vāviyuṟi nīrum vaṭaniḻalum pāvakamum                                        |
| ēvaṉiya kaṇṇār iḷamuliyum - ōviyamē                                        |
| meṉcīta kālattu vemmitarum emmitaṉil                                       |
| iṉpārum cītaḷamā mē.                                                     |
|                                                                       |
| 44. iṉṉāriṉṉārkku iviyivi illiyeṉal                                    |
|                                                                       |
| uṟṟatoḻil ceyvōrkku uṟupañcam illiyām                                    |
| paṟṟucepat tōrkkilli pāvaṅkaḷ - muṟṟum                                    |
| mavuṉattōrkku illi varukālam tuñcāp                                       |
| pavaṉattōrkkilli payam.                                                    |
|                                                                       |
| 45. celvattiṉ ciṟappu                                                   |
|                                                                       |
| āpattu vantāl arumporuḷ tāṉvēṇṭumē                                      |
| āpattēṉpūmātu arukiruntāl - āpattu                                      |
| vantāl avaḷum maruvāmal epporuḷum                                         |
| antō vuṭaṉpōm aṟi.                                                     |
|                                                                       |
| 46. poruḷāl tuṉpam                                                     |
|                                                                       |
| iṉṉal tarumporuḷi īṭṭutalum tuṉpamē                                       |
| piṉṉataṉip pēṇutalum tuṉpamē - aṉṉatu                                      |
| aḻittalum tuṉpamē antō piṟarpāl                                          |
| iḻattalē tuṉpamēyām.                                                     |
|                                                                       |
| 47. viṉippayaṉ viṭātu                                                   |
|                                                                       |
| tāṉē puriviṉiyāl cārum irupayaṉum                                       |
| tāṉē aṉupavittal tappātu - tāṉṉūṟu                                       |
| kōṭikaṟpam ceṉṟālum kōtiyē ceytaviṉi                                     |
| nāṭiniṟkum eṉṟār nayantu.                                               |
|                                                                       |
| 48. ñāṉikku tuṉpamilli tuṭṭaṉukku iṉpamilli                              |
|                                                                       |
| tuya aṟiviṉarmuṉ cūḻtuṉpa milliyām                                       |
| kāyum viṭamkaruṭarkku illiyām - āyuṉkāl                                  |
| paṉmukaṉcēr tīmuṉ payilcīta milliyām                                        |
| tuṉmukaṉukku uṇṭō cukam.                                                |
|                                                                       |
| 49. taṉittuṇṭal takātu                                                   |
|                                                                       |
| teṉpulattār teyvam viruntuokkal eṉṟivarōṭu                                |
| iṉpuṟat tāṉuṇṭal iṉitāmē - aṉpuṟavē                                      |
| takkavari iṉṟit taṉittuṇṭal tāṉkavarmīṉ                                       |
| kokakaruntal eṉṟē kuṟi.                                                  |
|                                                                       |
| 50. aṭiyāriṭiyē āṇṭavaṉ nilippāṉ                                        |
|                                                                       |
| intiravi nīḷkiraṇam eṅkum niṟintālum                                      |
| intaravi kāntat tilaṅkumē - intiravi                                       |
| ēntirattōṉ eṅkum niṟintālum nīttaṉaruḷ                                    |
| ēntirattōr pālē niṟivu.                                                |
|                                                                       |
| 51. āṇṭavaṉi vaṇaṅku                                                      |
|                                                                       |
| tāmō taraṉmutalēr cātalnūl cāṟṟuvatum                                      |
| pūmēlōr oṉṟuvatum kaṇṭōmē - nāmuṭali                                     |
| nēcippatu eṉṉō niliyākum caṅkaraṉip                                       |
| pūcippa toṉṟē pukal.                                                    |
|                                                                       |
| 52. iṟappataṟku muṉ iṟivaṉaṭi toḻu                                         |
|                                                                       |
| araciṉ iliyataṉiṉ akkiramat tiṉiṉṟu                                        |
| viriya viḻutuḷiyē pōlum - puriyuṭiya                                    |
| ākkiviṭā muṉṉam araṉpātam pūcittal                                        |
| nōkkalnaṉṟu eṉṟē navil.                                                  |
|                                                                       |
| 53. uyarnta poruḷkaḷ                                                     |
|                                                                       |
| cattiyatti vellātu acattiyantāṉ nīḷpoṟiyi                                  |
| mettiya kōpamatu vellātu - pattimiku                                      |
| puṇṇayatti pāvamatu vellātu pōrarakkar                                      |
| kaṇṇaṉittāṉ velluvarō kāṇ.                                               |
|                                                                       |
| 54. naṟputalvarip peṟuka                                                  |
|                                                                       |
| poṟpaṟivil lātapala puttirarip pēṟaliṉōr                                    |
| naṟputalvaṉip peṟutal naṉṟāmē - poṟkoṭiyē                                  |
| paṉṟipala kuṭṭi payantatiṉāl ētupayaṉ                                         |
| oṉṟamiyātō karikkoṉṟu ōtu.                                              |
|                                                                       |
| 55. peṇmaṉattiyāraṟivār                                                  |
|                                                                       |
| atti malarum aruṅkākki veṇṇiṟamum                                        |
| kattupuṉal mīṉpatam kaṇṭālum - pittarē                                       |
| kāṉār teriyal kaṭavuḷarum kāṇparō                                          |
| māṉār viḻiyār maṉam.                                                    |
|                                                                       |
| 56. yōkikaku piṇiyilli                                                 |
|                                                                       |
| kāḷaviṭap pāntaḷ karuṭaṉik kaṭṭumō                                          |
| vāḷeriyik kaṭṭumō vaṉkayiṟu - nīḷum                                       |
| pavamaruḷum pācamvem pañcēn tiriyam                                         |
| civayōkiyip piṇiyāvē.                                                  |
|                                                                       |
| 57. puṇṇiyamē vāḻvu                                                    |
|                                                                       |
| puttiyoṭu muttitarum puṇṇiyattā laṉṟiyē                                  |
| mattamiku pāvattāl vāḻvāmō - vittupayir                                   |
| tāyākiyē vaḷarkkum taṇpuṉalāl allātu                                      |
| tīyāl vaḷarumō ceppu.                                                    |
|                                                                       |
| 58. aṭiyavar piṉ āṇṭavaṉ                                                  |
|                                                                       |
| civaṉē civaṉē civaṉēyeṉ pārpiṉ                                           |
| civaṉumi yāḷoṭum tirivaṉ - civaṉaruḷāl                                    |
| peṟṟiḷaṅ kaṉṟip piriyāmal piṉṉōṭic                                       |
| cuṟṟupacup pōl toṭarntu.                                                |
|                                                                       |
| 59. īvati niṟuttātē                                                    |
|                                                                       |
| tāmumko ṭārkoṭup pōrtamiyum īyātavaki                                    |
| cēmamceyvārum cilaruṇṭē - ēmaniḻal                                        |
| iṭṭumalar kāykaṉikaḷ īntutavum naṉmarattik                                    |
| kaṭṭumuṭi muḷeṉavē kāṇ.                                                 |
|                                                                       |
| 60. īvōr varuntāmal ēṟṟal naṉṟu                                           |
|                                                                       |
| āyumalart tēṉvaṇṭu aruntuvatu pōlirappōr                                   |
| īyumavar varuntātu ēṟṟalaṟam - tūyayiḷam                                      |
| pacciliyik kīṭamaṟiyāp paṟṟi arippatupōl                                    |
| accamuṟa vāṅkal akam.                                                     |
|                                                                       |
| 61. ivar pirivāl ivi nīṅkum                                             |
|                                                                       |
| mātā marikkiṉ makaṉnāviṉ naṟcuvipōm                                       |
| tātā veṉilkalvi tāmakalum - ōtiluṭaṉ                                      |
| vantōṉ marittuviṭil vākuvalipōm maṉiyēl                                   |
| antō iviyāvum pōm.                                                    |
|                                                                       |
| 62. kāṇat takkaṉa takātaṉa                                                   |
|                                                                       |
| ōtuporuḷ kaṇṭōrkku uṟumāci nītiyilāp                                    |
| pātakarik kaṇṭōrkkup pāvamām - cītamalar                                      |
| kaṇṭōrk kuṟumvācam maṟṟaminta naṟṟavarit                                      |
| kaṇṭōrkku uṭaṉām kati.                                                   |
|                                                                       |
| 63. tīyōr celvam nallavarkku yatavātu.                                       |
|                                                                       |
| pāvitaṉam taṇṭippōr pālākum allataruḷ                                      |
| mēvucivaṉ aṉparpāl mēvātē - ōviyamē                                      |
| nāyiṉpāl attaṉiyum nāytaṉakkām aṉṟiyē                                    |
| tuyavarukku ākumō col.                                                  |
|                                                                       |
| 64. tuṉpattilum nallavar nallavarāvār                                        |
|                                                                       |
| poṉṉum karumpum pukaḻpālum cantaṉamum                                      |
| ciṉṉampaṭa varuttam ceytālum - muṉṉirunta                                   |
| naṟkuṇamē tōṉṟum nalintālum uttamarpāl                                     |
| naṟkuṇamē tōṉṟum nayantu.                                                 |
|                                                                       |
| 65. ekkālattum pakivarāvōr                                               |
|                                                                       |
| vēciyarum nāyum vitinūl vayittiyarum                                     |
| pūcurarum kōḻikaḷum poṉṉaṉiyāy - pēcilōru                                |
| kāraṇantāṉ iṉṟiyē kaṇṭavuṭaṉē pakiyām                                       |
| kāraṇantāṉ appiṟappē kāṇ.                                                |
|                                                                       |
| 66. aḻakikkoṭuppaṉa                                                      |
|                                                                       |
| aṉṉamaṉiyāy kuyilukku āṉavaḻaku yiṉṉiciyē                                  |
| kaṉṉal moḻiyārkku kaṟpāmē - maṉṉukali                                      |
| kaṟṟōrkku aḻaku karuṇiyē ācicamayakku                                       |
| aṟṟōrkku aḻaku poṟiyām.                                                |
|                                                                       |
| 67. nallatāyiṉum eṇṇiccolluka                                            |
|                                                                       |
| itamakita vārtti evarkēṉum mēlām                                          |
| itameṉavē kūṟilitamaṉṟē - itamuritta                                        |
| vākkiṉāl ēraṇṭa māmuṉiyumcōḻaṉoṭu                                        |
| tēkkunīr vīḻntoḻintāṉ cērntu.                                           |
|                                                                       |
| 68. mēṉmiyāṉavar iruvakiyiṉar                                             |
|                                                                       |
| ittariyōr taṉṉil iruvarē mēlāṉōr                                         |
| citti racavāti civayōki - muttaṉiyāy                                      |
| nalkuravu muṟpavamum nācam purivārē                                        |
| allavarē vīriyak kīṭam.                                                     |
|                                                                       |
| 69. racavāti yōkikaḷiṉ mukkuṇaṅkaḷ                                         |
|                                                                       |
| aṟṟaciva yōkikku aruñciṉṉam mūṉṟuṇṭu                                     |
| paṟṟalaki uṉmattar pālariyal - muṟṟiraca                                       |
| vātikkuc ciṉṉam mūṉṟuṇṭē makiḻ pōkam ītal iravāki eṉṟu.                    |
|                                                                       |
| 70. nallavar tīyavar ceyal                                                   |
|                                                                       |
| vallavarpāl kalvi matamā ṇavampōkkum                                          |
| allavarpāl kalvi aviyākkum - nalliṭattil                                   |
| yōkam payilvār uyarntōr iḻintōrkaḷ                                        |
| pōkam payilvōr purintu.                                                 |
|                                                                       |
| 71. kaṟṟavarāyiṉum tīyōr tīyavarē.                                           |
|                                                                       |
| tīyavarpāl kalvi ciṟantālum maṟṟavarit                                        |
| tuyavarēṉṟu eṇṇiyē tuṉṉaṟka - cēyiḻiyē                                    |
| taṇṇoḷiya māṇikkam carppam tarittālum                                       |
| naṇṇuvarō maṟṟataṉi nāṭi.                                                  |
|                                                                       |
| 72. nīttōrukku ulakatuṉpamilli                                            |
|                                                                       |
| ūrur yeṉumvaṉattē oḷvāṭkaṇ mātareṉum                                      |
| kūrur viṭamuṭkuḻām uṇṭē - cīrūr                                         |
| virattivi rākkiyavi vēkattoṭu tōl                                        |
| urattaṇiyat tiyeṉ ṟōtu.                                                  |
|                                                                       |
| 73. ivarkaḷukku iviyilli                                                |
|                                                                       |
| pōṟṟu kurukiḷiñar poṉṉaci yōrkkilali                                     |
| tōṟṟu pacikkilli cuvipākam - tēṟṟukalvi                                  |
| nēcarkku illicukamum nittiriyum kimukartam                                |
| ācikkilliyām māṉam.                                                    |
|                                                                       |
| 74. tīyavarukku iṭamkoṭukkak kūṭātu                                        |
|                                                                       |
| naṉṟuṟiyāt tīyōrk kiṭamaḷitta nallōrkkum                                    |
| tuṉṟu kiḷikkum tuyarcērum - kuṉṟiṭattil                                 |
| piṉṉiravil vantakarum piḷḷik kiṭamakoṭutta                                   |
| aṉṉamutal paṭṭatu pōlām.                                                  |
|                                                                       |
| 75. nallōr tīyavarilpu                                                    |
|                                                                       |
| maṉamvēṟu colvēṟu maṉṉu toḻilvēṟu                                        |
| viṉivēṟu paṭṭavarpāl mēvum - aṉamē                                        |
| maṉamoṉṟu colloṉṟu vāṉporuḷum oṉṟē                                      |
| kaṉamoṉṟu mēlavartam kaṇ.                                                   |
|                                                                       |
| 76. itaṟku ituvaḻaku                                                     |
|                                                                       |
| kaṇṇukku iṉiya capikkumaṇi kaṟṟōṉē                                         |
| viṇṇukku iṉiyamaṇi veyyōṉē - vaṇṇanaṟum                                    |
| canta muliyāḷ cayaṉattu iṉiyamaṇi                                            |
| minataṉ maṉikku maṇi.                                                     |
|                                                                       |
| 77. nallōr naṇṇampaṟku uyirumaḷippar                                        |
|                                                                       |
| pāliṉnīr tīyaṇukap pālvekuṇṭu tīppukantu                                    |
| mēlumnīr kaṇṭamiyum mēṉmipōl - nūliṉneṟi                                 |
| uṟṟōr iṭukkaṇ uyirkoṭuttum māṟṟuvarē                                    |
| maṟṟōr pukala matittu.                                                    |
|                                                                       |
| 78. aṭivarporuḷ kavartalākātu                                             |
|                                                                       |
| antō purameritta aṇṇalaṭi yārporuḷkaḷ                                      |
| centīyiṉum koṭiya tīkkaṇṭāy - centīyi                                      |
| nīṅkiṉ cuṭātē neṭuntūram pōṉālum                                        |
| īṅkac cuṭumē itu.                                                      |
|                                                                       |
| 79. tīyōr kēṇmi tīyavē payakkum                                            |
|                                                                       |
| nintiyilāt tuyavarum nintiyaric cērilavar                                  |
| nintiyatu tammiṭattē niṟkumē - nintimiku                                 |
| tālaniḻil kīḻiruntāṉ āṉpā laruntiṭiṉum                                   |
| pālateṉac collumō pār.                                                  |
|                                                                       |
| 80. tīyavar naṟcol ēṟkār                                                  |
|                                                                       |
| kaṉmamē pūritta kāyattōr tamceviyil                                        |
| taṉmanūl pukkālum taṅkātē - caṉmamelum                                     |
| puṇṭucamikkum nāy ūṇāviṉ neyyataṉi                                       |
| uṇṭu camikkumō ōtu.                                                    |
|                                                                       |
| 81. maṇamakaṉ ivaṉāvāṉ                                                     |
|                                                                       |
| peṇṇutavuṅ kālip pitāvirumpum vittiyē                                  |
| eṇṇil taṉamvirumpum īṉṟatāy - naṇṇiṭiyil                                  |
| kūriyanal cuṟṟamum kulamvirumpum kāntaṉatu                                  |
| pēraḻuku tāṉvirumpum kaṇ.                                               |
|                                                                       |
| 82. viruppu palvakittatu                                                 |
|                                                                       |
| kāntanaṟum puṇṇik kalantī virumpumē                                        |
| vēntar taṉamē virumpuvar - cāntanūl                                        |
| kallār pakicēr kalakam virumpuvar                                           |
| nallār virumpuvar naṭpu.                                                 |
|                                                                       |
| 83. nīttār nukarpporuḷ naṇṇalākātu                                        |
|                                                                       |
| maṟṟik kuḻalār kaviṉellām ōrmakavip                                        |
| peṟṟak kaṇamē piriyumē - kaṟṟaruḷi                                         |
| vēṭṭa poriyōr perumiyelām vēṟoṉṟik                                     |
| kēṭṭa poḻutē keṭum.                                                    |
|                                                                       |
| 84. tīyoḻukkam tīmiyē nalkum                                              |
|                                                                       |
| cīlam kulamaṭiyāḷ tīṇṭiṉkeṭum kaṇiki                                       |
| āliṅkaṉam taṉanā camākum - nūliḻanta                                         |
| vallitaḻuvakkuṟiyum vāḻnāḷ piṟartāram                                      |
| pulliṉarkkel lānalamum pōm.                                              |
|                                                                       |
| 85. uṇmiyi cilarē virumpuvar                                            |
|                                                                       |
| cattayam ekkālum caṉavirutta mākumē                                         |
| ettayapoy yārkkum itamākum - nattiyapāl                                    |
| vīṭuceṉṟu viliyām matuyirunta                                            |
| vīṭutaṉi lēviai layāmē.                                                   |
|                                                                       |
| 86. tīyor naṇṇiya nallōrkkum tīmiyē                                        |
|                                                                       |
| nalloḻukkam illār iṭamcērnta nallōrkkum                                    |
| nalloḻukka millāccol naṇṇumē - kollumviṭap                                |
| pāmpeṉa vuṉṉārē paḻutiyē āṉālum                                         |
| tūmpamarum puṟṟaṭuttāl col.                                              |
|                                                                       |
| 87. nallōri aṟiya vākku                                                 |
|                                                                       |
| vākkunayat tālaṉṟi kaṟṟavari maṟṟavari                                         |
| ākkinayat tālaṟiyal ākātē - kākkiyoṭu                                    |
| nīlac ciṟukuyili nīṭuiciyāl aṉṟiyē                                       |
| kōlattu aṟivarumō kūṟu.                                                 |
|                                                                       |
| 88. tuyaruṇṭu illattil                                                  |
|                                                                       |
| ācieṉum pācattāl āṭavartam cintitaṉi                                       |
| vīcumaṉiyām taṟiyil vīḻttiyē - mācupuri                                   |
| māyā maṉiviyarām mākkaḷ makaveṉṉum                                         |
| nāyāl kaṭippittal nāṭu.                                                 |
|                                                                       |
| 89. tāṉam mūvaki                                                        |
|                                                                       |
| tāṉaṟintōruk kutavi taṉṉāl amiyumeṉil                                    |
| tāṉuvantu ītal taliyāmē - āṉataṉāl                                         |
| coṉṉāl puritaliṭi colliyum paṉṉāḷmaṟuttup                                |
| piṉṉāḷ purivatuvē piṉ.                                                 |
|                                                                       |
| 90. mūvakiyār taṉmikaḷ                                                   |
|                                                                       |
| uṟṟa maṟiyakattiṉ uykkumavaṉ uttamaṉē                                         |
| maṟṟam maṟipakarvōṉ mattimaṉē - muṟṟiḻiyē                                    |
| attam uṟalāl pukalvāṉ atamaṉeṉa                                             |
| vittaka nūlōtum virittu.                                                |
|                                                                       |
| 91. mūvakiyiṉar īkittaṉmi                                                |
|                                                                       |
| uttamartām īyumiṭattu ōṅkupaṉi pōlvarē                                     |
| mattimartām teṅkutaṉi māṉuvarē - muttalarum                                 |
| āmkamuku pōlvar atamar avarkaḷē                                             |
| tēmkataliyum pōlvār tērntu.                                             |
|                                                                       |
| 92. uyarntōr kimmāṟu karutār                                            |
|                                                                       |
| ellōr tamakkum iṉitutaval aṉṟiyē                                          |
| nallōr tamakkutavi nāṭārē - vallataru                                        |
| nāmaniti mēkam nayantutaval aṉṟiyē                                          |
| tāmutavi nāṭumō cāṟṟu.                                                 |
|                                                                       |
| 93. tīyōr col mikavum varuttam                                            |
|                                                                       |
| veyyōṉ kiraṇam mikaccuṭumē veyyavaṉiṉ                                      |
| ceyyōṉ kiraṇammikat tītāmē - veyyakatir                                     |
| ellōṉ kiraṇat teriyiṉilum eṇṇamilār                                      |
| collē mikavum cuṭum.                                                   |
|                                                                       |
| 94. iṉiya collē iṉpam payakkum                                            |
|                                                                       |
| tiṅkaḷ amirta kiraṇammikac cītaḷamē                                           |
| tiṅkaḷiṉum cantaṉamē cītaḷamām - iṅkivaṟṟiṉ                                   |
| aṉpaṟivu cāntam aruḷuṭiyār nalvacaṉam                                       |
| iṉpamikum cītaḷa māmē.                                                    |
|                                                                       |
| 95. nīṟṟiṉ perumi                                                      |
|                                                                       |
| cīrām veṇṇīṟṟut tiripuṇṭaram viṭuttē                                      |
| pērāṉa mutti peṟavirumpal - āramirta                                       |
| cañcīviyi viṭuttē cākā tiruppataṟku                                       |
| nañcē pucittatupōṉm nāṭu.                                               |
|                                                                       |
| 96. aṭiyārkaḷ tiyāṉattil āṇṭavarkaḷi etirpārppar                            |
|                                                                       |
| centāmari yiravi cērutayam pārkkumē                                       |
| cantrō tayampārkkum taṇkumutam - kantamikum                                  |
| pūvalarap pārkkum poṟivaṇṭu araṉaṉpar                                        |
| tēvaravip pārppar tuintu.                                                |
|                                                                       |
| 97. mantiraṅkaḷ ainteḻuttukku ōppākā                                      |
|                                                                       |
| villam aṟukukkuovvā meṉmalarkaḷ nālvareṉum                                 |
| nallaṉpar coṟkovvā nāṉmaṟikaḷ - mellinallāy                                 |
| āmantiram eviyum ainteḻutti ovvāvē                                       |
| cōmacunta raṟkueṉṟē col.                                                 |
|                                                                       |
| 98. kaṟṟavarkku nikarilli                                                 |
|                                                                       |
| kallār palarkūṭik kātalittu vāḻiṉumnūl                                    |
| vallāṉ oruvaṉiyē māṉuvarō - alārum                                       |
| eṇṇilā vāṉmīṉ ilakiṭiṉum vāṉakattōr                                       |
| veṇṇilā ākumō viḷampu.                                                 |
|                                                                       |
| 99. cērnta iṭattiṉ payaṉ                                                  |
|                                                                       |
| cantaṉattic cērtaruvum takkamaṇam kamaḻum                                       |
| cantaṉattic cārvēy taḻalpaṟṟa - antavaṉam                                       |
| tāṉumac cantaṉamum taṉṉiṉamum māḷvataṉṟit                                     |
| tāṉum keṭaccuṭumō tāṉ.                                                 |
|                                                                       |
| 100. periyōric cēriṉ tuṉpam nīṅkum                                      |
|                                                                       |
| kaṅkinati pāvam cacitāpam kaṟpakantāṉ                                         |
| maṅka luṟumvaṟumi māṟṟumē - tuṅkamikum                                    |
| ikkuṇamōr mūṉṟum periyō riṭamcēril                                      |
| akkaṇamē pōmeṉṟu aṟi.                                                   |
