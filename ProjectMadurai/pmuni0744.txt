          oḷavaiyār ceytaruḷiya kuṟaḷ (ñāṉakkuṟaḷ)
     mūlamum vaṭivēlu mutaliyār eḻutiya vicēṣa viruttiyuraiyum
       1. vīṭṭu neṟippāl -- piṟappiṉ nilamai
       1. ātiyāy niṉṟa vaṟivu mutaleḻut
       tōtiya nūliṉ payaṉ.
       (patavurai) ātiyāy - (intac carīrattiṟku) mutaṉmaiyāy, niṉṟa =
       irunta, aṟuvu = aṟivāṉatu, (eṉakku itaic colla iṭaṅkoṭuttatu) mutal
       eḻuttu = ātiyaṭcaramākiya (piraṇavattai) ōtiya (mutalilē)
       uccarikkiṉṟa, nūliṉ vētattiṉ payaṉ = pirayōcaṉamākum. (e-ṟu.)
       (karutturai.) nāṉku vētaṅkaḷai mutalākakkoṇṭu innūlai collukiṉṟēṉ
       eṉpatu karuttu.
       (vicēṣaurai.) intac carīrattukku aṟivu ātiyāyuḷḷa teṉpatu aṟiveṉṟu
       collappaṭum āṉmā taṉṉuṭaiya viṉaiyiṉaḷavukkut takavēṟōr
       carīra-meṭuppataṟkuk kāraṇamākap peṟappaṭutaliṉ, 'ātiyāy
       niṉṟavaṟivu' eṉavum, vētam ārampattil uccarippatu piraṇavamē eṉṟum,
       anta vētattaiyē ātāramākak koṇṭu collappaṭṭatu innūleṉṟuñ colluvār,
       'mutaleḻuttōtiya nūliṉ payaṉ' eṉavuṅ kūṟiṉār.
       aṟivē āṉmāveṉṟatai ;

   ''ōcaiyaic ceviyālōrntu muruviṉaik kaṇṇāluṟṟu
       nāciyāṟ kantaṅkoṇṭu nāviṉā liratan tuyttum
       pūciyatōliṉālē pulappaṭap paricamuṟṟum
       ācaṟavuṭaliniṟku maṟivukāṇāṉ māttāṉē "

   eṉpatiṉālaṟika.
   ------
   2. paramāya cattiyuṭ pañcamāpūtan
   taramāṟiṟ ṟōṉṟum piṟappu.
   (patavurai) param = paramporuḷiṭattil, āya = uṇṭāṉa, cattiyuḷ =
   parācatti-yilaṭaṅkiya, pañcamāpūtam = aintu periya pūtaṅkaḷum,
   tarammāṟil = taṅkaḷil oṉṟuṭaṉoṉṟu māṟiṉāl, piṟappu jeṉmamāṉatu, tōṉṟum
   = uṇṭākum. (e-ṟu.)
   (karutturai) pañcapūtaṅkaḷiṉ pariṇāmamē tēkam eṉpatu karuttu.
   paramāyacattiyuḷ eṉṟataṟku parattilirukkum māyācattiyuḷ eṉṟu
   koḷḷalumām.
   pañcapūta pariṇāmamētēka meṉpār, 'pañcamāpūtantara māṟiṟṟōṉṟum piṟappu'
   eṉavum, atu parācattiyiṉikaḻva teṉpār, 'paramāyacattiyuḷ'
   eṉavuṅkūṟiṉār.
   --------
   3. ōcai parica muruvañ cuvai nāṟṟa
   mācai paṭuttu maḷaṟu.
   (patavurai) ōcai = cattamum, paricam = paricamum, uruvam = rūpamum,
   cuvai = racamum, nāṟṟam = kantamum, (ākiya pañcataṉ māttiraikaḷum)
   ācaippaṭuttum = ācaiyai uṇṭākkukiṉṟa, aḷaṟu - cēṟākum. (e-ṟu.)
   (karutturai.) taṉmāttiraikaḷ aintum ācaiyai uṇṭākki āṉmāvaik
   keṭuppavaikaḷākum eṉpatu karuttu.
   (vicēṣavurai.) pautātikākaṅkārattil tōṉṟuvatuṭaṉ tamō kuṇattiṉaiyu
   muṭaiyavaikaḷākaiyāl pañca taṉmāttiraikaḷai 'ācaippaṭuttu maḷaṟu' eṉṟu
   kūṟiṉār. (3)
   -------
   4. tarumam poruḷkāmam vīṭeṉu nāṉku
   muruvattā lāya payaṉ.
   (patavurai) tarumam = tarumam, poruḷ - poruḷ, kāmam = ācai, vīṭu -
   mōṭcam, eṉṉum - eṉṟu collappaṭum, nāṉkum - puruṣārttaṅkaḷ nāṉkum,
   uruvattāl = carīrattāl, āya = uṇṭāṉa, payaṉ = pirayōjaṉamām. (e-ṟu.)
   (karutturai.) puruṣārttaṅkaḷ nāṉkum carīrattiṉ pirayōcaṉam eṉpatu
   karuttu.
   (vicēṣavurai.) puruṣārttaṅkaḷ māṉiṭar piṟavikkē mukkiyamākac
   collap-paṭṭiruttaliṉ, avai nāṉkum uruvattālāya payaṉ, eṉakkūṟiṉār.
   tarumam eṉpatu, muppattiraṇṭu tarumaṅkaḷai aṉṟi, piramacāri,
   vāṉappirastaṉ, canniyāci ivarkaḷ mūvarkkum illaṟatti liruppōṉ
   ceyyavēṇṭiya tarumam eṉiṉumām.
   itaṉai,
   ''ilvāḻvā ṉeṉpā ṉiyalpuṭaiya mūvarkkum
       nallāṟṟi ṉiṉṟa tuṇai.''

   eṉpatiṉālaṟika.
   poruḷ eṉṟatu - celvapporuḷiṉai. atu illai yāyiṉ tarumam nikaḻātākaliṉ,
   atuvum nalvaḻiyil tēṭiyatāyiruttal vēṇṭum. itaṉai,
   ''poruḷilārk kivvulakamillai.'' eṉpatiṉālaṟika.
   kāmam eṉpatu=ācai. vīṭu eṉpatu = immūṉṟu tarumaṅkaḷaiyum viṭṭu viṭutal
   itaṉai;
   ''ītalaṟan tīviṉaiviṭ ṭīṭṭal poru ḷeññāṉṟuṅ
       kātaliruvar karuttorumit - tātaravu
       paṭṭatē yiṉpam paraṉai niṉain timmūṉṟum
       viṭṭatē pēriṉpa vīṭu."

   eṉpatiṉālaṟika.
   ---------------
   5. nilamaintu nīrnāṉku nīṭaṅki mūṉṟē
   yulavaiyiraṇ ṭoṉṟu viṇ.
   (patavurai) nilam - pirutiviyāṉatu, aintu = aintāvatākavum, nīr =
   appūtamāṉatu, nāṉku = nālāvatākavum, nīṭu - nīṇṭa, aṅki tēyupūtamāṉatu,
   mūṉṟu = mūṉṟāvatākavum, ulavai = vāya pūtamāṉatu, iraṇṭu =
   iraṇṭāvatākavum, viṇ = ākāyapūtamāṉatu, oṉṟu - mutalākavum ākum. (e-ṟu)
   (karutturai) pañcapūtaṅkaḷum eṇṇalaḷavaiyāl ik kaṇakkukaḷai yamaiyum
   eṉpatu karuttu.
   (vicēṣavurai.) pirutivi, appu, tēyu, vāyu, ākāyam, eṉṉum
   pañcapūtaṅkaḷum varicaikkiramaṅkaḷāl mēṟcoṉṉa eṇkaḷaiyuṭaiyaṉaveṉpār
   iṅṅaṉaṅ kūṟiṉār.
   -----------
   6. māyaṉ pirama ṉuruttiraṉ makēcaṉō
   ṭāyuñ civamūrtti yaintu.
   (patavurai.) māyaṉ - viṣṇuvum, piramaṉ - piramaṉum, uruttiraṉ =
   ruttiraṉum, makēcaṉ = makēcaṉum, āyum - vētattilārāyum, civamūrtti =
   catācivaṉumāka, aintu = pañcamūrttaṅkaḷām. (e-ṟu.)
   (karutturai.) mūrttikaḷ aivar āvārkaḷ eṉpatu karuttu
   --------
   7. mālaya ṉaṅki yiravi matiyumaiyō
   ṭēlun tikaḻcatti yāṟu.
   (patavurai.) elum = poruntiya, tikaḻ - viḷaṅkukiṉṟa, catti = cattikaḷ,
   māl - viṣṇu, ayaṉ = piramaṉ, aṅki = akkiṉiyum, iravi = cūriyaṉum, mati=
   cantiraṉum, umai = umātēviyum, (āka) āṟu = aṟuvāram. (e-ṟu.)
   (karutturai) cattikaḷ aṟuvarkaḷām eṉpatu karuttu. (7)
   ---------
   8. tokkutirat tōṭūṉ mūḷai niṇameṉpu
   cukkilan tātuka ḷēḻu.
   (patavurai.) tokku = carīram, utiram -irattam, ūṇ = māmicam, mūḷai =
   mūḷai, niṇam = niṇam, eṉpu = elumpu, cukkilam = cukkilam (āka) tātukaḷ
   ēḻu ēḻutā tukaḷākum.
   (karutturai.) eḻutātukaḷākum eṉpatu karuttu. (8)
   ----------
   9. maṇṇoṭu nīraṅki matiyoṭu kāṟṟiravi
   viṇṇecca mūrttiyō ṭeṭṭu.
   (patavurai) maṇ = pirutivi, nīr = appu, aṅki = tēyu, mati = cantiraṉ,
   kāṟṟu - vāyu, iravi = cūriyaṉ, viṇ = ākāyam, eccamūrtti - yākatēvatai,
   (āka) eṭṭu = eṭṭu mūrttaṅkaḷāvār.
   (karutturai) eṇvakaiyāṉa mūrttaṅkaḷāvārkaḷ eṉpatu karuttu.
   aṣṭamūrttaṅkaḷāvaṉa;
   "nilanīrneruppuyirnīḷ vicumpunilāppakalōṉ
       pulaṉāyamaintaṉō ṭeṇvakaiyāyp puṇarntuniṉṟāṉ
       ulakēḻeṉatticaipat teṉattāṉoruvaṉumē
       palavākiniṉṟavātō ṇōkkamāṭāmō''

   eṉṟu srīman māṇikkavācakar kūṟiyatiṉālaṟika.
   ------------
   10. ivaiyellāṅkūṭi yuṭampāyavoṉṟi
   ṉavaiyellā māṉatu vintu.
   (patavurai.) ivaiyellām = mēlē collappaṭṭavai kaḷellām, kūṭi = cērntu,
   uṭampu āya = carīramāṉa, oṉṟiṉ = oru vastuvil, navai = kuṟṟaṅkaḷ, ellām
   - yāvum, āṉatu = uṇṭāṉatu, vintu - cukkilattālākum. (e-ṟu.)
   (karutturai.) pañcapūtaṅkaḷ, pañcataṉ māttiraikaḷ nāṉku puruṣārttaṅkaḷ
   ; pañcamūrttikaḷ, āṟucattikaḷ, eḻutātukkaḷ aṣṭamūrttaṅkaḷ ākiya
   ivaikaḷellāṅ kūṭi vintuviṉ kāraṇattāl carīramuṇṭāṉatu eṉpatu karuttu.
   (10)
   --------------
   2. uṭampiṉ payaṉ.
   11. uṭampiṉaip peṟṟa payaṉāva tellā
   muṭampiṉi luttamaṉaik kāṇ.
   (patavurai) uṭampiṉai = carīrattai, peṟṟa = aṭainta, payaṉ āvatu ellām
   = pirayōcaṉamāvatu, uṭampiṉil = carīrattiluḷḷa, uttamaṉai = kaṭavuḷai,
   kāṇ - taricippataṟkākum. (e-ṟu.)
   (karutturai.) carīrattiṉ payaṉ īsvaraṉaikkāṇutal eṉpatu karuttu.
   (vicēṣavurai.) carvēsvaraṉ jīvāṉmākkaḷiṭattil viyāpittirukka vēṇṭiyatu
   avaṉuṭaiya kaṭamaiyākaiyāl 'uṭampiṉi luttamaṉaik kāṇ' eṉṟār.
   --------
   12. uṇarvāva vellā muṭampiṉ payaṉē
   yuṇarka vuṇarvuṭai yār.
   (patavurai) uṇarvāva = uṇarcciyāvaṉa, ellām - yāvum, uṭampiṉ =
   tēkattiṉ, payaṉ = pirayōcaṉamākum, (atai) uṇarvu uṭaiyār = nalluṇarcci
   yuḷḷavarkaḷ, uṇarka - aṟintukoḷḷakkaṭavar. (e-ṟu.)
   (karutturai) āṉmākkaḷuk kuṇṭāyirukkiṉṟa uṇarcci carīraṅkaḷiṉ
   pirayōcaṉa-mēyām eṉpatu karuttu.
   carīraṅkaḷiṉ pirakirutikaḷukkut takunta uṇarcciyaiyē āṉmākkaḷ
   aṭaikiṉṟaṉa-veṉpār, 'uṇarvāvavellā muṭampiṉ payaṉē' eṉavum,
   ivviṣayattai uṇarcci yuṭai yavarkaḷē aṟintukoḷḷak kaṭavarkaḷeṉpār.
   'uṇarkavuṇar vuṭaiyār' eṉavuṅ kūṟiṉār.
   carīrattiṉ uṇarcciyē āṉmā aṭaiyumeṉṟatai;
   "mātāvuttarattil malamikil mantaṉām"
   eṉpatiṉālaṟika. (2)
   ------------
   13. orupayaṉāva tuṭampiṉ payaṉē
   tarupayaṉāñ caṅkaraṉaic cār.
   (patavurai.) oru = oppaṟṟa, payaṉāvatu = pirayōcaṉamāvatu, uṭampiṉ =
   carīrattiṉatu, payaṉē = pirayōcaṉamākum, (atāvatu) taru - koṭukkiṉṟa,
   payaṉām = pirayōcaṉamākiya, caṅkaraṉai = civaperumāṉai, cār =
   aṭaitalām. (e-ṟu.)
   (karutturai.) carīrattiṉ payaṉāvatu civaperumāṉaic cērtalākum eṉpatu
   karuttu.
   (vicēṣavurai.) orupayaṉ eṉṟatu vīṭṭaiyaṭaital. itaiyaṭaiyac caṅkaraṉaic
   cēravēṇṭumeṉpār, 'tarupayaṉāñ caṅkaraṉaiccār' eṉṟār. (3)
   ----------
   14. piṟappiṉāṟ peṟṟa payaṉāva vellān
   tuṟappatān tūneṟikkaṭ ceṉṟu.
   (patavurai) piṟappiṉāl - caṉmattiṉāl, peṟṟa - aṭainta, payaṉāva ellām -
   pirayōcaṉaṅkaḷellām, tūneṟik kaṇ ceṉṟu - uyarnta mārkkattiṟ pōy,
   tuṟappatu ām = carva iṉpaṅkaḷaiyum viṭṭoḻivatākum. (e-ṟu.)
   (karutturai.) intappiṟaviṉālākum payaṉāvatu carva iṉpaṅkaḷaiyun
   tuṟappatākum eṉpatu karuttu.
   (vicēṣavurai.) piṟavikaḷil māṉiṭappiṟavi vicēṭitta tākaliṉ,
   ippiṟavilēyē īsvaraṉai yaṭaiya vēṇṭu meṉpār. 'tuṟappatānta
   neṟikkaṭceṉṟu' eṉṟu kūṟiṉār. (4)
   ------------
   15. uṭampiṉā laṉṟi yuṇarvutā ṉillai
   yuṭampiṉā luṉṉiyatē yām.
   (patavurai.) uṭampiṉāl = carīrattiṉāl, aṉṟi - allāmal, uṇarvutāṉ =
   uṇarcciyāṉatu, illai = uṇṭāvatillai, (ākaiyāl avvuṇarcci) uṭampiṉāl -
   carīrattiṉāl, uṉṉiyatē ām - niṉaikkappaṭṭatē yākum. (e-ṟu.)
   (karutturai.) uṭampiṉāl uṇarcciyuṇṭāvatē yaṉṟi vēṟetiṉālu maṉṟu eṉpatu
   karuttu.
   (vicēṣavurai) uṇarcciyāṉatu uṭampiṉāluṉṉappaṭṭatēyeṉpār.
   'uṭampiṉāluṉṉiyatēyām' eṉakkūṟiṉār.
   ------------
   16. mācaṟṟa koḷkai maṉatti laṭaintakkāl
   īcaṉaik kāṭṭu muṭampu.
   (patavurai) mācu aṟṟa = kuṟṟam nīṅkiya, koḷkai = kuṇamāṉatu, maṉattil -
   maṉattil, aṭaintakkāl = uṇṭāṉāl, uṭampu - carīramāṉatu, īcaṉai -
   carvēsvaraṉai, kāṭṭum = uṇarvikkum. (e-ṟu.)
   (karutturai) uṭampāṉatu maṉattiluḷḷa mācaṟṟavuṭaṉ kaṭavuḷai uṇarvikkum
   eṉpatu karuttu.
   (vicēṣavurai.) carīram māyā campantappaṭṭiruppatākaiyāl atiṉuḷḷaṭaṅkiya
   maṉamāṉatu cīkkirattil cuttamaṭaiyā teṉpatai nōkki 'mācaṟṟa koḷkai
   maṉattilaṭaintak kāl' eṉavum, aṅṅaṉañ cuttamaṭaintāl antac carīrattāl
   carvēsvaraṉaik kāṇalāku meṉpār, 'īcaṉaik kāṭṭum uṭampu ' eṉavuṅ
   kūṟiṉār.
   -------
   17. ōcai yuṇarvuka ḷellān taruvikku
   nēcattā lāya vuṭampu.
   (patavurai.) ōcai = cattam mutaliya, uṇarvukaḷ ellām - uṇarccikaḷai
   yellām, nēcattāl - srīpuruṭarkaḷatu viruppattāl, āya = uṇṭāṉa, uṭampu =
   carīramāṉatu, taruvikkum uṇṭākkum. (e-ṟu.)

   289. aṟupatoṭāṟu varuṭamitaṉai
   uṟutiyatāka vuṇar.
   (patavurai.) aṟupatoṭāṟuvaruṭam aṟupattāṟu varu ṣam varaikkum, itaṉai =
   itai, uṟutiyatākavuṇar =uṟuti yāka ārāyvāy. (e - ṟu.)
   (karutturai.) ivviṣayaṅkaḷai yellām aṟupattāṟu varuṣam varaikkum ārāya
   vēṇṭum eṉpatu karuttu. (9)
   ---------
   290 aṭṭamācittiyaṭaiyumō rāṇṭiṉil
   iṭṭa mitaṉait teḷi.
   (patavurai.) aṭṭamācitti = aṣṭamācittikaḷum, aṭai yum = uṇṭākum,
   (ākaiyāl) ōrāṇṭiṉil oruvaruṣat til, iṭṭam = iṣṭamāka, itaṉaitteḷi =
   itai ārāyvā yāka. (e-ṟu.)
   (karutturai) itaṉāl aṣṭamā cittikaḷaiyu maṭaiya lām. ākaiyāl itaṉai
   ōrāṇṭu varaikkum ārāyavēṇṭum eṉpatu karuttu. (10)
   ------
   10. turiyataricaṉam.
   291. vaṉṉiyateṭṭu matiyampatiṉāṟu
   muṉṉiya paṉṉiraṇṭu muḷ.
   (patavurai) vaṉṉiyatu eṭṭu - cūriyaṉ eṭṭum, matiyam' patiṉāṟu -
   cantiraṉpatiṉāṟum, muṉṉiya = niṉaitta, paṉṉi raṇṭumuḷ = paṉṉiraṇṭu muḷ
   ḷaṭakka vēṇṭum. (e-ṟu.) (1)
   ---------
   292. cūriyaṉvaṉṉiyoṉ ṟākiṭiṟcōmaṉām
   pāru miṉītu payaṉ.
   (patavurai.) cūriyaṉ - cūriyaṉum, vaṉṉi - akkiṉiyum, oṉṟākiṭil oṉṟāṉāl,
   cōmaṉām = cantiraṉām, ītu payaṉ = intappayaṉai, pārumiṉ = nīṅkaḷ
   pāruṅkaḷ. (e-ṟu.) (2)
   293. matiyoṭu vaṉṉiyoṉ ṟākavē vantāl
   katirava ṉāmeṉṟu kāṇ.
   (patavurai) matiyōṭu - cantiraṉuṭaṉ, vaṉṉi - akkiṉi yum, oṉṟākavē
   vantāl = kalantu vantāl, katiravaṉām = cūriya ṉāvāṉ, eṉṟu = eṉṟu, kāṇ =
   kāṇpāyāka. (e - ṟu.) (3)
   ---------
   294. matikkuṭkatiravaṉ vantaṅkoṭuṅkil
   utikkumām pūraṇaic col.
   (patavurai) matikkuṭ katiravaṉ vantu - cantiraṉukkuḷḷē cūriyaṉum vantu,
   aṅku oṭuṅkil = avviṭattil oṭuṅkiṉāl, pūraṇaiccol - peḷarṇami eṉṉuñ
   collāṉatu, utikku mām = uṇṭākumām. (e-ṟu.)
   (karutturai) cantiraṉukkuḷḷē cūriyaṉ vantu oṭuṅkiṉāl paurṇamiyeṉṟu
   colluvārkaḷ eṉpatu karuttu. (4)
   ---------
   295. tōṟṟuṅkatirava ṉuṇmatipukkiṭil
   cāṟṟu mamāvācai tāṉ
   (patavurai) tōṟṟum = kāṇappaṭukiṉṟa, katiravaṉuḷ = cūriyaṉukkuḷ,
   matipukkiṭil = cantiraṉ oṭuṅkiṉāl, cāṟṟum = collappaṭukiṉṟa,
   amāvācaitāṉ = amāvācaiyākum. (e-ṟu.)
   (karutturai.) cūriyaṉukkuḷ cantiraṉ oṭuṅkiṉāl amāvā caiyākum eṉpatu
   karuttu.
   ---------
   296. vaṉṉikatiravaṉ kūṭiṭilattakai
   piṉṉivaiyāku melām.
   (patavurai) attakai vaṉṉi - appaṭippaṭṭa akkiṉi yum, katiravaṉ -
   cūriyaṉum, kūṭiṭil = cērntāl, piṉ = piṟa ku, ivaiyākum elām -
   ivaikaḷellāmākum. (e-ṟu.) (6)
   ---------
   297. amāvācai pūraṇai yākumavarkkuc
   camaṉā muyiruṭampu tāṉ.
   (patavurai) amāvācai = amāvācaiyē, pūraṇaiyākum avarkku = pauraṇaiyāka
   koḷḷupavarukku, uyir uṭampu tāṉ = uyirum uṭampum, camaṉām =
   camāṉamākum. (e-ṟu.) (7)
   ---------
   298. aṇṭattiluminta vāṟeṉ ṟaṟintiṭu
   piṇṭattilu matuvē pēcu.
   (patavurai) aṇṭattilum = veḷiyaṇṭattilum, inta vāṟeṉṟu - ivvitameṉṟu,
   aṟintiṭu = uṇarntiṭu, ap piṇṭattilum = uḷḷaṇṭattilum, atuvē pēcu =
   appaṭi yēyākumeṉṟu pēcu . (e - ṟu.)
   (karutturai) aṇṭattilum piṇṭattilum oṉṟeṉṟē yuṇaravēṇṭum eṉpatu
   karuttu.
   ---------
   299. ēṟumatiya miṟaṅkiṭi luṟaṅkilum
   kūṟumap pūraṇai koḷ
   (patavurai) ēṟum matiyam = ēṟukiṉṟa cantiraṉāṉavaṉ, iṟaṅkiṭil =
   iṟaṅkumāṉāl, uṟaṅkiṭum = uṟaṅkum, kūṟum = appoḻutu collappaṭukiṉṟa,
   appūraṇai = antappeḷar ṇamiyai, koḷ = koḷḷakkaṭavāy. (e-ṟu.)
   ---------
   300. utikku matiyamuṅ kaṇṭaṅ kuṟaṅkil
   matikku mamāvācai yām.
   (patavurai) utikkum matiyamum = utayamākiṉṟa cantiraṉai yum, kaṇṭu =
   tericittu, aṅku = avviṭattil, uṟaṅkiṉ = tūṅkiṉāl, matikkum
   niṉaikkappaṭukiṉṟa, amāvācaiyām amāvācaiyākum. (e-ṟu.) (10)
   -----------
   11. uyarñāṉa taricaṉam
   301. koṇṭiṭu maṇṭala mūṉṟaṅki taṉṉaiyip
   piṇṭa mu mūḻi piriyā.
   (patavurai.) koṇṭiṭu = yāvarāluṅ koḷḷap paṭu kiṉṟa, maṇṭalam mūṉṟu =
   mummaṇṭalaṅkaḷuḷ, aṅki taṉṉai = akkiṉi maṇṭalattai, ippiṇṭamum -
   intappiṉ ṭattilum, ūḻi piriyā = ūḻiyilum piriyamāṭṭā . (e-ṟu.)
   (karutturai.) mummaṇṭalaṅkaḷuḷ akkiṉi maṇṭalattai entakkālattilum
   piriyamāṭṭā eṉpatu karuttu. (1)
   ---------
   302. veḷḷi putaṉoṭu tiṅkaḷiṭameṉat
   taḷḷumiṉ kāla caram.
   (patavurai) kālacaram = kālattil naṭakkuñ carattai, veḷḷi putaṉoṭu
   tiṅkaḷ - veḷḷi putaṉ tiṅkaḷ immūṉṟu nāṭkaḷilum, iṭameṉattaḷḷumiṉ =
   iṭatu pakkattil taḷḷuṅkaḷ. (e-ṟu.)
   (karutturai) tiṅkaḷ, putaṉ, veḷḷi, ikkiḻamaikaḷil cantiranāṭiyil
   kālacarattaic celutta vēṇṭum eṉpatu karuttu.
   ---------
   303. cevvāy caṉinā yiṟuvala mākavē
   koḷḷiliv vāṟiṭaṟu mil
   (patavurai.) cevvāy caṉiñāyiṟu = cevvāy caṉi ñāyiṟu eṉṉuṅkiḻamaikaḷil,
   valamāka koḷḷiṉ - valatupak kamākat taḷḷiṉāl, ivvāṟiṭarumil
   ippaṭippaṭṭa tuṉpam oṉṟumillai . (e-ṟu.)
   (karutturai) cevvāy, caṉi, ñāyiṟu eṉṉum cūriya nāḷkaḷil, cūriya nāṭiyil
   carattait taḷḷavēṇṭum eṉpatu karuttu. (3)
   ---------
   304. vaḷarpoṉ ṉiṭampiṟait tēyvuvalamā
   vaḷarpiṟai yeṉṟē mati
   (patavurai .) vaḷar = vaḷarkiṉṟa, poṉ - viyāḻakkiḻamai kaḷil,
   piṟaittēyvu - tēypiṟaikaḷil, iṭam = iṭatu pakka mākavum, vaḷarpiṟai -
   vaḷarpiṟaiyil valamām = valatu pakka mākavum, cellum eṉṟēmati = cellum
   eṉṟē eṇṇu vāy. (e - ṟu.)
   (karutturai) viyāḻakkiḻamaikaḷil tēypiṟaiyil iṭatu pakkamākavum
   vaḷarpiṟaiyil valatu pakkamākavum carañ cellum eṉpatu karuttu.
   ---------
   305. valattiṟ caṉikkē yirāppakal vāyu
   celuttu pērātu ceyal.
   (patavurai) canikkē = canikkiḻamaikaḷil, irāppakal = irāttiriyum
   pakalum, vāyu = vāyuvai, valattil = valatu pak kattilē, pērātu =
   oḻiyātu, celuttu = celuttuvāy, ceyal = ituvē ataṉ ceykaikaḷām. (e-ṟu.)
   ---------
   306. iyaṅkum pakalvala mirāviṭam vāyu
   tayaṅkuṟal nāṭikkuṭ ṭāṉ.
   (patavurai.) vāyu = vāyuvāṉatu, tayaṅkuṟa = viḷaṅka, nāṭikkuṭṭāṉ =
   nāṭikkuḷ, pakalvalam =pakalil valamākavum, irāiṭam = iravil iṭamākavum,
   iyaṅkum naṭakkum. (e - ṟu)
   ---------
   307. aracaṟiyāma lavaṉpē ruṟaintut
   taraitaṉai yāṇṭa camaṉ.
   (patavurai) aracaṟiyāmal = aracaṉai aṟiyāmal, avaṉ pēr = avaṉuṭaiya
   pērai, uraittu = colli, taraitaṉai yāṇṭacamaṉ =pūmiyaiyāṇṭa camaṉākum.
   (e-ṟu.) (7)
   ---------
   308. kallāta mūṭar tiruvuruk koṇṭiṭac
   collāta teṉṉa ceyal.
   (patavurai.) kallāta mūṭar = kaṟkātamūṭarkaḷ, tiruvuruk koṇṭiṭa =
   tiruvuruvattaiyaṭaiya, eṉṉaceyal cellā tatu = eṉṉa kāriyam naṭavātatu.
   (e - ṟu .)
   (karutturai.) yāvarāyiṉum tiruvurukkoṇṭāl el lākkāriyaṅkaḷum kai kūṭum
   eṉpatu karuttu. (8)
   ---------
   309. tiruvaruṭ pālait terintu teḷiyil
   kuruvirup pāmeṉṟu koḷ
   (patavurai) tiruvaruṭpālai - tiruvaruḷeṉṉum amir tattai, terintu =
   uṇarntu, teḷiyil = oḷivaṭaintāl, kuruviruppāmeṉṟu koḷ =
   ñāṉāciriyaṉuṭaiya iruppiṭa māmeṉṟu koḷḷuvāy, (e - ṟu.)
   (karutturai) tiruvaruṭpālai uṇarntavarkaḷ kuruviṉ piṭamāvārkaḷ eṉpatu
   karuttu.
   ---------
   310. kaṟkiluṅ kēṭkilum ñāṉak karuttuṟa
   niṟkiṟ paramavai vīṭu.
   (patavurai.) kaṟkilum = ellāc cāstiraṅkaḷaik kaṟṟā lum, kēṭkilum =
   kēṭṭālum, ñāṉakkaruttuṟai = ñāṉa mākiya vāṉavaḻiyil, niṟkil iruntāl,
   paramavaivīṭu = param poruḷ eḻuntaruḷiyirukkiṉṟa vīṭukai kūṭum. (e-ṟu.)
   (karutturai.) cakalacāstiraṅkaḷaiyum uḷḷaṅkai nel likkaṉi pōl kaṟṟālum
   kēṭṭālum mōṭcavīṭu kai kūṭum eṉpatu karuttu. (10)
