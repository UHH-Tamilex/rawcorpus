maṉitaṉ



pallakkil iruppavaṉ maṉitaṉ, pallakkut tūkkupavaṉum maṉitaṉ tāṉ. -cīṉā



ulakam eṉṟa cāṇaiyil maṉitaṉ oru katti. -ārmīṉiyā



ulakam eṉṟa pāṉaiyil maṉitaṉ oru karaṇṭi. -( ,, )



oru maṉitaṉ vāḻntāṉ eṉpataṟku, avaṉ oru vīṭāvatu kaṭṭiyirukka vēṇṭum, oru makaṉaiyāvatu peṟṟirukka vēṇṭum, allatu oru nūlāvatu eḻutiyirukkavēṇṭum. - itāli



maṉitaṉ kāṟṟaṭaitta oru tōṟpai. -lattīṉ



nī kaṭaluṭaṉ pōṭṭiyiṭṭukkoṇṭirukkum ōr āṟu. -( ,, )

maṉitaṉ naṭamāṭum piṇam. - raṣyā



oruvaṉ pūraṇa maṉitaṉāka viḷaṅka vēṇṭumāṉāl, avaṉ potup paḷḷiyil mūṉṟu āṇṭukaḷum, palkalaik kaḻakattil ōrāṇṭum, ciṟaiyil iraṇṭāṇṭukaḷum kaḻittirukka vēṇṭum. -( ,, )



ovvoru maṉitaṉum potumakkaḷē. -speyiṉ



melintavaṉai arai āḷ eṉṟum, paruttavaṉai iraṇṭu āḷ eṉṟum kaṇakkiṭuvatillai. -āppirikā





maṉitaṉ tāṉē taṉakkuc cayittāṉ. -intiyā



malai iṭam peyarntu viṭṭatu eṉṟu nī kēḷvippaṭṭāl nampalām; āṉāl oru maṉitaṉ kuṇam tiruntiviṭṭāṉ eṉṟu kēṭṭāl, atai nampa vēṇṭām. - arēpiyā

maṉitaṉum vilaṅkukaḷum oṉṟupōlattāṉ irukkiṟārkaḷ. -( ,, )



mēlāṉa maṉitaṉ tēṭuvatu avaṉuḷḷēyē irukkiṉṟatu; cātāraṇa maṉitaṉ tēṭuvatu maṟṟavarkaḷiṭam irukkiṟatu. -kaṉḵpūṣiyas



maṉitaṉaip pōla naṭantu koḷpavaṉē maṉitaṉ.

-hālantu

veṭkam maṉitaṉai viṭṭu vilaki niṉṟāl, avaṉ vilaṅkāvāṉ. -cuviṉparṉ

teyvap paṭaippil maṉitaṉē talaiciṟantavaṉ.

-iṅkilāntu

maṉitaṉ iyaṟkaiyil ōr aṟputam. -iṅkilāntu



maṉitaṉukku mutaṉmaiyāṉa pakaivaṉ maṉitaṉē. -( ,, )



cirikkum mirukam maṉitaṉ oruvaṉ tāṉ. -( ,, )



veṭkappaṭum vilaṅku maṉitaṉ oruvaṉē. - mārkṭveyiṉ



maṉitarkaḷukku maṉam paḷiṅku, peṇkaḷukku maṉam meḻuku. -ṣēkspiyar



irakkamaṟṟa taṉmaiyaik kāṭṭilum maṉitaṉukku iḻivāṉatu etuvumillai. -speṉsar



puttakaṅkaḷaip paṭippataik kāṭṭilum, maṉitarkaḷaip paṭikka vēṇṭiyatu avaciyam. -ḵpirāṉs



maṉitaṉ taṉakkuḷ oru koṭiya vilaṅkai vaittirukkiṟāṉ. -jermaṉi



mirukattaiyum atimāṉiṭaṉaiyum piṇaittuk kaṭṭum kayiṟu maṉitaṉ. -nīṭṣē





[maṉitaṉē taṉṉilum mēmpaṭṭa atimāṉiṭaṉākap pariṇamikka muṭiyum eṉṟa koḷkaiyuṭaiyavar nīṭṣē, eṉṟa tattuvañāṉi.]

maṉitaṉukku maṉitaṉ kaṭavuḷ. - kirīs



perumpālāṉa maṉitar tīyavar. -( ,, )



maṉitaṉ pakuttaṟivuḷḷa vilaṅku. -lattīṉ



maṉitaṉ taṉakku evvaḷavu vēṇṭiyavaṉō ataiviṭa atikamākat tēvarkaḷukku vēṇṭiyavaṉ. -( ,, )



maṉitaṉukku maṉitaṉ ōnāyāka irukkiṟāṉ. -( ,, )

vāḻkkai

cila camayam mūḻkutal, cila camayam mēleḻutal: itu tāṉ vāḻkkai. -( ,, )



vāḻkkai kāṟṟiṉ naṭuviluḷḷa oru tīpam. -jappāṉ



vāḻkkai eṉpatu aṉpum maṉaiviyum. -( ,, )



uṇavukkākavum uṭaikkākavumē nām iraṇṭu kālkaḷālum ōṭit tirikiṟōm. -cīṉā



uṉ vāḻkkaiyil ovvoru nāḷum uṉ carittirattil ōr ēṭākum. -arēpiyā

nī kālaiyaik kaṇṭirukkiṟāy, iṉṉum mālaiyaik kāṇa villai . -yūtar

vāḻkkai eṉpatu iṭaiviṭāta kuṭiveṟi-makiḻcci maṟainta piṉpum, talaivali iruntukoṇṭēyirukkum. -pāracīkam



mūccu varuvatum pōvatum toṭṭiliṉ āṭṭam; muṭivāṉa tūkkam varumuṉ eccarikkaiyāyiru. -( ,, )

vāḻkkai oru veṅkāyam, atai urikkumpoḻutu kaṇṇīr varum. - ḵpirāṉs



vāḻkkai eṉṉaveṉṟu nām terintu koḷḷumuṉ, pāti vāḻkkai kaḻintu viṭukiṉṟatu. -( ,, )



vāḻkkaiyiṉ muṟpakuti iraṇṭām pakutiyai virumpuvatil kaḻikiṉṟatu; iraṇṭām pakuti mutaṟ pakutikkāka varuntuvatil kaḻikiṉṟatu. -ḵpirāṉs



nām varukiṟōm, aḻukiṟōm, itu tāṉ vāḻkkai ; nām aḻukiṟōm, pōkiṟōm, itu tāṉ maraṇam. -( ,, )



nēṟṟu, iṉṟu, nāḷai ākiya mūṉṟu nāṭkaḷē maṉitaṉiṉ nāṭkaḷ. -( ,, )



maraṇattaip paṟṟic cintippavaṉ vāḻat toṭaṅkukiṟāṉ . -jermaṉi

paṉṉiraṇṭu vayatil kuḻantaip paruvattaip putaikkiṟōm; patiṉeṭṭil vālipap paruvattaiyum, irupatil mutaṟ kātalaiyum, muppatil maṉitariṭam koṇṭa nampikkaiyaiyum, aṟupatiliruntu ciṟitu ciṟitāka aimpulaṉkaḷaiyum putaittu viṭukiṟōm. -( ,, )



ovvoru maṇiyum (nēramum) nammaik kāyappaṭuttik koṇṭēyirukkiṉṟatu, kaṭaici maṇi aṭittavuṭaṉ āvi pirikiṉṟatu. -( ,, )

nāṉ piṟakkumpoḻutē aḻutēṉ ; ēṉ aḻutēṉ eṉpatai ovvoru nāḷum uṇarkiṟēṉ. -( ,, )



vāḻvum tuyaramum oṉṟākat tōṉṟiyavai. -( ,, )

inta miṉṉūlaip paṟṟi


uṅkaḷukku immiṉṉūl, iṇaiya nūlakamāṉa, vikkimūlattil iruntu kiṭaittuḷḷatu[1].

inta iṇaiya nūlakam taṉṉārvalarkaḷāl vaḷarukiṟatu. vikkimūlam patiya taṉṉārvalarkaḷai varavēṟkiṟatu. tāṅkaḷum vikkimūlattil iṇaintu mēlum pala miṉṉūlkaḷai aṉaivarum paṭikkumāṟu ceyyalām.

mikunta akkaṟaiyuṭaṉ meyppu ceytālum, miṉṉūlil piḻai ētēṉum iruntāl tayakkam illāmal, vikkimūlattil immiṉṉūliṉ pēccu pakkattil terivikkalām allatu piḻaikaḷai nīṅkaḷē kūṭa cari ceyyalām.
